# Changelog

What each release brings, with live demos of what is new, and what to change when you upgrade.

[このページを編集](https://github.com/ZiZIGY/vue-dnd-kit/edit/master/docs/content/en/5.changelog/0.index.md)

Every release has a page here: what is new, with the demos that show it; what to change when you upgrade; and every change. The same notes go to its [**GitHub release**](https://github.com/ZiZIGY/vue-dnd-kit/releases), and each package keeps its list of commits in its `**CHANGELOG.md**`.

```
npm i @vue-dnd-kit/core
```

v3 follows semantic versioning: a minor or patch release changes no API you use, and what changes is said on its page. Coming from v2, see [**migrating from v2**](https://zizigy.github.io/vue-dnd-kit/ja/docs/getting-started/migrating-from-v2).

## Releases

[3.1.0](https://zizigy.github.io/vue-dnd-kit/ja/docs/changelog/v3-1-0)

**3.1.0**

Drags in other windows of the app: a popup, a detached panel, a Picture-in-Picture window, under the same provider.

[3.0.0](https://zizigy.github.io/vue-dnd-kit/ja/docs/changelog/v3-0-0)

**3.0.0**

v3 is stable: drag and drop, sortable lists and trees, multi-drag, files from other apps, the keyboard and screen readers, in one package.

[3.0.0-beta.2](https://zizigy.github.io/vue-dnd-kit/ja/docs/changelog/v3-0-0-beta-2)

**3.0.0-beta.2**

Files and other apps, drop targets that shape the overlay, drags that don't wait for landings, an overlay that lifts and settles, filtered lists.

[3.0.0-beta.1](https://zizigy.github.io/vue-dnd-kit/ja/docs/changelog/v3-0-0-beta-1)

**3.0.0-beta.1**

The first beta of v3: one package, sortable lists and trees, multi-drag, the keyboard and screen readers.
