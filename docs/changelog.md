> Index of every page on this site: [llms.txt](https://zizigy.github.io/vue-dnd-kit/llms.txt)

Every release has a page here: what is new, with the demos that show it; what to change when
you upgrade; and every change. The same notes go to its
[GitHub release](https://github.com/ZiZIGY/vue-dnd-kit/releases), and each package keeps its
list of commits in its `CHANGELOG.md`.

v3 is in beta, under the npm tag `next`:

```bash
npm i @vue-dnd-kit/core@next
```

Until the release candidate, an API may still change from one beta to the next: the page of
each release says what to change. Coming from v2, see [migrating from v2](https://zizigy.github.io/docs/getting-started/migrating-from-v2).
