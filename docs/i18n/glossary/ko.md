# 용어집: 한국어 (ko)

문체: **합니다체**(격식체)로 통일합니다. 안내와 지시는 "~하세요", 설명은 "~합니다". 해요체와 섞지
않습니다. 독자를 따로 부르지 않고, 꼭 필요할 때만 "직접", "여러분의"를 씁니다(예: "your array" →
"여러분의 배열" 대신 가능하면 "원본 배열", "직접 만든").

코드, API·옵션·이벤트·파일·패키지 이름은 영어 그대로 `code`로 둡니다. 영어 단어 뒤 조사는 발음
기준으로 붙입니다(`onDrop`은, `items`를, overlay → 오버레이는).
