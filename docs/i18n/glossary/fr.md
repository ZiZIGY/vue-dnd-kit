# Glossaire français

Le lecteur est vouvoyé (« vous »). Les instructions sont à l'impératif (« Passez », « Rendez »).
Phrases courtes et directes, comme l'anglais. Typographie française : espace insécable avant
`:` `;` `?` `!`, guillemets « » avec espaces insécables. Pas de deux-points suivis d'une espace
dans les valeurs YAML du frontmatter (ou alors entre guillemets).

Tout le code reste tel quel : noms d'API, d'options, d'événements, de fichiers, de paquets.
