# Glossar: Deutsch (de)

## Ton

- Die Leserin, der Leser wird geduzt: „du“, klein geschrieben, wie in den deutschen Docs von
  React oder Astro. Anleitungen im Imperativ: „Umschließe“, „Übergib“, „Rendere“.
- Kurze, direkte Sätze wie im Englischen. Nichts hinzufügen, nichts weglassen.
- Anführungszeichen „…“, Gedankenstrich „ – “ (Halbgeviertstrich mit Leerzeichen).
- Englische Fachwörter als Komposita mit Bindestrich: „Drop-Ziel“, „Drag-Handle“,
  „Template-Ref“.
- Code, Namen von APIs, Optionen, Events, Dateien und Paketen bleiben wie im Original, in `code`.

## Bleibt Englisch

- Beschriftungen aus den Live-Beispielen und der DevTools-Oberfläche (**Done**, **Images**,
  **Options**, **Pick**, **Drop**, **Cancel**), weil sie dort englisch angezeigt werden.
- Die eingebauten Screenreader-Texte („Picked up item t2 …“): Die Bibliothek spricht sie englisch.
