Use `makeDraggable` e `makeDroppable` para tudo o que não é uma lista ordenável: arquivos em
pastas, uma lixeira, um tabuleiro de xadrez, um calendário, notas em um quadro.

::example{name="drop-zones" hint="Imagens vão para Images, documentos para Documents" height="30rem"}
::

## Um draggable {#a-draggable}

```vue [FileCard.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeDraggable } from '@vue-dnd-kit/core';

const props = defineProps<{ file: { id: string; name: string; kind: 'image' | 'doc' } }>();
const el = useTemplateRef<HTMLElement>('el');

const { isDragging } = makeDraggable(el, {
  id: () => props.file.id,      // read back as `active.id`
  data: () => props.file,       // anything: `active.data`
  type: () => props.file.kind,  // matched by the targets' `accept`
});
</script>

<template>
  <div ref="el" :class="{ dragging: isDragging }">{{ file.name }}</div>
</template>
```

Passe o id a partir dos seus dados, como um getter. O id padrão vem do `useId()` e é novo a cada
instância do componente, então não significa nada para o resto do seu app.

| Retorno | O que é |
| --- | --- |
| `isDragging` | Este elemento está sendo arrastado. |
| `selected` | Gravável, ligado à [seleção](/docs/guides/multi-drag) do provider. |
| `transform` | O deslocamento do arraste, para `overlay: false` (abaixo). |
| `id` | O id em uso. |

Botões, inputs e outros filhos interativos não iniciam um arraste por ponteiro, então continuam
funcionando dentro de um draggable. Para arrastar só por uma parte, passe um `handle` (veja
[listas ordenáveis](/docs/guides/sortable-lists#handles)). Todas as opções estão na
[API do makeDraggable](/docs/api/make-draggable).

## Um alvo de drop {#a-drop-target}

```vue [Folder.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeDroppable } from '@vue-dnd-kit/core';

const props = defineProps<{ id: string; accept: string }>();
const emit = defineEmits<{ drop: [fileId: string | number] }>();
const el = useTemplateRef<HTMLElement>('el');

const { isOver, isAccepting } = makeDroppable(el, {
  id: props.id,
  accept: props.accept,
  onDrop: (event) => emit('drop', event.active.id),
});
</script>

<template>
  <section ref="el" :class="{ accepting: isAccepting, over: isOver && isAccepting, refused: isOver && !isAccepting }">
    <slot />
  </section>
</template>
```

| Retorno | `true` quando |
| --- | --- |
| `isOver` | O arraste está sobre este alvo, quer ele aceite o arraste ou não. |
| `isAccepting` | Algo está sendo arrastado e este alvo o aceita: destaque as zonas válidas. |
| `placement` | Não é um booleano: `{ top, right, bottom, left }`, as metades do alvo em que o ponteiro está, ou `null` quando ele não está sob o ponteiro. Use para "antes / depois deste card". |

`isOver` sem `isAccepting` significa que o arraste está sobre um alvo que o recusa. Mostre isso,
como as pastas acima fazem: um drop ali é cancelado e o item volta ao lugar.

## Quais arrastes um alvo aceita {#which-drags-a-target-takes}

O `type` de um draggable é comparado com o `accept` de um alvo:

| `accept` | Aceita |
| --- | --- |
| omitido ou `'*'` | Tudo. |
| `'image'` | Draggables do tipo `image`, e os sem tipo. |
| `['image', 'doc']` | Qualquer um dos dois tipos, e os sem tipo. |
| `({ active, items, types }) => boolean` | O que a sua função disser. |

Um draggable sem `type` passa em qualquer regra de string. Use uma função para todo o resto:

```ts
makeDroppable(el, {
  accept: ({ items }) => items.every((item) => (item.data as File).size < 10_000_000),
});
```

`type` também pode ser um array (`['image', 'large']`): basta um tipo coincidir.

Quando vários itens são arrastados de uma vez, `acceptMode` diz quantos precisam passar: `'all'`
(padrão) ou `'some'`. Com `'some'`, retorne do `onBeforeDrop` os ids a manter, e os outros
voltam ao lugar. Veja [decisões de drop](/docs/guides/drop-decisions).

## O drop {#the-drop}

O `onDrop` de um alvo de drop simples é onde **você** altera os seus dados. A biblioteca não move
nada por conta própria:

```ts
makeDroppable(el, {
  id: 'archive',
  onDrop: ({ active }) => {
    for (const id of active.ids) archive(id);   // every dragged id, the grabbed one first
  },
});
```

| Campo do evento | O que contém |
| --- | --- |
| `active` | O arraste: `id`, `ids`, `items` (cada um `{ id, data, type, item }`), `data`, `type`. |
| `over` | Este alvo: `id`, `data`, `element`, `rect`. |
| `pointer`, `delta` | Onde o ponteiro está, e quanto ele se moveu desde o início. |
| `position` | Onde a caixa arrastada fica dentro deste alvo (próxima seção). |
| `source` | Definido quando os itens vêm de uma lista ordenável: `{ list, remove() }`. |

A ordem é `onBeforeDrop` (decidir), `onDrop` (aplicar), depois o `drag-end` do provider.
Para perguntar antes de um drop, manter o arraste em andamento ou aceitar só alguns itens, veja
[decisões de drop](/docs/guides/drop-decisions).

## Deixar onde foi solto {#leave-it-where-it-was-dropped}

Um quadro, um canvas, uma planta baixa: o item fica onde você o solta. Todo evento traz
`position`, o `left` / `top` que colocam um item com posicionamento absoluto onde ele foi
solto.

::example{name="constraints" hint="Arraste uma nota, depois trave um eixo ou desligue a grade" height="26rem"}
::

```ts [Board.vue]
const board = useTemplateRef<HTMLElement>('board');
makeDroppable(board, { id: 'board' });

useDnDMonitor({
  onDragEnd({ active, over, position }) {
    const note = notes.value.find((item) => item.id === active.id);
    if (!note || over?.id !== 'board' || !position) return;
    note.x = Math.round(position.x);
    note.y = Math.round(position.y);
  },
});
```

```vue [Note.vue]
<div ref="el" class="note" :style="{ left: `${note.x}px`, top: `${note.y}px` }">…</div>
```

`position` é o canto superior esquerdo da caixa arrastada dentro de `over`: medido a partir da
borda do padding dele, com a rolagem dele somada. É `null` quando não há nada embaixo. Com
`overlay: false`, é o canto do próprio elemento.

::tip
Não calcule o ponto a partir de `active.rect` e `delta`: isso ignora a borda e a rolagem do
alvo. Encaixe, limites e travas de eixo para esses quadros estão em
[restrições](/docs/guides/constraints).
::

## Soltar dentro de um item ordenável {#drop-into-a-sortable-item}

Uma linha de uma lista ordenável também pode ser um alvo de drop: uma pasta que aceita arquivos,
um grupo que aceita tarefas. Coloque um droppable no elemento do item:

```ts [FolderRow.vue]
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { item: () => props.folder });

const { isOver } = makeDroppable(el, {
  accept: 'file',
  onDrop: (e) => {
    props.folder.children.push(...e.active.items.map((entry) => entry.item as FileEntry));
    e.source?.remove();   // take them out of the list they came from
  },
});
```

Nos momentos em que a lista ordenaria o arraste, um alvo assim só conta no **meio** do seu item
(de 25 a 75% ao longo do eixo da lista). Ali, o drop vai para dentro do item e a lista não se
mexe. Perto das bordas, a lista ordena normalmente.

- Um alvo cujo `accept` recusa o arraste é ignorado: a lista ordena sobre o item como sobre
  qualquer outro. Uma pasta que só aceita arquivos deixa as pastas passarem por ela.
- Um alvo nunca recebe o próprio arraste.
- Se o item não é mais exibido depois do drop, o overlay encolhe para dentro do alvo em vez de
  voltar ao lugar.

## Zonas de lixeira {#trash-zones}

Um arraste que começa em uma lista ordenável traz `e.source`. Chame `remove()` e a lista
descarta os itens:

```ts
makeDroppable(trash, {
  id: 'trash',
  onDrop: (e) => e.source?.remove(),
});
```

O próprio `onDrop` da lista então roda com `to.index === -1`, e `e.result` contém a lista sem
os itens. Uma lista também pode remover o que é solto fora de tudo: veja
[`dropOutside`](/docs/guides/shared-lists#dropping-outside).

## Sem overlay {#without-an-overlay}

Por padrão, um clone do elemento segue o ponteiro, e o elemento fica no lugar. Com
`overlay: false` não há clone: mova o elemento você mesmo com `transform`.

```vue
<script setup lang="ts">
const { transform } = makeDraggable(el, { id: 'piece', overlay: false });
</script>

<template>
  <div ref="el" :style="transform && { transform: `translate3d(${transform.x}px, ${transform.y}px, 0)` }">♞</div>
</template>
```

Para uma prévia de arraste personalizada em vez do clone, veja [o overlay](/docs/guides/overlay).

## Teclado {#keyboard}

Um draggable em foco é pego com :kbd{value="Space"} ou :kbd{value="Enter"}. As setas o movem
25 px (o `keyboard.step` do provider). Com `keyboard: 'droppables'` no draggable, elas saltam
entre os alvos que o aceitam, o que serve para zonas distantes entre si. Mais em
[acessibilidade](/docs/guides/accessibility).
