A ordenação é orientada a dados: o rascunho `items` é um novo array a cada reordenação, as linhas
são identificadas pelo item, e as animações só precisam das linhas que estão montadas. Então
qualquer virtualizador que renderiza a partir de um array funciona — passe a ele o rascunho em
vez do seu array.

::example{name="virtual-list" hint="10.000 linhas, só algumas no DOM: arraste uma, ou role enquanto arrasta" height="26rem"}
::

## As regras {#the-rules}

1. Dê ao virtualizador o **rascunho `items`**, não o seu array de origem.
2. **Use a key do item como key das linhas**, nunca o índice. Os exemplos oficiais do TanStack e
   do VueUse usam o índice; mude isso.
3. Passe os ids para `makeSortableItem` como um **getter**, `{ id: () => props.item.id }`: o
   virtualizador pode entregar outro item a um componente de linha.
4. Guarde arrays grandes em um **`shallowRef`**. A biblioteca nunca percorre os seus dados em
   profundidade.
5. Mantenha o placeholder do mesmo tamanho que a linha.
6. Use um overscan de pelo menos 5 linhas (VueUse: pelo menos 1), para que as linhas estejam
   montadas antes que a rolagem automática chegue a elas.
7. Não anime `height`, `margin` ou `padding` das linhas, e não coloque `will-change` no elemento
   de rolagem.

## TanStack Virtual {#tanstack-virtual}

```vue [TaskList.vue]
<script setup lang="ts">
import { computed, shallowRef, useTemplateRef } from 'vue';
import { defaultRangeExtractor, useVirtualizer, type Range } from '@tanstack/vue-virtual';
import { makeSortableList } from '@vue-dnd-kit/core';
import Row from './Row.vue';

const ROW = 40;
const tasks = shallowRef(makeRows(10_000));
const scrollRef = useTemplateRef<HTMLElement>('scroll');
const { items, activeIndex, captureLayout } = makeSortableList(scrollRef, { items: tasks });

// One computed that reads the draft once: TanStack memoizes measurements and the range on
// the identity of `getItemKey` and `rangeExtractor`, so they must be new after every reorder.
const virtualizer = useVirtualizer(
  computed(() => {
    const arr = items.value;
    const pin = activeIndex.value;
    return {
      count: arr.length,
      getScrollElement: () => scrollRef.value,
      estimateSize: () => ROW,
      overscan: 8,
      getItemKey: (index: number) => arr[index]!.id,
      // Keep the dragged row mounted while it is scrolled out of range.
      rangeExtractor: (range: Range) => {
        const indexes = defaultRangeExtractor(range);
        return pin < 0 || indexes.includes(pin) ? indexes : [...indexes, pin].sort((a, b) => a - b);
      },
      // Re-measures land after the library's animation pass: animate them too.
      onChange: () => captureLayout(),
    };
  }),
);
const rows = computed(() => virtualizer.value.getVirtualItems());
const measure = (el: unknown) => virtualizer.value.measureElement(el as HTMLElement | null);
</script>

<template>
  <div ref="scroll" style="height: 600px; overflow: auto; contain: strict">
    <div :style="{ height: `${virtualizer.getTotalSize()}px`, position: 'relative' }">
      <div
        v-for="row in rows"
        :key="(row.key as string)"
        :ref="measure"
        :data-index="row.index"
        :style="{ position: 'absolute', top: 0, left: 0, width: '100%', transform: `translateY(${row.start}px)` }"
      >
        <Row :item="items[row.index]!" />
      </div>
    </div>
  </div>
</template>
```

```vue [Row.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ item: { id: string; title: string } }>();
const el = useTemplateRef<HTMLElement>('el');
// A getter: the virtualizer may give this component another item.
makeSortableItem(el, { id: () => props.item.id });
</script>

<template>
  <div ref="el" class="row">{{ item.title }}</div>
</template>
```

- O elemento de rolagem é o elemento da lista ordenável: a biblioteca o ordena e o rola
  automaticamente.
- Fixar a linha arrastada (`rangeExtractor`) exige linhas posicionadas uma a uma, de forma
  absoluta, como acima.
- Mantenha o `anchorTo: 'start'` do TanStack, o padrão. Com `lanes`, use o
  `@tanstack/vue-virtual` 3.19 ou mais recente.

### Colunas de kanban {#kanban-columns}

Quando um card chega de outra coluna, a altura dele pode ser diferente da estimativa da coluna.
Leia `activeSize` no mesmo computed, e estime a linha que chega com o tamanho real dela:

```ts
const { items, activeIndex, activeSize, captureLayout } = makeSortableList(scrollRef, {
  id: props.column.id,
  items: props.column.tasks,
  group: 'board',
});

const virtualizer = useVirtualizer(
  computed(() => {
    const arr = items.value;
    const pin = activeIndex.value;
    const size = activeSize.value;
    return {
      count: arr.length,
      getScrollElement: () => scrollRef.value,
      // A card coming from another column gets its real height before it is measured.
      estimateSize: (index: number) => (index === pin && size ? size.height : 72),
      // …getItemKey, rangeExtractor and onChange as above
    };
  }),
);
```

## VueUse useVirtualList {#vueuse-usevirtuallist}

```vue [TaskList.vue]
<script setup lang="ts">
import { shallowRef, useTemplateRef } from 'vue';
import { useVirtualList } from '@vueuse/core';
import { makeSortableList } from '@vue-dnd-kit/core';
import Row from './Row.vue';

const ROW = 40;
const tasks = shallowRef(makeRows(10_000));
// The outer element is the sortable list: `containerProps` owns the scroller's ref.
const listRef = useTemplateRef<HTMLElement>('list');
const { items } = makeSortableList(listRef, { items: tasks });
// A number keeps VueUse's math O(1). It must be the row's real height, borders and margins included.
const { list, containerProps, wrapperProps } = useVirtualList(items, { itemHeight: ROW, overscan: 8 });
</script>

<template>
  <div ref="list">
    <div v-bind="containerProps" style="height: 600px">
      <div v-bind="wrapperProps">
        <!-- Keyed by id, not by index as in VueUse's docs. -->
        <Row v-for="{ data } in list" :key="data.id" :item="data" :style="{ height: `${ROW}px` }" />
      </div>
    </div>
  </div>
</template>
```

O VueUse não consegue fixar a linha arrastada: ela é desmontada quando você a rola para fora da
tela. Não tem problema — veja abaixo.

## O que continua montado {#what-stays-mounted}

A linha arrastada pode ser desmontada enquanto você arrasta: ela saiu do intervalo ao rolar, ou o
virtualizador reciclou o componente dela. O arraste sobrevive a isso. O overlay continua mostrando
o item, a seleção é mantida por id, e o item pousa onde o rascunho o coloca. As animações só
mexem nas linhas que estão montadas.

Onde o virtualizador permite, mantenha a linha arrastada montada mesmo assim, como a receita do
TanStack faz com `rangeExtractor`. A lista diz qual é essa linha:

| Retornado pela lista | Para que serve |
| --- | --- |
| `activeIndex` | O índice da linha a manter montada no rascunho desta lista, `-1` quando ela não está aqui. |
| `activeKey` | A key dessa linha. |
| `activeSize` | O tamanho da linha arrastada no início do arraste: use-o para estimar uma linha que chega. |
| `captureLayout()` | Chame-o logo antes de uma mudança de layout que a biblioteca não fez (uma nova medição). Ele anima as linhas a partir de onde estavam. Fora de um arraste, não faz nada. |

## Árvores {#trees}

`makeSortableTree` retorna um `items` plano com as linhas visíveis, então uma árvore é
virtualizada como uma lista: com `node.key` como key, e `activeIndex` e `activeKey` indicando a
linha a manter montada. Veja [Árvores](/docs/guides/trees).
