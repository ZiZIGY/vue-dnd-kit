Arraste um bloco, depois embaralhe, adicione e remova alguns. A ordenação e o drop são animados
por padrão; as mudanças dos botões são animadas porque a grade liga `animate`.

::example{name="animate" hint="Arraste, embaralhe, adicione, remova" height="22rem"}
::

## Três animações {#three-animations}

| Opção | Onde | Padrão | O que anima |
| --- | --- | --- | --- |
| `animation` | provider, lista, árvore | ligado, 200 ms | Itens deslizando para os novos lugares enquanto você ordena, no drop e no cancelamento. |
| `dropAnimation` | provider | ligado, 250 ms | O overlay pousando na sua posição, ou voltando ao lugar no cancelamento. |
| `animate` | provider, lista, árvore | **desligado** | Mudanças nos seus dados que nenhum arraste fez: itens adicionados, removidos, movidos ou filtrados, linhas de árvore mostradas ou ocultas. |

Cada uma aceita `true` (o tempo padrão), `false` (desligado), `{ duration, easing }`, ou uma
função com a qual você mesmo faz a animação.

```vue
<DnDProvider
  :animation="{ duration: 180, easing: 'cubic-bezier(.2, .8, .2, 1)' }"
  :drop-animation="{ duration: 300 }"
>
```

`animation` e `animate` da própria lista ou árvore prevalecem sobre os do provider.

## Ordenação {#sorting}

Enquanto você arrasta, o rascunho se reordena e os itens deslizam para os novos lugares: FLIP na
propriedade CSS `translate`, pela Web Animations API. `translate` se combina com qualquer
`transform` seu, então o posicionamento das linhas de uma lista virtual fica intacto. Quando um
item se move de novo antes de a animação dele terminar, a próxima começa de onde ele está sendo
mostrado.

::warning
Não envolva itens ordenáveis em `<TransitionGroup>`: todo movimento seria animado duas vezes. Para
mudanças que nenhum arraste fez, ligue `animate`.
::

## O drop {#the-drop}

No drop, o overlay voa de onde você soltou até a posição do item; no cancelamento, de volta para
onde o item começou. Quando o item não tem uma posição visível depois do drop — rolou para fora
da tela, ou foi solto dentro de uma pasta ou de uma zona de lixeira —, o overlay desaparece aos
poucos, encolhendo para dentro da zona onde foi solto.

O overlay também assume o tamanho da posição onde vai pousar enquanto você arrasta
(`overlayFit: 'slot'`, o padrão), então o drop não precisa de redimensionamento. `'source'`
mantém o tamanho do elemento arrastado. Veja [O overlay](/docs/guides/overlay).

## Mudanças de dados: animate {#data-changes-animate}

```ts
makeSortableList(listRef, { items: swatches, animate: true });
```

Desligado por padrão, `animate` anima o que muda o seu array sem um arraste: uma ordenação, um
embaralhamento, um movimento entre listas de um mesmo grupo, um item adicionado, removido ou
filtrado. Em uma árvore, ele também cobre as linhas que um nó mostra ou oculta ao expandir e
recolher. `<DnDProvider animate>` o liga para todas as listas e árvores.

As partes dele podem ser ajustadas uma a uma:

```ts
animate: { duration: 250, move: true, enter: true, leave: { duration: 150 } },
```

| Parte | Por padrão |
| --- | --- |
| `move` | Itens que trocaram de lugar deslizam, como com `animation`. |
| `enter` | Itens que apareceram surgem aos poucos onde estão. |
| `leave` | Uma cópia do item que saiu desaparece aos poucos onde ele estava, encolhendo um pouco. Ela é marcada com `data-dnd-leaving` e removida quando termina. |

`duration` e `easing` valem para todas as partes; cada parte aceita `true`, opções, `false` ou
uma função. Só os itens perto da área visível são animados, então as linhas que uma lista virtual
não montou são ignoradas. A opção é lida quando `items` muda, então um ref pode alterná-la, como
faz o botão de alternância do exemplo.

## As suas próprias animações {#your-own-animations}

Cada opção também aceita uma função. Ela recebe um contexto, inicia a animação e retorna a
`Animation` dela, uma promise que é resolvida quando ela termina, ou nada.

```ts
// animation, animate.move: an item moved from `from` to `to`
({ key, element, from, to, options, reason, signal, reducedMotion }) => Animation | Promise | void
// dropAnimation: `to` is null when there is no visible slot; `into` is the zone it went into
({ overlay, from, to, into, reason, active, options, reducedMotion }) => …
// animate.enter: the element is already in place
({ key, element, to, options, reducedMotion }) => …
// animate.leave: `element` is a copy where the item was, removed when you finish
({ key, element, from, options, reducedMotion }) => …
```

Uma função de layout com a Web Animations API, sem nenhuma biblioteca:

```ts
import type { LayoutAnimationContext } from '@vue-dnd-kit/core';

const springy = ({ element, from, to, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  return element.animate(
    [{ translate: `${from.left - to.left}px ${from.top - to.top}px` }, { translate: '0 0' }],
    { duration: 400, easing: 'cubic-bezier(.34, 1.56, .64, 1)' },
  );
};
```

```vue
<DnDProvider :animation="springy">
```

Três regras mantêm as animações personalizadas em sintonia com a biblioteca:

- **Anime `translate`** de `from - to` até zero, não `transform`. Ele se combina com os
  transforms que listas virtuais ou o seu CSS colocam nas linhas, e os arrastes medem os itens
  sem ele.
- **Respeite `signal`.** Ele é abortado quando o item se move de novo antes de a animação
  terminar. Pare a sua animação e limpe os estilos dela na hora: o layout é medido logo em
  seguida. Uma `Animation` retornada é cancelada automaticamente.
- **No overlay, anime a posição e o tamanho** (`width`, `height`), nunca `scale`: o conteúdo
  dele é diagramado de novo no novo tamanho.

### GSAP {#gsap}

```ts [gsap-animations.ts]
import gsap from 'gsap';
import type {
  DropAnimationContext,
  EnterAnimationContext,
  LayoutAnimationContext,
  LeaveAnimationContext,
  Rect,
} from '@vue-dnd-kit/core';

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const tween = gsap.fromTo(
    element,
    { translate: `${from.left - to.left}px ${from.top - to.top}px` },
    { translate: '0px 0px', duration: 0.4, ease: 'power3.out' },
  );
  signal.addEventListener('abort', () => tween.revert());
  return tween.then();
};

const box = (rect: Rect) => ({ x: rect.left, y: rect.top, width: rect.width, height: rect.height });

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return gsap.to(overlay, { opacity: 0, duration: 0.2 }).then();
  return gsap.fromTo(overlay, box(from), { ...box(to), duration: 0.45, ease: 'back.out(1.2)' }).then();
};

const enter = ({ element, reducedMotion }: EnterAnimationContext) =>
  gsap.from(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.35 }).then();

const leave = ({ element, reducedMotion }: LeaveAnimationContext) =>
  gsap.to(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.25 }).then();

export const gsapAnimations = { animation: move, dropAnimation: drop, animate: { move, enter, leave } };
```

```vue
<DnDProvider v-bind="gsapAnimations">
```

### motion {#motion}

```ts [motion-animations.ts]
import { animate } from 'motion-v';
import type { DropAnimationContext, LayoutAnimationContext } from '@vue-dnd-kit/core';

const spring = { type: 'spring', duration: 0.45, bounce: 0.25 } as const;

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const controls = animate(
    element,
    { translate: [`${from.left - to.left}px ${from.top - to.top}px`, '0px 0px'] },
    spring,
  );
  signal.addEventListener('abort', () => {
    controls.stop();
    element.style.translate = '';
  });
  return controls.finished;
};

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return animate(overlay, { opacity: 0 }, { duration: 0.18 }).finished;
  return animate(
    overlay,
    { x: [from.left, to.left], y: [from.top, to.top], width: [from.width, to.width], height: [from.height, to.height] },
    spring,
  ).finished;
};
```

Os tipos completos das opções estão em [Animações](/docs/api/animations).

## Movimento reduzido {#reduced-motion}

Com `prefers-reduced-motion: reduce`, as animações da própria biblioteca não rodam: os itens e o
overlay vão direto para os seus lugares. As suas funções sempre rodam, com `reducedMotion: true`,
então elas decidem — pular o movimento, ou manter um fade curto como as receitas acima fazem.

## Mudanças de layout que a biblioteca não causou {#layout-changes-the-library-didnt-cause}

Quando outra coisa move as linhas durante um arraste — um virtualizador medindo de novo, uma
imagem carregando —, chame o `captureLayout()` da lista logo antes de a mudança ser renderizada.
Ele mede as linhas onde estão e as anima até os novos lugares depois da próxima renderização.
Fora de um arraste, ele não faz nada.
Veja [Listas virtuais](/docs/guides/virtual-lists).
