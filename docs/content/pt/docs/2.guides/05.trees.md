## Renderizada de forma plana {#rendered-flat}

Uma árvore é renderizada como uma **lista plana** dos nós visíveis, em ordem, cada um com a sua
`depth`. Você mesmo faz a indentação das linhas. Assim todas as linhas ficam irmãs em um único
contêiner, e elas deslizam e são animadas como as linhas de uma lista.

```vue [FileTree.vue]
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { makeSortableTree, type Key } from '@vue-dnd-kit/core';
import TreeRow from './TreeRow.vue';

interface FileNode { id: string; name: string; folder?: boolean; children?: FileNode[] }

const files = ref<FileNode[]>([
  { id: 'src', name: 'src', folder: true, children: [{ id: 'main', name: 'main.ts' }] },
  { id: 'readme', name: 'README.md' },
]);
const collapsed = ref(new Set<Key>());
const INDENT = 18;

const root = useTemplateRef<HTMLElement>('root');
const { items } = makeSortableTree(root, {
  items: files,                                  // the root nodes
  indentation: INDENT,                           // px per level: match your row padding
  collapsed,
  canNest: (_node, parent) => !!parent.folder,   // only folders take children
});

const toggle = (key: Key) => (collapsed.value.has(key) ? collapsed.value.delete(key) : collapsed.value.add(key));
</script>

<template>
  <div ref="root">
    <TreeRow v-for="node in items" :key="node.key" :node="node" :indent="INDENT" @toggle="toggle" />
  </div>
</template>
```

```vue [TreeRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode, type Key } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const emit = defineEmits<{ toggle: [key: Key] }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { id: () => props.node.key });
</script>

<template>
  <div ref="el" :style="{ paddingLeft: `${node.depth * indent}px` }">
    <button
      v-if="node.item.folder"
      type="button"
      :aria-expanded="!node.collapsed"
      :aria-label="node.collapsed ? 'Expand' : 'Collapse'"
      @click="emit('toggle', node.key)"
    >
      {{ node.collapsed ? '▸' : '▾' }}
    </button>
    {{ node.item.name }}
  </div>
</template>
```

As linhas usam `makeSortableItem`, como as linhas de uma lista. `items` contém `FlatNode`s:

| Campo de `FlatNode` | O que contém |
| --- | --- |
| `key` | A key do nó (`getKey`, padrão `node.id`). Use-a no `:key` e no `id` da linha. |
| `item` | O seu nó. |
| `depth` | `0` para as raízes. A profundidade do nó arrastado é onde ele **pousaria**, então a posição dele se indenta ao vivo. |
| `parentKey` | A key do pai, `null` para as raízes. |
| `index` | O índice entre os irmãos. |
| `hasChildren`, `collapsed` | Para o botão de expandir. |

Os filhos são lidos de `node.children` e gravados ali. Outros formatos usam `getChildren` e
`setChildren`:

```ts
makeSortableTree(root, {
  items: outline,
  getKey: (node) => node.uuid,
  getChildren: (node) => node.nested,
  setChildren: (node, children) => { node.nested = children; },
});
```

## Aninhamento {#nesting}

Um arraste muda a profundidade de duas formas, ambas ligadas por padrão (`nesting: 'both'`):

- **Para o lado** (`'offset'`): arraste para a esquerda ou para a direita `indentation` pixels
  para subir ou descer um nível, até onde as linhas ao redor da posição permitirem.
- **Pairando** (`'hover'`): mantenha o arraste sobre o meio de uma linha, e o drop vai para
  dentro dela, como o primeiro filho.

Defina `indentation` com o padding que as suas linhas acrescentam por nível, para que o
deslocamento acompanhe o ponteiro. Com `axis: 'y'`, o arraste não se move para o lado, mas as
linhas ainda se aninham ao pairar.

## Nós recolhidos {#collapsed-nodes}

`collapsed` é um `Set` de keys cujos filhos estão ocultos (um ref ou um getter). Os filhos delas
não estão em `items`. Uma pasta arrastada leva junto toda a subárvore, recolhida ou não. Com a
opção `animate` da árvore ligada, as linhas que uma pasta mostra ou oculta entram e saem com
animação.

## Regras {#rules}

| Opção | Limita |
| --- | --- |
| `canNest(node, parent)` | Se `node` pode ficar sob `parent`. Um multi-drag pergunta para cada nó arrastado. |
| `maxDepth` | A maior profundidade permitida, sendo `0` a das raízes. Os descendentes do nó arrastado contam: uma pasta com filhos e netos vai no máximo até a profundidade `maxDepth - 2`. |
| `group.put` | Se a árvore aceita itens de outras listas e árvores. |
| `onBeforeDrop` | Qualquer outra coisa, decidida no drop: veja [decisões de drop](/docs/guides/drop-decisions). |

Quando uma regra recusa uma profundidade, a posição assume a maior profundidade que passa. Onde
nenhuma passa, a posição não vai para lá. Cópias e nós vindos de `createItem` também seguem
`canNest` e `maxDepth`.

## Árvores e listas em um mesmo grupo {#trees-and-lists-in-one-group}

Uma árvore e uma lista com o mesmo `group` trocam nós, como duas listas fazem. Uma pasta movida
para a lista mantém a sua subárvore, e volta com ela. As cópias funcionam como nas listas
(`clone`, `pull: 'clone'`, a tecla Alt), mas `clone` precisa retornar a cópia **com toda a sua
subárvore**, e cada nó nela precisa de uma nova key:

```ts
let count = 0;
const copyNode = (node: FileNode): FileNode => ({
  ...node,
  id: `${node.id}-${++count}`,
  children: node.children?.map(copyNode),
});

makeSortableTree(root, { items: files, group: 'files', clone: copyNode });
```

Veja [listas que compartilham itens](/docs/guides/shared-lists) para grupos, cópia e
`createItem`.

## Uma linha de inserção {#an-insertion-line}

Com `placeholder: 'indicator'`, a árvore não se move enquanto você arrasta. Cada linha lê o seu
`indicator` e desenha a linha, indentada até a profundidade onde o drop pousa:

```vue [TreeRow.vue]
<script setup lang="ts">
import { computed, useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const el = useTemplateRef<HTMLElement>('el');
const { indicator } = makeSortableItem(el, { id: () => props.node.key });

// 'inside': the drop goes into this row. Otherwise a line before or after it.
const into = computed(() => indicator.value?.side === 'inside');
const line = computed(() => {
  const value = indicator.value;
  if (!value || value.side === 'inside') return null;
  return { side: value.side, left: `${(value.depth ?? 0) * props.indent}px` };
});
</script>

<template>
  <div ref="el" class="row" :class="{ into }" :style="{ paddingLeft: `${node.depth * indent}px` }">
    {{ node.item.name }}
    <span v-if="line" class="line" :class="line.side" :style="{ left: line.left }" />
  </div>
</template>

<style scoped>
.row { position: relative; }
.row.into { background: color-mix(in srgb, #42b883 15%, transparent); }
.line { position: absolute; right: 0; height: 2px; background: #42b883; }
.line.before { top: -1px; }
.line.after { bottom: -1px; }
</style>
```

Nas árvores, `indicator` acrescenta `depth` e `parentKey`: o nível e o pai que os nós soltos
recebem. Arrastar para o lado move a linha entre os níveis. Neste modo, um drop fora da árvore
cancela.

## O drop {#the-drop}

O evento de drop da árvore é o de uma lista, com `parentKey` acrescentado a `from` e `to`:

```ts
makeSortableTree(root, {
  items: files,
  onDrop: (e) => {
    console.log(e.keys, e.from.parentKey, '→', e.to.parentKey, e.to.index);
  },
});
```

`to.index` é a posição entre os novos irmãos, contada depois que o nó saiu do lugar antigo. No
drop, a biblioteca dá aos nós alterados os novos filhos (`setChildren`) e grava um novo array de
raízes no seu ref.

`e.result.get(treeId)` é a nova árvore como um novo array de raízes: os nós nos caminhos
alterados são cópias, as subárvores intactas são compartilhadas, e os seus nós ficam como estão.
Para uma store ou dados imutáveis, passe um getter, chame `e.preventDefault()` e salve
`e.result`. As cópias são feitas com `withChildren(node, children)`, por padrão `{ ...node }`
com os novos filhos; passe a sua própria função para instâncias de classes.

## Teclado e multi-drag {#keyboard-and-multi-drag}

Pelo teclado, :kbd{value="ArrowUp"} e :kbd{value="ArrowDown"} movem entre as linhas, e
:kbd{value="ArrowLeft"} e :kbd{value="ArrowRight"} mudam a profundidade onde as linhas ao redor
permitem.

Os nós selecionados se movem juntos como um bloco, cada um com a sua subárvore, na ordem do
documento. Um nó selecionado dentro de outro selecionado vai junto na subárvore do pai. Veja
[multi-drag](/docs/guides/multi-drag).

Todas as opções estão na [API do makeSortableTree](/docs/api/make-sortable-tree). Para árvores
com milhares de linhas, veja [listas virtuais](/docs/guides/virtual-lists).
