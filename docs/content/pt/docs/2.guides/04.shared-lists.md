## Um grupo {#a-group}

Listas com o mesmo nome de `group` trocam itens. Por padrão, cada lista é um grupo à parte.

```vue [Column.vue]
<script setup lang="ts">
import { toRef, useTemplateRef } from 'vue';
import { makeSortableList } from '@vue-dnd-kit/core';
import Card from './Card.vue';

type Task = { id: string; title: string };
const props = defineProps<{ column: { id: string; title: string; cards: Task[] } }>();

const zone = useTemplateRef<HTMLElement>('zone');
const list = useTemplateRef<HTMLElement>('list');
const { items, isOver } = makeSortableList(list, {
  id: props.column.id,                   // names the list in drop events
  items: toRef(props.column, 'cards'),   // a writable ref into the reactive column
  group: 'board',                        // same name: cards move between these lists
  dropzone: zone,                        // the whole column takes drops
});
</script>

<template>
  <section ref="zone" :class="{ over: isOver }">
    <h3>{{ column.title }}</h3>
    <ul ref="list">
      <Card v-for="card in items" :key="card.id" :card="card" />
    </ul>
  </section>
</template>
```

```vue [Board.vue]
<script setup lang="ts">
import { reactive } from 'vue';
import Column from './Column.vue';

const columns = reactive([
  { id: 'todo', title: 'To do', cards: [{ id: 'vdk-12', title: 'Pick a palette' }] },
  { id: 'done', title: 'Done', cards: [] },
]);
</script>

<template>
  <Column v-for="column in columns" :key="column.id" :column="column" />
</template>
```

- Cada coluna é um componente próprio: uma lista por componente.
- `toRef(props.column, 'cards')` é gravável porque o pai passa um objeto reativo. O drop grava
  os dois arrays, o que o card deixou e aquele em que ele entrou.
- `id` aparece nos eventos de drop como `from.list` e `to.list`, e é a chave de `e.result`, os
  novos arrays de todas as listas que o drop altera. `id` e `group` são lidos uma única vez.
- As keys precisam ser únicas no grupo inteiro.

O `onDrop` de uma lista roda para os drops **para dentro** dela. Mover de `todo` para `done`
chama o `onDrop` da lista `done`, e o `e.result` dele contém os novos arrays das duas listas.

## A coluna inteira recebe drops: `dropzone` {#the-whole-column-takes-drops-dropzone}

Uma lista curta em uma coluna alta deixa um espaço vazio abaixo do último card. Com
`dropzone: zone`, o elemento da coluna recebe os drops pela lista: um card solto abaixo do último
pousa no final. Os cards ficam no `<ul>`; só a área que recebe drops cresce.

::tip
Sem um `dropzone`, uma lista vazia ainda precisa de um tamanho para receber drops: dê a ela um
`min-height`.
::

## O que entra e o que sai: `pull` e `put` {#what-goes-in-and-out-pull-and-put}

`group` também aceita um objeto:

```ts
group: { name: 'board', pull: true, put: true }
```

| Opção | Valores |
| --- | --- |
| `pull` | `true` (padrão): os itens podem sair. `false`: não podem. `'clone'`: cópias saem, os itens ficam. |
| `put` | `true` (padrão): os itens podem entrar. `false`: nada entra. Uma função: você decide a cada arraste. |

Uma função `put` recebe `{ keys, items, types, from, to }`. `from` é a lista de onde os itens
vêm, `null` para draggables simples. Movimentos dentro de uma lista são sempre permitidos.

### Limites {#limits}

Uma coluna que comporta no máximo três cards:

```ts
makeSortableList(list, {
  id: props.column.id,
  items: toRef(props.column, 'cards'),
  group: {
    name: 'board',
    put: ({ keys }) => props.column.cards.length + keys.length <= 3,
  },
});
```

Sobre uma lista que recusa o arraste, a posição volta para onde o arraste começou, então as
listas mostram o que um drop faria: nada. Um drop ali é cancelado e o card volta ao lugar. O
`isAccepting` da lista é `false` durante um arraste assim: use-o para esmaecer a coluna.

Quando vários itens selecionados de tipos diferentes são arrastados, `acceptMode` diz se
`'all'` (padrão) ou `'some'` deles precisam passar no `put`. Com `'some'`, os que passam pousam
e os outros voltam ao lugar.

## Cópia: paletas e a tecla Alt {#copy-palettes-and-the-alt-key}

::example{name="palette" hint="Arraste da paleta; arrastar com Alt copia; solte fora da página para remover" height="24rem"}
::

```ts [Palette.vue]
makeSortableList(list, {
  items: templates,
  group: { name: 'blocks', pull: 'clone', put: false },  // copies go out, nothing comes in
  sort: false,                                           // its own order stays
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),
});
```

```ts [Sheet.vue]
makeSortableList(list, {
  items: blocks,
  group: 'blocks',
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),  // for Alt-drags
});
```

- `pull: 'clone'` copia todo arraste que sai da lista. O original fica, e a cópia viaja e pousa.
- Segurar :kbd{value="Alt"} durante o arraste também copia, a partir de qualquer lista. Troque
  a tecla com o `copyModifier` do provider, ou desligue com `null`.
- Em ambos os casos, a lista de onde o item vem precisa de `clone`. Ele precisa retornar a cópia
  com uma **nova key**. Sem `clone`, nada é copiado.
- O evento de drop tem `mode: 'copy'`, e `e.items` são as cópias. Um componente de overlay
  também recebe `mode`, para mostrar um "+" durante a cópia (veja [o overlay](/docs/guides/overlay)).

## Draggables simples para dentro de uma lista {#plain-draggables-into-a-list}

Uma lista recebe itens arrastados com `makeDraggable` quando sabe como criar um item a partir
deles:

```ts
makeSortableList(list, {
  items: tasks,
  createItem: (active) => ({ id: crypto.randomUUID(), title: (active.data as Chip).title }),
});
```

Enquanto o draggable está sobre a lista, o item criado fica no rascunho e é renderizado pelo seu
template como qualquer outra linha. Ele se torna real no drop (`mode: 'insert'`,
`from.list === null`). Retorne `undefined` para recusar. Listas sem `createItem` ignoram
draggables simples. Pelo teclado, uma seta em direção à lista leva o draggable para dentro dela.

## Trocar em vez de deslocar {#swap-instead-of-shift}

```ts
makeSortableList(grid, { items: tiles, strategy: 'grid', behavior: 'swap' });
```

O item arrastado troca de lugar com o que está embaixo dele, e os outros ficam onde estão. A
troca é ao vivo: voltar, ou sair da lista, a desfaz. O evento de drop tem `mode: 'swap'` e
`partner`, o item com o qual ele trocou.

- Duas listas de um mesmo grupo trocam entre si quando ambas têm `behavior: 'swap'`. O item sob
  o ponteiro vai para a outra lista, então precisa ter permissão para sair (`pull: true`) e
  entrar (`put`).
- Um multi-drag ordena em vez de trocar.

## Uma linha de inserção {#an-insertion-line}

Com `placeholder: 'indicator'`, a lista fica parada enquanto você arrasta, e uma linha mostra
onde o drop vai acontecer. Você desenha a linha:

```ts [TaskList.vue]
const { items, indicator } = makeSortableList(listRef, { items: tasks, placeholder: 'indicator' });
```

```vue [TaskRow.vue]
<script setup lang="ts">
const { indicator } = makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el" :class="indicator && `drop-${indicator.side}`">{{ task.title }}</li>
</template>

<style scoped>
.drop-before { box-shadow: inset 0 2px 0 #42b883; }
.drop-after { box-shadow: inset 0 -2px 0 #42b883; }
</style>
```

| Campo de `indicator` | O que contém |
| --- | --- |
| `list` | A lista para onde o drop vai. |
| `index` | O índice de inserção na lista como renderizada. |
| `key` | O item ao qual a linha está presa; `null` em uma lista vazia (nesse caso, desenhe-a na lista). |
| `side` | `'before'` ou `'after'` desse item. Árvores acrescentam `'inside'`. |
| `depth`, `parentKey` | Só em árvores: onde o drop pousa. Veja [árvores](/docs/guides/trees#an-insertion-line). |

O `indicator` da lista está definido enquanto a linha está nessa lista, e o `indicator` de um
item enquanto ela está presa a esse item. O teclado também move a linha.

## Soltar fora {#dropping-outside}

O que acontece quando um arraste termina sem nenhum alvo embaixo é definido pelo `dropOutside`
da lista:

| `dropOutside` | Os itens |
| --- | --- |
| `'placeholder'` (padrão) | Pousam onde a posição foi mostrada por último. |
| `'cancel'` | Voltam ao lugar. O padrão com `placeholder: 'indicator'`. |
| `'remove'` | Saem da lista: arraste para fora para excluir. |

`'remove'` consulta primeiro o `onBeforeDrop` da lista. Depois o `onDrop` da lista roda com
`to.index === -1`, e `e.result` contém a lista sem os itens. Uma lixeira que recebe drops
funciona do mesmo jeito: veja [zonas de lixeira](/docs/guides/drag-and-drop#trash-zones).

Para confirmar um movimento, salvá-lo primeiro em um servidor ou aplicar os drops você mesmo a
uma store, veja [decisões de drop](/docs/guides/drop-decisions). Todas as opções de lista estão
na [API do makeSortableList](/docs/api/make-sortable-list).
