## O que observar {#what-to-look-at}

- **`FileTree.vue`**: `makeSortableTree` com `indentation`, `collapsed` e
  `canNest: (_node, parent) => !!parent.folder` — só as pastas aceitam filhos.
- **`TreeRow.vue`**: cada linha é um item ordenável identificado por `node.key`; o padding
  esquerdo dela acompanha `node.depth`, também enquanto você arrasta, então a posição mostra a
  profundidade que o drop vai ter.
