## O que observar {#what-to-look-at}

- **`TaskList.vue`**: a lista virtual recebe o rascunho `items`, não o array de origem, então as
  linhas se movem enquanto você arrasta. O array é um `shallowRef`.
- **`TaskList.vue`**: a key das linhas é o id, não o índice como na documentação do VueUse.
- **`Row.vue`**: o id é um getter, `{ id: () => props.task.id }`: a lista virtual pode entregar
  outra tarefa ao componente.

Leia mais: [Listas virtuais](/docs/guides/virtual-lists)
