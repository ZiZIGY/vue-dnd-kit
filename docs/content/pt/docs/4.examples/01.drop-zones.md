## O que observar {#what-to-look-at}

- **`FileCard.vue`**: um `makeDraggable` simples com um `type` — `image` ou `doc`.
- **`Folder.vue`**: um `makeDroppable` cujo `accept` aceita um tipo (`'*'` para a área de
  trabalho e a lixeira). `isAccepting` destaca as pastas que aceitam o arraste; uma pasta que não
  aceita mostra isso com `isOver && !isAccepting`. `onDrop` é onde os dados mudam: a biblioteca
  não move nada por conta própria.
- Os arquivos têm a mesma aparência em todo lugar, então um drop só voa; os arquivos que ficaram
  para trás deslizam para preencher o espaço com o `<TransitionGroup>` do Vue.
