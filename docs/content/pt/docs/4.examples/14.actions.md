## O que observar {#what-to-look-at}

- **`TrackRow.vue`**: `moveItem(id, { index })` para os botões de seta, e
  `startDrag(id, { type: 'keyboard' })` para entregar a linha às setas do teclado.
- **`Queue.vue`**: o embaralhamento aguarda um `moveItem` depois do outro; o arraste roteirizado
  começa com `startDrag`, desliza com `moveTo` e pousa com `drop()`.

Leia mais: [Sensores e arrastes programáticos](/docs/guides/sensors#programmatic-drags)
