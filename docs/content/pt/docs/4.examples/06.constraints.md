## O que observar {#what-to-look-at}

- **`Board.vue`**: `makeDragArea(board, { axis, restrictToArea, modifiers })` define as regras
  para todo arraste que começa no quadro. As opções são refs e um getter, lidos quando um arraste
  começa, então as mudanças valem a partir do próximo arraste.
- O quadro também é um alvo de drop; `onDragEnd` coloca a nota em `position`, o `left`/`top` onde
  ela foi solta.
- **`Note.vue`** só diz que pode ser arrastada: a área faz o resto.
