## O que observar {#what-to-look-at}

- **`FileChip.vue`**: cada arquivo tem um `type`, o que os alvos de drop verificam.
- **`Zone.vue`**: `accept` aceita um tipo ou uma lista de tipos. `isAccepting` destaca as zonas
  que aceitariam o arraste; `isOver` sem `isAccepting` é uma zona que o recusa.
- **`index.vue`**: um alvo de drop não move nada sozinho: `onDrop` diz qual arquivo entrou, e o
  app o move.
