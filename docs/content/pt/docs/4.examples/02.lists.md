## O que observar {#what-to-look-at}

- **`Playlist.vue`**: `axis: 'y'` e `modifiers: [restrictToParent]` mantêm as faixas no seu eixo
  e dentro da lista; as pontas da lista continuam ao alcance.
- **`Track.vue`**: `handle: '.grip'` — só a alça (um `<button>` com um `aria-label`) inicia um
  arraste. `index` acompanha o rascunho, então os números mudam enquanto você arrasta. A linha tem
  um fundo próprio: o overlay é uma cópia dela, e uma cópia só mostra o que a própria linha pinta.
- **`AppGrid.vue`**: `strategy: 'grid'` ordena em duas dimensões; `overlay: AppOverlay` eleva só
  o ícone, em vez de uma cópia do bloco.
- A posição onde um item arrastado vai pousar é estilizada com `[data-dnd-placeholder]::after`.
