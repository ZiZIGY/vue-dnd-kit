::api-signature{name="makeDraggable"}
::

```ts
const el = useTemplateRef<HTMLElement>('el');
const { isDragging } = makeDraggable(el, { id: 'card', type: 'card', data: { title } });
```

Veja [Arrastar e soltar](/docs/guides/drag-and-drop). Os itens ordenáveis também são draggables:
[`makeSortableItem`](/docs/api/make-sortable-item) aceita as mesmas opções e outras mais.
