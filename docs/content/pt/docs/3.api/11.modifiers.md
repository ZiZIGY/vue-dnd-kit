## Modificadores {#modifiers}

```ts
import { restrictToParent, snapToGrid } from '@vue-dnd-kit/core';

makeSortableList(list, { items, modifiers: [restrictToParent] });
makeDragArea(board, { modifiers: [snapToGrid({ x: 24, y: 24, smooth: true })] });
```

Um modificador recebe o deslocamento do arraste e retorna um novo. Eles rodam em ordem: os
`modifiers` do provider, os de uma área de arraste, os do próprio draggable (ou da lista dele),
depois os limites da área (`restrictToArea`), e a trava de `axis` por último. Veja
[Eixos, limites e grades](/docs/guides/constraints).

| Modificador | O que faz |
| --- | --- |
| `restrictToVerticalAxis` | Move só na vertical. A opção `axis: 'y'` faz o mesmo, por último. |
| `restrictToHorizontalAxis` | Move só na horizontal (`axis: 'x'`). |
| `restrictToWindowEdges` | Mantém o overlay dentro da janela. |
| `restrictToParent` | Mantém o overlay dentro do contêiner onde o arraste começou: a lista ordenável, ou o elemento pai de um draggable simples. |
| `restrictToElement(element)` | Mantém o overlay dentro de um elemento (um ref, um getter ou o elemento). |
| `restrictToFirstScrollableAncestor` | Mantém o overlay dentro do primeiro ancestral rolável do elemento arrastado. |
| `snapToGrid(size \| options)` | Encaixa em uma grade: `{ x, y, origin: 'container' \| 'delta', smooth }`. `'container'` (padrão) coloca o canto superior esquerdo da caixa nas linhas de uma grade que parte do canto superior esquerdo do contêiner; `'delta'` arredonda o deslocamento. `smooth` faz o overlay deslizar entre as células. |
| `snapCenterToCursor` | Centraliza o overlay sob o ponteiro em vez de manter o deslocamento de onde ele foi pego. |

## Detecção de colisão {#collision-detection}

```ts
import { closestCorners } from '@vue-dnd-kit/core';
```

```vue
<DnDProvider :collision="closestCorners" />
```

O `collision` do provider escolhe o alvo; o melhor candidato vem primeiro.

| Função | O que escolhe |
| --- | --- |
| `pointerFirst` | Padrão: o que está sob o ponteiro, senão o que o overlay sobrepõe. |
| `pointerWithin` | Alvos sob o ponteiro, testando o que está embaixo dele (respeitando z-order, overlays e shadow roots). |
| `rectIntersection` | Alvos que se sobrepõem ao overlay: maior prioridade, depois aninhamento mais profundo, depois interseção sobre união. |
| `closestCenter` | Todos os alvos, pela distância entre os centros. |
| `closestCorners` | Todos os alvos, pela soma das distâncias entre os cantos (alvos empilhados, como colunas de kanban). |
