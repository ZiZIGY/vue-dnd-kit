## DragPreview {#dragpreview}

```vue [StackOverlay.vue]
<script setup lang="ts">
import { DragPreview, type DragItem } from '@vue-dnd-kit/core';

defineProps<{ items: DragItem[] }>();
</script>

<template>
  <div class="stack">
    <DragPreview v-for="item in items.slice(0, 3)" :id="item.id" :key="item.id" />
  </div>
</template>
```

Os clones são feitos quando o item é pego: do item pego e de até quatro outros ao lado dele na
ordem do drop. Para qualquer outro item, `DragPreview` renderiza o seu slot padrão, ou nada. Cada
prévia pousa no seu próprio item quando o drop pousa. Veja [o guia do overlay](/docs/guides/overlay).
