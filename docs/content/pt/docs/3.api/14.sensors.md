```ts
import { defineSensor, useSensor, pointerSensor, keyboardSensor } from '@vue-dnd-kit/core';
```

| Export | O que é |
| --- | --- |
| `pointerSensor` | Mouse, toque e caneta via Pointer Events. Está em `sensors` por padrão. |
| `keyboardSensor` | Space/Enter pegam e soltam, as setas movem, Escape cancela. Está em `sensors` por padrão. |
| `defineSensor(sensor)` | Tipa um objeto de sensor. |
| `useSensor(sensor)` | Roda um sensor em um componente sob o provider, enquanto ele viver. |

Um sensor só diz "arraste este item a partir daqui", depois para onde ele se moveu e que ele
soltou ou foi cancelado; o provider verifica o resto (o que pode ser arrastado, a ativação, um
arraste por vez). Veja [Sensores e arrastes programáticos](/docs/guides/sensors).
