## O núcleo {#the-core}

::code-group

```bash [npm]
npm i @vue-dnd-kit/core
```

```bash [yarn]
yarn add @vue-dnd-kit/core
```

```bash [pnpm]
pnpm add @vue-dnd-kit/core
```

```bash [bun]
bun add @vue-dnd-kit/core
```

::

Vue `^3.5` é uma peer dependency. O pacote tem uma única dependência própria, `@vueuse/core`.

## Nuxt {#nuxt}

O módulo Nuxt registra `DnDProvider` e `DragPreview` como componentes globais e importa
automaticamente os composables e os tipos principais.

```bash
npx nuxi module add @vue-dnd-kit/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@vue-dnd-kit/nuxt'],
});
```

::note
Modificadores, helpers de colisão e sensores têm nomes genéricos (`snapToGrid`, `closestCenter`),
por isso não são importados automaticamente, a menos que você peça:
`vueDndKit: { autoImports: { modifiers: true, collision: true, sensors: true } }`.
::

## Pacotes opcionais {#optional-packages}

| Pacote | O que adiciona |
| --- | --- |
| `@vue-dnd-kit/actions` | Arrastes programáticos: botões "mover para cima", menus, tours e testes. |
| `@vue-dnd-kit/devtools` | Uma aba do Vue DnD Kit no Vue DevTools e no Nuxt DevTools. |

```bash
npm i @vue-dnd-kit/actions
npm i -D @vue-dnd-kit/devtools
```
