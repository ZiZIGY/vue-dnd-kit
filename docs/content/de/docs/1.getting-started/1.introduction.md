## Was es ist {#what-it-is}

Vue DnD Kit ist eine Sammlung von **Composables** und eine **Provider**-Komponente. Du renderst
deine eigenen Elemente und übergibst ihre Template-Refs an die Composables; um den Rest kümmert
sich die Bibliothek: Eingaben per Zeiger, Touch und Tastatur, die Suche nach dem Ziel, das
Neuordnen, Animationen, Auto-Scroll und die Mitteilung an Screenreader, was passiert ist.

Selbst rendert sie nichts außer einem schwebenden **Overlay** – standardmäßig einem Klon des
gezogenen Elements. Dein Markup und deine Styles bleiben deine.

## Was du bekommst {#what-you-get}

- **Sortierbare Listen und Raster**, die sich schon während des Ziehens neu ordnen. Du renderst
  einen *Entwurf* deines Arrays; beim Drop schreibt die Bibliothek die neue Reihenfolge in deinen
  Ref.
- **Kanban-Boards**: Listen derselben Gruppe tauschen Elemente aus. Kopieren aus Paletten,
  einfache ziehbare Elemente annehmen, tauschen statt verschieben.
- **Bäume** mit Verschachtelung per horizontalem Versatz oder per Hovern über einer Zeile,
  Tiefenbegrenzung und Regeln.
- **Multi-Drag** mit deiner eigenen Auswahl (Strg-Klick, Auswahlrahmen): Der Block bewegt sich
  gemeinsam.
- **Animationen von Haus aus**: Elemente gleiten an ihre neuen Plätze, der Drop landet in seinem
  Slot.
- **Barrierefreiheit**: Ziehen per Tastatur von Slot zu Slot, Live-Ansagen, ARIA-Attribute.
- **Virtuelle Listen**: TanStack Virtual und VueUse, Tausende Zeilen.
- **Kontrollierter Modus** für Stores und Server: Überspringe das Standard-Schreiben und wende das
  Ergebnis an.

## Wie alles zusammenpasst {#how-it-fits-together}

| Baustein | Was er macht |
| --- | --- |
| `DnDProvider` | Verantwortet den Drag: Eingabe, Overlay, Auswahl, Auto-Scroll, Ansagen. |
| `makeSortableList` / `makeSortableItem` | Eine Liste, die sich neu ordnet, und ihre Zeilen. |
| `makeSortableTree` | Ein Baum, flach gerendert mit Tiefen. |
| `makeDraggable` / `makeDroppable` | Freies Ziehen und Drop-Zonen. |
| `makeDragArea` | Regeln für einen Teil der Seite: Achse, Grenzen, Einrasten, Auto-Scroll. |
| `makeSelectionArea` | Auswahl per Auswahlrahmen. |
| `useDnD` / `useDnDMonitor` | Der Zustand des Drags und seine Events, überall unterhalb des Providers. |

::tip
Kommst du von v2? Die API hat sich geändert: Aus `useDnDProvider` wurde `useDnD`, aus
`makeConstraintArea` und `makeAutoScroll` wurde `makeDragArea`. Sortierbare Listen sind jetzt
eingebaut.
::

## Voraussetzungen {#requirements}

- Vue **3.5** oder neuer.
- Moderne Browser: Chrome und Edge 104+, Safari 15.4+, Firefox 104+.
- Funktioniert mit SSR und Nuxt: Das Overlay und die Live-Region werden auf dem Client gemountet.
