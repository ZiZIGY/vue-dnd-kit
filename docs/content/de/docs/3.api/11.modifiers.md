## Modifier {#modifiers}

```ts
import { restrictToParent, snapToGrid } from '@vue-dnd-kit/core';

makeSortableList(list, { items, modifiers: [restrictToParent] });
makeDragArea(board, { modifiers: [snapToGrid({ x: 24, y: 24, smooth: true })] });
```

Ein Modifier nimmt den Versatz des Drags entgegen und gibt einen neuen zurück. Sie laufen in
dieser Reihenfolge: die `modifiers` des Providers, die eines Drag-Bereichs, die eigenen des
ziehbaren Elements (oder die seiner Liste), dann die Grenzen des Bereichs (`restrictToArea`) und
zuletzt die `axis`-Sperre. Siehe [Achsen, Grenzen und Raster](/docs/guides/constraints).

| Modifier | Was er macht |
| --- | --- |
| `restrictToVerticalAxis` | Bewegung nur vertikal. Die Option `axis: 'y'` tut dasselbe, aber zuletzt. |
| `restrictToHorizontalAxis` | Bewegung nur horizontal (`axis: 'x'`). |
| `restrictToWindowEdges` | Hält das Overlay innerhalb des Fensters. |
| `restrictToParent` | Hält das Overlay innerhalb des Containers, in dem der Drag begonnen hat: der sortierbaren Liste oder des Elternelements eines einfachen ziehbaren Elements. |
| `restrictToElement(element)` | Hält das Overlay innerhalb eines Elements (ein Ref, ein Getter oder das Element selbst). |
| `restrictToFirstScrollableAncestor` | Hält das Overlay innerhalb des ersten scrollbaren Vorfahren des gezogenen Elements. |
| `snapToGrid(size \| options)` | Rastet an einem Raster ein: `{ x, y, origin: 'container' \| 'delta', smooth }`. `'container'` (Standard) legt die linke obere Ecke der Box auf Rasterlinien, die an der linken oberen Ecke des Containers beginnen; `'delta'` rundet den Versatz. `smooth` lässt das Overlay zwischen den Zellen gleiten. |
| `snapCenterToCursor` | Zentriert das Overlay unter dem Zeiger, statt den Greifversatz beizubehalten. |

## Kollisionserkennung {#collision-detection}

```ts
import { closestCorners } from '@vue-dnd-kit/core';
```

```vue
<DnDProvider :collision="closestCorners" />
```

Die Option `collision` des Providers wählt das Ziel; der beste Kandidat kommt zuerst.

| Funktion | Was sie wählt |
| --- | --- |
| `pointerFirst` | Standard: was unter dem Zeiger liegt, sonst das, was das Overlay überlappt. |
| `pointerWithin` | Ziele unter dem Zeiger, per Hit-Testing (z-Reihenfolge, Overlays und Shadow Roots werden berücksichtigt). |
| `rectIntersection` | Ziele, die das Overlay überlappen: höhere Priorität, dann tiefere Verschachtelung, dann Intersection over Union. |
| `closestCenter` | Jedes Ziel, nach dem Abstand zwischen den Mittelpunkten. |
| `closestCorners` | Jedes Ziel, nach der Summe der Abstände zwischen den Ecken (übereinanderliegende Ziele wie Kanban-Spalten). |
