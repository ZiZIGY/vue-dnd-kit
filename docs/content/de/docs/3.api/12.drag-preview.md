## DragPreview {#dragpreview}

```vue [StackOverlay.vue]
<script setup lang="ts">
import { DragPreview, type DragItem } from '@vue-dnd-kit/core';

defineProps<{ items: DragItem[] }>();
</script>

<template>
  <div class="stack">
    <DragPreview v-for="item in items.slice(0, 3)" :id="item.id" :key="item.id" />
  </div>
</template>
```

Klone werden beim Aufnehmen erstellt: vom gegriffenen Element und von bis zu vier weiteren, die
in Drop-Reihenfolge daneben liegen. Für jedes andere Element rendert `DragPreview` seinen
Default-Slot oder nichts. Jede Vorschau landet auf ihrem eigenen Element, wenn der Drop landet.
Siehe den Leitfaden [Das Overlay](/docs/guides/overlay).
