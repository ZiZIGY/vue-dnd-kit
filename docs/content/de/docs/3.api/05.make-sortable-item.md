```ts
function makeSortableItem<TData = unknown>(
  target: MaybeElementRef,
  options: SortableItemOptions<TData>,
): SortableItemReturn;
```

```ts
const el = useTemplateRef<HTMLElement>('el');
const { isPlaceholder, index } = makeSortableItem(el, { item: () => props.task, handle: '.grip' });
```

Rufe es in der Zeilenkomponente auf, die innerhalb des Elements der Liste gerendert wird.
Identifiziere die Zeile über `item` (mit dem Schlüssel aus `getKey` der Liste, standardmäßig `item.id`)
oder über `id`. Siehe [Sortierbare Listen](/docs/guides/sortable-lists).
