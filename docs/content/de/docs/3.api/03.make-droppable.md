```ts
function makeDroppable<TData = unknown>(
  target: MaybeElementRef,
  options?: DroppableOptions<TData>,
): DroppableReturn;
```

```ts
const zone = useTemplateRef<HTMLElement>('zone');
const { isOver, isAccepting } = makeDroppable(zone, {
  accept: 'image',
  onDrop: (e) => move(e.active.id),
});
```

Siehe [Drag and Drop](/docs/guides/drag-and-drop) und [Über einen Drop entscheiden](/docs/guides/drop-decisions).
