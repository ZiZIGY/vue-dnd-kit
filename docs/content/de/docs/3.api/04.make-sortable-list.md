::api-signature{name="makeSortableList"}
::

```ts
const list = useTemplateRef<HTMLElement>('list');
const { items } = makeSortableList(list, { items: tasks, group: 'board' });
```

Ihre Zeilen rufen [`makeSortableItem`](/docs/api/make-sortable-item) auf. Siehe
[Sortierbare Listen](/docs/guides/sortable-lists) und [Listen mit gemeinsamen Elementen](/docs/guides/shared-lists).
