## Flach gerendert {#rendered-flat}

Ein Baum wird als **flache Liste** der sichtbaren Knoten gerendert, der Reihe nach, jeder mit
seiner `depth`. Die Zeilen rückst du selbst ein. So bleibt jede Zeile ein Geschwisterelement in
einem einzigen Container, und die Zeilen gleiten und animieren wie die Zeilen einer Liste.

```vue [FileTree.vue]
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { makeSortableTree, type Key } from '@vue-dnd-kit/core';
import TreeRow from './TreeRow.vue';

interface FileNode { id: string; name: string; folder?: boolean; children?: FileNode[] }

const files = ref<FileNode[]>([
  { id: 'src', name: 'src', folder: true, children: [{ id: 'main', name: 'main.ts' }] },
  { id: 'readme', name: 'README.md' },
]);
const collapsed = ref(new Set<Key>());
const INDENT = 18;

const root = useTemplateRef<HTMLElement>('root');
const { items } = makeSortableTree(root, {
  items: files,                                  // the root nodes
  indentation: INDENT,                           // px per level: match your row padding
  collapsed,
  canNest: (_node, parent) => !!parent.folder,   // only folders take children
});

const toggle = (key: Key) => (collapsed.value.has(key) ? collapsed.value.delete(key) : collapsed.value.add(key));
</script>

<template>
  <div ref="root">
    <TreeRow v-for="node in items" :key="node.key" :node="node" :indent="INDENT" @toggle="toggle" />
  </div>
</template>
```

```vue [TreeRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode, type Key } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const emit = defineEmits<{ toggle: [key: Key] }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { id: () => props.node.key });
</script>

<template>
  <div ref="el" :style="{ paddingLeft: `${node.depth * indent}px` }">
    <button
      v-if="node.item.folder"
      type="button"
      :aria-expanded="!node.collapsed"
      :aria-label="node.collapsed ? 'Expand' : 'Collapse'"
      @click="emit('toggle', node.key)"
    >
      {{ node.collapsed ? '▸' : '▾' }}
    </button>
    {{ node.item.name }}
  </div>
</template>
```

Zeilen nutzen `makeSortableItem`, wie die Zeilen einer Liste. `items` enthält `FlatNode`s:

| `FlatNode`-Feld | Was es enthält |
| --- | --- |
| `key` | Der Schlüssel des Knotens (`getKey`, Standard `node.id`). Nutze ihn für `:key` und die `id` der Zeile. |
| `item` | Dein Knoten. |
| `depth` | `0` für Wurzeln. Die Tiefe des gezogenen Knotens ist die, auf der er landen **würde**, deshalb rückt sein Slot live ein. |
| `parentKey` | Der Schlüssel des Elternknotens, `null` für Wurzeln. |
| `index` | Der Index unter seinen Geschwistern. |
| `hasChildren`, `collapsed` | Für den Aufklapp-Button. |

Kinder werden aus `node.children` gelesen und dorthin geschrieben. Für andere Formen gibt es
`getChildren` und `setChildren`:

```ts
makeSortableTree(root, {
  items: outline,
  getKey: (node) => node.uuid,
  getChildren: (node) => node.nested,
  setChildren: (node, children) => { node.nested = children; },
});
```

## Verschachteln {#nesting}

Ein Drag ändert die Tiefe auf zwei Arten, beide standardmäßig an (`nesting: 'both'`):

- **Seitwärts** (`'offset'`): Ziehe um `indentation` Pixel nach links oder rechts, um eine Ebene
  hoch- oder herunterzugehen, so weit es die Zeilen um den Slot zulassen.
- **Halten** (`'hover'`): Halte den Drag über der Mitte einer Zeile, und der Drop geht in sie
  hinein, als ihr erstes Kind.

Setze `indentation` auf das Padding, das deine Zeilen pro Ebene hinzufügen, damit der Versatz dem
Zeiger folgt. Mit `axis: 'y'` kann sich der Drag nicht seitwärts bewegen, aber Zeilen lassen sich
weiterhin durch Halten verschachteln.

## Eingeklappte Knoten {#collapsed-nodes}

`collapsed` ist ein `Set` von Schlüsseln, deren Kinder verborgen sind (ein Ref oder ein Getter).
Ihre Kinder sind nicht in `items`. Ein gezogener Ordner nimmt seinen ganzen Teilbaum mit,
eingeklappt oder nicht. Ist die Option `animate` des Baums an, werden die Zeilen, die ein Ordner
zeigt oder verbirgt, animiert ein- und ausgeblendet.

## Regeln {#rules}

| Option | Begrenzt |
| --- | --- |
| `canNest(node, parent)` | Ob `node` unter `parent` darf. Ein Multi-Drag fragt für jeden gezogenen Knoten. |
| `maxDepth` | Die tiefste erlaubte Tiefe, wobei Wurzeln `0` sind. Die Nachfahren des gezogenen Knotens zählen mit: Ein Ordner mit Kindern und Enkeln geht höchstens auf Tiefe `maxDepth - 2`. |
| `group.put` | Ob der Baum überhaupt Elemente aus anderen Listen und Bäumen annimmt. |
| `onBeforeDrop` | Alles andere, entschieden beim Drop: siehe [Über einen Drop entscheiden](/docs/guides/drop-decisions). |

Lehnt eine Regel eine Tiefe ab, nimmt der Slot die tiefste Tiefe, die erlaubt ist. Wo keine
erlaubt ist, bewegt sich der Slot nicht dorthin. Auch Kopien und Knoten aus `createItem` folgen
`canNest` und `maxDepth`.

## Bäume und Listen in einer Gruppe {#trees-and-lists-in-one-group}

Ein Baum und eine Liste mit derselben `group` tauschen Knoten aus, so wie zwei Listen. Ein Ordner,
der in die Liste verschoben wird, behält seinen Teilbaum und kommt mit ihm zurück. Kopien
funktionieren wie in Listen (`clone`, `pull: 'clone'`, die Alt-Taste), aber `clone` muss die
Kopie **mit ihrem ganzen Teilbaum** zurückgeben, und jeder Knoten darin braucht einen neuen
Schlüssel:

```ts
let count = 0;
const copyNode = (node: FileNode): FileNode => ({
  ...node,
  id: `${node.id}-${++count}`,
  children: node.children?.map(copyNode),
});

makeSortableTree(root, { items: files, group: 'files', clone: copyNode });
```

Zu Gruppen, Kopieren und `createItem` siehe
[Listen mit gemeinsamen Elementen](/docs/guides/shared-lists).

## Eine Einfügelinie {#an-insertion-line}

Mit `placeholder: 'indicator'` bewegt sich der Baum beim Ziehen nicht. Jede Zeile liest ihren
`indicator` und zeichnet die Linie, eingerückt auf die Tiefe, in der der Drop landet:

```vue [TreeRow.vue]
<script setup lang="ts">
import { computed, useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const el = useTemplateRef<HTMLElement>('el');
const { indicator } = makeSortableItem(el, { id: () => props.node.key });

// 'inside': the drop goes into this row. Otherwise a line before or after it.
const into = computed(() => indicator.value?.side === 'inside');
const line = computed(() => {
  const value = indicator.value;
  if (!value || value.side === 'inside') return null;
  return { side: value.side, left: `${(value.depth ?? 0) * props.indent}px` };
});
</script>

<template>
  <div ref="el" class="row" :class="{ into }" :style="{ paddingLeft: `${node.depth * indent}px` }">
    {{ node.item.name }}
    <span v-if="line" class="line" :class="line.side" :style="{ left: line.left }" />
  </div>
</template>

<style scoped>
.row { position: relative; }
.row.into { background: color-mix(in srgb, #42b883 15%, transparent); }
.line { position: absolute; right: 0; height: 2px; background: #42b883; }
.line.before { top: -1px; }
.line.after { bottom: -1px; }
</style>
```

In Bäumen kommen bei `indicator` noch `depth` und `parentKey` hinzu: die Ebene und der
Elternknoten, die die abgelegten Knoten bekommen. Seitliches Ziehen bewegt die Linie zwischen den
Ebenen. In diesem Modus bricht ein Drop außerhalb des Baums ab.

## Der Drop {#the-drop}

Das Drop-Event des Baums ist das einer Liste, mit `parentKey` zusätzlich in `from` und `to`:

```ts
makeSortableTree(root, {
  items: files,
  onDrop: (e) => {
    console.log(e.keys, e.from.parentKey, '→', e.to.parentKey, e.to.index);
  },
});
```

`to.index` ist die Position unter den neuen Geschwistern, gezählt, nachdem der Knoten seinen alten
Platz verlassen hat. Beim Drop gibt die Bibliothek den geänderten Knoten ihre neuen Kinder
(`setChildren`) und schreibt ein neues Wurzel-Array in dein Ref.

`e.result.get(treeId)` ist der neue Baum als neues Wurzel-Array: Die Knoten auf den geänderten
Pfaden sind Kopien, unberührte Teilbäume werden geteilt, und deine Knoten bleiben, wie sie sind.
Für einen Store oder unveränderliche Daten übergib einen Getter, rufe `e.preventDefault()` auf und
speichere `e.result`. Kopien entstehen mit `withChildren(node, children)`, standardmäßig
`{ ...node }` mit den neuen Kindern; übergib für Klasseninstanzen eine eigene Funktion.

## Tastatur und Multi-Drag {#keyboard-and-multi-drag}

Mit der Tastatur bewegen :kbd{value="ArrowUp"} und :kbd{value="ArrowDown"} zwischen den Zeilen,
:kbd{value="ArrowLeft"} und :kbd{value="ArrowRight"} ändern die Tiefe, wo die umliegenden Zeilen
es zulassen.

Ausgewählte Knoten bewegen sich gemeinsam als ein Block, jeder mit seinem Teilbaum, in
Dokumentreihenfolge. Ein ausgewählter Knoten innerhalb eines anderen ausgewählten fährt im
Teilbaum seines Elternknotens mit. Siehe [Multi-Drag und Auswahl](/docs/guides/multi-drag).

Alle Optionen stehen in der [makeSortableTree-API](/docs/api/make-sortable-tree). Für Bäume mit
Tausenden von Zeilen siehe [Virtuelle Listen](/docs/guides/virtual-lists).
