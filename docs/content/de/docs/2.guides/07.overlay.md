Während du ziehst, folgt eine Box dem Zeiger: das **Overlay**. Das gezogene Element selbst bleibt,
wo es war, als der Slot, in dem es landen wird. Beim Drop fliegt das Overlay zu diesem Slot und
verschwindet.

Das Overlay wird nach `body` teleportiert, außerhalb deiner Komponenten. Standardmäßig zeigt es
einen Klon des gezogenen Elements.

::example{name="overlay" hint="Ziehe eine Nachricht: Die Kopie bekommt den Hintergrund des Posteingangs" height="24rem"}
::

## Der Standard-Klon {#the-default-clone}

Der Klon wird beim Aufnehmen erstellt, bevor sich etwas bewegt. Er ist eine tiefe Kopie des
Elements:

- Formularwerte und die Pixel von `<canvas>` werden kopiert.
- Die berechneten Styles, die das Element außerhalb seiner Liste verlieren würde, werden inline
  gesetzt: geerbte Schriften und Farben, Styles, die über Vorfahren greifen (`.list li { … }`),
  Breiten von Tabellenzellen. Eine Tabellenzeile kommt in einer eigenen Tabelle verpackt.
- `id`s und `data-dnd-*`-Attribute werden entfernt, und der Klon ist `aria-hidden`.
- Ripple-Effekte und andere Effekte beim Drücken aus UI-Kits (Vuetify, Quasar, PrimeVue, Naive UI)
  werden weggelassen.

Markiere alles andere, was nicht mitreisen soll, mit **`data-dnd-no-clone`**: einen Menü-Button,
einen Tooltip, ein Badge.

```vue
<li ref="el" class="mail-row">
  {{ mail.subject }}
  <button type="button" aria-label="Archive" data-dnd-no-clone>…</button>
</li>
```

### Hintergründe werden nicht erraten {#backgrounds-arent-guessed}

Der Klon zeigt das Element, wie es ist. Eine Zeile ohne eigenen Hintergrund, weil ihre Liste ihn
malt (ein `<li>` in einem weißen `<ul>`, ein `v-list-item`, eine Tabellenzeile), ergibt einen
**durchsichtigen** Klon. Gib ihm per CSS den Hintergrund der Liste:

```vue [MailRow.vue]
<style scoped>
[data-dnd-overlay] .mail-row {
  background: var(--surface);
}
</style>
```

Der Klon behält die Klassen und Attribute des Elements, einschließlich des Scope-Attributs von Vue,
deshalb funktioniert die Regel im Scoped Style der Zeile ebenso wie in einem globalen Stylesheet.
Der andere Ausweg ist ein Hintergrund an der Zeile selbst. Icons und Kacheln, die schweben sollen,
wie die App-Icons in [Sortierbare Listen](/docs/guides/sortable-lists), bleiben absichtlich
transparent.

## Die Box stylen {#styling-the-box}

Die Box ist das Element mit `data-dnd-overlay`. Sie hat `position: fixed` und
`pointer-events: none`, und der Wert des Attributs sagt, was sie gerade tut:

| `data-dnd-overlay` | Wann |
| --- | --- |
| `"dragging"` | Sie folgt dem Zeiger. |
| `"dropping"` | Sie landet auf ihrem Slot, fliegt zurück oder wartet auf ein asynchrones `onBeforeDrop`. |

Ein angehobener Look beim Ziehen, der beim Landen verschwindet:

```css
[data-dnd-overlay='dragging'] .mail-row {
  box-shadow: 0 18px 32px -14px rgb(0 0 0 / 0.5);
}
```

## Overlay-Komponenten {#overlay-components}

Um etwas anderes als den Klon zu zeigen, übergib eine Komponente. Sie wird in der Box gerendert:

```vue [CardOverlay.vue]
<script setup lang="ts">
import type { OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <!-- Fill the box: it resizes to the slot and animates on drop. -->
  <div class="card-overlay" :class="{ refused: over && !accepted }">
    {{ (items[0]?.item as Task).title }}
    <small v-if="mode === 'copy'">+ copy</small>
    <span v-if="items.length > 1" class="count">{{ items.length }}</span>
  </div>
</template>

<style scoped>
.card-overlay { width: 100%; height: 100%; }
</style>
```

```ts
import CardOverlay from './CardOverlay.vue';

makeSortableList(listRef, { items: tasks, overlay: CardOverlay });          // every item of the list
makeSortableItem(el, { item: () => props.task, overlay: CardOverlay });      // this item
makeDraggable(el, { id: 'chip', overlay: CardOverlay });                     // a plain draggable
```

| `OverlayProps` | Was es enthält |
| --- | --- |
| `active` | Der Drag (`id`, `ids`, `data`, `type`, …). |
| `items` | Jedes gezogene Element, das gegriffene zuerst: `{ id, item, data, type }`. `item` ist bei sortierbaren Drags das Listenelement. |
| `over` | Das Ziel unter dem Drag oder, beim Drop, das, auf dem es landet. `null` über nichts und während ein abgebrochener Drag zurückfliegt. |
| `accepted` | Ob `over` den Drag annimmt: Färbe das Overlay rot, wenn nicht. |
| `status` | `'dragging'` oder `'dropping'`. |
| `mode` | `'move'`, `'copy'`, `'swap'` oder `'insert'`. |

Eine Komponente kann direkt übergeben werden oder in einem `shallowRef`, um sie auszutauschen.
Lege sie nie in ein tiefes `ref` oder `reactive`: Vue würde die Komponente reaktiv machen und
warnen.

Das App-Raster aus [Sortierbare Listen](/docs/guides/sortable-lists) nutzt eine: Das Icon reist
allein und hebt sich an, und der Name bleibt zurück.

## Der `#overlay`-Slot des Providers {#the-providers-overlay-slot}

Für jeden Drag ohne eigene Komponente rendert der Slot des Providers das Overlay:

```vue [App.vue]
<DnDProvider>
  <RouterView />
  <template #overlay="{ items, mode, accepted }">
    <CardOverlay v-if="items[0]?.type.includes('card')" v-bind="{ items, mode, accepted }" />
  </template>
</DnDProvider>
```

Der Slot bekommt dieselben Props wie eine Overlay-Komponente. Rendert er nichts (das `v-if` oben),
fällt der Drag auf den Klon zurück.

## Was gewinnt {#what-wins}

Für jeden Drag gilt das Erste, das zutrifft:

1. Das eigene `overlay` des Elements (`makeSortableItem`, `makeDraggable`).
2. Das `overlay` seiner Liste oder seines Baums.
3. Der `#overlay`-Slot des Providers, außer er rendert nichts.
4. Der Standard-Klon. Beim Multi-Drag eine Spalte oder ein Stapel von Klonen: siehe
   [Multi-Drag und Auswahl](/docs/guides/multi-drag#the-default-overlay).

Die Komponente wird gewählt, wenn der Drag beginnt, und für den ganzen Drag beibehalten, auch über
anderen Listen.

## `DragPreview`: der Klon in deinem Layout {#dragpreview-the-clone-in-your-layout}

`DragPreview` rendert den Klon der Bibliothek für ein gezogenes Element. Nutze es in einer
Overlay-Komponente, die mehrere Elemente selbst anordnet oder einen Rahmen um den Klon legt:

```vue [CopyOverlay.vue]
<script setup lang="ts">
import { DragPreview, type OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <div class="with-badge">
    <DragPreview :id="active.id" :style="{ width: '100%', height: '100%' }" />
    <span v-if="mode === 'copy'" class="badge">+</span>
  </div>
</template>
```

Klone gibt es für das gegriffene Element und bis zu vier weitere daneben; für jedes andere Element
rendert `DragPreview` seinen Default-Slot. Einen Stapel von Vorschauen zeigt
[Multi-Drag und Auswahl](/docs/guides/multi-drag#a-custom-overlay-for-several-items).

## Größe: `overlayFit` {#size-overlayfit}

| `overlayFit` (Provider) | Die Box |
| --- | --- |
| `'slot'` (Standard) | Nimmt die Größe des Slots an, in dem sie landen wird. Über einer Liste mit breiteren Karten wird sie breiter. |
| `'source'` | Behält die Größe des gezogenen Elements. |

Bei `'slot'` ändert die Box ihre Größe um den Zeiger herum, der an derselben relativen Stelle der
Box bleibt. Der Inhalt wird nie skaliert: Er ordnet sich in der neuen Größe neu an.

Ein Drop macht bei beiden Einstellungen dasselbe: Die Box fliegt zu dem Element, auf dem sie
landet, und animiert zu **dessen** Größe, und der Inhalt ordnet sich unterwegs neu an. Sieht ein
Element in zwei Listen unterschiedlich aus (ein kompakter Chip in einer Palette, eine volle Karte
auf einem Board), ordnet sich der Klon der Quelle in der Größe des Ziels neu an und kann dort
gequetscht oder gestreckt aussehen. Zwei Wege, damit es stimmt:

- Gib dem Element in jeder Liste, in der es landen kann, den **gleichen Look**. Die Dateien in
  [Drag and Drop](/docs/guides/drag-and-drop) haben in jedem Ordner eine feste Größe, deshalb
  bewegt ein Drop sie nur.
- Rendere den **Look des Ziels** in einer Overlay-Komponente. Sie bekommt `over`, kann also zum
  Look der Liste wechseln, über der sie ist, und füllt die Box in jeder Größe.

Eine feste Größe am Root-Element einer Overlay-Komponente bleibt in der Box erhalten. Gib dem Root
`width: 100%; height: 100%`, damit es der Box folgt.

## Wo es gerendert wird: `overlayTo` {#where-it-renders-overlayto}

Der Provider teleportiert das Overlay nach `body`. In einem `<dialog>`, das mit `showModal()`
geöffnet wurde, oder in einem Shadow Root läge das Overlay unter dem Top Layer oder außerhalb der
Styles. Richte `overlayTo` auf einen Selektor oder ein Element dort:

```vue
<DnDProvider overlay-to="#dialog-overlay">
```

## Kein Overlay {#no-overlay}

`makeDraggable(el, { overlay: false })` hat überhaupt keine Box: Das Element selbst bewegt sich,
über das zurückgegebene `transform`. Siehe
[Drag and Drop](/docs/guides/drag-and-drop#without-an-overlay). Wie die Box landet, bestimmt
`dropAnimation` des Providers: siehe [Animationen](/docs/guides/animations).
