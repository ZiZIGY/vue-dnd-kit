Ziehe eine Kachel, dann mische, füge hinzu und entferne einige. Sortieren und Drop sind
standardmäßig animiert; die Änderungen durch die Buttons werden animiert, weil das Raster
`animate` einschaltet.

::example{name="animate" hint="Ziehen, mischen, hinzufügen, entfernen" height="22rem"}
::

## Drei Animationen {#three-animations}

| Option | Wo | Standard | Was sie animiert |
| --- | --- | --- | --- |
| `animation` | Provider, Liste, Baum | an, 200 ms | Elemente, die beim Sortieren, beim Drop und beim Abbrechen an ihre neuen Plätze gleiten. |
| `dropAnimation` | Provider | an, 250 ms | Das Overlay, das auf seinem Slot landet oder beim Abbrechen zurückfliegt. |
| `animate` | Provider, Liste, Baum | **aus** | Änderungen deiner Daten, die kein Drag ausgelöst hat: hinzugefügte, entfernte, verschobene oder gefilterte Elemente, Baumzeilen, die erscheinen oder verschwinden. |

Jede nimmt `true` (das Standard-Timing), `false` (aus), `{ duration, easing }` oder eine Funktion,
mit der du selbst animierst.

```vue
<DnDProvider
  :animation="{ duration: 180, easing: 'cubic-bezier(.2, .8, .2, 1)' }"
  :drop-animation="{ duration: 300 }"
>
```

Die eigenen `animation` und `animate` einer Liste oder eines Baums haben Vorrang vor denen des
Providers.

## Sortieren {#sorting}

Während du ziehst, ordnet sich der Entwurf neu, und die Elemente gleiten an ihre neuen Plätze: FLIP
auf der CSS-Eigenschaft `translate`, über die Web Animations API. `translate` lässt sich mit jedem
deiner `transform` kombinieren, deshalb bleibt die Positionierung der Zeilen einer virtuellen Liste
intakt. Bewegt sich ein Element erneut, bevor seine Animation endet, startet die nächste dort, wo
es gerade angezeigt wird.

::warning
Umschließe sortierbare Elemente nicht mit `<TransitionGroup>`: Jede Bewegung würde doppelt
animiert. Für Änderungen, die kein Drag ausgelöst hat, schalte `animate` ein.
::

## Der Drop {#the-drop}

Beim Drop fliegt das Overlay von dort, wo du loslässt, zum Slot des Elements; beim Abbrechen
zurück dorthin, wo das Element begann. Hat das Element nach dem Drop keinen sichtbaren Slot –
weggescrollt oder in einen Ordner oder eine Papierkorb-Zone abgelegt –, blendet das Overlay
stattdessen aus und schrumpft dabei in die Zone, auf der es abgelegt wurde.

Das Overlay nimmt außerdem schon beim Ziehen die Größe des Slots an, in dem es landen wird
(`overlayFit: 'slot'`, der Standard), deshalb braucht der Drop keine Größenänderung. `'source'`
behält die Größe des gezogenen Elements. Siehe [Das Overlay](/docs/guides/overlay).

## Datenänderungen: animate {#data-changes-animate}

```ts
makeSortableList(listRef, { items: swatches, animate: true });
```

`animate` ist standardmäßig aus und animiert, was dein Array ohne Drag ändert: ein Sortieren, ein
Mischen, eine Verschiebung zwischen Listen einer Gruppe, ein hinzugefügtes, entferntes oder
herausgefiltertes Element. In einem Baum deckt es auch die Zeilen ab, die ein Knoten beim Auf- und
Zuklappen zeigt oder verbirgt. `<DnDProvider animate>` schaltet es für jede Liste und jeden Baum
ein.

Seine Teile lassen sich einzeln einstellen:

```ts
animate: { duration: 250, move: true, enter: true, leave: { duration: 150 } },
```

| Teil | Standardmäßig |
| --- | --- |
| `move` | Elemente, die ihren Platz gewechselt haben, gleiten, wie bei `animation`. |
| `enter` | Elemente, die erschienen sind, blenden dort ein, wo sie sind. |
| `leave` | Eine Kopie des Elements, das gegangen ist, blendet dort aus, wo es war, und schrumpft dabei ein wenig. Sie ist mit `data-dnd-leaving` markiert und wird entfernt, wenn sie fertig ist. |

`duration` und `easing` gelten für jeden Teil; jeder Teil nimmt `true`, Optionen, `false` oder eine
Funktion. Nur Elemente nahe dem sichtbaren Bereich werden animiert, deshalb werden Zeilen
übersprungen, die eine virtuelle Liste nicht gemountet hat. Die Option wird gelesen, wenn sich
`items` ändert, deshalb kann ein Ref sie umschalten, wie es der Schalter im Beispiel tut.

## Eigene Animationen {#your-own-animations}

Jede Option nimmt auch eine Funktion. Sie bekommt einen Kontext, startet die Animation und gibt
ihre `Animation` zurück, ein Promise, das abgeschlossen ist, wenn sie endet, oder nichts.

```ts
// animation, animate.move: an item moved from `from` to `to`
({ key, element, from, to, options, reason, signal, reducedMotion }) => Animation | Promise | void
// dropAnimation: `to` is null when there is no visible slot; `into` is the zone it went into
({ overlay, from, to, into, reason, active, options, reducedMotion }) => …
// animate.enter: the element is already in place
({ key, element, to, options, reducedMotion }) => …
// animate.leave: `element` is a copy where the item was, removed when you finish
({ key, element, from, options, reducedMotion }) => …
```

Eine Layout-Funktion mit der Web Animations API, ganz ohne Bibliothek:

```ts
import type { LayoutAnimationContext } from '@vue-dnd-kit/core';

const springy = ({ element, from, to, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  return element.animate(
    [{ translate: `${from.left - to.left}px ${from.top - to.top}px` }, { translate: '0 0' }],
    { duration: 400, easing: 'cubic-bezier(.34, 1.56, .64, 1)' },
  );
};
```

```vue
<DnDProvider :animation="springy">
```

Drei Regeln halten eigene Animationen im Takt mit der Bibliothek:

- **Animiere `translate`** von `from - to` auf null, nicht `transform`. Es lässt sich mit
  Transforms kombinieren, die virtuelle Listen oder dein CSS auf Zeilen setzen, und Drags messen
  Elemente ohne es.
- **Beachte `signal`.** Es bricht ab, wenn sich das Element erneut bewegt, bevor die Animation
  endet. Stoppe deine Animation und entferne ihre Styles sofort: Das Layout wird direkt danach
  gemessen. Eine zurückgegebene `Animation` wird für dich abgebrochen.
- **Beim Overlay animiere Position und Größe** (`width`, `height`), nie `scale`: Sein Inhalt
  ordnet sich in der neuen Größe neu an.

### GSAP {#gsap}

```ts [gsap-animations.ts]
import gsap from 'gsap';
import type {
  DropAnimationContext,
  EnterAnimationContext,
  LayoutAnimationContext,
  LeaveAnimationContext,
  Rect,
} from '@vue-dnd-kit/core';

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const tween = gsap.fromTo(
    element,
    { translate: `${from.left - to.left}px ${from.top - to.top}px` },
    { translate: '0px 0px', duration: 0.4, ease: 'power3.out' },
  );
  signal.addEventListener('abort', () => tween.revert());
  return tween.then();
};

const box = (rect: Rect) => ({ x: rect.left, y: rect.top, width: rect.width, height: rect.height });

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return gsap.to(overlay, { opacity: 0, duration: 0.2 }).then();
  return gsap.fromTo(overlay, box(from), { ...box(to), duration: 0.45, ease: 'back.out(1.2)' }).then();
};

const enter = ({ element, reducedMotion }: EnterAnimationContext) =>
  gsap.from(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.35 }).then();

const leave = ({ element, reducedMotion }: LeaveAnimationContext) =>
  gsap.to(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.25 }).then();

export const gsapAnimations = { animation: move, dropAnimation: drop, animate: { move, enter, leave } };
```

```vue
<DnDProvider v-bind="gsapAnimations">
```

### motion {#motion}

```ts [motion-animations.ts]
import { animate } from 'motion-v';
import type { DropAnimationContext, LayoutAnimationContext } from '@vue-dnd-kit/core';

const spring = { type: 'spring', duration: 0.45, bounce: 0.25 } as const;

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const controls = animate(
    element,
    { translate: [`${from.left - to.left}px ${from.top - to.top}px`, '0px 0px'] },
    spring,
  );
  signal.addEventListener('abort', () => {
    controls.stop();
    element.style.translate = '';
  });
  return controls.finished;
};

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return animate(overlay, { opacity: 0 }, { duration: 0.18 }).finished;
  return animate(
    overlay,
    { x: [from.left, to.left], y: [from.top, to.top], width: [from.width, to.width], height: [from.height, to.height] },
    spring,
  ).finished;
};
```

Die vollständigen Typen der Optionen stehen unter [Animationen](/docs/api/animations).

## Reduzierte Bewegung {#reduced-motion}

Mit `prefers-reduced-motion: reduce` laufen die eigenen Animationen der Bibliothek nicht: Elemente
und Overlay gehen direkt an ihre Plätze. Deine Funktionen laufen immer, mit `reducedMotion: true`,
und entscheiden selbst – die Bewegung weglassen oder ein kurzes Überblenden behalten, wie es die
Rezepte oben tun.

## Layoutänderungen, die nicht von der Bibliothek kommen {#layout-changes-the-library-didnt-cause}

Wenn während eines Drags etwas anderes Zeilen bewegt – ein Virtualizer, der neu misst, ein Bild,
das lädt –, rufe `captureLayout()` der Liste direkt vor dem Rendern der Änderung auf. Es misst die
Zeilen dort, wo sie sind, und animiert sie nach dem nächsten Rendern an ihre neuen Plätze.
Außerhalb eines Drags tut es nichts. Siehe [Virtuelle Listen](/docs/guides/virtual-lists).
