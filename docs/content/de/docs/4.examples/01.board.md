## Worauf du achten solltest {#what-to-look-at}

- **`Board.vue`**: Die Spalten sind eine eigene horizontale sortierbare Liste, und jede Spalte ist
  ein sortierbares Element, das an seinem Kopf gezogen wird (`handle`).
- **`Column.vue`**: Die Karten aller Spalten bilden eine `group`. `put` ist eine Funktion, die die
  eingehenden Karten zählt, sodass eine Spalte an ihrem WIP-Limit den Drag ablehnt und der Slot
  an seinem Platz bleibt. Ein asynchrones `onBeforeDrop` fragt nach, bevor eine Karte in Done
  kommt, und antwortet mit `'accept'`, `'reject'` oder `'continue'` (weiterziehen).
- **`Card.vue`**: `selected` aus `makeSortableItem`, an Strg/Cmd-Klick gebunden: Ein Multi-Drag
  verschiebt die ganze Auswahl.
- **`Trash.vue`**: ein einfaches Drop-Ziel, das nur Karten annimmt (`accept: 'card'`) und sie mit
  `e.source.remove()` entfernt.
- **`CardOverlay.vue`**: die Overlay-Komponente der Karten (das `overlay` der Liste), gebaut aus
  `DragPreview`-Klonen: Die Karte neigt sich während des Ziehens, der Rest einer Auswahl stapelt
  sich darunter, und beim Landen richtet sie sich wieder auf (`status`).
