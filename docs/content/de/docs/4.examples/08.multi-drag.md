## Worauf du achten solltest {#what-to-look-at}

- **`Gallery.vue`**: `makeSelectionArea` auf dem Bereich um das Raster; er füllt seine Box aus,
  sodass ein Rahmen überall darauf beginnen kann. Rendere den Rahmen anhand von `isSelecting` und
  `style`.
- **`Shot.vue`**: `selected` ist an die Auswahl des Providers gebunden; Strg/Cmd-Klick schaltet
  sie um.
- In einem Raster ist das Overlay eines Multi-Drags ein Stapel: das gegriffene Foto oben, ein paar
  andere dahinter, die Anzahl darauf.
