## Worauf du achten solltest {#what-to-look-at}

- **`FileTree.vue`**: `makeSortableTree` mit `indentation`, `collapsed` und
  `canNest: (_node, parent) => !!parent.folder` – nur Ordner nehmen Kinder auf.
- **`TreeRow.vue`**: Jede Zeile ist ein sortierbares Element mit `node.key` als Schlüssel; ihr linkes
  Padding folgt `node.depth`, auch während des Ziehens, sodass der Slot die Tiefe zeigt, die der
  Drop annehmen wird.
