## Worauf du achten solltest {#what-to-look-at}

- **`Shape.vue`** und **`Artboard.vue`**: Jede Ebene ist ein einfaches ziehbares Element, und ein
  Frame wird an seinem Namen gezogen (`handle`), mit seinen Ebenen darin. Ein Drücken wählt
  sofort aus, wie in Figma, also nimmt ein Drag die Auswahl des Providers mit: Drücke auf eine von
  mehreren ausgewählten Ebenen, und alle bewegen sich.
- **`useLayerDrop.ts`**: Die Leinwand und jeder Frame sind Drop-Ziele, die gleich funktionieren.
  Eine über einem Frame losgelassene Ebene wandert in ihn hinein; über der Leinwand aus ihm
  heraus. Halte :kbd{value="Alt"}, und stattdessen landen Kopien, während die Ebenen bleiben, wo
  sie waren.
- **`LayersPanel.vue`**: Das Panel ist `makeSortableTree` auf dem Design selbst. Die Reihenfolge
  der Zeilen ist die Stapelreihenfolge, und eine Zeile in einen Frame abzulegen verschiebt die
  Ebene in diesen Frame.
- **`Canvas.vue`**: Die Smart Guides sind ein eigener Modifier der Demo; `makeSelectionArea`
  zeichnet den Auswahlrahmen, und `makeDragArea` gibt jedem Drag, der auf der Leinwand startet,
  seine Regeln.
- **`editor.ts`**, **`geometry.ts`** und **`design.ts`**: das Design, sein Verlauf, die Ansicht und
  die Mathematik des Einrastens und Ausrichtens, ganz ohne Drag and Drop.

## Im Zoom gezeichnet {#drawn-at-the-zoom}

Die Leinwand zoomt ohne CSS-`scale()`: Jede Ebene wird in ihrer Größe mal dem Zoom angeordnet, in
Bildschirmpixeln. Was die Bibliothek misst, ist dann das, was auf dem Bildschirm ist, also
brauchen die Drop-Ziele, der Auswahlrahmen und die Klone im Overlay nichts Besonderes. Die Welt in
der Leinwand wird allein durch das Verschieben der Ansicht bewegt, mit `translate()`.

```ts [Shape.vue]
const style = computed(() => {
  const { zoom } = editor.view;
  const { x, y, width, height } = props.shape;
  return { left: `${x * zoom}px`, top: `${y * zoom}px`, width: `${width * zoom}px`, height: `${height * zoom}px` };
});
```

Das Mausrad verschiebt und zoomt (:kbd{value="Ctrl"} oder ein Pinch), ebenso Ziehen mit
:kbd{value="Space"}, das Hand-Werkzeug und die Buttons in der Ecke: einfache Zeiger- und
Mausrad-Events, wie auch die Resize-Handles. Da Space die Hand ist, nimmt allein
:kbd{value="Enter"} eine Ebene auf (`keyboard.keys` des Providers).

## Ebenen zwischen Frames verschieben {#moving-layers-between-frames}

Eine Ebene ist ein einfaches ziehbares Element mit einem eigenen Overlay, `DragGroup.vue`. Es legt
die gezogenen Ebenen so aus, wie sie liegen: eine `DragPreview` (der beim Aufnehmen angelegte
Klon) von jeder, platziert aus dem `data` ihrer Ebene, dort, wo sie gezeichnet ist. Die Ebenen
selbst treten zur Seite, während sich ihre Klone bewegen, außer :kbd{value="Alt"} wird gehalten.

```ts [Shape.vue]
const { isDragging, selected } = makeDraggable(el, {
  id: () => props.shape.id,
  type: 'layer',
  data: () => editor.dragData(props.shape), // { layer, left, top }
  overlay: DragGroup,
});
```

Beim Drop ist `position` die Stelle im Ziel, an der die Ecke der gegriffenen Ebene losgelassen
wurde, in Bildschirmpixeln. Durch den Zoom geteilt, sagt sie, wie weit diese Ebene in der Welt
gewandert ist, und jede gezogene Ebene wandert genauso weit, in den Frame oder auf die Leinwand:

```ts [useLayerDrop.ts]
const corner = target ? editor.boxOf(target) : { x: -view.x / view.zoom, y: -view.y / view.zoom };
const toWorld = (x: number, y: number) => ({ x: corner.x + x / view.zoom, y: corner.y + y / view.zoom });

const from = editor.boxOf(grabbed); // the layer of `active.id`
const to = toWorld(position.x, position.y);
editor.move(active.ids, { x: to.x - from.x, y: to.y - from.y }, target, editor.altHeld.value);
```

Ein Frame nimmt Ebenen an, keine Frames: Ein Drag, der einen Frame trägt, geht über die anderen
Frames hinweg (`disabled`, live gelesen) auf die Leinwand. Die Ziele haben `dropAnimation: false`,
da die Ebenen genau dort erscheinen, wo ihre Klone losgelassen wurden. Werkzeuge in der
Werkzeugleiste sind ebenfalls einfache ziehbare Elemente: Auf einem Frame abgelegt, fügen sie ihre
Ebene in ihn ein, zentriert auf den Drop-Punkt; angeklickt, in der Mitte der Ansicht.

```ts [Artboard.vue]
makeDroppable(body, {
  id: () => props.frame.id,
  accept: 'layer',
  disabled: () => !!active.value?.items.some((item) => item.type.includes('frame')),
  dropAnimation: false,
  onDrop: useLayerDrop(() => props.frame),
});
```

## Smart Guides {#smart-guides}

`smartGuides` ist ein Modifier: Er bekommt den Versatz des Drags, rechnet aus, wo die gezogenen
Ebenen in der Welt wären, und zieht sie auf die nächste Kante oder Mitte einer anderen Ebene
innerhalb von 6 Bildschirmpixeln. Das Overlay, das Ziel darunter und der Drop folgen alle. Ein
Monitor zeichnet die pinken Linien und die Abstände aus dem `delta` des Drags, dem Versatz nach
den Modifiern.

```ts [Canvas.vue]
const smartGuides: Modifier = ({ transform, active }) => {
  const moving = editor.boundsOf(active.ids);
  if (!moving) return transform; // a tool from the toolbar
  const { zoom } = view;
  const box = offsetBox(moving, transform.x / zoom, transform.y / zoom);
  const targets = editor.snapTargets(active.ids);
  return {
    x: transform.x + snapBox(box, targets, 'x', SNAP / zoom) * zoom,
    y: transform.y + snapBox(box, targets, 'y', SNAP / zoom) * zoom,
  };
};

// Every drag that starts on the canvas, frames and layers alike, gets the guides.
makeDragArea(viewport, { modifiers: [smartGuides], disabled: panning });
```

Die Resize-Handles rasten an denselben Linien ein und zeichnen dieselben Hilfslinien.

## Auswählen {#selecting}

Ein auf der leeren Leinwand gezogener Auswahlrahmen wählt Frames und lose Ebenen aus; in einem
Frame gezogen, die Ebenen des Frames. Beide sind `makeSelectionArea`: Der innerste Bereich nimmt
das Drücken und besitzt die ziehbaren Elemente darin. :kbd{value="Shift"} fügt zur Auswahl hinzu
(`strategy: 'toggle'`).

```ts [Artboard.vue]
const { isSelecting, style: band } = makeSelectionArea(body, {
  strategy: () => (editor.shiftHeld.value ? 'toggle' : 'select'),
  disabled: editor.panning,
});
```

Der Editor wählt nie einen Frame zusammen mit einer Ebene darin aus: Gezogen, würde sich die Ebene
doppelt bewegen. Ein Rahmen fängt den Zeiger ein, wenn er startet, ein Klick auf die leere Fläche
eines Frames erreicht den Frame also nie: `Artboard.vue` wählt den Frame aus, wenn ein Drücken
dort an derselben Stelle losgelassen wird, an der es begann.

## Das Ebenen-Panel {#the-layers-panel}

Die Elemente des Baums sind das Design: Frames mit ihren `children`, die oberste Zeile vorn.
`canNest` lässt Frames Ebenen annehmen und hält Frames auf der obersten Ebene. Zeilen haben eigene
Schlüssel (`row:…`), da die IDs der Ebenen ihren ziehbaren Elementen auf der Leinwand gehören; die
Auswahl ist die der Leinwand, eine Zeile leuchtet also mit ihrer Ebene auf.

```ts [LayersPanel.vue]
makeSortableTree(tree, {
  items: editor.layers,
  getKey: (layer) => `row:${layer.id}`,
  canNest: (layer, parent) => parent.kind === 'frame' && layer.kind !== 'frame',
  maxDepth: 1,
  animate: true,
  onDrop: ({ items, from, to }) => {
    // Positions count from the frame's corner: a layer changing frames takes the
    // difference, so it stays where it is on the canvas.
  },
});
```

`onDrop` läuft, bevor der Baum geschrieben wird, der Editor weiß also noch, aus welchem Frame jede
Ebene kommt, und sichert das Design für Undo. Eine Ebene, die in einen Frame verschoben wird, der
sie nicht abdeckt, würde unsichtbar abgeschnitten: Sie kommt stattdessen in die Mitte des Frames.
Mit `animate` gleiten Zeilen auch bei Änderungen auf der Leinwand und durch Undo. Eine Zeile hat
einen Typ (`type: 'row'`), also lehnen die Leinwand und die Frames, die Ebenen und Werkzeuge
annehmen, sie ab.

## Tastatur {#keyboard}

Springe mit Tab zu einer Ebene (sie wird ausgewählt), dann nimmt :kbd{value="Enter"} sie auf, die
Pfeile bewegen sie um 10 Pixel (:kbd{value="Shift"}: 40), und :kbd{value="Enter"} legt sie in dem
Frame darunter ab. Ohne Drag schieben die Pfeile die Auswahl um ein Pixel. Ein Werkzeug wird
genauso aufgenommen, und seine Pfeile springen zwischen der Leinwand und den Frames
(`keyboard: 'droppables'`). Die anderen Tastenkürzel stehen im Design-Panel, wenn nichts
ausgewählt ist.
