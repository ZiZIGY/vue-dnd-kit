Jedes Beispiel ist eine kleine Vue-App: eine `index.vue` mit ihrem `DnDProvider` und den
Komponenten, die sie braucht. Die Code-Tabs unter einer Demo sind genau die Dateien, die sie
ausführen.

## Apps {#apps}

Ganze Oberflächen, so wie du sie bauen würdest: mehrere Listen, Regeln, Overlays und die Tastatur
im Zusammenspiel.

::card-group

::card{title="Projekt-Board" icon="i-lucide-square-kanban" to="/docs/examples/board"}
Spalten, die du umsortierst, WIP-Limits, eine Bestätigung vor Done, Mehrfachauswahl und ein
Papierkorb.
::

::card{title="Wochenkalender" icon="i-lucide-calendar-days" to="/docs/examples/calendar"}
Termine, die über Tage und halbe Stunden gezogen werden, am Raster eingerastet.
::

::card{title="Dateimanager" icon="i-lucide-folder-open" to="/docs/examples/file-manager"}
Ein Ordnerbaum und ein Raster aus Dateien: Auswahl per Auswahlrahmen, Drops auf Ordner, Alt zum
Kopieren.
::

::card{title="Block-Editor" icon="i-lucide-blocks" to="/docs/examples/block-editor"}
Blöcke wie in Notion, an ihren Handles verschoben, verschachtelt und aus einer Palette eingefügt.
::

::card{title="Schach" icon="i-lucide-chess-knight" to="/docs/examples/chess"}
Ein Brett, dessen Felder nur gültige Züge annehmen: Schlagen, wer am Zug ist, eine angehobene
Figur, die Pfeiltasten.
::

::
