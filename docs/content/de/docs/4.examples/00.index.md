Jedes Beispiel ist eine kleine Vue-App: eine `index.vue` mit ihrem `DnDProvider` und den
Komponenten, die sie braucht. Die Code-Tabs unter einer Demo sind genau die Dateien, die sie
ausführen.

## Apps {#apps}

Ganze Oberflächen, so wie du sie bauen würdest: mehrere Listen, Regeln, Overlays und die Tastatur
im Zusammenspiel.

::card-group

::card{title="Projekt-Board" icon="i-lucide-square-kanban" to="/docs/examples/board"}
Spalten, die du umsortierst, WIP-Limits, eine Bestätigung vor Done, Mehrfachauswahl und ein
Papierkorb.
::

::card{title="Wochenkalender" icon="i-lucide-calendar-days" to="/docs/examples/calendar"}
Termine, die über Tage und halbe Stunden gezogen werden, am Raster eingerastet.
::

::card{title="Dateimanager" icon="i-lucide-folder-open" to="/docs/examples/file-manager"}
Ein Ordnerbaum und ein Raster aus Dateien: Auswahl per Auswahlrahmen, Drops auf Ordner, Alt zum
Kopieren.
::

::card{title="Block-Editor" icon="i-lucide-blocks" to="/docs/examples/block-editor"}
Blöcke wie in Notion, an ihren Handles verschoben, verschachtelt und aus einer Palette eingefügt.
::

::

## Bausteine {#building-blocks}

Jeweils eine Idee, klein genug, um sie in einer Minute zu lesen.

::card-group

::card{title="Kanban-Board" icon="i-lucide-columns-3" to="/docs/examples/kanban"}
Spalten, die Karten austauschen und Drops auf ihrer ganzen Höhe annehmen.
::

::card{title="Listen und Raster" icon="i-lucide-list-ordered" to="/docs/examples/lists"}
Eine Playlist, die an ihrem Griff gezogen wird, auf einer Achse, und ein Homescreen-Raster aus
Apps.
::

::card{title="Dateibaum" icon="i-lucide-list-tree" to="/docs/examples/tree"}
Der Explorer eines Editors: Verschachtelung durch Ziehen zur Seite oder durch Hovern über einem
Ordner.
::

::card{title="Multi-Drag" icon="i-lucide-images" to="/docs/examples/multi-drag"}
Wähle mit einem Auswahlrahmen oder Strg/Cmd-Klick aus und verschiebe dann die ganze Auswahl.
::

::card{title="Drag and Drop" icon="i-lucide-folder-input" to="/docs/examples/drop-zones"}
Dateien, sortiert in Ordner, die jeweils eine Art annehmen; ein Papierkorb, der jede annimmt.
::

::card{title="Achsen, Grenzen und Raster" icon="i-lucide-frame" to="/docs/examples/constraints"}
Ein Board, dessen Regeln sich live ändern: eine Achsensperre, seine Ränder, ein Raster.
::

::card{title="To-do-Liste" icon="i-lucide-list-checks" to="/docs/examples/todo-list"}
Zeilen, die an einem Griff gezogen werden, mit einer Checkbox, die weiterhin funktioniert.
::

::card{title="Listenoptionen" icon="i-lucide-sliders-horizontal" to="/docs/examples/sortable-options"}
Strategie, Platzhalter und Verhalten, umgeschaltet, während die Liste läuft.
::

::card{title="Virtuelle Liste" icon="i-lucide-rows-3" to="/docs/examples/virtual-list"}
Zehntausend Zeilen, eine Handvoll im DOM.
::

::card{title="Verschieben per Code" icon="i-lucide-wand-sparkles" to="/docs/examples/actions"}
Buttons, Mischen und ein geskripteter Drag – alles echte Drags.
::

::card{title="Ziehbare Elemente" icon="i-lucide-hand-grab" to="/docs/examples/draggable"}
Überall, an einem Handle, ohne Overlay oder gar nicht.
::

::card{title="Drop-Ziele" icon="i-lucide-inbox" to="/docs/examples/droppable"}
Zonen, die manche Dateien annehmen und andere ablehnen.
::

::
