Jedes Beispiel ist eine kleine Vue-App: eine `index.vue` mit ihrem `DnDProvider` und den
Komponenten, die sie braucht. Die Code-Tabs unter einer Demo sind genau die Dateien, die sie
ausführen.

::card-group

::card{title="Drag and Drop" icon="i-lucide-folder-input" to="/docs/examples/drop-zones"}
Dateien, sortiert in Ordner, die jeweils eine Art annehmen; ein Papierkorb, der jede annimmt.
::

::card{title="Listen und Raster" icon="i-lucide-list-ordered" to="/docs/examples/lists"}
Eine Playlist, die an ihrem Griff gezogen wird, auf einer Achse, und ein Homescreen-Raster aus
Apps.
::

::card{title="Kanban-Board" icon="i-lucide-columns-3" to="/docs/examples/kanban"}
Spalten, die Karten austauschen und Drops auf ihrer ganzen Höhe annehmen.
::

::card{title="Dateibaum" icon="i-lucide-list-tree" to="/docs/examples/tree"}
Der Explorer eines Editors: Verschachtelung durch Ziehen zur Seite oder durch Hovern über einem
Ordner.
::

::card{title="Multi-Drag" icon="i-lucide-images" to="/docs/examples/multi-drag"}
Wähle mit einem Auswahlrahmen oder Strg/Cmd-Klick aus und verschiebe dann die ganze Auswahl.
::

::card{title="Achsen, Grenzen und Raster" icon="i-lucide-frame" to="/docs/examples/constraints"}
Ein Board, dessen Regeln sich live ändern: eine Achsensperre, seine Ränder, ein Raster.
::
