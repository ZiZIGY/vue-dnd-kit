## Worauf du achten solltest {#what-to-look-at}

- **`Week.vue`**: `makeDragArea` gibt den Tagen eigene Regeln: `snapToGrid` (ein Tag mal eine
  halbe Stunde) und `restrictToArea`, sodass ein Termin die Woche nie verlässt.
  `getKeyboardCoordinates` sorgt dafür, dass die Pfeiltasten um eine Zelle bewegen.
- **`DayColumn.vue`**: Jeder Tag ist ein Drop-Ziel. `position` im Drop-Event ist die Stelle, an
  der die Box des Termins innerhalb des Tages gelandet ist: Ihre Oberkante ergibt die neue
  Startzeit.
- **`EventBlock.vue`**: ein einfaches ziehbares Element mit einer eigenen Overlay-Komponente.
- **`EventOverlay.vue`**: zeigt, während sich der Termin bewegt, die Uhrzeit, auf der er landen
  würde, anhand von `position` in `onDragMove`.
