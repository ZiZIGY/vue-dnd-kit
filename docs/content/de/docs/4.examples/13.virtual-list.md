## Worauf du achten solltest {#what-to-look-at}

- **`TaskList.vue`**: Die virtuelle Liste bekommt den Entwurf `items`, nicht das Quell-Array,
  sodass sich Zeilen während des Ziehens bewegen. Das Array ist ein `shallowRef`.
- **`TaskList.vue`**: Zeilen haben ihre ID als Schlüssel, nicht den Index wie in der Doku von
  VueUse.
- **`Row.vue`**: Die ID ist ein Getter, `{ id: () => props.task.id }`: Die virtuelle Liste kann
  der Komponente eine andere Aufgabe übergeben.
