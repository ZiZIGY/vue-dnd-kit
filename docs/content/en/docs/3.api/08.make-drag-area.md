```ts
function makeDragArea(
  target: MaybeElementRef,
  options?: DragAreaOptions,
): DragAreaReturn;
```

```ts
const board = useTemplateRef<HTMLElement>('board');
makeDragArea(board, { restrictToArea: true, modifiers: [snapToGrid(24)] });
```

The closest area wins when areas are nested, except `disabled`, which inner areas inherit.
See [Axes, bounds and grids](/docs/guides/constraints).

The chips inside the area follow its rules; the one outside it drags freely.
