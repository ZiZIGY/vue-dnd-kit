```vue [App.vue]
<script setup lang="ts">
import { DnDProvider } from '@vue-dnd-kit/core';
</script>

<template>
  <DnDProvider :animation="{ duration: 200 }" @drag-end="save">
    <RouterView />
    <template #overlay="{ items, over, accepted }">
      <!-- optional: a custom overlay for every drag -->
    </template>
  </DnDProvider>
</template>
```

Every composable must run in a component rendered **inside** a provider. One provider for the
whole app is the goal: parts of the page get their own rules with
[`makeDragArea`](/docs/api/make-drag-area). See [the provider guide](/docs/guides/provider).

Most props are read when the provider needs them: change one, and the next drag uses it.

::example{name="api-provider-props" hint="Switch a prop, then drag a task: by mouse, held, with Alt or Shift, or with Space on a focused task" height="37rem"}
::

### Where the overlay renders {#where-the-overlay-renders}

`overlayTo` moves the overlay out of `body`: into a modal `<dialog>`, which sits above
everything else on the page. Turn the switch off, and the rows you drag vanish under the
dialog. The [overlay guide](/docs/guides/overlay#where-it-renders-overlayto) explains when
it is needed.

::example{name="overlay-dialog" hint="Open the dialog and drag a column; then turn the switch off and drag again" height="22rem"}
::

## Events

| Event | Payload | When |
| --- | --- | --- |
| `drag-start` | `DnDEvent` | A drag started (after its activation). |
| `drag-move` | `DnDEvent` | The pointer moved during a drag (once per frame at most). |
| `drag-over` | `DnDEvent` | The target under the drag changed. |
| `drag-end` | `DnDEndEvent` | A drop went through and was written. |
| `drag-cancel` | `DnDEvent` | The drag was cancelled or the drop refused. |
| `drag-resume` | `DnDEvent` | `onBeforeDrop` answered `'continue'`: there was no drop, and the drag goes on. |
| `drag-settle` | `DnDEndEvent` or `DnDEvent` | The drag's overlay has landed: what `drag-end` or `drag-cancel` got. |

The same events, plus `onBeforeDrop`, are available anywhere under the
provider with [`useDnDMonitor`](/docs/api/use-dnd). Their payloads are on
[the events page](/docs/api/events).

## Slot `#overlay`

Renders what follows the pointer, for every drag that has no overlay component of its own
(see [the overlay guide](/docs/guides/overlay)). Rendering nothing falls back to the clone.
