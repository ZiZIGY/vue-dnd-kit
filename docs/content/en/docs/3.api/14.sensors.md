```ts
import { defineSensor, useSensor, pointerSensor, keyboardSensor } from '@vue-dnd-kit/core';
```

| Export | What it is |
| --- | --- |
| `pointerSensor` | Mouse, touch and pen via Pointer Events. In `sensors` by default. |
| `keyboardSensor` | Space/Enter pick up and drop, arrows move, Escape cancels. In `sensors` by default. |
| `defineSensor(sensor)` | Types a sensor object. |
| `useSensor(sensor)` | Runs a sensor in a component under the provider, for as long as it lives. |

A sensor only says "drag this item from here", then where it moved and that it dropped or
was cancelled; the provider checks the rest (what may be dragged, activation, one drag at a
time). See [Sensors and programmatic drags](/docs/guides/sensors).
