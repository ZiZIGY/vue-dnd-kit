```ts
function makeSortableItem<TData = unknown>(
  target: MaybeElementRef,
  options: SortableItemOptions<TData>,
): SortableItemReturn;
```

```ts
const el = useTemplateRef<HTMLElement>('el');
const { isPlaceholder, index } = makeSortableItem(el, { item: () => props.task, handle: '.grip' });
```

Call it in the row component, rendered inside the list's element. Identify the row with
`item` (keyed by the list's `getKey`, `item.id` by default) or `id`. See
[Sortable lists](/docs/guides/sortable-lists).
