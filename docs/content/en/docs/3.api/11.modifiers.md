## Modifiers

```ts
import { restrictToParent, snapToGrid } from '@vue-dnd-kit/core';

makeSortableList(list, { items, modifiers: [restrictToParent] });
makeDragArea(board, { modifiers: [snapToGrid({ x: 24, y: 24, smooth: true })] });
```

A modifier takes the drag's offset and returns a new one. They run in order: the provider's
`modifiers`, a drag area's, the draggable's own (or its list's), then the area's bounds
(`restrictToArea`), and the `axis` lock last. See [Axes, bounds and grids](/docs/guides/constraints).

| Modifier | What it does |
| --- | --- |
| `restrictToVerticalAxis` | Moves only vertically. The `axis: 'y'` option does the same, last. Horizontally it stays with the content it started in (`containerShift`), however the page scrolls. |
| `restrictToHorizontalAxis` | Moves only horizontally (`axis: 'x'`), and vertically stays with the content it started in. |
| `restrictToWindowEdges` | Keeps the overlay inside the window. |
| `restrictToParent` | Keeps the overlay inside the container the drag started in: the sortable list, or a plain draggable's parent element. |
| `restrictToElement(element)` | Keeps the overlay inside an element (a ref, a getter or the element). |
| `restrictToFirstScrollableAncestor` | Keeps the overlay inside the first scrollable ancestor of the dragged element. |
| `snapToGrid(size \| options)` | Snaps to a grid: `{ x, y, origin: 'container' \| 'delta', smooth }`. `'container'` (default) puts the box's top-left on grid lines from the container's top-left; `'delta'` rounds the offset. `smooth` glides the overlay between cells. |
| `snapCenterToCursor` | Centers the overlay under the pointer instead of keeping the grab offset. |

## Collision detection

```ts
import { closestCorners } from '@vue-dnd-kit/core';
```

```vue
<DnDProvider :collision="closestCorners" />
```

The provider's `collision` picks the target; the best candidate comes first.

| Function | What it picks |
| --- | --- |
| `pointerFirst` | Default: what is under the pointer, else what the overlay overlaps. |
| `pointerWithin` | Targets under the pointer, by hit-testing (z-order, overlays and shadow roots respected). |
| `rectIntersection` | Targets overlapping the overlay: higher priority, then deeper nesting, then intersection over union. |
| `closestCenter` | Every target, by distance between centers. |
| `closestCorners` | Every target, by summed distance between corners (stacked targets such as kanban columns). |
