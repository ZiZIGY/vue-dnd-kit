```ts
function makeSortableList<T>(
  target: MaybeElementRef,
  options: SortableListOptions<T>,
): SortableListReturn<T>;
```

```ts
const list = useTemplateRef<HTMLElement>('list');
const { items } = makeSortableList(list, { items: tasks, group: 'board' });
```

Render the returned `items` (the draft), not your array. Its rows call
[`makeSortableItem`](/docs/api/make-sortable-item). See [Sortable lists](/docs/guides/sortable-lists)
and [Lists that share items](/docs/guides/shared-lists).
