The provider's `animation` (layout moves while sorting), `dropAnimation` (the overlay landing)
and `animate` (data changes no drag made) take `false`, options, or your own function — for
GSAP or motion. Lists and trees can override `animation` and `animate`. See
[Animations](/docs/guides/animations).

```vue
<DnDProvider :animation="{ duration: 180, easing: 'ease-out' }" :drop-animation="false" />
```

Each lane below is a provider of its own that gives `animation`, `dropAnimation` and `animate`
the same kind of value (`animate` takes a function in `move`).
