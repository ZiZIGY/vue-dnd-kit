## DragPreview

```vue [StackOverlay.vue]
<script setup lang="ts">
import { DragPreview, type DragItem } from '@vue-dnd-kit/core';

defineProps<{ items: DragItem[] }>();
</script>

<template>
  <div class="stack">
    <DragPreview v-for="item in items.slice(0, 3)" :id="item.id" :key="item.id" />
  </div>
</template>
```

Clones are taken at pickup, of the grabbed item and of up to four others next to it in drop
order. For any other item `DragPreview` renders its default slot, or nothing. Each preview
lands on its own item when the drop lands. See [the overlay guide](/docs/guides/overlay).
