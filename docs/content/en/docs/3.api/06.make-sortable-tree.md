---
title: makeSortableTree
description: Makes a container a sortable tree, rendered flat with depths — nesting by a sideways drag or by hovering a node.
category: API
navigation:
  icon: i-lucide-list-tree
---

```ts
function makeSortableTree<T>(
  target: MaybeElementRef,
  options: SortableTreeOptions<T>,
): SortableTreeReturn<T>;
```

```ts
const root = useTemplateRef<HTMLElement>('root');
const { items } = makeSortableTree(root, { items: files, indentation: 20, collapsed });
```

Render `items` (flat nodes with a `depth`); each row calls
[`makeSortableItem`](/docs/api/make-sortable-item) with `id: () => node.key`. See [Trees](/docs/guides/trees).
