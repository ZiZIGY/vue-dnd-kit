---
title: makeDraggable
description: Makes an element draggable — free dragging, or into the drop targets that accept it.
category: API
navigation:
  icon: i-lucide-move
---

```ts
function makeDraggable<TData = unknown>(
  target: MaybeElementRef,
  options?: DraggableOptions<TData>,
): DraggableReturn;
```

```ts
const el = useTemplateRef<HTMLElement>('el');
const { isDragging } = makeDraggable(el, { id: 'card', type: 'card', data: { title } });
```

See [Drag and drop](/docs/guides/drag-and-drop). Sortable items are draggables too:
[`makeSortableItem`](/docs/api/make-sortable-item) takes the same options and more.
