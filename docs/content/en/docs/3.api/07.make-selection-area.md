---
title: makeSelectionArea
description: A rubber band that selects the draggables it touches — drag one of them and the whole selection travels.
category: API
navigation:
  icon: i-lucide-square-dashed-mouse-pointer
---

```ts
function makeSelectionArea(
  target: MaybeElementRef,
  options?: SelectionAreaOptions,
): SelectionAreaReturn;
```

```vue
<script setup lang="ts">
const area = useTemplateRef<HTMLElement>('area');
const { isSelecting, style } = makeSelectionArea(area);
</script>

<template>
  <div ref="area" class="area">
    <!-- items -->
    <div v-if="isSelecting" class="band" :style="style" />
  </div>
</template>
```

A press on the empty space of the area starts the band; render the band yourself. See
[Multi-drag and selection](/docs/guides/multi-drag).
