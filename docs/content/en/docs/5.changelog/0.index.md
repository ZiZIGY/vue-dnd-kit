Every release has a page here: what is new, with the demos that show it; what to change when
you upgrade; and every change. The same notes go to its
[GitHub release](https://github.com/ZiZIGY/vue-dnd-kit/releases), and each package keeps its
list of commits in its `CHANGELOG.md`.

```bash
npm i @vue-dnd-kit/core
```

v3 follows semantic versioning: a minor or patch release changes no API you use, and what
changes is said on its page. Coming from v2, see [migrating from v2](/docs/getting-started/migrating-from-v2).
