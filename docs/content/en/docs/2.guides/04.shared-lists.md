## A group

Lists with the same `group` name exchange items. By default every list is a group of its
own.

```vue [Column.vue]
<script setup lang="ts">
import { toRef, useTemplateRef } from 'vue';
import { makeSortableList } from '@vue-dnd-kit/core';
import Card from './Card.vue';

type Task = { id: string; title: string };
const props = defineProps<{ column: { id: string; title: string; cards: Task[] } }>();

const zone = useTemplateRef<HTMLElement>('zone');
const list = useTemplateRef<HTMLElement>('list');
const { items, isOver } = makeSortableList(list, {
  id: props.column.id,                   // names the list in drop events
  items: toRef(props.column, 'cards'),   // a writable ref into the reactive column
  group: 'board',                        // same name: cards move between these lists
  dropzone: zone,                        // the whole column takes drops
});
</script>

<template>
  <section ref="zone" :class="{ over: isOver }">
    <h3>{{ column.title }}</h3>
    <ul ref="list">
      <Card v-for="card in items" :key="card.id" :card="card" />
    </ul>
  </section>
</template>
```

```vue [Board.vue]
<script setup lang="ts">
import { reactive } from 'vue';
import Column from './Column.vue';

const columns = reactive([
  { id: 'todo', title: 'To do', cards: [{ id: 'vdk-12', title: 'Pick a palette' }] },
  { id: 'done', title: 'Done', cards: [] },
]);
</script>

<template>
  <Column v-for="column in columns" :key="column.id" :column="column" />
</template>
```

- Each column is a component of its own: one list per component.
- `toRef(props.column, 'cards')` is writable because the parent passes a reactive object.
  The drop writes both arrays, the one the card left and the one it entered.
- `id` shows up in drop events as `from.list` and `to.list`, and keys `e.result`, the new
  arrays of every list the drop changes. `id` and `group` are read once.
- Keys must be unique across the whole group.

A list's `onDrop` runs for the drops **into** it. A move from `todo` to `done` calls the
`done` list's `onDrop`, and its `e.result` holds the new arrays of both lists.

## The whole column takes drops: `dropzone`

A short list in a tall column leaves empty space below the last card. With
`dropzone: zone`, the column's element takes the drops for the list: a card let go below
the last one lands at the end. The cards stay in the `<ul>`; only the area that takes
drops grows.

::tip
Without a `dropzone`, an empty list still needs a size to take drops: give it a
`min-height`.
::

## What goes in and out: `pull` and `put`

`group` also takes an object:

```ts
group: { name: 'board', pull: true, put: true }
```

| Option | Values |
| --- | --- |
| `pull` | `true` (default): items can leave. `false`: they can't. `'clone'`: copies leave, the items stay. |
| `put` | `true` (default): items can come in. `false`: nothing comes in. A function: you decide per drag. |

A `put` function gets `{ keys, items, types, from, to }`. `from` is the list the items come
from, `null` for plain draggables. Moves inside a list are always allowed.

### Limits

A column that holds three cards at most:

```ts
makeSortableList(list, {
  id: props.column.id,
  items: toRef(props.column, 'cards'),
  group: {
    name: 'board',
    put: ({ keys }) => props.column.cards.length + keys.length <= 3,
  },
});
```

Over a list that refuses the drag, the slot goes back to where the drag started, so the
lists show what a drop would do: nothing. A drop there is cancelled and the card flies
back. The list's `isAccepting` is `false` during such a drag: dim the column with it.

When several selected items of different types are dragged, `acceptMode` says whether
`'all'` (default) or `'some'` of them must pass `put`. With `'some'`, the ones that pass
land and the others fly back.

## Copy: palettes and the Alt key

::example{name="palette" hint="Drag from the palette; Alt-drag copies; drop off the page to remove" height="24rem"}
::

```ts [Palette.vue]
makeSortableList(list, {
  items: templates,
  group: { name: 'blocks', pull: 'clone', put: false },  // copies go out, nothing comes in
  sort: false,                                           // its own order stays
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),
});
```

```ts [Sheet.vue]
makeSortableList(list, {
  items: blocks,
  group: 'blocks',
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),  // for Alt-drags
});
```

- `pull: 'clone'` copies every drag out of the list. The original stays, and the copy
  travels and lands.
- Holding :kbd{value="Alt"} while dragging copies too, from any list. Change the key with
  the provider's `copyModifier`, or turn it off with `null`.
- Either way, the list the item comes from needs `clone`. It must return the copy with a
  **new key**. Without `clone`, nothing is copied.
- The drop event has `mode: 'copy'`, and `e.items` are the copies. An overlay component
  gets `mode` too, to show a "+" while copying (see [the overlay](/docs/guides/overlay)).

## Plain draggables into a list

A list takes in items dragged with `makeDraggable` when it knows how to make an item from
them:

```ts
makeSortableList(list, {
  items: tasks,
  createItem: (active) => ({ id: crypto.randomUUID(), title: (active.data as Chip).title }),
});
```

While the draggable is over the list, the created item sits in the draft and is rendered
by your template like any other row. It becomes real on drop (`mode: 'insert'`,
`from.list === null`). Return `undefined` to refuse. Lists without `createItem` ignore plain
draggables. With the keyboard, an arrow toward the list takes the draggable in.

## Swap instead of shift

```ts
makeSortableList(grid, { items: tiles, strategy: 'grid', behavior: 'swap' });
```

The dragged item trades places with the one under it, and the others stay put. The swap is
live: moving back, or off the list, undoes it. The drop event has `mode: 'swap'` and
`partner`, the item it traded with.

- Two lists of one group swap between them when both have `behavior: 'swap'`. The hovered
  item moves into the other list, so it must be allowed out (`pull: true`) and in (`put`).
- A multi-drag sorts instead of swapping.

## An insertion line

With `placeholder: 'indicator'`, the list stays still while you drag, and a line shows
where the drop goes. You draw the line:

```ts [TaskList.vue]
const { items, indicator } = makeSortableList(listRef, { items: tasks, placeholder: 'indicator' });
```

```vue [TaskRow.vue]
<script setup lang="ts">
const { indicator } = makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el" :class="indicator && `drop-${indicator.side}`">{{ task.title }}</li>
</template>

<style scoped>
.drop-before { box-shadow: inset 0 2px 0 #42b883; }
.drop-after { box-shadow: inset 0 -2px 0 #42b883; }
</style>
```

| `indicator` field | What it holds |
| --- | --- |
| `list` | The list the drop goes into. |
| `index` | The insertion index in the list as rendered. |
| `key` | The item the line is attached to; `null` in an empty list (draw it in the list then). |
| `side` | `'before'` or `'after'` that item. Trees add `'inside'`. |
| `depth`, `parentKey` | Trees only: where the drop lands. See [trees](/docs/guides/trees#an-insertion-line). |

The list's `indicator` is set while the line is in that list, and an item's `indicator`
while it is attached to that item. The keyboard moves the line, too.

## Dropping outside

What happens when a drag ends over no target at all is the list's `dropOutside`:

| `dropOutside` | The items |
| --- | --- |
| `'placeholder'` (default) | Land where the slot was last shown. |
| `'cancel'` | Fly back. The default with `placeholder: 'indicator'`. |
| `'remove'` | Leave their list: drag off to delete. |

`'remove'` asks the list's `onBeforeDrop` first. Then the list's `onDrop` runs with
`to.index === -1`, and `e.result` holds the list without the items. A trash can that takes
drops works the same way: see [trash zones](/docs/guides/drag-and-drop#trash-zones).

To confirm a move, save it to a server first, or apply drops to a store yourself, see
[drop decisions](/docs/guides/drop-decisions). All list options are in the
[makeSortableList API](/docs/api/make-sortable-list).
