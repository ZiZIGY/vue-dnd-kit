## What to look at

- **`TodoRow.vue`**: `handle: grip`, so only the grip starts a drag and the checkbox stays
  usable. `index` is the row's place in the draft: it changes while you drag.
- **`TodoRow.vue`**: `isPlaceholder` draws the slot as a dashed hole of the same size.
- **`TodoList.vue`**: the rows render the list's draft `items`; the drop is written into
  `todos`.
