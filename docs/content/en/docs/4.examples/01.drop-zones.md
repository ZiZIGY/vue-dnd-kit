## What to look at

- **`FileCard.vue`**: a plain `makeDraggable` with a `type` — `image` or `doc`.
- **`Folder.vue`**: a `makeDroppable` whose `accept` takes one type (`'*'` for the desktop and
  the trash). `isAccepting` lights up the folders that take the drag; a folder that doesn't
  shows it with `isOver && !isAccepting`. `onDrop` is where the data changes: the library
  moves nothing on its own.
- Files look the same everywhere, so a drop only flies; the files left behind slide into the
  gap with Vue's `<TransitionGroup>`.

Read more: [Drag and drop](/docs/guides/drag-and-drop) · [`makeDroppable`](/docs/api/make-droppable)
