## What to look at

- **`TaskList.vue`**: the virtual list is fed the draft `items`, not the source array, so rows
  move while you drag. The array is a `shallowRef`.
- **`TaskList.vue`**: rows are keyed by id, not by index as in VueUse's docs.
- **`Row.vue`**: the id is a getter, `{ id: () => props.task.id }`: the virtual list may hand
  the component another task.

Read more: [Virtual lists](/docs/guides/virtual-lists)
