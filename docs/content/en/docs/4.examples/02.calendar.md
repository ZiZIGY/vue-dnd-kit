## What to look at

- **`Week.vue`**: `makeDragArea` gives the days their own rules: `snapToGrid` (a day by half
  an hour) and `restrictToArea`, so an event never leaves the week. `getKeyboardCoordinates`
  makes the arrow keys move by one cell.
- **`DayColumn.vue`**: each day is a drop target. `position` in the drop event is where the
  event's box landed inside the day: its top gives the new start time.
- **`EventBlock.vue`**: a plain draggable with an overlay component of its own.
- **`EventOverlay.vue`**: shows the time the event would land on while it moves, from
  `position` in `onDragMove`.
