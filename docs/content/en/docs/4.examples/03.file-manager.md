## What to look at

- **`FileGrid.vue`**: the files are a sortable grid (`strategy: 'grid'`) with `clone`, so Alt
  copies instead of moving. `makeSelectionArea` draws the rubber band; the selection it makes is
  the one a multi-drag moves, shown as a pile.
- **`FileTile.vue`**: `selected` from `makeSortableItem`, bound to a click and Ctrl/Cmd-click.
- **`useFolderDrop.ts`**: the rows of the tree and the folder tiles are drop targets. `accept` is
  a function: a folder refuses itself, its own subfolders and the folder that is open. On a
  folder tile, only the middle of the tile takes the drop; near its edges the grid sorts.
- **`FileManager.vue`**: a folder is a plain drop target; `event.mode` says whether Alt turned
  the drag into a copy.
