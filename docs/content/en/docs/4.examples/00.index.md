Each example is a small Vue app: an `index.vue` with its `DnDProvider`, and the components it
needs. The code tabs under a demo are the very files that run it.

## Apps {#apps}

Whole interfaces, the way you would build them: several lists, rules, overlays and the keyboard
working together.

::card-group

::card{title="Project board" icon="i-lucide-square-kanban" to="/docs/examples/board"}
Columns you reorder, WIP limits, a confirmation before Done, multi-select and a trash.
::

::card{title="Week calendar" icon="i-lucide-calendar-days" to="/docs/examples/calendar"}
Events dragged across days and half-hours, snapped to the grid.
::

::card{title="File manager" icon="i-lucide-folder-open" to="/docs/examples/file-manager"}
A folder tree and a grid of files: select with a rubber band, drop on folders, Alt to copy.
::

::card{title="Block editor" icon="i-lucide-blocks" to="/docs/examples/block-editor"}
Notion-like blocks moved by their handles, nested, and dragged in from a "/" menu or the
sidebar.
::

::card{title="Chess" icon="i-lucide-chess-knight" to="/docs/examples/chess"}
Legal moves light up, the piece in hand says why a square is refused, a pawn asks what it
becomes, and a bot plays back with real drags.
::

::card{title="Form builder" icon="i-lucide-text-cursor-input" to="/docs/examples/form-builder"}
Nuxt UI fields from a palette, set side by side in rows, filled in a live preview and
exported as Vue code.
::

::card{title="Design canvas" icon="i-lucide-pen-tool" to="/docs/examples/design-canvas"}
Frames and layers on a zoomable canvas, smart guides, Alt to duplicate, and a layers panel
that is the design's tree.
::

::card{title="Page builder" icon="i-lucide-layout-template" to="/docs/examples/page-builder"}
Sections that turn into the real thing over the page, elements between columns, a layers
tree on the same data, inline editing.
::

::card{title="Data table" icon="i-lucide-table-2" to="/docs/examples/data-table"}
A Nuxt UI table of 2,000 tasks: virtualized, searchable, sorted by its rows' grips.
::

::
