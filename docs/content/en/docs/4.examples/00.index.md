Each example is a small Vue app: an `index.vue` with its `DnDProvider`, and the components it
needs. The code tabs under a demo are the very files that run it.

## Apps {#apps}

Whole interfaces, the way you would build them: several lists, rules, overlays and the keyboard
working together.

::card-group

::card{title="Project board" icon="i-lucide-square-kanban" to="/docs/examples/board"}
Columns you reorder, WIP limits, a confirmation before Done, multi-select and a trash.
::

::card{title="Week calendar" icon="i-lucide-calendar-days" to="/docs/examples/calendar"}
Events dragged across days and half-hours, snapped to the grid.
::

::card{title="File manager" icon="i-lucide-folder-open" to="/docs/examples/file-manager"}
A folder tree and a grid of files: select with a rubber band, drop on folders, Alt to copy.
::

::card{title="Block editor" icon="i-lucide-blocks" to="/docs/examples/block-editor"}
Notion-like blocks moved by their handles, nested, and inserted from a palette.
::

::card{title="Chess" icon="i-lucide-chess-knight" to="/docs/examples/chess"}
A board whose squares take legal moves only: captures, turns, a lifted piece, the arrow keys.
::

::

## Building blocks {#building-blocks}

One idea each, small enough to read in a minute.

::card-group

::card{title="Kanban board" icon="i-lucide-columns-3" to="/docs/examples/kanban"}
Columns that exchange cards and take drops anywhere in their height.
::

::card{title="Lists and grids" icon="i-lucide-list-ordered" to="/docs/examples/lists"}
A playlist dragged by its grip, on one axis, and a home screen grid of apps.
::

::card{title="File tree" icon="i-lucide-list-tree" to="/docs/examples/tree"}
An editor's explorer: nesting by a sideways drag or by hovering a folder.
::

::card{title="Multi-drag" icon="i-lucide-images" to="/docs/examples/multi-drag"}
Select with a rubber band or Ctrl/Cmd-click, then move the whole selection.
::

::card{title="Drag and drop" icon="i-lucide-folder-input" to="/docs/examples/drop-zones"}
Files sorted into folders that take one kind each; a trash that takes any.
::

::card{title="Axes, bounds and grids" icon="i-lucide-frame" to="/docs/examples/constraints"}
A board whose rules change live: an axis lock, its edges, a grid.
::

::
