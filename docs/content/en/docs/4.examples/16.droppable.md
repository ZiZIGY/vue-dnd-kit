## What to look at

- **`FileChip.vue`**: each file has a `type`, the thing drop targets check.
- **`Zone.vue`**: `accept` takes a type or a list of types. `isAccepting` lights the zones that
  would take the drag; `isOver` without `isAccepting` is a zone that refuses it.
- **`index.vue`**: a drop target moves nothing itself: `onDrop` says which file came in, and
  the app moves it.
