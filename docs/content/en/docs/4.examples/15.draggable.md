## What to look at

- **`DragCard.vue`**: `handle` takes a template ref (or a selector); the rest of the card
  doesn't start a drag.
- **`DragCard.vue`**: with `overlay: false` the card moves itself, by the returned
  `transform`.
- There is no drop target here, so every drag flies back where it started.
