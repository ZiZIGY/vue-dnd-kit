## What to look at

- **`Page.vue`**: the page is a sortable tree with `placeholder: 'indicator'`: nothing moves while
  you drag, a line shows where the block goes and how deep. `canNest` lets blocks into toggles
  only.
- **`BlockRow.vue`**: `handle: '.grip'`, so the text stays editable and selectable, and only the
  handle starts a drag.
- **`Palette.vue`**: a list of the same `group` with `pull: 'clone'` and `put: false`: it hands out
  new blocks (`clone`) and takes nothing back.
- **`Editable.vue`**: plain `contenteditable` text. The model is updated from the DOM and never
  written back, so the caret doesn't jump.
