`animation` провайдера (перемещения раскладки при сортировке), `dropAnimation` (приземление
оверлея) и `animate` (изменения данных, сделанные не драгом) принимают `false`, опции или вашу
собственную функцию — для GSAP или motion. Списки и деревья могут переопределять `animation` и
`animate`. См. [анимации](/docs/guides/animations).

```vue
<DnDProvider :animation="{ duration: 180, easing: 'ease-out' }" :drop-animation="false" />
```

Каждая дорожка ниже — отдельный провайдер, с одной формой для `animation`, `dropAnimation` и
`animate` (который принимает функцию в `move`).
