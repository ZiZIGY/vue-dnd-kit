## Модификаторы {#modifiers}

```ts
import { restrictToParent, snapToGrid } from '@vue-dnd-kit/core';

makeSortableList(list, { items, modifiers: [restrictToParent] });
makeDragArea(board, { modifiers: [snapToGrid({ x: 24, y: 24, smooth: true })] });
```

Модификатор принимает смещение драга и возвращает новое. Модификаторы выполняются по порядку:
`modifiers` провайдера, области перетаскивания, собственные модификаторы перетаскиваемого
элемента (или его списка), затем границы области (`restrictToArea`) и последней — фиксация
`axis`. См. [оси, границы и сетки](/docs/guides/constraints).

| Модификатор | Что делает |
| --- | --- |
| `restrictToVerticalAxis` | Двигает только по вертикали. Опция `axis: 'y'` делает то же самое, последней. |
| `restrictToHorizontalAxis` | Двигает только по горизонтали (`axis: 'x'`). |
| `restrictToWindowEdges` | Держит оверлей внутри окна. |
| `restrictToParent` | Держит оверлей внутри контейнера, в котором начался драг: сортируемого списка или родительского элемента обычного перетаскиваемого элемента. |
| `restrictToElement(element)` | Держит оверлей внутри элемента (ref, геттера или самого элемента). |
| `restrictToFirstScrollableAncestor` | Держит оверлей внутри первого прокручиваемого предка перетаскиваемого элемента. |
| `snapToGrid(size \| options)` | Привязывает к сетке: `{ x, y, origin: 'container' \| 'delta', smooth }`. `'container'` (по умолчанию) ставит левый верхний угол блока на линии сетки от левого верхнего угла контейнера; `'delta'` округляет смещение. `smooth` плавно ведёт оверлей между ячейками. |
| `snapCenterToCursor` | Центрирует оверлей под указателем вместо того, чтобы сохранять смещение захвата. |

## Определение коллизий {#collision-detection}

```ts
import { closestCorners } from '@vue-dnd-kit/core';
```

```vue
<DnDProvider :collision="closestCorners" />
```

`collision` провайдера выбирает цель; лучший кандидат идёт первым.

| Функция | Что выбирает |
| --- | --- |
| `pointerFirst` | По умолчанию: то, что под указателем, а иначе — то, что перекрывает оверлей. |
| `pointerWithin` | Цели под указателем, по проверке попадания (с учётом z-порядка, оверлеев и shadow root). |
| `rectIntersection` | Цели, которые перекрывает оверлей: сначала по приоритету, затем по глубине вложенности, затем по отношению пересечения к объединению. |
| `closestCenter` | Все цели, по расстоянию между центрами. |
| `closestCorners` | Все цели, по сумме расстояний между углами (для целей друг над другом, например колонок канбана). |
