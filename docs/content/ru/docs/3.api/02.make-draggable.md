::api-signature{name="makeDraggable"}
::

```ts
const el = useTemplateRef<HTMLElement>('el');
const { isDragging } = makeDraggable(el, { id: 'card', type: 'card', data: { title } });
```

См. [drag and drop](/docs/guides/drag-and-drop). Элементы сортируемых списков — тоже
перетаскиваемые элементы: [`makeSortableItem`](/docs/api/make-sortable-item) принимает те же
опции и не только.
