```vue [App.vue]
<script setup lang="ts">
import { DnDProvider } from '@vue-dnd-kit/core';
</script>

<template>
  <DnDProvider :animation="{ duration: 200 }" @drag-end="save">
    <RouterView />
    <template #overlay="{ items, over, accepted }">
      <!-- optional: a custom overlay for every drag -->
    </template>
  </DnDProvider>
</template>
```

Каждый композабл должен вызываться в компоненте, отрендеренном **внутри** провайдера. Цель —
один провайдер на всё приложение: части страницы получают свои правила через
[`makeDragArea`](/docs/api/make-drag-area). См. [руководство по провайдеру](/docs/guides/provider).

Большинство пропсов читается тогда, когда они нужны провайдеру: измените один, и следующий драг
его использует.

## События {#events}

| Событие | Данные | Когда |
| --- | --- | --- |
| `drag-start` | `DnDEvent` | Драг начался (после своей активации). |
| `drag-move` | `DnDEvent` | Указатель сдвинулся во время драга (не чаще раза за кадр). |
| `drag-over` | `DnDEvent` | Сменилась цель под драгом. |
| `drag-end` | `DnDEndEvent` | Бросок состоялся и был записан. |
| `drag-cancel` | `DnDEvent` | Драг отменён или бросок отклонён. |
| `drag-settle` | `DnDEndEvent` или `DnDEvent` | Оверлей драга приземлился: то же, что получил `drag-end` или `drag-cancel`. |

Те же события, а также `onBeforeDrop` и `onDragResume`, доступны в любом месте под провайдером
через [`useDnDMonitor`](/docs/api/use-dnd). Их данные описаны на
[странице событий](/docs/api/events).

## Слот `#overlay` {#slot-overlay}

Рендерит то, что следует за указателем, для каждого драга без собственного компонента оверлея
(см. [руководство по оверлею](/docs/guides/overlay)). Если слот ничего не рендерит, используется
клон.
