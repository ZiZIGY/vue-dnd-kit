```ts
function makeSortableList<T>(
  target: MaybeElementRef,
  options: SortableListOptions<T>,
): SortableListReturn<T>;
```

```ts
const list = useTemplateRef<HTMLElement>('list');
const { items } = makeSortableList(list, { items: tasks, group: 'board' });
```

Рендерите возвращённый `items` (черновик), а не свой массив. Его строки вызывают
[`makeSortableItem`](/docs/api/make-sortable-item). См.
[сортируемые списки](/docs/guides/sortable-lists) и
[списки с общими элементами](/docs/guides/shared-lists).
