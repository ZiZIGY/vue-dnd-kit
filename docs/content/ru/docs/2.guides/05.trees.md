## Плоский рендер {#rendered-flat}

Дерево рендерится как **плоский список** видимых узлов по порядку, у каждого — своя `depth`.
Отступы строкам задаёте вы. Так все строки остаются соседями в одном контейнере и сдвигаются и
анимируются, как строки списка.

```vue [FileTree.vue]
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { makeSortableTree, type Key } from '@vue-dnd-kit/core';
import TreeRow from './TreeRow.vue';

interface FileNode { id: string; name: string; folder?: boolean; children?: FileNode[] }

const files = ref<FileNode[]>([
  { id: 'src', name: 'src', folder: true, children: [{ id: 'main', name: 'main.ts' }] },
  { id: 'readme', name: 'README.md' },
]);
const collapsed = ref(new Set<Key>());
const INDENT = 18;

const root = useTemplateRef<HTMLElement>('root');
const { items } = makeSortableTree(root, {
  items: files,                                  // the root nodes
  indentation: INDENT,                           // px per level: match your row padding
  collapsed,
  canNest: (_node, parent) => !!parent.folder,   // only folders take children
});

const toggle = (key: Key) => (collapsed.value.has(key) ? collapsed.value.delete(key) : collapsed.value.add(key));
</script>

<template>
  <div ref="root">
    <TreeRow v-for="node in items" :key="node.key" :node="node" :indent="INDENT" @toggle="toggle" />
  </div>
</template>
```

```vue [TreeRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode, type Key } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const emit = defineEmits<{ toggle: [key: Key] }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { id: () => props.node.key });
</script>

<template>
  <div ref="el" :style="{ paddingLeft: `${node.depth * indent}px` }">
    <button
      v-if="node.item.folder"
      type="button"
      :aria-expanded="!node.collapsed"
      :aria-label="node.collapsed ? 'Expand' : 'Collapse'"
      @click="emit('toggle', node.key)"
    >
      {{ node.collapsed ? '▸' : '▾' }}
    </button>
    {{ node.item.name }}
  </div>
</template>
```

Строки используют `makeSortableItem`, как строки списка. `items` содержит `FlatNode`:

| Поле `FlatNode` | Что содержит |
| --- | --- |
| `key` | Ключ узла (`getKey`, по умолчанию `node.id`). Используйте его для `:key` и для `id` строки. |
| `item` | Ваш узел. |
| `depth` | `0` для корней. Глубина перетаскиваемого узла — та, на которую он **приземлился бы**, поэтому отступ его слота меняется на лету. |
| `parentKey` | Ключ родителя, `null` для корней. |
| `index` | Индекс среди соседних узлов. |
| `hasChildren`, `collapsed` | Для кнопки разворачивания. |

Потомки читаются из `node.children` и записываются туда же. Для других структур есть
`getChildren` и `setChildren`:

```ts
makeSortableTree(root, {
  items: outline,
  getKey: (node) => node.uuid,
  getChildren: (node) => node.nested,
  setChildren: (node, children) => { node.nested = children; },
});
```

## Вложение {#nesting}

Драг меняет глубину двумя способами, оба включены по умолчанию (`nesting: 'both'`):

- **Сдвигом вбок** (`'offset'`): сдвиньте влево или вправо на `indentation` пикселей, чтобы
  подняться или опуститься на уровень, насколько позволяют строки вокруг слота.
- **Наведением** (`'hover'`): задержите драг над серединой строки, и бросок пойдёт внутрь неё,
  первым потомком.

Задайте `indentation` равным отступу, который ваши строки добавляют на каждый уровень, чтобы
сдвиг следовал за указателем. С `axis: 'y'` драг не может сдвигаться вбок, но строки всё равно
вкладываются наведением.

## Свёрнутые узлы {#collapsed-nodes}

`collapsed` — это `Set` ключей, чьи потомки скрыты (ref или геттер). Их потомков нет в `items`.
Перетаскиваемая папка уносит с собой всё поддерево, свёрнутое или нет. С включённой опцией
дерева `animate` строки, которые папка показывает или скрывает, анимируются при появлении и
исчезновении.

## Правила {#rules}

| Опция | Что ограничивает |
| --- | --- |
| `canNest(node, parent)` | Можно ли поместить `node` под `parent`. При мульти-драге спрашивает про каждый перетаскиваемый узел. |
| `maxDepth` | Наибольшая допустимая глубина, у корней — `0`. Потомки перетаскиваемого узла учитываются: папка с детьми и внуками опускается не глубже `maxDepth - 2`. |
| `group.put` | Принимает ли дерево элементы из других списков и деревьев вообще. |
| `onBeforeDrop` | Всё остальное, решается при броске: см. [решения о броске](/docs/guides/drop-decisions). |

Когда правило отклоняет глубину, слот берёт самую глубокую из допустимых. Если допустимой нет,
слот туда не сдвигается. Копии и узлы из `createItem` тоже подчиняются `canNest` и `maxDepth`.

## Деревья и списки в одной группе {#trees-and-lists-in-one-group}

Дерево и список с одинаковой `group` обмениваются узлами, как два списка. Папка, перенесённая в
список, сохраняет своё поддерево и возвращается вместе с ним. Копирование работает как в
списках (`clone`, `pull: 'clone'`, клавиша Alt), но `clone` должен вернуть копию **со всем её
поддеревом**, и каждому узлу в нём нужен новый ключ:

```ts
let count = 0;
const copyNode = (node: FileNode): FileNode => ({
  ...node,
  id: `${node.id}-${++count}`,
  children: node.children?.map(copyNode),
});

makeSortableTree(root, { items: files, group: 'files', clone: copyNode });
```

Про группы, копирование и `createItem` — в разделе
[списки с общими элементами](/docs/guides/shared-lists).

## Линия вставки {#an-insertion-line}

С `placeholder: 'indicator'` дерево во время драга не двигается. Каждая строка читает свой
`indicator` и рисует линию с отступом той глубины, на которую придётся бросок:

```vue [TreeRow.vue]
<script setup lang="ts">
import { computed, useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const el = useTemplateRef<HTMLElement>('el');
const { indicator } = makeSortableItem(el, { id: () => props.node.key });

// 'inside': the drop goes into this row. Otherwise a line before or after it.
const into = computed(() => indicator.value?.side === 'inside');
const line = computed(() => {
  const value = indicator.value;
  if (!value || value.side === 'inside') return null;
  return { side: value.side, left: `${(value.depth ?? 0) * props.indent}px` };
});
</script>

<template>
  <div ref="el" class="row" :class="{ into }" :style="{ paddingLeft: `${node.depth * indent}px` }">
    {{ node.item.name }}
    <span v-if="line" class="line" :class="line.side" :style="{ left: line.left }" />
  </div>
</template>

<style scoped>
.row { position: relative; }
.row.into { background: color-mix(in srgb, #42b883 15%, transparent); }
.line { position: absolute; right: 0; height: 2px; background: #42b883; }
.line.before { top: -1px; }
.line.after { bottom: -1px; }
</style>
```

В деревьях `indicator` добавляет `depth` и `parentKey`: уровень и родителя, которых получат
брошенные узлы. Сдвиг вбок перемещает линию между уровнями. В этом режиме бросок за пределами
дерева отменяется.

## Бросок {#the-drop}

Событие броска дерева — то же, что у списка, только в `from` и `to` добавлен `parentKey`:

```ts
makeSortableTree(root, {
  items: files,
  onDrop: (e) => {
    console.log(e.keys, e.from.parentKey, '→', e.to.parentKey, e.to.index);
  },
});
```

`to.index` — позиция среди новых соседних узлов, отсчитанная после того, как узел покинул
старое место. При броске библиотека отдаёт изменённым узлам их новых потомков (`setChildren`) и
записывает в ваш ref новый массив корней.

`e.result.get(treeId)` — новое дерево в виде нового массива корней: узлы на изменённых путях —
копии, нетронутые поддеревья общие, а ваши узлы остаются как есть. Для стора или иммутабельных
данных передайте геттер, вызовите `e.preventDefault()` и сохраните `e.result`. Копии создаются
через `withChildren(node, children)`, по умолчанию это `{ ...node }` с новыми потомками; для
экземпляров классов передайте свою функцию.

## Клавиатура и мульти-драг {#keyboard-and-multi-drag}

С клавиатуры :kbd{value="ArrowUp"} и :kbd{value="ArrowDown"} перемещают между строками, а
:kbd{value="ArrowLeft"} и :kbd{value="ArrowRight"} меняют глубину там, где это позволяют
соседние строки.

Выделенные узлы перемещаются вместе, одним блоком, каждый со своим поддеревом, в порядке
документа. Выделенный узел внутри другого выделенного едет в поддереве своего родителя. См.
[мульти-драг](/docs/guides/multi-drag).

Все опции — в [API makeSortableTree](/docs/api/make-sortable-tree). Про деревья с тысячами
строк — в разделе [виртуальные списки](/docs/guides/virtual-lists).
