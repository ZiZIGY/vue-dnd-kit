анимируются по умолчанию; изменения от кнопок анимируются, потому что у сетки включён `animate`.

## Три анимации {#three-animations}

| Опция | Где | По умолчанию | Что анимирует |
| --- | --- | --- | --- |
| `animation` | провайдер, список, дерево | включено, 200 мс | Сдвиг элементов на новые места во время сортировки, при броске и при отмене. |
| `dropAnimation` | провайдер | включено, 250 мс | Приземление оверлея на свой слот или его полёт обратно при отмене. |
| `animate` | провайдер, список, дерево | **выключено** | Изменения ваших данных, сделанные не драгом: элементы добавлены, удалены, перемещены или отфильтрованы, строки дерева показаны или скрыты. |

Каждая принимает `true` (тайминг по умолчанию), `false` (выключено), `{ duration, easing }` или
функцию, которая анимирует сама.

```vue
<DnDProvider
  :animation="{ duration: 180, easing: 'cubic-bezier(.2, .8, .2, 1)' }"
  :drop-animation="{ duration: 300 }"
>
```

Собственные `animation` и `animate` списка или дерева важнее, чем у провайдера.

## Сортировка {#sorting}

Во время драга черновик перестраивается, а элементы плавно сдвигаются на новые места: FLIP по
CSS-свойству `translate` через Web Animations API. `translate` складывается с любым вашим
`transform`, поэтому позиционирование строк виртуального списка не нарушается. Когда элемент
сдвигается снова до конца своей анимации, следующая начинается с того места, где он показан.

::warning
Не оборачивайте элементы сортируемого списка в `<TransitionGroup>`: каждое перемещение
анимировалось бы дважды. Для изменений, сделанных не драгом, включите `animate`.
::

## Бросок {#the-drop}

При броске оверлей летит от места, где его отпустили, в слот элемента; при отмене — обратно туда,
где элемент начинал. Когда у элемента после броска нет видимого слота — он прокручен за пределы
видимости или брошен в папку или корзину, — оверлей вместо этого растворяется, сжимаясь в зону,
на которую его бросили.

Ещё во время драга оверлей принимает размер слота, в который приземлится
(`overlayFit: 'slot'`, по умолчанию), поэтому броску не нужно менять размер. `'source'`
сохраняет размер перетаскиваемого элемента. См. [оверлей](/docs/guides/overlay).

## Изменения данных: animate {#data-changes-animate}

```ts
makeSortableList(listRef, { items: swatches, animate: true });
```

Выключенный по умолчанию, `animate` анимирует то, что меняет ваш массив без драга: сортировку,
перемешивание, перенос между списками одной группы, добавление, удаление или отфильтровывание
элемента. В дереве он также охватывает строки, которые узел показывает или скрывает при
разворачивании и сворачивании. `<DnDProvider animate>` включает его для всех списков и деревьев.

Его части можно настраивать по отдельности:

```ts
animate: { duration: 250, move: true, enter: true, leave: { duration: 150 } },
```

| Часть | По умолчанию |
| --- | --- |
| `move` | Элементы, сменившие место, плавно сдвигаются, как с `animation`. |
| `enter` | Появившиеся элементы проявляются на своём месте. |
| `leave` | Копия ушедшего элемента растворяется там, где он был, немного сжимаясь. Она помечена `data-dnd-leaving` и удаляется по завершении. |

`duration` и `easing` действуют на все части; каждая часть принимает `true`, опции, `false` или
функцию. Анимируются только элементы рядом с видимой областью, поэтому строки, которые
виртуальный список не смонтировал, пропускаются. Опция читается при изменении `items`, так что
её можно переключать ref, как это делает переключатель в примере.

## Свои анимации {#your-own-animations}

Каждая опция принимает и функцию. Она получает контекст, запускает анимацию и возвращает её
`Animation`, промис, который завершается вместе с ней, или ничего.

```ts
// animation, animate.move: an item moved from `from` to `to`
({ key, element, from, to, options, reason, signal, reducedMotion }) => Animation | Promise | void
// dropAnimation: `to` is null when there is no visible slot; `into` is the zone it went into
({ overlay, from, to, into, reason, active, options, reducedMotion }) => …
// animate.enter: the element is already in place
({ key, element, to, options, reducedMotion }) => …
// animate.leave: `element` is a copy where the item was, removed when you finish
({ key, element, from, options, reducedMotion }) => …
```

Функция для раскладки на Web Animations API, без библиотек:

```ts
import type { LayoutAnimationContext } from '@vue-dnd-kit/core';

const springy = ({ element, from, to, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  return element.animate(
    [{ translate: `${from.left - to.left}px ${from.top - to.top}px` }, { translate: '0 0' }],
    { duration: 400, easing: 'cubic-bezier(.34, 1.56, .64, 1)' },
  );
};
```

```vue
<DnDProvider :animation="springy">
```

Три правила, чтобы свои анимации шли в ногу с библиотекой:

- **Анимируйте `translate`** от `from - to` до нуля, а не `transform`. Он складывается с
  трансформациями, которые виртуальные списки или ваш CSS задают строкам, а драг измеряет
  элементы без него.
- **Учитывайте `signal`.** Он срабатывает, когда элемент сдвигается снова до конца анимации.
  Сразу остановите анимацию и очистите её стили: раскладка измеряется сразу после этого.
  Возвращённую `Animation` библиотека отменит сама.
- **У оверлея анимируйте позицию и размер** (`width`, `height`), но не `scale`: его содержимое
  заново раскладывается под новый размер.

### GSAP {#gsap}

```ts [gsap-animations.ts]
import gsap from 'gsap';
import type {
  DropAnimationContext,
  EnterAnimationContext,
  LayoutAnimationContext,
  LeaveAnimationContext,
  Rect,
} from '@vue-dnd-kit/core';

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const tween = gsap.fromTo(
    element,
    { translate: `${from.left - to.left}px ${from.top - to.top}px` },
    { translate: '0px 0px', duration: 0.4, ease: 'power3.out' },
  );
  signal.addEventListener('abort', () => tween.revert());
  return tween.then();
};

const box = (rect: Rect) => ({ x: rect.left, y: rect.top, width: rect.width, height: rect.height });

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return gsap.to(overlay, { opacity: 0, duration: 0.2 }).then();
  return gsap.fromTo(overlay, box(from), { ...box(to), duration: 0.45, ease: 'back.out(1.2)' }).then();
};

const enter = ({ element, reducedMotion }: EnterAnimationContext) =>
  gsap.from(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.35 }).then();

const leave = ({ element, reducedMotion }: LeaveAnimationContext) =>
  gsap.to(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.25 }).then();

export const gsapAnimations = { animation: move, dropAnimation: drop, animate: { move, enter, leave } };
```

```vue
<DnDProvider v-bind="gsapAnimations">
```

### motion {#motion}

```ts [motion-animations.ts]
import { animate } from 'motion-v';
import type { DropAnimationContext, LayoutAnimationContext } from '@vue-dnd-kit/core';

const spring = { type: 'spring', duration: 0.45, bounce: 0.25 } as const;

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const controls = animate(
    element,
    { translate: [`${from.left - to.left}px ${from.top - to.top}px`, '0px 0px'] },
    spring,
  );
  signal.addEventListener('abort', () => {
    controls.stop();
    element.style.translate = '';
  });
  return controls.finished;
};

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return animate(overlay, { opacity: 0 }, { duration: 0.18 }).finished;
  return animate(
    overlay,
    { x: [from.left, to.left], y: [from.top, to.top], width: [from.width, to.width], height: [from.height, to.height] },
    spring,
  ).finished;
};
```

Полные типы опций — в разделе [анимации](/docs/api/animations).

## Уменьшение движения {#reduced-motion}

При `prefers-reduced-motion: reduce` собственные анимации библиотеки не запускаются: элементы и
оверлей сразу встают на свои места. Ваши функции вызываются всегда, с `reducedMotion: true`,
так что решают они — пропустить движение или оставить короткое затухание, как в рецептах выше.

## Изменения раскладки, которые вызвала не библиотека {#layout-changes-the-library-didnt-cause}

Когда во время драга строки сдвигает что-то другое — виртуализатор, который их перемеряет,
загрузившееся изображение, — вызовите `captureLayout()` списка прямо перед тем, как изменение
отрендерится. Он измеряет строки там, где они находятся, и после следующего рендера анимирует их
на новые места. Вне драга он ничего не делает. См. [виртуальные списки](/docs/guides/virtual-lists).
