`@vue-dnd-kit/devtools` добавляет вкладку **Vue DnD Kit** в Vue DevTools
(`vite-plugin-vue-devtools`) и в Nuxt DevTools. Она показывает все списки, деревья и цели
страницы на живой мини-карте, перетаскивает любой элемент джойстиком, правит опции, пока
приложение работает, и записывает, что сделал каждый драг. Работает только в разработке: в
продакшен-сборку из неё ничего не попадает.

## Установка {#install}

```bash
npm i -D @vue-dnd-kit/devtools @vue-dnd-kit/actions
```

`@vue-dnd-kit/actions` — peer-зависимость: перемещения из вкладки идут через неё. npm 7+ и pnpm
устанавливают её сами; с Yarn 1 добавьте её вручную.

::code-group

```ts [vite.config.ts]
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import vueDevTools from 'vite-plugin-vue-devtools';
import { vueDnDKitDevtools } from '@vue-dnd-kit/devtools/vite';

export default defineConfig({
  plugins: [vueDevTools(), vueDnDKitDevtools(), vue()],
});
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  // With @vue-dnd-kit/devtools installed, the tab appears in development.
  modules: ['@vue-dnd-kit/nuxt'],
});
```

::

С Vite плагин раздаёт вкладку по адресу `/__vue-dnd-kit-devtools/`, добавляет её в Vue DevTools и
подключает страницу к ней до старта вашего приложения. `app.use()` не нужен. Плагин работает
только на dev-сервере (`vite serve`); сборки он не трогает.

С Nuxt модуль `@vue-dnd-kit/nuxt` находит пакет, раздаёт вкладку, добавляет её в Nuxt DevTools и
устанавливает часть для страницы клиентским плагином. `vueDndKit: { devtools: false }` выключает
её.

### Без плагинов {#without-the-plugins}

Для собственного dev-сервера или страницы, которую Vite раздаёт не из `index.html` (SSR-сборки),
установите часть для страницы сами:

```ts [main.ts]
import { createApp } from 'vue';
import { DnDDevtools } from '@vue-dnd-kit/devtools';
import App from './App.vue';

const app = createApp(App);
app.use(DnDDevtools); // before mount: providers set up earlier aren't seen
app.mount('#app');
```

Или импортируйте `@vue-dnd-kit/devtools/auto` первым в точке входа. Используйте
`vueDnDKitDevtools({ inject: false })`, когда плагин должен раздавать вкладку, а часть для
страницы вы устанавливаете сами; `serveTab()` из `@vue-dnd-kit/devtools/vite` — это middleware,
которое раздаёт вкладку.

## Как открыть {#open-it}

- **Vue DevTools**: :kbd{value="Alt"} + :kbd{value="Shift"} + :kbd{value="D"} или кнопка Vue
  внизу страницы, затем вкладка **Vue DnD Kit**.
- **Nuxt DevTools**: :kbd{value="Shift"} + :kbd{value="Alt"} + :kbd{value="D"} или кнопка Nuxt,
  затем **Vue DnD Kit** (в боковой панели или в её меню переполнения).
- **В отдельном окне**: откройте `http://localhost:5173/__vue-dnd-kit-devtools/` на своём
  dev-сервере или нажмите кнопку ⧉ во вкладке. Удобно на втором экране.

::warning
Держите вкладку в отдельном окне, а не в фоновой вкладке браузера: скрытая страница отменяет драги.
::

## Что показывает вкладка {#what-the-tab-shows}

### Мини-карта {#the-mini-map}

Живая карточка на каждый список, дерево и цель, с копиями их элементов там, где они находятся, —
те же клоны, что показал бы оверлей. Во время драга она отмечает списки, которые принимают драг
(синим) или отклоняют его (красным), плейсхолдер, цель под указателем, блок оверлея и линию
вставки у списков с `placeholder: 'indicator'`. Клик выбирает элемент; двойной клик прокручивает
к нему страницу.

Пользуйтесь ею, когда бросок идёт не туда, куда вы ожидаете: она сразу показывает, какие списки
принимают драг.

### Drive: джойстик {#drive-the-joystick}

Выберите элемент — на карте, в дереве или через **Pick**, который берёт следующее нажатие на
странице, — и толкните ручку джойстика. Элемент берётся и движется в ту сторону, тем быстрее, чем
дальше ручка от центра. **Drop** и **Cancel** завершают драг.

Это настоящий драг указателем от сенсора с именем `devtools`, поэтому списки сортируются,
контейнеры прокручиваются автоскроллом, а `onBeforeDrop` и `onDrop` вызываются, как при любом
драге. Элементы сортируемых списков получают ещё и кнопки: вверх, вниз, в начало, в конец, в
другой список группы.

| Клавиша во вкладке | Действие |
| --- | --- |
| Стрелки или :kbd{value="W"} :kbd{value="A"} :kbd{value="S"} :kbd{value="D"} | Толкнуть ручку в эту сторону; с :kbd{value="Shift"} — до упора |
| :kbd{value="G"} | Взять выбранный элемент |
| :kbd{value="Space"} / :kbd{value="Enter"} | Бросить |
| :kbd{value="Escape"} | Отменить |
| :kbd{value="P"} | Выбрать на странице |

### Options {#options}

Любую опцию, кроме колбэков, можно править, пока приложение работает: опции провайдера
(`collision`, `modifiers`, `overlayFit`, `autoScroll`, анимации, `activation`, `keyboard`…),
списка (`strategy`, `placeholder`, `behavior`, `multiple`, `dropOutside`, `disabled`…), дерева,
цели и элемента. Выберите узел и откройте **Options**.

Правка применяется сразу, только к этой странице, и никогда не записывается в ваш код. Она
действует, пока вы её не сбросите, провайдер не размонтируется или страница не перезагрузится.

### State {#state}

Что знает каждый провайдер, в виде дерева: его сессия драга (статус, активные id и сенсор, цель
и принимает ли она драг, указатель), его списки и деревья с их порядком и черновиком, цели с их
правилами, а также типы и данные элементов.

### Log {#log}

Одна полоса на каждый драг: начало (id, сенсор, список, из которого он пришёл), каждый `over` и
`left` с признаком принятия, отпускание, вердикт `onBeforeDrop` — принят, принят частично,
отклонён хуком, отклонён `accept` цели — и `drop` с `e.result` и признаком того, вызывался ли
`preventDefault()`, или `cancel` и его причина. Кликните по записи, чтобы увидеть её данные.

Пользуйтесь им, когда бросок отклонён и непонятно чем, или когда управляемый список не
изменился: журнал показывает, вызывался ли `preventDefault()` и что было в `e.result`.

## Как это работает {#how-it-works}

Провайдеры отчитываются хуку, который устанавливает часть для страницы. Пока за страницей не
наблюдает ни одна вкладка, данные только записываются; затем страница слушает драги, как любой
монитор, и отправляет вкладке то, что та показывает, — каждые 40 мс во время драга и дважды в
секунду в остальное время, — и останавливается, когда несколько секунд за ней не наблюдает ни
одна вкладка. Вкладка общается со страницей через `BroadcastChannel` origin страницы. Она не
меняет ничего, кроме того, о чём вы просите: драгов, выделения и переопределённых опций.
