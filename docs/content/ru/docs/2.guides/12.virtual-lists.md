Сортировка управляется данными: черновик `items` — новый массив при каждой перестановке, ключи
строк — по элементу, а анимациям нужны только смонтированные строки. Поэтому подходит любой
виртуализатор, который рендерит из массива, — отдайте ему черновик вместо своего массива.

::example{name="virtual-list" hint="10 000 строк, в DOM — лишь несколько: перетащите одну или прокручивайте прямо во время драга" height="26rem"}
::

## Правила {#the-rules}

1. Отдавайте виртуализатору **черновик `items`**, а не исходный массив.
2. **Задавайте строкам ключи по ключу элемента**, никогда по индексу. В официальных примерах
   TanStack и VueUse ключи — индексы; измените это.
3. Передавайте id в `makeSortableItem` **геттером**, `{ id: () => props.item.id }`: виртуализатор
   может отдать компоненту строки другой элемент.
4. Храните большие массивы в **`shallowRef`**. Библиотека никогда не обходит ваши данные вглубь.
5. Плейсхолдер должен быть того же размера, что и строка.
6. Задайте overscan хотя бы в 5 строк (в VueUse — хотя бы 1), чтобы строки монтировались до того,
   как до них доберётся автоскролл.
7. Не анимируйте у строк `height`, `margin` или `padding` и не ставьте `will-change` на
   прокручиваемый контейнер.

## TanStack Virtual {#tanstack-virtual}

```vue [TaskList.vue]
<script setup lang="ts">
import { computed, shallowRef, useTemplateRef } from 'vue';
import { defaultRangeExtractor, useVirtualizer, type Range } from '@tanstack/vue-virtual';
import { makeSortableList } from '@vue-dnd-kit/core';
import Row from './Row.vue';

const ROW = 40;
const tasks = shallowRef(makeRows(10_000));
const scrollRef = useTemplateRef<HTMLElement>('scroll');
const { items, activeIndex, captureLayout } = makeSortableList(scrollRef, { items: tasks });

// One computed that reads the draft once: TanStack memoizes measurements and the range on
// the identity of `getItemKey` and `rangeExtractor`, so they must be new after every reorder.
const virtualizer = useVirtualizer(
  computed(() => {
    const arr = items.value;
    const pin = activeIndex.value;
    return {
      count: arr.length,
      getScrollElement: () => scrollRef.value,
      estimateSize: () => ROW,
      overscan: 8,
      getItemKey: (index: number) => arr[index]!.id,
      // Keep the dragged row mounted while it is scrolled out of range.
      rangeExtractor: (range: Range) => {
        const indexes = defaultRangeExtractor(range);
        return pin < 0 || indexes.includes(pin) ? indexes : [...indexes, pin].sort((a, b) => a - b);
      },
      // Re-measures land after the library's animation pass: animate them too.
      onChange: () => captureLayout(),
    };
  }),
);
const rows = computed(() => virtualizer.value.getVirtualItems());
const measure = (el: unknown) => virtualizer.value.measureElement(el as HTMLElement | null);
</script>

<template>
  <div ref="scroll" style="height: 600px; overflow: auto; contain: strict">
    <div :style="{ height: `${virtualizer.getTotalSize()}px`, position: 'relative' }">
      <div
        v-for="row in rows"
        :key="(row.key as string)"
        :ref="measure"
        :data-index="row.index"
        :style="{ position: 'absolute', top: 0, left: 0, width: '100%', transform: `translateY(${row.start}px)` }"
      >
        <Row :item="items[row.index]!" />
      </div>
    </div>
  </div>
</template>
```

```vue [Row.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ item: { id: string; title: string } }>();
const el = useTemplateRef<HTMLElement>('el');
// A getter: the virtualizer may give this component another item.
makeSortableItem(el, { id: () => props.item.id });
</script>

<template>
  <div ref="el" class="row">{{ item.title }}</div>
</template>
```

- Прокручиваемый контейнер — это элемент сортируемого списка: библиотека сортирует его и
  прокручивает автоскроллом.
- Закрепление перетаскиваемой строки (`rangeExtractor`) требует, чтобы строки позиционировались
  по отдельности, абсолютно, как выше.
- Оставьте в TanStack `anchorTo: 'start'`, значение по умолчанию. С `lanes` используйте
  `@tanstack/vue-virtual` 3.19 или новее.

### Колонки канбана {#kanban-columns}

Когда карточка приходит из другой колонки, её высота может отличаться от оценки колонки.
Читайте `activeSize` в том же computed и оценивайте входящую строку по её реальному размеру:

```ts
const { items, activeIndex, activeSize, captureLayout } = makeSortableList(scrollRef, {
  id: props.column.id,
  items: props.column.tasks,
  group: 'board',
});

const virtualizer = useVirtualizer(
  computed(() => {
    const arr = items.value;
    const pin = activeIndex.value;
    const size = activeSize.value;
    return {
      count: arr.length,
      getScrollElement: () => scrollRef.value,
      // A card coming from another column gets its real height before it is measured.
      estimateSize: (index: number) => (index === pin && size ? size.height : 72),
      // …getItemKey, rangeExtractor and onChange as above
    };
  }),
);
```

## VueUse useVirtualList {#vueuse-usevirtuallist}

```vue [TaskList.vue]
<script setup lang="ts">
import { shallowRef, useTemplateRef } from 'vue';
import { useVirtualList } from '@vueuse/core';
import { makeSortableList } from '@vue-dnd-kit/core';
import Row from './Row.vue';

const ROW = 40;
const tasks = shallowRef(makeRows(10_000));
// The outer element is the sortable list: `containerProps` owns the scroller's ref.
const listRef = useTemplateRef<HTMLElement>('list');
const { items } = makeSortableList(listRef, { items: tasks });
// A number keeps VueUse's math O(1). It must be the row's real height, borders and margins included.
const { list, containerProps, wrapperProps } = useVirtualList(items, { itemHeight: ROW, overscan: 8 });
</script>

<template>
  <div ref="list">
    <div v-bind="containerProps" style="height: 600px">
      <div v-bind="wrapperProps">
        <!-- Keyed by id, not by index as in VueUse's docs. -->
        <Row v-for="{ data } in list" :key="data.id" :item="data" :style="{ height: `${ROW}px` }" />
      </div>
    </div>
  </div>
</template>
```

VueUse не умеет закреплять перетаскиваемую строку: она размонтируется, когда вы прокрутите её из
виду. Это не страшно — см. ниже.

## Что остаётся смонтированным {#what-stays-mounted}

Перетаскиваемая строка может размонтироваться во время драга: её прокрутили за пределы диапазона
или виртуализатор переиспользовал её компонент. Драг это переживает. Оверлей продолжает
показывать элемент, выделение сохраняется по id, а элемент приземляется туда, куда его ставит
черновик. Анимации затрагивают только смонтированные строки.

Где виртуализатор это позволяет, всё же держите перетаскиваемую строку смонтированной, как
рецепт для TanStack делает с `rangeExtractor`. Список подсказывает, какая это строка:

| Возвращает список | Для чего |
| --- | --- |
| `activeIndex` | Индекс строки, которую нужно держать смонтированной, в черновике этого списка; `-1`, если её здесь нет. |
| `activeKey` | Ключ этой строки. |
| `activeSize` | Размер перетаскиваемой строки в начале драга: оценивайте по нему входящую строку. |
| `captureLayout()` | Вызывайте прямо перед изменением раскладки, которое сделала не библиотека (перемеривание). Анимирует строки от того места, где они были. Вне драга ничего не делает. |

## Деревья {#trees}

`makeSortableTree` возвращает плоский `items` из видимых строк, поэтому дерево виртуализируется
как список: ключи по `node.key`, а `activeIndex` и `activeKey` называют строку, которую нужно
держать смонтированной. См. [деревья](/docs/guides/trees).
