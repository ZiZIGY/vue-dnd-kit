## Группа {#a-group}

Списки с одинаковым именем `group` обмениваются элементами. По умолчанию каждый список — сам
себе группа.

```vue [Column.vue]
<script setup lang="ts">
import { toRef, useTemplateRef } from 'vue';
import { makeSortableList } from '@vue-dnd-kit/core';
import Card from './Card.vue';

type Task = { id: string; title: string };
const props = defineProps<{ column: { id: string; title: string; cards: Task[] } }>();

const zone = useTemplateRef<HTMLElement>('zone');
const list = useTemplateRef<HTMLElement>('list');
const { items, isOver } = makeSortableList(list, {
  id: props.column.id,                   // names the list in drop events
  items: toRef(props.column, 'cards'),   // a writable ref into the reactive column
  group: 'board',                        // same name: cards move between these lists
  dropzone: zone,                        // the whole column takes drops
});
</script>

<template>
  <section ref="zone" :class="{ over: isOver }">
    <h3>{{ column.title }}</h3>
    <ul ref="list">
      <Card v-for="card in items" :key="card.id" :card="card" />
    </ul>
  </section>
</template>
```

```vue [Board.vue]
<script setup lang="ts">
import { reactive } from 'vue';
import Column from './Column.vue';

const columns = reactive([
  { id: 'todo', title: 'To do', cards: [{ id: 'vdk-12', title: 'Pick a palette' }] },
  { id: 'done', title: 'Done', cards: [] },
]);
</script>

<template>
  <Column v-for="column in columns" :key="column.id" :column="column" />
</template>
```

- Каждая колонка — отдельный компонент: один список на компонент.
- `toRef(props.column, 'cards')` доступен для записи, потому что родитель передаёт реактивный
  объект. Бросок записывает оба массива: тот, из которого карточка ушла, и тот, в который пришла.
- `id` появляется в событиях броска как `from.list` и `to.list` и служит ключом в `e.result` —
  новых массивах всех списков, которые бросок меняет. `id` и `group` читаются один раз.
- Ключи должны быть уникальны во всей группе.

`onDrop` списка вызывается для бросков **в** него. Перенос из `todo` в `done` вызывает `onDrop`
списка `done`, а его `e.result` содержит новые массивы обоих списков.

## Вся колонка принимает броски: `dropzone` {#the-whole-column-takes-drops-dropzone}

Короткий список в высокой колонке оставляет пустое место под последней карточкой. С
`dropzone: zone` элемент колонки принимает броски за список: карточка, отпущенная ниже
последней, встаёт в конец. Карточки остаются в `<ul>`; растёт только область, которая принимает
броски.

::tip
Без `dropzone` пустому списку всё равно нужен размер, чтобы принимать броски: задайте ему
`min-height`.
::

## Что входит и выходит: `pull` и `put` {#what-goes-in-and-out-pull-and-put}

`group` принимает и объект:

```ts
group: { name: 'board', pull: true, put: true }
```

| Опция | Значения |
| --- | --- |
| `pull` | `true` (по умолчанию): элементы могут уходить. `false`: не могут. `'clone'`: уходят копии, элементы остаются. |
| `put` | `true` (по умолчанию): элементы могут входить. `false`: ничего не входит. Функция: вы решаете для каждого драга. |

Функция `put` получает `{ keys, items, types, from, to }`. `from` — список, из которого пришли
элементы, `null` для обычных перетаскиваемых элементов. Перемещения внутри списка разрешены
всегда.

### Ограничения {#limits}

Колонка, в которой не больше трёх карточек:

```ts
makeSortableList(list, {
  id: props.column.id,
  items: toRef(props.column, 'cards'),
  group: {
    name: 'board',
    put: ({ keys }) => props.column.cards.length + keys.length <= 3,
  },
});
```

Над списком, который отклоняет драг, слот возвращается туда, где драг начался, так что списки
показывают, к чему привёл бы бросок: ни к чему. Бросок туда отменяется, и карточка улетает
обратно. Во время такого драга `isAccepting` списка равен `false`: приглушите по нему колонку.

Когда перетаскивается несколько выделенных элементов разных типов, `acceptMode` определяет,
должны ли пройти `put` `'all'` (по умолчанию) или `'some'` из них. С `'some'` прошедшие
приземляются, а остальные улетают обратно.

## Копирование: палитры и клавиша Alt {#copy-palettes-and-the-alt-key}

::example{name="palette" hint="Тащите из палитры; с Alt — копия; бросьте за пределы страницы, чтобы удалить" height="24rem"}
::

```ts [Palette.vue]
makeSortableList(list, {
  items: templates,
  group: { name: 'blocks', pull: 'clone', put: false },  // copies go out, nothing comes in
  sort: false,                                           // its own order stays
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),
});
```

```ts [Sheet.vue]
makeSortableList(list, {
  items: blocks,
  group: 'blocks',
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),  // for Alt-drags
});
```

- `pull: 'clone'` копирует каждый драг из списка. Оригинал остаётся, а копия едет и
  приземляется.
- Если держать :kbd{value="Alt"} во время драга, тоже получится копия — из любого списка.
  Клавишу можно сменить опцией провайдера `copyModifier` или отключить через `null`.
- В обоих случаях списку, из которого берётся элемент, нужен `clone`. Он должен вернуть копию с
  **новым ключом**. Без `clone` ничего не копируется.
- У события броска `mode: 'copy'`, а `e.items` — это копии. Компонент оверлея тоже получает
  `mode`, чтобы показывать «+» при копировании (см. [оверлей](/docs/guides/overlay)).

## Обычные перетаскиваемые элементы в список {#plain-draggables-into-a-list}

Список принимает элементы, перетаскиваемые с `makeDraggable`, если знает, как сделать из них
элемент списка:

```ts
makeSortableList(list, {
  items: tasks,
  createItem: (active) => ({ id: crypto.randomUUID(), title: (active.data as Chip).title }),
});
```

Пока перетаскиваемый элемент над списком, созданный элемент лежит в черновике и рендерится
вашим шаблоном, как любая другая строка. Настоящим он становится при броске (`mode: 'insert'`,
`from.list === null`). Верните `undefined`, чтобы отказать. Списки без `createItem`
игнорируют обычные перетаскиваемые элементы. С клавиатуры стрелка в сторону списка принимает
перетаскиваемый элемент в него.

## Обмен местами вместо сдвига {#swap-instead-of-shift}

```ts
makeSortableList(grid, { items: tiles, strategy: 'grid', behavior: 'swap' });
```

Перетаскиваемый элемент меняется местами с тем, что под ним, а остальные стоят на месте. Обмен
происходит на лету: если вернуться назад или уйти со списка, он отменяется. У события броска
`mode: 'swap'` и `partner` — элемент, с которым произошёл обмен.

- Два списка одной группы меняются элементами между собой, если у обоих
  `behavior: 'swap'`. Элемент под курсором переходит в другой список, поэтому ему должно быть
  разрешено выходить (`pull: true`) и входить (`put`).
- Мульти-драг сортирует, а не меняет местами.

## Линия вставки {#an-insertion-line}

С `placeholder: 'indicator'` список во время драга стоит на месте, а линия показывает, куда
придётся бросок. Линию рисуете вы:

```ts [TaskList.vue]
const { items, indicator } = makeSortableList(listRef, { items: tasks, placeholder: 'indicator' });
```

```vue [TaskRow.vue]
<script setup lang="ts">
const { indicator } = makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el" :class="indicator && `drop-${indicator.side}`">{{ task.title }}</li>
</template>

<style scoped>
.drop-before { box-shadow: inset 0 2px 0 #42b883; }
.drop-after { box-shadow: inset 0 -2px 0 #42b883; }
</style>
```

| Поле `indicator` | Что содержит |
| --- | --- |
| `list` | Список, в который идёт бросок. |
| `index` | Индекс вставки в списке в том виде, как он отрендерен. |
| `key` | Элемент, к которому привязана линия; `null` в пустом списке (тогда рисуйте её в списке). |
| `side` | `'before'` или `'after'` этого элемента. Деревья добавляют `'inside'`. |
| `depth`, `parentKey` | Только для деревьев: куда приземлится бросок. См. [деревья](/docs/guides/trees#an-insertion-line). |

`indicator` списка задан, пока линия в этом списке, а `indicator` элемента — пока она
привязана к этому элементу. Клавиатура тоже двигает линию.

## Бросок за пределами целей {#dropping-outside}

Что происходит, когда драг заканчивается вообще не над целью, решает опция списка
`dropOutside`:

| `dropOutside` | Элементы |
| --- | --- |
| `'placeholder'` (по умолчанию) | Приземляются туда, где последний раз был показан слот. |
| `'cancel'` | Улетают обратно. Значение по умолчанию при `placeholder: 'indicator'`. |
| `'remove'` | Покидают свой список: утащите за пределы, чтобы удалить. |

`'remove'` сначала спрашивает `onBeforeDrop` списка. Затем вызывается `onDrop` списка с
`to.index === -1`, а `e.result` содержит список без этих элементов. Корзина, которая принимает
броски, работает так же: см. [корзины](/docs/guides/drag-and-drop#trash-zones).

Как подтвердить перемещение, сначала сохранить его на сервер или самостоятельно применять
броски к стору — см. [решения о броске](/docs/guides/drop-decisions). Все опции списка — в
[API makeSortableList](/docs/api/make-sortable-list).
