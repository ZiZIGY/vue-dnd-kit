## На что обратить внимание {#what-to-look-at}

- **`TaskList.vue`**: виртуальному списку отдаётся черновик `items`, а не исходный массив,
  поэтому строки двигаются во время драга. Массив — `shallowRef`.
- **`TaskList.vue`**: ключи строк — по id, а не по индексу, как в документации VueUse.
- **`Row.vue`**: id — геттер, `{ id: () => props.task.id }`: виртуальный список может отдать
  компоненту другую задачу.
