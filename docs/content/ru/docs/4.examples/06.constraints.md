## На что обратить внимание {#what-to-look-at}

- **`Board.vue`**: `makeDragArea(board, { axis, restrictToArea, modifiers })` задаёт правила для
  каждого драга, который начинается на доске. Опции — это ref и геттер, которые читаются в
  начале драга, поэтому переключатели действуют со следующего драга.
- Доска — ещё и цель; `onDragEnd` ставит заметку в `position` — те `left`/`top`, где её бросили.
- **`Note.vue`** только сообщает, что её можно перетаскивать: остальное делает область.
