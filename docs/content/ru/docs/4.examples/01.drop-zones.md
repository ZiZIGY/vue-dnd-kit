## На что обратить внимание {#what-to-look-at}

- **`FileCard.vue`**: обычный `makeDraggable` с `type` — `image` или `doc`.
- **`Folder.vue`**: `makeDroppable`, чей `accept` принимает один тип (`'*'` для рабочего стола и
  корзины). `isAccepting` подсвечивает папки, которые принимают драг; папка, которая не
  принимает, показывает это через `isOver && !isAccepting`. `onDrop` — место, где меняются
  данные: сама библиотека ничего не перемещает.
- Файлы везде выглядят одинаково, поэтому бросок — это только полёт; оставшиеся файлы
  сдвигаются в образовавшийся промежуток с помощью `<TransitionGroup>` из Vue.
