## На что обратить внимание {#what-to-look-at}

- **`FileTree.vue`**: `makeSortableTree` с `indentation`, `collapsed` и
  `canNest: (_node, parent) => !!parent.folder` — потомков принимают только папки.
- **`TreeRow.vue`**: каждая строка — элемент сортируемого списка с ключом `node.key`; её отступ
  слева следует за `node.depth`, в том числе во время драга, поэтому слот показывает глубину,
  которую получит бросок.
