Каждый пример — небольшое Vue-приложение: `index.vue` со своим `DnDProvider` и нужные ему
компоненты. Вкладки с кодом под демо — это те самые файлы, которые его запускают.

## Приложения {#apps}

Целые интерфейсы — такие, какими вы бы их строили сами: несколько списков, правила, оверлеи и
клавиатура работают вместе.

::card-group

::card{title="Доска проекта" icon="i-lucide-square-kanban" to="/docs/examples/board"}
Колонки, которые можно переставлять, WIP-лимиты, подтверждение перед Done, множественное
выделение и корзина.
::

::card{title="Календарь на неделю" icon="i-lucide-calendar-days" to="/docs/examples/calendar"}
События перетаскиваются между днями и получасами с привязкой к сетке.
::

::card{title="Файловый менеджер" icon="i-lucide-folder-open" to="/docs/examples/file-manager"}
Дерево папок и сетка файлов: выделение рамкой, броски на папки, Alt для копирования.
::

::card{title="Блочный редактор" icon="i-lucide-blocks" to="/docs/examples/block-editor"}
Блоки в духе Notion: перемещаются за ручки, вкладываются друг в друга и вставляются из палитры.
::

::card{title="Шахматы" icon="i-lucide-chess-knight" to="/docs/examples/chess"}
Доска, поля которой принимают только допустимые ходы: взятия, очерёдность ходов, приподнятая
фигура, стрелки.
::

::

## Строительные блоки {#building-blocks}

В каждом — одна идея, и каждый можно прочитать за минуту.

::card-group

::card{title="Канбан-доска" icon="i-lucide-columns-3" to="/docs/examples/kanban"}
Колонки, которые обмениваются карточками и принимают броски по всей своей высоте.
::

::card{title="Списки и сетки" icon="i-lucide-list-ordered" to="/docs/examples/lists"}
Плейлист, который перетаскивают за ручку по одной оси, и сетка приложений домашнего экрана.
::

::card{title="Дерево файлов" icon="i-lucide-list-tree" to="/docs/examples/tree"}
Проводник редактора: вложение сдвигом вбок или наведением на папку.
::

::card{title="Мульти-драг" icon="i-lucide-images" to="/docs/examples/multi-drag"}
Выделите рамкой или Ctrl/Cmd-кликом, затем перенесите всё выделение.
::

::card{title="Drag and drop" icon="i-lucide-folder-input" to="/docs/examples/drop-zones"}
Файлы раскладываются по папкам, каждая из которых принимает один тип; корзина принимает любые.
::

::card{title="Оси, границы и сетки" icon="i-lucide-frame" to="/docs/examples/constraints"}
Доска, правила которой меняются на лету: фиксация оси, её края, сетка.
::

::
