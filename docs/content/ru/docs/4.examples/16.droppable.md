## На что обратить внимание {#what-to-look-at}

- **`FileChip.vue`**: у каждого файла есть `type` — то, что проверяют цели.
- **`Zone.vue`**: `accept` принимает тип или список типов. `isAccepting` подсвечивает зоны,
  которые приняли бы драг; `isOver` без `isAccepting` — зона, которая его отклоняет.
- **`index.vue`**: цель сама ничего не перемещает: `onDrop` сообщает, какой файл пришёл, а
  перемещает его приложение.
