## На что обратить внимание {#what-to-look-at}

- **`TrackRow.vue`**: `moveItem(id, { index })` для кнопок со стрелками и
  `startDrag(id, { type: 'keyboard' })`, чтобы передать строку клавишам со стрелками.
- **`Queue.vue`**: перемешивание ждёт один `moveItem` за другим; драг по сценарию начинается со
  `startDrag`, скользит через `moveTo` и приземляется через `drop()`.
