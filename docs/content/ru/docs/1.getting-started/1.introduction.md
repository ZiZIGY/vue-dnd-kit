## Что это

Vue DnD Kit — это набор **композаблов** и один компонент-**провайдер**. Вы рендерите свои
элементы и передаёте их template ref в композаблы, а остальное делает библиотека: ввод с мыши,
тача и клавиатуры, поиск цели, пересортировку, анимации, автоскролл и озвучивание для
скринридеров.

Сама библиотека не рендерит ничего, кроме плавающего **оверлея** — по умолчанию это клон
перетаскиваемого элемента. Разметка и стили остаются вашими.

## Что вы получаете

- **Сортируемые списки и сетки**, которые перестраиваются прямо во время драга. Вы рендерите
  *черновик* массива, а при броске библиотека записывает новый порядок в ваш ref.
- **Канбан-доски**: списки одной группы обмениваются элементами. Копирование из палитры, приём
  внешних draggable, обмен местами вместо сдвига.
- **Деревья**: вложение сдвигом вбок или наведением на строку, ограничение глубины и правила.
- **Мульти-драг** с вашим собственным выделением (Ctrl-клик, рамка): блок едет целиком.
- **Анимации по умолчанию**: элементы плавно встают на новые места, бросок приземляется на слот.
- **Доступность**: перенос с клавиатуры по слотам, озвучивание, ARIA-атрибуты.
- **Виртуальные списки**: TanStack Virtual и VueUse, тысячи строк.
- **Управляемый режим** для сторов и серверов: пропустите запись по умолчанию и примените результат.

## Как всё устроено

| Часть | Что делает |
| --- | --- |
| `DnDProvider` | Владеет драгом: ввод, оверлей, выделение, автоскролл, озвучивание. |
| `makeSortableList` / `makeSortableItem` | Сортируемый список и его строки. |
| `makeSortableTree` | Дерево, отрисованное плоско с глубинами. |
| `makeDraggable` / `makeDroppable` | Свободный драг и зоны сброса. |
| `makeDragArea` | Правила для части страницы: ось, границы, привязка к сетке, автоскролл. |
| `makeSelectionArea` | Выделение рамкой. |
| `useDnD` / `useDnDMonitor` | Состояние драга и его события в любом месте под провайдером. |

::tip
Переходите с v2? API изменился: `useDnDProvider` стал `useDnD`, а `makeConstraintArea` и
`makeAutoScroll` объединились в `makeDragArea`. Сортируемые списки теперь встроены.
::

## Требования

- Vue **3.5** или новее.
- Современные браузеры: Chrome и Edge 104+, Safari 15.4+, Firefox 104+.
- Работает с SSR и Nuxt: оверлей и live-регион монтируются на клиенте.
