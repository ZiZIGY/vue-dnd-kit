## Что это {#what-it-is}

Vue DnD Kit — это набор **композаблов** и один компонент-**провайдер**. Вы рендерите свои
элементы и передаёте их template ref в композаблы, а остальное делает библиотека: ввод
указателем, касанием и с клавиатуры, поиск цели, пересортировку, анимации, автоскролл и
сообщения скринридерам о том, что произошло.

Сама библиотека не рендерит ничего, кроме плавающего **оверлея** — по умолчанию это клон
перетаскиваемого элемента. Разметка и стили остаются вашими.

## Что вы получаете {#what-you-get}

- **Сортируемые списки и сетки**, которые перестраиваются прямо во время драга. Вы рендерите
  *черновик* массива, а при броске библиотека записывает новый порядок в ваш ref.
- **Канбан-доски**: списки одной группы обмениваются элементами. Копирование из палитр, приём
  обычных перетаскиваемых элементов, обмен местами вместо сдвига.
- **Деревья**: вложение сдвигом по горизонтали или наведением на строку, ограничение глубины и
  правила.
- **Мульти-драг** с вашим собственным выделением (Ctrl-клик, рамка): блок перемещается целиком.
- **Анимации по умолчанию**: элементы плавно встают на новые места, бросок приземляется на свой
  слот.
- **Доступность**: перетаскивание с клавиатуры по слотам, озвучивание на лету, ARIA-атрибуты.
- **Виртуальные списки**: TanStack Virtual и VueUse, тысячи строк.
- **Управляемый режим** для сторов и серверов: пропустите запись по умолчанию и примените
  результат сами.

## Как всё устроено {#how-it-fits-together}

| Часть | Что делает |
| --- | --- |
| `DnDProvider` | Отвечает за драг: ввод, оверлей, выделение, автоскролл, озвучивание. |
| `makeSortableList` / `makeSortableItem` | Список, который сортируется, и его строки. |
| `makeSortableTree` | Дерево, отрисованное плоским списком с глубинами. |
| `makeDraggable` / `makeDroppable` | Свободное перетаскивание и зоны сброса. |
| `makeDragArea` | Правила для части страницы: ось, границы, привязка к сетке, автоскролл. |
| `makeSelectionArea` | Выделение рамкой. |
| `useDnD` / `useDnDMonitor` | Состояние драга и его события в любом месте под провайдером. |

::tip
Переходите с v2? API изменился: `useDnDProvider` стал `useDnD`, а `makeConstraintArea` и
`makeAutoScroll` — `makeDragArea`. Сортируемые списки теперь встроены.
::

## Требования {#requirements}

- Vue **3.5** или новее.
- Современные браузеры: Chrome и Edge 104+, Safari 15.4+, Firefox 104+.
- Работает с SSR и Nuxt: оверлей и live-регион монтируются на клиенте.
