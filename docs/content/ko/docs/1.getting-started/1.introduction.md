## Vue DnD Kit이란 {#what-it-is}

Vue DnD Kit은 **컴포저블** 모음과 **프로바이더** 컴포넌트 하나로 이루어져 있습니다. 요소는 직접
렌더링하고, 그 템플릿 ref를 컴포저블에 넘기면 됩니다. 나머지는 라이브러리가 처리합니다. 포인터,
터치, 키보드 입력, 대상 찾기, 순서 변경, 애니메이션, 자동 스크롤, 그리고 무슨 일이 일어났는지
스크린 리더에 알리는 일까지 맡습니다.

라이브러리가 직접 렌더링하는 것은 떠다니는 **오버레이** 하나뿐입니다. 기본값은 드래그 중인 요소의
클론입니다. 마크업과 스타일은 그대로 여러분의 것입니다.

## 제공하는 기능 {#what-you-get}

- 드래그하는 동안 실시간으로 순서가 바뀌는 **정렬 가능한 리스트와 그리드**. 배열의 *초안*을
  렌더링하면, 드롭할 때 라이브러리가 새 순서를 ref에 기록합니다.
- **칸반 보드**: 같은 그룹의 리스트끼리 항목을 주고받습니다. 팔레트에서 복사하고, 일반 draggable을
  받아들이고, 밀어내는 대신 자리를 맞바꿀 수 있습니다.
- **트리**: 가로 오프셋이나 행 위에 머무르는 방식으로 중첩하며, 깊이 제한과 규칙을 둘 수 있습니다.
- 직접 만든 선택(Ctrl-클릭, 선택 사각형)으로 하는 **멀티 드래그**: 선택한 블록이 함께 움직입니다.
- **기본 애니메이션**: 항목은 새 자리로 미끄러지듯 이동하고, 드롭한 항목은 제자리에 안착합니다.
- **접근성**: 자리 단위로 움직이는 키보드 드래그, 실시간 안내, ARIA 속성.
- **가상 리스트**: TanStack Virtual과 VueUse로 수천 개의 행을 다룹니다.
- 스토어와 서버를 위한 **제어 모드**: 기본 기록을 건너뛰고 결과를 직접 적용합니다.

## 구성 요소 {#how-it-fits-together}

| 구성 요소 | 하는 일 |
| --- | --- |
| `DnDProvider` | 드래그를 관리합니다. 입력, 오버레이, 선택, 자동 스크롤, 안내 문구. |
| `makeSortableList` / `makeSortableItem` | 순서가 바뀌는 리스트와 그 행. |
| `makeSortableTree` | 깊이와 함께 평평하게 렌더링되는 트리. |
| `makeDraggable` / `makeDroppable` | 자유로운 드래그와 드롭 영역. |
| `makeDragArea` | 페이지 일부에 적용하는 규칙: 축, 경계, 스냅, 자동 스크롤. |
| `makeSelectionArea` | 사각형 선택. |
| `useDnD` / `useDnDMonitor` | 프로바이더 아래 어디서든 쓰는 드래그 상태와 이벤트. |

::tip
v2에서 넘어오셨다면, API가 바뀌었습니다. `useDnDProvider`는 `useDnD`가 되었고, `makeConstraintArea`와
`makeAutoScroll`은 `makeDragArea`로 합쳐졌습니다. 정렬 가능한 리스트는 이제 기본으로 들어 있습니다.
::

## 요구 사항 {#requirements}

- Vue **3.5** 이상.
- 최신 브라우저: Chrome과 Edge 104+, Safari 15.4+, Firefox 104+.
- SSR과 Nuxt에서 동작합니다. 오버레이와 라이브 리전은 클라이언트에서 마운트됩니다.
