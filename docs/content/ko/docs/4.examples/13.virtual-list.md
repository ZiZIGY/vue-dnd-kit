## 살펴볼 점 {#what-to-look-at}

- **`TaskList.vue`**: 가상 리스트에 원본 배열이 아니라 초안 `items`를 넘기므로, 드래그하는 동안
  행이 움직입니다. 배열은 `shallowRef`입니다.
- **`TaskList.vue`**: 행의 key는 VueUse 문서처럼 인덱스가 아니라 id입니다.
- **`Row.vue`**: id는 getter `{ id: () => props.task.id }`입니다. 가상 리스트가 컴포넌트에 다른
  작업을 넘길 수 있기 때문입니다.
