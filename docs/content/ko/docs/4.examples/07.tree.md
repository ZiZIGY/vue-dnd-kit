## 살펴볼 점 {#what-to-look-at}

- **`FileTree.vue`**: `indentation`, `collapsed`, `canNest: (_node, parent) => !!parent.folder`를
  쓰는 `makeSortableTree`. 폴더만 자식을 받습니다.
- **`TreeRow.vue`**: 각 행은 `node.key`로 식별하는 정렬 가능한 항목입니다. 왼쪽 패딩이 드래그 중에도
  `node.depth`를 따르므로, 자리가 드롭될 깊이를 보여 줍니다.

더 읽어 보기: [트리](/docs/guides/trees) · [`makeSortableTree`](/docs/api/make-sortable-tree)
