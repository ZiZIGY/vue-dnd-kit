각 예제는 작은 Vue 앱입니다. `DnDProvider`가 들어 있는 `index.vue`와 필요한 컴포넌트로 이루어져
있습니다. 데모 아래의 코드 탭은 그 데모를 실행하는 바로 그 파일들입니다.

## 앱 {#apps}

실제로 만들 때와 같은 방식으로 만든 완전한 인터페이스입니다. 여러 리스트, 규칙, 오버레이, 키보드가
함께 동작합니다.

::card-group

::card{title="프로젝트 보드" icon="i-lucide-square-kanban" to="/docs/examples/board"}
순서를 바꿀 수 있는 컬럼, WIP 제한, Done 전의 확인, 다중 선택, 휴지통.
::

::card{title="주간 캘린더" icon="i-lucide-calendar-days" to="/docs/examples/calendar"}
요일과 30분 단위를 넘나들며 드래그하고 그리드에 스냅되는 일정.
::

::card{title="파일 관리자" icon="i-lucide-folder-open" to="/docs/examples/file-manager"}
폴더 트리와 파일 그리드: 선택 사각형으로 고르고, 폴더에 놓고, Alt로 복사합니다.
::

::card{title="블록 에디터" icon="i-lucide-blocks" to="/docs/examples/block-editor"}
핸들로 옮기고, 중첩하고, 팔레트에서 삽입하는 Notion 같은 블록.
::

::card{title="체스" icon="i-lucide-chess-knight" to="/docs/examples/chess"}
칸마다 합법적인 수만 받는 체스판. 기물 잡기, 차례, 들어 올린 기물, 화살표 키.
::

::

## 기본 구성 요소 {#building-blocks}

각각 한 가지 아이디어만 다루며, 1분이면 읽을 수 있을 만큼 작습니다.

::card-group

::card{title="칸반 보드" icon="i-lucide-columns-3" to="/docs/examples/kanban"}
카드를 주고받고, 높이 어디에서든 드롭을 받는 컬럼.
::

::card{title="리스트와 그리드" icon="i-lucide-list-ordered" to="/docs/examples/lists"}
그립으로 한 축을 따라 드래그하는 재생 목록과, 홈 화면 앱 그리드.
::

::card{title="파일 트리" icon="i-lucide-list-tree" to="/docs/examples/tree"}
에디터의 탐색기: 옆으로 드래그하거나 폴더 위에 머물러 중첩합니다.
::

::card{title="멀티 드래그" icon="i-lucide-images" to="/docs/examples/multi-drag"}
선택 사각형이나 Ctrl/Cmd-클릭으로 선택한 뒤, 선택 전체를 옮깁니다.
::

::card{title="드래그 앤 드롭" icon="i-lucide-folder-input" to="/docs/examples/drop-zones"}
각각 한 종류만 받는 폴더로 파일을 분류하고, 휴지통은 무엇이든 받습니다.
::

::card{title="축, 경계, 그리드" icon="i-lucide-frame" to="/docs/examples/constraints"}
규칙이 실시간으로 바뀌는 보드: 축 고정, 가장자리, 그리드.
::

::
