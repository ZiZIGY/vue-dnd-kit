## 살펴볼 점 {#what-to-look-at}

- **`FileCard.vue`**: `type`(`image` 또는 `doc`)이 있는 일반 `makeDraggable`.
- **`Folder.vue`**: `accept`가 한 타입만 받는 `makeDroppable`(바탕화면과 휴지통은 `'*'`).
  `isAccepting`은 드래그를 받아들이는 폴더를 강조하고, 받아들이지 않는 폴더는
  `isOver && !isAccepting`으로 이를 표시합니다. 데이터는 `onDrop`에서 바뀝니다. 라이브러리는
  스스로 아무것도 옮기지 않습니다.
- 파일은 어디서나 모양이 같으므로 드롭은 날아가는 움직임뿐입니다. 남은 파일은 Vue의
  `<TransitionGroup>`으로 빈자리로 미끄러져 들어갑니다.
