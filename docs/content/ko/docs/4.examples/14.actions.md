## 살펴볼 점 {#what-to-look-at}

- **`TrackRow.vue`**: 화살표 버튼에는 `moveItem(id, { index })`를, 행을 화살표 키에 넘길 때는
  `startDrag(id, { type: 'keyboard' })`를 씁니다.
- **`Queue.vue`**: 섞기는 `moveItem`을 하나씩 차례로 await합니다. 스크립트 드래그는
  `startDrag`로 시작해 `moveTo`로 미끄러지듯 움직이고 `drop()`으로 안착합니다.

더 읽어 보기: [센서와 프로그래밍 방식 드래그](/docs/guides/sensors#programmatic-drags)
