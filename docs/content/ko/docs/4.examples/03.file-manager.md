## 살펴볼 점 {#what-to-look-at}

- **`FileGrid.vue`**: 파일은 `clone`을 쓰는 정렬 가능한 그리드(`strategy: 'grid'`)라서, Alt를
  누르면 옮기는 대신 복사합니다. `makeSelectionArea`가 선택 사각형을 그리고, 이렇게 만든 선택이
  멀티 드래그가 옮기는 선택이 되어 더미로 표시됩니다.
- **`FileTile.vue`**: `makeSortableItem`의 `selected`를 클릭과 Ctrl/Cmd-클릭에 연결합니다.
- **`useFolderDrop.ts`**: 트리의 행과 폴더 타일은 드롭 대상입니다. `accept`는 함수입니다. 폴더는
  자기 자신, 자신의 하위 폴더, 그리고 열려 있는 폴더를 거부합니다. 폴더 타일에서는 타일의 가운데만
  드롭을 받고, 가장자리 근처에서는 그리드가 정렬됩니다.
- **`FileManager.vue`**: 일반 드롭 대상은 Alt를 모르므로, 키를 직접 읽어(VueUse의
  `useKeyModifier`) 복사할지 옮길지 정합니다.
