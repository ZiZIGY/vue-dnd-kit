## 살펴볼 점 {#what-to-look-at}

- **`Dashboard.vue`**: 그리드는 `strategy: 'grid'`를 쓰는 정렬 가능한 리스트 하나이며, 이 전략은
  크기가 서로 다른 위젯을 정렬합니다. 컬럼 수는 자기 너비(`useElementSize`)로 셉니다. 4개, 3개, 또는
  2개입니다. 행은 높이가 최소 92 px이고 내용에 따라 커지며, `grid-auto-flow: dense`가 크기 조절로
  생긴 빈자리를 채웁니다.
- **`Widget.vue`**: 위젯은 헤더(`handle`)로 움직이므로 내용은 자유롭게 쓸 수 있습니다. 작업은 체크할
  수 있고, 메모에는 글을 입력할 수 있습니다. 모서리는 그 자체로 draggable이며, 위젯의 크기를
  바꿉니다.
- **`WidgetBody.vue`**: 위젯이 보여 주는 내용입니다. 메모에 입력해 보세요. 행은 글에 맞춰 커지고, 옆의
  위젯도 행에 맞춰 커집니다. 아무것도 위젯을 측정하지 않습니다. 이것은 그리드 자체의 레이아웃이며,
  라이브러리는 드래그가 시작될 때의 크기를 있는 그대로 읽습니다.
- **`widgets.ts`**: 위젯, 칸 단위의 크기, 그리드의 수치.

예제를 펼쳐 보세요. 그리드가 4컬럼이 되고, 작은 화면에서 좁아졌던 위젯은 다시 원래 너비로
돌아갑니다.

## 크기 조절: 모서리는 draggable입니다 {#resizing-the-corner-is-a-draggable}

모서리는 위젯 안에 있고, 누르면 가장 가까운 draggable, 즉 위젯이 아니라 모서리가 드래그됩니다.
모서리에는 오버레이가 없고, 절대 움직이지 않습니다. 대신 위젯이 커집니다.

```ts [Widget.vue]
makeDraggable(corner, {
  id: cornerId,
  type: 'resize',
  overlay: false,
  activation: { touch: { distance: 4 } }, // a finger resizes at once, not after a long press
  attributes: false,                       // no tab stop: Shift + arrows on the header resize
});
```

크기는 포인터를 따라갑니다. 누른 곳에서 포인터가 얼마나 움직였는지를 칸 단위로 셉니다. 모서리를
잡고 있는 동안 그리드는 그 크기를 보여 주고, 그리드의 다른 위젯들은 자리를 내줍니다.

```ts [Widget.vue]
const preview = computed<Size | null>(() => {
  const start = from.value;
  if (!resizing.value || !start || !pointer.value) return null;
  return {
    w: clamp(cellsIn(pixels(own.value.w, props.cell) + pointer.value.x - start.x, props.cell), 1, props.columns),
    h: clamp(cellsIn(pixels(own.value.h, ROW) + pointer.value.y - start.y, ROW), 1, MAX_ROWS),
  };
});
```

드롭하면 그 크기가 유지됩니다. 모니터가 모서리의 `onDragEnd`를 듣습니다. :kbd{value="Escape"}는
대신 드래그를 취소하고, 위젯은 원래 크기로 돌아갑니다.

```ts [Widget.vue]
useDnDMonitor({
  onDragEnd: ({ active: dropped }) => {
    if (dropped.id === cornerId() && preview.value) emit('resize', preview.value);
  },
});
```

## 그리드는 크기 조절에 끼지 않습니다 {#the-grid-sits-the-resize-out}

모서리는 위젯이 아니므로 그리드는 그것을 거부할 것입니다. 드래그를 거부하는 대상에 드롭하면 취소가
됩니다. 그래서 모서리를 드래그하는 동안 그리드는 `disabled`이고, 모서리의 드롭은 어떤 대상 위에도
놓이지 않습니다.

```ts [Dashboard.vue]
const { active } = useDnD();
const { items } = makeSortableList(grid, {
  items: widgets,
  strategy: 'grid',
  label: 'Dashboard',
  disabled: () => !!active.value?.type.includes('resize'),
});
```

## 맞춰지는 크기 {#sizes-that-adapt}

위젯은 주어진 크기를 유지합니다. 컬럼이 적을 때도 그리드보다 넓어지지 않고(`Math.min(w, columns)`),
그리드에 다시 공간이 생기면 원래 너비를 되찾습니다. 행에는 높이가 아니라 최소 높이가 있습니다.
높이는 내용이 정하고, 한 행의 위젯은 모두 가장 높은 위젯에 맞춰 늘어납니다.

## 키보드 {#the-keyboard}

Tab으로 위젯의 헤더에 가서 :kbd{value="Space"}를 눌러 위젯을 집으세요. 화살표 키는 다른 위젯
사이에서 위젯을 옮기고, :kbd{value="Space"}는 드롭하고, :kbd{value="Escape"}는 되돌립니다. 헤더에
포커스가 있을 때 :kbd{value="Shift"}와 화살표 키를 누르면 위젯의 크기가 한 칸씩 바뀌고, 스크린
리더는 새 크기를 듣습니다.
