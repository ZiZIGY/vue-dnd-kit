## 살펴볼 점 {#what-to-look-at}

- **`Board.vue`**: 컬럼들은 그 자체로 가로 방향의 정렬 가능한 리스트이고, 각 컬럼은 헤더로
  드래그하는 정렬 가능한 항목입니다(`handle`).
- **`Column.vue`**: 모든 컬럼의 카드가 하나의 `group`입니다. `put`은 들어오는 카드 수를 세는
  함수이므로, WIP 제한에 다다른 컬럼은 드래그를 거부하고 자리는 원래 컬럼에 남습니다. 비동기
  `onBeforeDrop`은 카드가 Done에 들어가기 전에 확인을 묻고, `'accept'`, `'reject'`,
  `'continue'`(계속 드래그) 중 하나로 답합니다.
- **`Card.vue`**: `makeSortableItem`의 `selected`를 Ctrl/Cmd-클릭에 연결합니다. 멀티 드래그는
  선택 항목 전체를 옮깁니다.
- **`Trash.vue`**: 카드만 받고(`accept: 'card'`) `e.source.remove()`로 제거하는 일반 드롭
  대상입니다.
- **`CardOverlay.vue`**: 카드의 오버레이 컴포넌트(리스트의 `overlay`)로, `DragPreview` 클론으로
  만듭니다. 드래그하는 동안 카드가 기울고, 선택의 나머지는 그 아래에 쌓이며, 안착할 때 다시 바로
  섭니다(`status`).
