```vue [App.vue]
<script setup lang="ts">
import { DnDProvider } from '@vue-dnd-kit/core';
</script>

<template>
  <DnDProvider :animation="{ duration: 200 }" @drag-end="save">
    <RouterView />
    <template #overlay="{ items, over, accepted }">
      <!-- optional: a custom overlay for every drag -->
    </template>
  </DnDProvider>
</template>
```

모든 컴포저블은 프로바이더 **안에서** 렌더링되는 컴포넌트에서 실행되어야 합니다. 앱 전체에
프로바이더 하나를 두는 것이 목표입니다. 페이지 일부의 규칙은
[`makeDragArea`](/docs/api/make-drag-area)로 따로 지정합니다. [프로바이더 가이드](/docs/guides/provider)를
참고하세요.

## 이벤트 {#events}

| 이벤트 | 페이로드 | 시점 |
| --- | --- | --- |
| `drag-start` | `DnDEvent` | 드래그가 시작되었습니다(활성화 이후). |
| `drag-move` | `DnDEvent` | 드래그 중에 포인터가 움직였습니다(최대 프레임당 한 번). |
| `drag-over` | `DnDEvent` | 드래그 아래의 대상이 바뀌었습니다. |
| `drag-end` | `DnDEndEvent` | 드롭이 완료되고 기록되었습니다. |
| `drag-cancel` | `DnDEvent` | 드래그가 취소되었거나 드롭이 거부되었습니다. |

같은 이벤트와 함께 `onBeforeDrop`, `onDragResume`도 [`useDnDMonitor`](/docs/api/use-dnd)로
프로바이더 아래 어디서든 받을 수 있습니다. 페이로드는 [이벤트 페이지](/docs/api/events)에 있습니다.

## `#overlay` 슬롯 {#slot-overlay}

자체 오버레이 컴포넌트가 없는 모든 드래그에서 포인터를 따라다니는 것을 렌더링합니다
([오버레이 가이드](/docs/guides/overlay) 참고). 아무것도 렌더링하지 않으면 클론을 사용합니다.
