프로바이더의 `animation`(정렬 중 레이아웃 이동), `dropAnimation`(오버레이 안착), `animate`(드래그가
아닌 데이터 변경)는 `false`, 옵션, 또는 직접 만든 함수를 받습니다. GSAP이나 motion에 쓸 수 있습니다.
리스트와 트리는 `animation`과 `animate`를 재정의할 수 있습니다.
[애니메이션](/docs/guides/animations)을 참고하세요.

```vue
<DnDProvider :animation="{ duration: 180, easing: 'ease-out' }" :drop-animation="false" />
```
