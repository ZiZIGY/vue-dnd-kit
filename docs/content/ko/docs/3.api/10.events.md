`DnDEndEvent`를 받습니다. 정렬 가능한 리스트와 트리는 자체 드롭 이벤트
([`SortableDropEvent`](/docs/api/make-sortable-list#the-drop-event),
[`SortableTreeDropEvent`](/docs/api/make-sortable-tree#the-drop-event))를 자신의 `onBeforeDrop`과 `onDrop`에 넘깁니다.
