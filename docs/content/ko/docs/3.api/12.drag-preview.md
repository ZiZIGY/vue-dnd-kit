## DragPreview {#dragpreview}

```vue [StackOverlay.vue]
<script setup lang="ts">
import { DragPreview, type DragItem } from '@vue-dnd-kit/core';

defineProps<{ items: DragItem[] }>();
</script>

<template>
  <div class="stack">
    <DragPreview v-for="item in items.slice(0, 3)" :id="item.id" :key="item.id" />
  </div>
</template>
```

클론은 집을 때 만들어집니다. 집은 항목과, 드롭 순서상 그 옆에 있는 최대 네 개 항목의 클론입니다.
그 밖의 항목에 대해서는 `DragPreview`가 기본 슬롯을 렌더링하거나 아무것도 렌더링하지 않습니다. 각
미리보기는 드롭이 안착할 때 자기 항목 위에 안착합니다. [오버레이 가이드](/docs/guides/overlay)를
참고하세요.

::api-table{name="DragPreviewProps"}
::

## 오버레이 props {#overlay-props}

오버레이 컴포넌트(draggable, 정렬 가능한 항목, 리스트, 트리의 `overlay` 옵션)와 프로바이더의
`#overlay` 슬롯이 받는 것입니다.

::api-table{name="OverlaySlotProps"}
::

`OverlayProps`는 `defineProps<OverlayProps>()`에 쓰는 같은 타입입니다.
