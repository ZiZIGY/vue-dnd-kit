## 선택 {#the-selection}

각 프로바이더는 선택 하나를 유지합니다. 반응형 id 집합입니다. **선택된** 항목을 드래그하면 선택된
모든 항목이 함께 드래그되며, 집은 항목이 맨 앞에 옵니다. 선택되지 않은 항목을 드래그하면 그 항목만
드래그됩니다.

라이브러리는 사용자가 어떻게 선택할지 정하지 않습니다. 클릭 규칙은 직접 정합니다. 라이브러리는
선택을 스스로 해제하지도 않으며, 가상 리스트가 재활용하는 행처럼 언마운트되어도 선택은 유지됩니다.

### Ctrl/Cmd-클릭 {#ctrlcmd-click}

모든 정렬 가능한 항목과 draggable은 선택과 연결된 쓰기 가능한 ref인 `selected`를 반환합니다:

```vue [Shot.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ shot: { id: string } }>();
const el = useTemplateRef<HTMLElement>('el');
const { selected } = makeSortableItem(el, { item: () => props.shot });

const onClick = (event: MouseEvent) => {
  if (event.ctrlKey || event.metaKey) selected.value = !selected.value;
};
</script>

<template>
  <div ref="el" :class="{ selected }" @click="onClick">…</div>
</template>
```

드래그를 끝내는 클릭은 `@click`에 도달하지 않으므로, 드롭이 실수로 선택을 토글하는 일은 없습니다.
항목 동작에는 `pointerup`이 아니라 `@click`을 사용하세요.

### 어디서든: `useDnD().selection` {#from-anywhere-usedndselection}

```ts
import { useDnD, useDnDMonitor } from '@vue-dnd-kit/core';

const { selection } = useDnD();

selection.has('a');               // is it selected?
selection.add('a', 'b');          // select
selection.delete('a');            // deselect
selection.toggle('a');            // flip it, or force it: toggle('a', true)
selection.set(['a', 'c']);        // exactly these
selection.clear();
selection.ids;                    // a reactive ReadonlySet<Key>

// A plain click selects only that item, Ctrl/Cmd-click adds or removes it:
const onClick = (event: MouseEvent, id: string) => {
  if (event.ctrlKey || event.metaKey) selection.toggle(id);
  else selection.set([id]);
};

// Clear it after every drop, if your UI wants that:
useDnDMonitor({ onDragEnd: () => selection.clear() });
```

선택은 id를 기준으로 하므로 여러 리스트의 항목을 담을 수 있습니다. 드래그는 프로바이더 아래의
선택된 모든 항목을 가져갑니다.

## 사각형 선택 {#rubber-band-selection}

`makeSelectionArea`는 요소를 선택 영역으로 만듭니다. 빈 공간을 누르면 사각형이 그려지고, 사각형이
지나가는 항목이 선택됩니다:

```vue [Gallery.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSelectionArea } from '@vue-dnd-kit/core';
import PhotoGrid from './PhotoGrid.vue';

const area = useTemplateRef<HTMLElement>('area');
const { isSelecting, style } = makeSelectionArea(area);
</script>

<template>
  <div ref="area" class="area">
    <PhotoGrid />
    <div v-if="isSelecting" class="band" :style="style" />
  </div>
</template>

<style scoped>
.area {
  position: relative;   /* the band is absolutely positioned inside */
  min-height: 320px;    /* room around the items to start a band */
}

.band {
  border: 1px solid #42b883;
  background: color-mix(in srgb, #42b883 15%, transparent);
}
</style>
```

- 사각형은 직접 렌더링합니다. `style`이 영역의 콘텐츠를 기준으로 위치를 정합니다.
- 영역에는 **static이 아닌 position**이 필요합니다(`relative`면 충분합니다). 그렇지 않으면 사각형이
  엉뚱한 곳에 그려집니다.
- 사각형은 영역 자체에서만 시작하므로 영역을 크게 만드세요. 꽉 맞는 래퍼가 아니라, 항목 주변에
  여백이 있는 패널 전체로 만드세요. 위의 갤러리는 박스 전체를 채웁니다.
- 항목을 누르면 그 항목이 드래그됩니다. 버튼, 입력 필드, 영역의 스크롤바는 원래대로 누를 수
  있습니다.
- 영역이나 페이지가 스크롤되는 동안 사각형은 콘텐츠에 고정되어 있습니다. :kbd{value="Escape"}를
  누르면 취소되고 선택이 복원됩니다.
- 사각형을 그리는 동안 `useDnD().status`는 `'selecting'`입니다.

| 옵션 | 하는 일 |
| --- | --- |
| `strategy` | `'toggle'`(기본값): 사각형이 지나가는 항목의 선택 상태가 뒤집힙니다. `'select'`: 사각형 안의 항목만 선택된 상태가 되므로, 빈 공간을 클릭하면 영역 안 항목의 선택이 해제됩니다. |
| `modifier` | 그리려면 누르고 있어야 하는 키: `{ keys: ['Shift'], method: 'every' }`(또는 `'some'`). |
| `accept` | 사각형이 선택할 draggable. `type`과 비교하는 [accept 규칙](/docs/guides/drag-and-drop#which-drags-a-target-takes)입니다. |
| `disabled` | 사각형을 그리지 않습니다. 켜면 진행 중인 사각형을 취소합니다. |
| `onSelected(ids)` | 사각형이 끝날 때 선택을 넘겨 호출됩니다. |
| `selection` | 프로바이더의 선택 대신 사용할 직접 만든 `Ref<Set<Key>>`. |

영역 안에 영역이 있으면 가장 안쪽 영역이 누르기를 받습니다. 모든 옵션은
[makeSelectionArea API](/docs/api/make-selection-area)에 있습니다.

## 나머지 항목이 움직이는 방식: `multiple` {#how-the-other-items-move-multiple}

멀티 드래그가 시작된 리스트가 드래그 동안 나머지 선택 항목이 어떻게 움직일지 정합니다:

```ts
makeSortableList(listRef, { items: tasks, multiple: 'gaps' });
```

| `multiple` | 드래그하는 동안 | 오버레이 |
| --- | --- | --- |
| `'group'`(기본값) | 나머지 항목이 제자리를 떠나 집은 항목과 함께 연속된 자리의 블록으로 이동하므로, 리스트는 이미 드롭 결과를 보여 줍니다. | 리스트 방향으로 드래그 중인 항목을 최대 다섯 개까지 보여 주는 열. |
| `'gaps'` | 나머지 항목은 드롭할 때까지 흐리게(`data-dnd-dragging`) 제자리에 남습니다. | 같은 열. |
| `'stack'` | 나머지 항목이 오버레이 안으로 날아 들어갑니다. | 집은 항목과 개수. |

드롭하면 항목들은 원래 순서대로 대상 인덱스에 함께 안착합니다. `'group'`과 `'gaps'`에서는 오버레이의
각 항목이 자기 자리로 날아갑니다.

### 기본 오버레이 {#the-default-overlay}

`'group'`과 `'gaps'`에서 오버레이는 드래그 중인 항목이 안착할 모습 그대로 늘어선 열입니다. 집은
항목이 포인터 아래에 있고, 나머지는 드롭 순서에 따라 그 앞뒤에 놓입니다(가로 리스트에서는 행).
최대 다섯 개까지 보여 줍니다. 그보다 많은 항목은 있는 위치에서 개수로 표시됩니다. 보이는 항목보다
앞에 안착할 항목은 열 시작 부분에 `+N`으로, 뒤에 안착할 항목은 끝부분에 `+N`으로 표시됩니다.

그리드에서는 셀 전체로 된 열이 페이지를 덮어 버리므로, 오버레이는 더미 형태가 됩니다. 집은 항목
뒤로 최대 세 개의 항목이 부채꼴로 펼쳐지고, 그 위에 전체 개수가 표시됩니다.

일반 draggable(`makeDraggable`)은 집은 항목과 개수를 보여 줍니다.

### 섞인 타입 {#mixed-types}

선택된 항목의 타입이 서로 다르면, 대상의 `acceptMode`가 그중 `'all'`(기본값)이 맞아야 하는지
`'some'`이 맞으면 되는지 정합니다. [항목을 공유하는 리스트](/docs/guides/shared-lists#limits)와
[드래그 앤 드롭](/docs/guides/drag-and-drop#which-drags-a-target-takes)을 참고하세요.

## 여러 항목을 위한 커스텀 오버레이 {#a-custom-overlay-for-several-items}

오버레이 컴포넌트와 프로바이더의 `#overlay` 슬롯은 `items`를 받습니다. 드래그 중인 모든 항목이며,
집은 항목이 맨 앞에 옵니다. `DragPreview`는 그중 어떤 항목이든 라이브러리가 만든 클론을 렌더링하므로,
레이아웃에서 실제 모양을 그대로 재사용할 수 있습니다:

```vue [PileOverlay.vue]
<script setup lang="ts">
import { DragPreview, type OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <div class="pile">
    <!-- The grabbed item on top, two more turned behind it -->
    <DragPreview
      v-for="(entry, i) in items.slice(0, 3)"
      :id="entry.id"
      :key="entry.id"
      class="card"
      :style="{ width: '100%', height: '100%', zIndex: 3 - i, rotate: `${i * 4}deg` }"
    >
      <!-- Shown for an item without a clone -->
      <div class="fallback">{{ entry.id }}</div>
    </DragPreview>
    <span v-if="items.length > 1" class="count">{{ items.length }}</span>
  </div>
</template>

<style scoped>
.pile { position: relative; width: 100%; height: 100%; }
.card { position: absolute; inset: 0; }
.fallback { width: 100%; height: 100%; border-radius: 8px; background: Canvas; }
.count { position: absolute; top: -8px; right: -8px; z-index: 4; }
</style>
```

```ts
makeSortableList(listRef, { items: photos, strategy: 'grid', overlay: PileOverlay });
```

클론은 집을 때 만들어집니다. 집은 항목과, 드롭 순서상 그 옆에 있는 최대 네 개의 다른 항목이
렌더링되어 있다면 그것들의 클론입니다. 그 밖의 항목에 대해서는 `DragPreview`가 기본 슬롯을
렌더링합니다. 미리보기는 위의 `style`처럼 크기를 지정하지 않으면 집을 때의 항목 크기를 가집니다
(`class`와 `style`은 그대로 전달됩니다). `'group'`과 `'gaps'`에서는 드롭할 때 각 미리보기가 자기
항목의 자리에 안착합니다. 오버레이 컴포넌트에 대한 자세한 내용은 [오버레이](/docs/guides/overlay)를
참고하세요.

## 트리 {#trees}

트리에서는 선택된 노드가 각자의 하위 트리와 함께 문서 순서대로 하나의 블록으로 움직입니다. 선택된
노드 안에 있는 다른 선택된 노드는 부모의 하위 트리에 실려 함께 갑니다. [트리](/docs/guides/trees)를
참고하세요.
