## 리스트와 그 행 {#a-list-and-its-rows}

정렬 가능한 리스트에는 컴포넌트 두 개가 필요합니다. 리스트와 그 행입니다.

```vue [TaskList.vue]
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { makeSortableList } from '@vue-dnd-kit/core';
import TaskRow from './TaskRow.vue';

const tasks = ref([
  { id: 1, title: 'Sketch the board' },
  { id: 2, title: 'Write the docs' },
  { id: 3, title: 'Ship v3' },
]);

const listRef = useTemplateRef<HTMLElement>('list');
const { items } = makeSortableList(listRef, { items: tasks });
</script>

<template>
  <ul ref="list">
    <TaskRow v-for="task in items" :key="task.id" :task="task" />
  </ul>
</template>
```

```vue [TaskRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ task: { id: number; title: string } }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el">{{ task.title }}</li>
</template>
```

행은 자신이 렌더링된 리스트에 등록됩니다. 그래서 리스트마다 별도의 컴포넌트가 필요합니다. 한
컴포넌트에서 리스트 두 개를 만들면 두 리스트가 행을 공유하게 됩니다.

## 초안 {#the-draft}

`makeSortableList`는 배열의 **초안**인 `items`를 반환합니다. 드래그하는 동안 초안은 실시간으로
순서가 바뀝니다. 드래그한 행은 새 자리를 차지하고, 다른 행은 비켜나며 미끄러집니다. 원본 배열은
드롭할 때까지 바뀌지 않습니다. 드롭하면 라이브러리가 새 순서를 원본 배열에 기록합니다.

::example{name="quick-start" hint="리스트 아래의 id가 원본 배열입니다. 드롭할 때 바뀝니다"}
::

- 원본 배열이 아니라 `items`를 렌더링하세요. 원본 배열을 렌더링하면 드롭할 때까지 아무것도
  움직이지 않습니다.
- 기록은 리스트의 `onDrop` 다음에 일어납니다. `onDrop` 안에서 원본 배열은 아직 이전 순서이고,
  `e.result`에 새 순서가 있습니다.
- `tasks`는 평범한 `ref`이므로 앱의 다른 부분도 다른 변경과 똑같이 이 변화를 봅니다.

```ts
makeSortableList(listRef, {
  items: tasks,
  onDrop: (e) => {
    console.log(e.from.index, '→', e.to.index, e.result.get(e.to.list));
  },
});
```

배열을 `v-model`로 받는 리스트 컴포넌트는 그 모델을 그대로 넘깁니다:

```ts
const tasks = defineModel<Task[]>({ required: true });
const { items } = makeSortableList(listRef, { items: tasks });   // the write emits update:modelValue
```

::tip
스토어, 서버 상태, 불변 데이터라면 ref 대신 getter나 `computed`를 넘기세요. 라이브러리는 읽기 전용
소스에 기록하지 않습니다. `e.preventDefault()`를 호출하고 `e.result`를 직접 적용하세요.
[드롭 결정](/docs/guides/drop-decisions)을 참고하세요.
::

## key {#keys}

행은 데이터로 식별하며, 인덱스나 자동 생성 id로 식별하지 않습니다. 기본 key는 `item.id`이고,
문자열과 숫자는 항목 자체가 key입니다.

```ts
// TaskList.vue: your items have another key
makeSortableList(listRef, { items: tasks, getKey: (task) => task.uuid });

// TaskRow.vue: `item` is keyed with the list's getKey…
makeSortableItem(el, { item: () => props.task });
// …or pass the key yourself
makeSortableItem(el, { id: () => props.task.uuid });
```

- `v-for`에서도 같은 key를 쓰세요: `:key="task.uuid"`. `:key="index"`를 쓰면 엉뚱한 행이
  애니메이션되고, 행의 상태가 다른 행으로 옮겨 갑니다.
- key는 항목을 주고받는 모든 리스트에서 고유해야 합니다.
- `item`과 `id`는 getter로 넘기세요. 그래야 props가 바뀌어도 행이 동기화된 상태로 유지됩니다.

## 전략 {#strategies}

| `strategy` | 용도 |
| --- | --- |
| `'vertical'`(기본값) | 행이 세로로 쌓인 열. |
| `'horizontal'` | 한 줄: 탭, 칩, 타임라인. |
| `'grid'` | CSS 그리드와 줄바꿈되는 flex 행. 크기가 서로 다른 항목도 지원합니다. |

```ts
const { items } = makeSortableList(grid, { items: apps, strategy: 'grid' });
```

## 핸들 {#handles}

기본적으로 행 전체에서 드래그가 시작됩니다(행 안의 버튼, 입력 필드 등 컨트롤은 제외). 한 부분으로만
드래그하려면 `handle`을 넘기세요:

```vue [Track.vue]
<script setup lang="ts">
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { item: () => props.track, handle: '.grip' });
</script>

<template>
  <li ref="el">
    {{ track.title }}
    <button type="button" class="grip" aria-label="Reorder">⠿</button>
  </li>
</template>
```

- `handle`은 항목 안의 선택자이거나 요소 ref입니다.
- 마우스 드래그는 핸들에서 평소의 4 px 이동 없이 바로 시작됩니다.
- 핸들이 드래그 속성(`role`, `tabindex`, `aria-*`)을 받고, 키보드 드래그도 핸들에서 시작합니다.

핸들은 `aria-label`이 있는 `<button type="button">`으로 만드세요. 그대로 포커스할 수 있고,
스크린 리더가 레이블을 읽어 줍니다. 아이콘만 있는 `<span>`도 동작하지만(라이브러리가
`tabindex="0"`과 `role="button"`을 부여합니다), 의미 있는 이름이 없습니다.

::note
터치 드래그는 페이지가 계속 스크롤될 수 있도록 200 ms 길게 누른 뒤에 시작됩니다. 핸들에서 바로
드래그하려면 핸들에 `touch-action: none`을, 항목에 `activation: { touch: { distance: 4 } }`를
지정하세요.
::

## 축 고정 {#lock-the-axis}

```ts
makeSortableList(listRef, { items: tracks, axis: 'y' });
```

`axis: 'y'`는 드래그를 세로축에, `'x'`는 가로축에 고정합니다. 항목 자체의 `axis`가 리스트의
`axis`보다 우선합니다. 드래그를 리스트 안에 가두려면 `restrictToParent` 모디파이어도 추가하세요.
위의 재생 목록은 둘 다 사용합니다. 자세한 내용은 [제약](/docs/guides/constraints)을 참고하세요.

## 자리 스타일링 {#style-the-slot}

드래그한 행은 안착할 자리로서 리스트에 남고, `data-dnd-placeholder`를 받습니다. 기본 스타일은 이
행을 40%로 흐리게 하며, 명시도가 0이라 어떤 규칙을 작성해도 그쪽이 우선합니다:

```css
/* An empty, dashed slot instead of a faded row */
.track[data-dnd-placeholder] {
  opacity: 1;
  position: relative;
}

.track[data-dnd-placeholder]::after {
  content: '';
  position: absolute;
  inset: 0;
  border: 1.5px dashed color-mix(in srgb, currentColor 30%, transparent);
  border-radius: inherit;
  background: Canvas;
}
```

`makeSortableItem`은 같은 상태를 ref로 반환하며, 몇 가지가 더 있습니다:

| 반환값 | 설명 |
| --- | --- |
| `isPlaceholder` | 이 행이 드래그한 항목이 안착할 자리입니다. |
| `isDragging` | 이 행이 드래그되는 중입니다(멀티 드래그에서는 드래그 중인 모든 행). |
| `index` | 초안에서의 인덱스. 드래그하는 동안 바뀝니다. |
| `selected` | 쓰기 가능하며, 프로바이더의 선택과 연결됩니다. |
| `indicator` | [인디케이터 모드](/docs/guides/shared-lists#an-insertion-line)에서 선이 들어갈 위치. |

리스트는 자체 강조 표시를 위한 `isOver`와 `isAccepting`을 반환합니다. 모든 속성과 레시피는
[스타일링](/docs/guides/styling)에 있습니다.

## 기능 끄기 {#turning-things-off}

- 리스트에 `disabled`: 리스트에서 나가는 드래그도, 리스트로 들어오는 드롭도 없습니다. 항목에
  지정하면 그 항목을 드래그할 수 없습니다.
- `sort: false`: 이 리스트 안에서는 순서를 바꿀 수 없지만, 리스트 밖으로는 나갈 수 있습니다
  (팔레트, [항목을 공유하는 리스트](/docs/guides/shared-lists) 참고).

## 애니메이션 {#animations}

드래그하는 동안 행은 새 자리로 미끄러지고, 드롭한 행은 제자리에 안착합니다. 기본으로 켜져 있으며
코드가 필요 없습니다. 행을 `<TransitionGroup>`으로 감싸지 마세요. 이동이 두 번 애니메이션됩니다.
드래그가 아닌 변경(추가, 삭제, 섞기)에는 리스트의 `animate` 옵션을 켜세요.
[애니메이션](/docs/guides/animations)을 참고하세요.

전체 옵션 목록은 [makeSortableList](/docs/api/make-sortable-list)와
[makeSortableItem](/docs/api/make-sortable-item) API에 있습니다.
