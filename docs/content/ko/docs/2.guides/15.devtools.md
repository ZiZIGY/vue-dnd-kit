`@vue-dnd-kit/devtools`는 Vue DevTools(`vite-plugin-vue-devtools`)와 Nuxt DevTools에 **Vue DnD Kit**
탭을 추가합니다. 이 탭은 페이지의 모든 리스트, 트리, 드롭 대상을 실시간 미니맵으로 보여 주고,
조이스틱으로 어떤 항목이든 드래그하며, 앱이 실행되는 동안 옵션을 편집하고, 각 드래그가 한 일을
기록합니다. 개발 환경에서만 동작하며, 프로덕션 빌드에는 아무것도 포함되지 않습니다.

## 설치 {#install}

```bash
npm i -D @vue-dnd-kit/devtools @vue-dnd-kit/actions
```

`@vue-dnd-kit/actions`는 peer dependency입니다. 탭의 이동이 이 패키지를 거칩니다. npm 7+와 pnpm은
자동으로 설치하며, Yarn 1에서는 직접 추가하세요.

::code-group

```ts [vite.config.ts]
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import vueDevTools from 'vite-plugin-vue-devtools';
import { vueDnDKitDevtools } from '@vue-dnd-kit/devtools/vite';

export default defineConfig({
  plugins: [vueDevTools(), vueDnDKitDevtools(), vue()],
});
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  // With @vue-dnd-kit/devtools installed, the tab appears in development.
  modules: ['@vue-dnd-kit/nuxt'],
});
```

::

Vite에서는 플러그인이 `/__vue-dnd-kit-devtools/`에서 탭을 제공하고, 탭을 Vue DevTools에 추가하며,
앱이 시작되기 전에 페이지가 탭에 보고하도록 합니다. `app.use()`는 필요 없습니다. 개발 서버
(`vite serve`)에서만 동작하며, 빌드에는 영향을 주지 않습니다.

Nuxt에서는 `@vue-dnd-kit/nuxt` 모듈이 패키지를 찾아 탭을 제공하고, Nuxt DevTools에 추가하며,
클라이언트 플러그인으로 페이지 쪽을 설치합니다. `vueDndKit: { devtools: false }`로 끌 수 있습니다.

### 플러그인 없이 {#without-the-plugins}

직접 만든 개발 서버나, Vite가 `index.html`로 제공하지 않는 페이지(SSR 구성)에서는 페이지 쪽을 직접
설치하세요:

```ts [main.ts]
import { createApp } from 'vue';
import { DnDDevtools } from '@vue-dnd-kit/devtools';
import App from './App.vue';

const app = createApp(App);
app.use(DnDDevtools); // before mount: providers set up earlier aren't seen
app.mount('#app');
```

또는 엔트리 파일에서 `@vue-dnd-kit/devtools/auto`를 가장 먼저 임포트하세요. 플러그인이 탭은
제공하되 페이지 쪽은 직접 설치하려면 `vueDnDKitDevtools({ inject: false })`를 사용하세요.
`@vue-dnd-kit/devtools/vite`의 `serveTab()`은 탭을 제공하는 미들웨어입니다.

## 열기 {#open-it}

- **Vue DevTools**: :kbd{value="Alt"} + :kbd{value="Shift"} + :kbd{value="D"} 또는 페이지 아래쪽의
  Vue 버튼을 누른 다음, **Vue DnD Kit** 탭을 엽니다.
- **Nuxt DevTools**: :kbd{value="Shift"} + :kbd{value="Alt"} + :kbd{value="D"} 또는 Nuxt 버튼을
  누른 다음, **Vue DnD Kit**을 엽니다(사이드바나 그 더보기 메뉴에 있습니다).
- **별도 창**: 개발 서버에서 `http://localhost:5173/__vue-dnd-kit-devtools/`를 열거나, 탭의 ⧉
  버튼을 누르세요. 두 번째 화면에서 쓰기 좋습니다.

::warning
탭은 백그라운드 브라우저 탭이 아니라 별도 창에 두세요. 숨겨진 페이지는 드래그를 취소합니다.
::

## 탭에 표시되는 것 {#what-the-tab-shows}

### 미니맵 {#the-mini-map}

리스트, 트리, 드롭 대상마다 실시간 카드가 하나씩 있고, 항목의 복사본이 실제 위치에 표시됩니다.
오버레이가 보여 줄 것과 같은 클론입니다. 드래그 중에는 드래그를 받아들이는 리스트(파란색)와 거부하는
리스트(빨간색), 플레이스홀더, 포인터 아래의 대상, 오버레이 박스, `placeholder: 'indicator'` 리스트의
삽입선을 표시합니다. 클릭하면 항목을 선택하고, 더블 클릭하면 페이지가 그 항목으로 스크롤됩니다.

드롭이 예상한 곳으로 가지 않을 때 사용하세요. 어떤 리스트가 드래그를 받아들이는지 한눈에 보여
줍니다.

### 조종: 조이스틱 {#drive-the-joystick}

맵이나 트리에서, 또는 페이지에서 다음에 누르는 것을 고르는 **Pick**으로 항목을 선택하고, 조이스틱의
노브를 미세요. 항목을 집어 그 방향으로 움직이며, 노브가 중심에서 멀수록 빨라집니다. **Drop**과
**Cancel**로 드래그를 끝냅니다.

`devtools`라는 센서가 하는 진짜 포인터 드래그이므로, 리스트가 정렬되고 컨테이너가 자동 스크롤되며
`onBeforeDrop`과 `onDrop`도 다른 드래그처럼 실행됩니다. 정렬 가능한 리스트의 항목에는 버튼도
생깁니다. 위로, 아래로, 맨 앞으로, 맨 끝으로, 그룹의 다른 리스트로 옮기는 버튼입니다.

| 키(탭 안에서) | 동작 |
| --- | --- |
| 화살표 키 또는 :kbd{value="W"} :kbd{value="A"} :kbd{value="S"} :kbd{value="D"} | 노브를 그 방향으로 밉니다. :kbd{value="Shift"}와 함께 누르면 끝까지 밉니다 |
| :kbd{value="G"} | 선택한 항목을 집습니다 |
| :kbd{value="Space"} / :kbd{value="Enter"} | 드롭 |
| :kbd{value="Escape"} | 취소 |
| :kbd{value="P"} | 페이지에서 고르기 |

### 옵션 {#options}

콜백이 아닌 모든 옵션은 앱이 실행되는 동안 편집할 수 있습니다. 프로바이더의 옵션(`collision`,
`modifiers`, `overlayFit`, `autoScroll`, 애니메이션, `activation`, `keyboard`…), 리스트의 옵션
(`strategy`, `placeholder`, `behavior`, `multiple`, `dropOutside`, `disabled`…), 트리, 드롭 대상,
항목의 옵션입니다. 노드를 선택하고 **Options**를 여세요.

편집은 즉시 이 페이지에만 적용되며, 코드에는 절대 기록되지 않습니다. 초기화하거나, 프로바이더가
언마운트되거나, 페이지를 새로 고칠 때까지 유지됩니다.

### 상태 {#state}

각 프로바이더가 알고 있는 것을 트리로 보여 줍니다. 드래그 세션(상태, 활성 id와 센서, 대상과 그
대상의 수락 여부, 포인터), 순서와 초안을 포함한 리스트와 트리, 규칙을 포함한 드롭 대상, 그리고
항목의 타입과 데이터입니다.

### 로그 {#log}

드래그마다 띠 하나가 표시됩니다. 시작(id, 센서, 출발한 리스트), 수락 여부와 함께 각 `over`와
`left`, 놓기, `onBeforeDrop`의 판정(수락, 일부 수락, 훅이 거부, 대상의 `accept`가 거부), 그리고
`e.result`와 `preventDefault()` 호출 여부를 포함한 `drop`, 또는 `cancel`과 그 이유입니다. 항목을
클릭하면 데이터를 볼 수 있습니다.

드롭이 거부되었는데 무엇이 거부했는지 모를 때, 또는 제어 리스트가 바뀌지 않았을 때 사용하세요.
로그는 `preventDefault()`가 실행되었는지, `e.result`에 무엇이 들어 있었는지 알려 줍니다.

## 동작 방식 {#how-it-works}

프로바이더는 페이지 쪽이 설치한 훅에 보고합니다. 탭이 페이지를 지켜보기 전까지는 기록만 해 둡니다.
탭이 지켜보기 시작하면 페이지는 다른 모니터처럼 이벤트를 듣고, 탭이 보여 줄 내용을 보냅니다. 드래그
중에는 40 ms마다, 그 밖에는 1초에 두 번 보내며, 몇 초 동안 지켜보는 탭이 없으면 멈춥니다. 탭은
페이지 출처(origin)의 `BroadcastChannel`로 페이지와 통신합니다. 요청한 것 외에는 아무것도 바꾸지
않습니다. 드래그, 선택, 옵션 덮어쓰기만 바꿉니다.
