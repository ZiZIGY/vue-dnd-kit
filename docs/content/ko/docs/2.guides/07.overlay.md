드래그하는 동안 박스 하나가 포인터를 따라다닙니다. 이것이 **오버레이**입니다. 드래그 중인 요소
자체는 안착할 자리로서 원래 위치에 남습니다. 드롭하면 오버레이가 그 자리로 날아가 사라집니다.

오버레이는 컴포넌트 바깥인 `body`로 텔레포트됩니다. 기본적으로 드래그 중인 요소의 클론을
보여 줍니다.

::example{name="overlay" hint="메시지를 드래그하세요. 복사본에 받은편지함의 배경이 적용됩니다" height="24rem"}
::

## 기본 클론 {#the-default-clone}

클론은 무엇이든 움직이기 전, 집을 때 만들어집니다. 요소의 깊은 복사본입니다:

- 폼 값과 `<canvas>` 픽셀이 복사됩니다.
- 요소가 리스트 밖에서 잃게 될 계산된 스타일이 인라인으로 들어갑니다. 상속된 글꼴과 색상, 조상을
  통해 일치하는 스타일(`.list li { … }`), 표 셀 너비 등입니다. 표의 행은 별도의 표로 감싸집니다.
- `id`와 `data-dnd-*` 속성은 제거되고, 클론은 `aria-hidden`이 됩니다.
- UI 키트(Vuetify, Quasar, PrimeVue, Naive UI)의 리플 같은 누르기 효과는 제외됩니다.

함께 옮겨지면 안 되는 그 밖의 요소에는 **`data-dnd-no-clone`을** 표시하세요. 메뉴 버튼, 툴팁,
배지 같은 것입니다.

```vue
<li ref="el" class="mail-row">
  {{ mail.subject }}
  <button type="button" aria-label="Archive" data-dnd-no-clone>…</button>
</li>
```

### 배경은 추측하지 않습니다 {#backgrounds-arent-guessed}

클론은 요소를 있는 그대로 보여 줍니다. 리스트가 배경을 칠하기 때문에 자체 배경이 없는 행(흰색
`<ul>` 안의 `<li>`, `v-list-item`, 표의 행)은 **투명한** 클론이 됩니다. CSS로 리스트의 배경을
지정하세요:

```vue [MailRow.vue]
<style scoped>
[data-dnd-overlay] .mail-row {
  background: var(--surface);
}
</style>
```

클론은 Vue의 스코프 속성을 포함해 요소의 클래스와 속성을 유지하므로, 이 규칙은 전역 스타일시트뿐
아니라 행의 scoped 스타일에서도 동작합니다. 다른 방법은 행 자체에 배경을 주는 것입니다. 떠다니도록
만든 아이콘과 타일은, [정렬 가능한 리스트](/docs/guides/sortable-lists)의 앱 아이콘처럼 일부러 투명하게
둡니다.

## 박스 스타일링 {#styling-the-box}

박스는 `data-dnd-overlay` 속성을 가진 요소입니다. `position: fixed`와 `pointer-events: none`이며,
속성 값은 지금 하고 있는 일을 나타냅니다:

| `data-dnd-overlay` | 시점 |
| --- | --- |
| `"dragging"` | 포인터를 따라다닙니다. |
| `"dropping"` | 자리에 안착하거나, 원래 자리로 돌아가거나, 비동기 `onBeforeDrop`을 기다립니다. |

드래그하는 동안 들어 올린 듯한 모양을 주고, 안착하면 사라지게 하려면:

```css
[data-dnd-overlay='dragging'] .mail-row {
  box-shadow: 0 18px 32px -14px rgb(0 0 0 / 0.5);
}
```

## 오버레이 컴포넌트 {#overlay-components}

클론이 아닌 다른 것을 보여 주려면 컴포넌트를 넘기세요. 컴포넌트는 박스 안에서 렌더링됩니다:

```vue [CardOverlay.vue]
<script setup lang="ts">
import type { OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <!-- Fill the box: it resizes to the slot and animates on drop. -->
  <div class="card-overlay" :class="{ refused: over && !accepted }">
    {{ (items[0]?.item as Task).title }}
    <small v-if="mode === 'copy'">+ copy</small>
    <span v-if="items.length > 1" class="count">{{ items.length }}</span>
  </div>
</template>

<style scoped>
.card-overlay { width: 100%; height: 100%; }
</style>
```

```ts
import CardOverlay from './CardOverlay.vue';

makeSortableList(listRef, { items: tasks, overlay: CardOverlay });          // every item of the list
makeSortableItem(el, { item: () => props.task, overlay: CardOverlay });      // this item
makeDraggable(el, { id: 'chip', overlay: CardOverlay });                     // a plain draggable
```

| `OverlayProps` | 담긴 값 |
| --- | --- |
| `active` | 드래그(`id`, `ids`, `data`, `type`, …). |
| `items` | 드래그 중인 모든 항목, 집은 항목이 맨 앞: `{ id, item, data, type }`. 정렬 드래그에서 `item`은 리스트 항목입니다. |
| `over` | 드래그 아래의 대상, 또는 드롭 중에는 안착하는 대상. 아래에 아무것도 없을 때와 취소된 드래그가 돌아가는 동안에는 `null`. |
| `accepted` | `over`가 드래그를 받아들이는지 여부. 받아들이지 않으면 오버레이를 빨갛게 칠하세요. |
| `status` | `'dragging'` 또는 `'dropping'`. |
| `mode` | `'move'`, `'copy'`, `'swap'`, `'insert'`. |

컴포넌트는 그대로 넘기거나, 바꿔 끼울 수 있도록 `shallowRef`에 담아 넘길 수 있습니다. 깊은 `ref`나
`reactive`에는 절대 넣지 마세요. Vue가 컴포넌트를 반응형으로 만들고 경고를 냅니다.

[정렬 가능한 리스트](/docs/guides/sortable-lists)의 앱 그리드가 이 방식을 씁니다. 아이콘만 떠올라
이동하고, 이름은 제자리에 남습니다.

::example{name="lists" hint="앱 아이콘을 드래그하세요. 오버레이가 컴포넌트입니다" height="28rem"}
::

## 프로바이더의 `#overlay` 슬롯 {#the-providers-overlay-slot}

자체 컴포넌트가 없는 모든 드래그에는 프로바이더의 슬롯이 오버레이를 렌더링합니다:

```vue [App.vue]
<DnDProvider>
  <RouterView />
  <template #overlay="{ items, mode, accepted }">
    <CardOverlay v-if="items[0]?.type.includes('card')" v-bind="{ items, mode, accepted }" />
  </template>
</DnDProvider>
```

슬롯은 오버레이 컴포넌트와 같은 props를 받습니다. 슬롯이 아무것도 렌더링하지 않으면(위의
`v-if`), 드래그는 클론을 대신 사용합니다.

## 우선순위 {#what-wins}

각 드래그마다 해당하는 첫 번째 것이 쓰입니다:

1. 항목 자체의 `overlay`(`makeSortableItem`, `makeDraggable`).
2. 항목이 속한 리스트나 트리의 `overlay`.
3. 프로바이더의 `#overlay` 슬롯. 단, 아무것도 렌더링하지 않으면 제외합니다.
4. 기본 클론. 멀티 드래그에서는 클론으로 된 열이나 더미입니다.
   [멀티 드래그](/docs/guides/multi-drag#the-default-overlay)를 참고하세요.

컴포넌트는 드래그가 시작될 때 선택되어, 다른 리스트 위에서도 드래그가 끝날 때까지 유지됩니다.

## `DragPreview`: 레이아웃 안의 클론 {#dragpreview-the-clone-in-your-layout}

`DragPreview`는 드래그 중인 항목 하나에 대해 라이브러리가 만든 클론을 렌더링합니다. 여러 항목을
직접 배치하거나 클론 둘레에 틀을 더하는 오버레이 컴포넌트에서 사용하세요:

```vue [CopyOverlay.vue]
<script setup lang="ts">
import { DragPreview, type OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <div class="with-badge">
    <DragPreview :id="active.id" :style="{ width: '100%', height: '100%' }" />
    <span v-if="mode === 'copy'" class="badge">+</span>
  </div>
</template>
```

클론은 집은 항목과 그 옆의 최대 네 개 항목에 대해서만 있습니다. 그 밖의 항목에 대해서는
`DragPreview`가 기본 슬롯을 렌더링합니다. 미리보기를 쌓는 방법은
[멀티 드래그](/docs/guides/multi-drag#a-custom-overlay-for-several-items)를 참고하세요.

## 크기: `overlayFit` {#size-overlayfit}

| `overlayFit` (프로바이더) | 박스는 |
| --- | --- |
| `'slot'`(기본값) | 안착할 자리의 크기를 따릅니다. 더 넓은 카드가 있는 리스트 위에서는 넓어집니다. |
| `'source'` | 드래그 중인 요소의 크기를 유지합니다. |

`'slot'`이면 박스는 포인터를 중심으로 크기가 바뀌며, 포인터는 박스 안에서 같은 비율의 위치에
머무릅니다. 콘텐츠는 절대 확대·축소되지 않고, 새 크기에 맞춰 다시 배치됩니다.

드롭은 두 설정 모두 똑같이 동작합니다. 박스가 안착할 요소로 날아가 **그 요소의** 크기로
애니메이션되고, 그동안 콘텐츠가 다시 배치됩니다. 두 리스트에서 항목 모양이 다르면(팔레트에서는
작은 칩, 보드에서는 완전한 카드), 원본의 클론이 대상의 크기에 맞춰 다시 배치되면서 찌그러지거나
늘어나 보일 수 있습니다. 이를 바로잡는 방법은 두 가지입니다:

- 항목이 안착할 수 있는 모든 리스트에서 **같은 모양**을 주세요.
  [드래그 앤 드롭](/docs/guides/drag-and-drop)의 파일은 어느 폴더에서나 크기가 같으므로 드롭해도
  위치만 바뀝니다.
- 오버레이 컴포넌트에서 **대상의 모양**을 렌더링하세요. 컴포넌트는 `over`를 받으므로 지금 위에 있는
  리스트의 모양으로 바꿀 수 있고, 어떤 크기에서든 박스를 채웁니다.

오버레이 컴포넌트의 루트에 고정 크기를 주면 박스 안에서 그 크기가 유지됩니다. 박스를 따르게 하려면
루트에 `width: 100%; height: 100%`를 지정하세요.

## 렌더링 위치: `overlayTo` {#where-it-renders-overlayto}

프로바이더는 오버레이를 `body`로 텔레포트합니다. `showModal()`로 연 `<dialog>`나 shadow root
안에서는 오버레이가 top layer 아래에 깔리거나 스타일 범위를 벗어납니다. 그 안의 선택자나 요소를
`overlayTo`로 지정하세요:

```vue
<DnDProvider overlay-to="#dialog-overlay">
```

## 오버레이 없음 {#no-overlay}

`makeDraggable(el, { overlay: false })`에는 박스가 전혀 없습니다. 반환된 `transform`으로 요소 자체가
움직입니다. [드래그 앤 드롭](/docs/guides/drag-and-drop#without-an-overlay)을 참고하세요. 박스가
안착하는 방식은 프로바이더의 `dropAnimation`이 정합니다. [애니메이션](/docs/guides/animations)을
참고하세요.
