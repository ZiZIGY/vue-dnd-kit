정렬 가능한 리스트가 아닌 모든 것에는 `makeDraggable`과 `makeDroppable`을 사용하세요. 폴더로
옮기는 파일, 휴지통, 체스판, 캘린더, 보드 위의 메모 등이 있습니다.

::example{name="drop-zones" hint="이미지는 Images로, 문서는 Documents로" height="30rem"}
::

## draggable {#a-draggable}

```vue [FileCard.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeDraggable } from '@vue-dnd-kit/core';

const props = defineProps<{ file: { id: string; name: string; kind: 'image' | 'doc' } }>();
const el = useTemplateRef<HTMLElement>('el');

const { isDragging } = makeDraggable(el, {
  id: () => props.file.id,      // read back as `active.id`
  data: () => props.file,       // anything: `active.data`
  type: () => props.file.kind,  // matched by the targets' `accept`
});
</script>

<template>
  <div ref="el" :class="{ dragging: isDragging }">{{ file.name }}</div>
</template>
```

id는 데이터에서 가져와 getter로 넘기세요. 기본 id는 `useId()`에서 오고 컴포넌트 인스턴스마다
새로 만들어지므로, 앱의 나머지 부분에는 아무 의미가 없습니다.

| 반환값 | 설명 |
| --- | --- |
| `isDragging` | 이 요소가 드래그되는 중입니다. |
| `selected` | 쓰기 가능하며, 프로바이더의 [선택](/docs/guides/multi-drag)과 연결됩니다. |
| `transform` | `overlay: false`일 때 쓰는 드래그 오프셋(아래 참고). |
| `id` | 사용 중인 id. |

버튼, 입력 필드 같은 상호작용 자식 요소는 포인터 드래그를 시작하지 않으므로, draggable 안에서도
그대로 동작합니다. 한 부분으로만 드래그하려면 `handle`을 넘기세요
([정렬 가능한 리스트](/docs/guides/sortable-lists#handles) 참고). 모든 옵션은
[makeDraggable API](/docs/api/make-draggable)에 있습니다.

## 드롭 대상 {#a-drop-target}

```vue [Folder.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeDroppable } from '@vue-dnd-kit/core';

const props = defineProps<{ id: string; accept: string }>();
const emit = defineEmits<{ drop: [fileId: string | number] }>();
const el = useTemplateRef<HTMLElement>('el');

const { isOver, isAccepting } = makeDroppable(el, {
  id: props.id,
  accept: props.accept,
  onDrop: (event) => emit('drop', event.active.id),
});
</script>

<template>
  <section ref="el" :class="{ accepting: isAccepting, over: isOver && isAccepting, refused: isOver && !isAccepting }">
    <slot />
  </section>
</template>
```

| 반환값 | `true`인 경우 |
| --- | --- |
| `isOver` | 드래그가 이 대상 위에 있습니다. 대상이 드래그를 받아들이는지와는 상관없습니다. |
| `isAccepting` | 무언가가 드래그되고 있고 이 대상이 그것을 받아들입니다. 유효한 영역을 강조하세요. |
| `placement` | 불리언이 아닙니다. `{ top, right, bottom, left }`, 즉 포인터가 대상의 어느 쪽 절반에 있는지를 나타내며, 대상 위에 포인터가 없으면 `null`입니다. "이 카드의 앞 / 뒤"에 사용하세요. |

`isAccepting` 없이 `isOver`만 참이면, 드래그를 거부하는 대상 위에 있다는 뜻입니다. 위의 폴더처럼
이를 표시해 주세요. 그곳에 드롭하면 취소되고 항목은 원래 자리로 돌아갑니다.

## 대상이 받아들이는 드래그 {#which-drags-a-target-takes}

draggable의 `type`을 대상의 `accept`와 비교합니다:

| `accept` | 받아들이는 것 |
| --- | --- |
| 생략 또는 `'*'` | 모두. |
| `'image'` | `image` 타입의 draggable, 그리고 타입이 없는 것. |
| `['image', 'doc']` | 두 타입 중 하나, 그리고 타입이 없는 것. |
| `({ active, items, types }) => boolean` | 함수가 결정하는 대로. |

`type`이 없는 draggable은 어떤 문자열 규칙에도 통과합니다. 그 밖의 경우에는 함수를 사용하세요:

```ts
makeDroppable(el, {
  accept: ({ items }) => items.every((item) => (item.data as File).size < 10_000_000),
});
```

`type`은 배열(`['image', 'large']`)일 수도 있습니다. 하나만 일치하면 됩니다.

여러 항목을 한꺼번에 드래그할 때는 `acceptMode`가 몇 개가 맞아야 하는지 정합니다. `'all'`(기본값)
또는 `'some'`입니다. `'some'`이면 `onBeforeDrop`에서 남길 id를 반환하고, 나머지는 원래 자리로
돌아갑니다. [드롭 결정](/docs/guides/drop-decisions)을 참고하세요.

## 드롭 {#the-drop}

일반 드롭 대상의 `onDrop`은 **직접** 데이터를 바꾸는 곳입니다. 라이브러리는 스스로 아무것도 옮기지
않습니다:

```ts
makeDroppable(el, {
  id: 'archive',
  onDrop: ({ active }) => {
    for (const id of active.ids) archive(id);   // every dragged id, the grabbed one first
  },
});
```

| 이벤트 필드 | 담긴 값 |
| --- | --- |
| `active` | 드래그: `id`, `ids`, `items`(각각 `{ id, data, type, item }`), `data`, `type`. |
| `over` | 이 대상: `id`, `data`, `element`, `rect`. |
| `pointer`, `delta` | 포인터의 위치와 시작점에서 움직인 거리. |
| `position` | 드래그 중인 박스가 이 대상 안에서 놓인 위치(다음 섹션). |
| `source` | 항목이 정렬 가능한 리스트에서 왔을 때 설정됩니다: `{ list, remove() }`. |

순서는 `onBeforeDrop`(결정), `onDrop`(적용), 그다음 프로바이더의 `drag-end`입니다. 드롭 전에
묻거나, 드래그를 계속하거나, 일부 항목만 받아들이려면 [드롭 결정](/docs/guides/drop-decisions)을
참고하세요.

## 놓은 자리에 그대로 두기 {#leave-it-where-it-was-dropped}

보드, 캔버스, 평면도에서는 손을 뗀 자리에 항목이 그대로 남습니다. 모든 이벤트에는 `position`이
들어 있습니다. 절대 위치로 배치한 항목을 드롭한 자리에 놓는 `left` / `top` 값입니다.

::example{name="constraints" hint="메모를 드래그한 뒤 축을 고정하거나 그리드를 끄세요" height="26rem"}
::

```ts [Board.vue]
const board = useTemplateRef<HTMLElement>('board');
makeDroppable(board, { id: 'board' });

useDnDMonitor({
  onDragEnd({ active, over, position }) {
    const note = notes.value.find((item) => item.id === active.id);
    if (!note || over?.id !== 'board' || !position) return;
    note.x = Math.round(position.x);
    note.y = Math.round(position.y);
  },
});
```

```vue [Note.vue]
<div ref="el" class="note" :style="{ left: `${note.x}px`, top: `${note.y}px` }">…</div>
```

`position`은 `over` 안에서 드래그 중인 박스의 왼쪽 위 모서리입니다. 대상의 패딩 가장자리부터
측정하고, 대상의 스크롤 값을 더합니다. 아래에 아무것도 없으면 `null`입니다. `overlay: false`일
때는 요소 자체의 모서리입니다.

::tip
`active.rect`와 `delta`로 위치를 계산하지 마세요. 대상의 테두리와 스크롤이 빠집니다. 이런 보드를
위한 스냅, 경계, 축 고정은 [제약](/docs/guides/constraints)에 있습니다.
::

## 정렬 가능한 항목 안으로 드롭 {#drop-into-a-sortable-item}

정렬 가능한 리스트의 행도 드롭 대상이 될 수 있습니다. 파일을 받는 폴더, 작업을 받는 그룹 같은
경우입니다. 항목의 요소에 droppable을 설정하세요:

```ts [FolderRow.vue]
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { item: () => props.folder });

const { isOver } = makeDroppable(el, {
  accept: 'file',
  onDrop: (e) => {
    props.folder.children.push(...e.active.items.map((entry) => entry.item as FileEntry));
    e.source?.remove();   // take them out of the list they came from
  },
});
```

리스트가 그 드래그를 정렬하려는 상황에서는, 이런 대상은 항목의 **가운데**(리스트 축 방향으로
25~75%)에서만 유효합니다. 그곳에서는 드롭이 항목 안으로 들어가고 리스트는 움직이지 않습니다.
가장자리 근처에서는 리스트가 평소처럼 정렬합니다.

- `accept`가 드래그를 거부하는 대상은 건너뜁니다. 리스트는 다른 항목과 똑같이 그 항목 위에서
  정렬합니다. 파일만 받는 폴더는 폴더가 자신을 지나 정렬되도록 둡니다.
- 대상은 자기 자신의 드래그를 받지 않습니다.
- 드롭 후 항목이 더 이상 표시되지 않으면, 오버레이는 원래 자리로 돌아가는 대신 대상 안으로
  줄어들며 사라집니다.

## 휴지통 영역 {#trash-zones}

정렬 가능한 리스트에서 시작한 드래그에는 `e.source`가 들어 있습니다. `remove()`를 호출하면 리스트가
그 항목들을 제거합니다:

```ts
makeDroppable(trash, {
  id: 'trash',
  onDrop: (e) => e.source?.remove(),
});
```

이때 리스트 자체의 `onDrop`이 `to.index === -1`로 실행되고, `e.result`에는 그 항목들이 빠진 리스트가
담깁니다. 리스트는 모든 대상 바깥에 드롭된 것도 제거할 수 있습니다.
[`dropOutside`](/docs/guides/shared-lists#dropping-outside)를 참고하세요.

## 오버레이 없이 {#without-an-overlay}

기본적으로 요소의 클론이 포인터를 따라다니고, 요소는 제자리에 남습니다. `overlay: false`이면
클론이 없으므로 `transform`으로 요소를 직접 움직이세요.

```vue
<script setup lang="ts">
const { transform } = makeDraggable(el, { id: 'piece', overlay: false });
</script>

<template>
  <div ref="el" :style="transform && { transform: `translate3d(${transform.x}px, ${transform.y}px, 0)` }">♞</div>
</template>
```

클론 대신 직접 만든 드래그 미리보기를 쓰려면 [오버레이](/docs/guides/overlay)를 참고하세요.

## 키보드 {#keyboard}

포커스된 draggable은 :kbd{value="Space"} 또는 :kbd{value="Enter"}로 집습니다. 화살표 키는 25 px씩
움직입니다(프로바이더의 `keyboard.step`). draggable에 `keyboard: 'droppables'`를 설정하면 화살표
키가 대신 그 항목을 받아들이는 대상 사이를 건너뜁니다. 멀리 떨어진 영역에 알맞습니다. 자세한 내용은
[접근성](/docs/guides/accessibility)을 참고하세요.
