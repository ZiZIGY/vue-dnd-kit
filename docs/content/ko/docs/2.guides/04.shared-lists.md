## 그룹 {#a-group}

`group` 이름이 같은 리스트끼리 항목을 주고받습니다. 기본적으로 모든 리스트는 각자 별도의
그룹입니다.

```vue [Column.vue]
<script setup lang="ts">
import { toRef, useTemplateRef } from 'vue';
import { makeSortableList } from '@vue-dnd-kit/core';
import Card from './Card.vue';

type Task = { id: string; title: string };
const props = defineProps<{ column: { id: string; title: string; cards: Task[] } }>();

const zone = useTemplateRef<HTMLElement>('zone');
const list = useTemplateRef<HTMLElement>('list');
const { items, isOver } = makeSortableList(list, {
  id: props.column.id,                   // names the list in drop events
  items: toRef(props.column, 'cards'),   // a writable ref into the reactive column
  group: 'board',                        // same name: cards move between these lists
  dropzone: zone,                        // the whole column takes drops
});
</script>

<template>
  <section ref="zone" :class="{ over: isOver }">
    <h3>{{ column.title }}</h3>
    <ul ref="list">
      <Card v-for="card in items" :key="card.id" :card="card" />
    </ul>
  </section>
</template>
```

```vue [Board.vue]
<script setup lang="ts">
import { reactive } from 'vue';
import Column from './Column.vue';

const columns = reactive([
  { id: 'todo', title: 'To do', cards: [{ id: 'vdk-12', title: 'Pick a palette' }] },
  { id: 'done', title: 'Done', cards: [] },
]);
</script>

<template>
  <Column v-for="column in columns" :key="column.id" :column="column" />
</template>
```

- 각 컬럼은 별도의 컴포넌트입니다. 컴포넌트 하나에 리스트 하나입니다.
- 부모가 반응형 객체를 넘기므로 `toRef(props.column, 'cards')`는 쓰기 가능합니다. 드롭은 카드가
  떠난 배열과 들어간 배열 모두에 기록됩니다.
- `id`는 드롭 이벤트에서 `from.list`와 `to.list`로 나타나며, 드롭으로 바뀌는 모든 리스트의 새
  배열인 `e.result`의 key가 됩니다. `id`와 `group`은 한 번만 읽습니다.
- key는 그룹 전체에서 고유해야 합니다.

리스트의 `onDrop`은 그 리스트 **안으로** 들어오는 드롭에 대해 실행됩니다. `todo`에서 `done`으로
옮기면 `done` 리스트의 `onDrop`이 호출되고, 그 `e.result`에는 두 리스트의 새 배열이 모두 담깁니다.

## 컬럼 전체가 드롭을 받음: `dropzone` {#the-whole-column-takes-drops-dropzone}

키가 큰 컬럼 안의 짧은 리스트는 마지막 카드 아래에 빈 공간을 남깁니다. `dropzone: zone`을 쓰면
컬럼 요소가 리스트 대신 드롭을 받습니다. 마지막 카드 아래에서 놓은 카드는 끝에 안착합니다. 카드는
`<ul>` 안에 그대로 있고, 드롭을 받는 영역만 커집니다.

::tip
`dropzone`이 없으면 빈 리스트도 드롭을 받으려면 크기가 있어야 합니다. `min-height`를 지정하세요.
::

## 들어오고 나가는 것: `pull`과 `put` {#what-goes-in-and-out-pull-and-put}

`group`은 객체도 받습니다:

```ts
group: { name: 'board', pull: true, put: true }
```

| 옵션 | 값 |
| --- | --- |
| `pull` | `true`(기본값): 항목이 나갈 수 있습니다. `false`: 나갈 수 없습니다. `'clone'`: 복사본이 나가고 항목은 남습니다. |
| `put` | `true`(기본값): 항목이 들어올 수 있습니다. `false`: 아무것도 들어오지 않습니다. 함수: 드래그마다 직접 결정합니다. |

`put` 함수는 `{ keys, items, types, from, to }`를 받습니다. `from`은 항목이 온 리스트이며, 일반
draggable이면 `null`입니다. 리스트 안에서의 이동은 항상 허용됩니다.

### 개수 제한 {#limits}

카드를 최대 세 장까지만 담는 컬럼:

```ts
makeSortableList(list, {
  id: props.column.id,
  items: toRef(props.column, 'cards'),
  group: {
    name: 'board',
    put: ({ keys }) => props.column.cards.length + keys.length <= 3,
  },
});
```

드래그를 거부하는 리스트 위에서는 자리가 드래그를 시작한 위치로 돌아갑니다. 그래서 리스트는 드롭이
일어났을 때의 결과, 즉 아무 변화도 없음을 보여 줍니다. 그곳에 드롭하면 취소되고 카드는 원래
자리로 돌아갑니다. 이런 드래그 동안 리스트의 `isAccepting`은 `false`입니다. 이 값으로 컬럼을
흐리게 표시하세요.

타입이 서로 다른 여러 선택 항목을 드래그할 때는, `acceptMode`가 그중 `'all'`(기본값)이 `put`을
통과해야 하는지 `'some'`이 통과하면 되는지 정합니다. `'some'`이면 통과한 항목은 안착하고 나머지는
원래 자리로 돌아갑니다.

## 복사: 팔레트와 Alt 키 {#copy-palettes-and-the-alt-key}

::example{name="palette" hint="팔레트에서 드래그하세요. Alt를 누른 채 드래그하면 복사되고, 페이지 밖에 놓으면 제거됩니다" height="24rem"}
::

```ts [Palette.vue]
makeSortableList(list, {
  items: templates,
  group: { name: 'blocks', pull: 'clone', put: false },  // copies go out, nothing comes in
  sort: false,                                           // its own order stays
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),
});
```

```ts [Sheet.vue]
makeSortableList(list, {
  items: blocks,
  group: 'blocks',
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),  // for Alt-drags
});
```

- `pull: 'clone'`은 리스트에서 나가는 모든 드래그를 복사합니다. 원본은 남고, 복사본이 이동해
  안착합니다.
- 드래그 중에 :kbd{value="Alt"}를 누르고 있어도 어느 리스트에서든 복사됩니다. 키는 프로바이더의
  `copyModifier`로 바꾸고, `null`로 끌 수 있습니다.
- 어느 경우든 항목이 출발하는 리스트에 `clone`이 있어야 합니다. `clone`은 **새 key**를 가진
  복사본을 반환해야 합니다. `clone`이 없으면 아무것도 복사되지 않습니다.
- 드롭 이벤트에는 `mode: 'copy'`가 들어 있고, `e.items`는 복사본입니다. 오버레이 컴포넌트도 `mode`를 받아
  복사 중에 "+"를 표시할 수 있습니다([오버레이](/docs/guides/overlay) 참고).

## 리스트로 들어오는 일반 draggable {#plain-draggables-into-a-list}

리스트는 `makeDraggable`로 드래그한 항목에서 새 항목을 만드는 방법을 알면 그것을 받아들입니다:

```ts
makeSortableList(list, {
  items: tasks,
  createItem: (active) => ({ id: crypto.randomUUID(), title: (active.data as Chip).title }),
});
```

draggable이 리스트 위에 있는 동안, 만들어진 항목은 초안에 들어가 다른 행처럼 템플릿으로
렌더링됩니다. 드롭하면 실제 항목이 됩니다(`mode: 'insert'`, `from.list === null`). 거부하려면
`undefined`를 반환하세요. `createItem`이 없는 리스트는 일반 draggable을 무시합니다. 키보드에서는
리스트 쪽 화살표 키를 누르면 draggable이 리스트로 들어갑니다.

## 밀어내는 대신 맞바꾸기 {#swap-instead-of-shift}

```ts
makeSortableList(grid, { items: tiles, strategy: 'grid', behavior: 'swap' });
```

드래그한 항목이 그 아래 항목과 자리를 맞바꾸고, 나머지는 그대로 있습니다. 맞바꾸기는 실시간입니다.
되돌아가거나 리스트 밖으로 나가면 취소됩니다. 드롭 이벤트에는 `mode: 'swap'`과,
자리를 맞바꾼 항목인 `partner`가 들어 있습니다.

- 같은 그룹의 두 리스트가 모두 `behavior: 'swap'`이면 리스트 사이에서도 맞바꿉니다. 포인터 아래
  항목이 다른 리스트로 옮겨 가므로, 그 항목은 나갈 수 있어야 하고(`pull: true`) 들어갈 수 있어야
  합니다(`put`).
- 멀티 드래그는 맞바꾸지 않고 정렬합니다.

## 삽입선 {#an-insertion-line}

`placeholder: 'indicator'`를 쓰면 드래그하는 동안 리스트는 움직이지 않고, 선 하나가 드롭될 위치를
보여 줍니다. 선은 직접 그립니다:

```ts [TaskList.vue]
const { items, indicator } = makeSortableList(listRef, { items: tasks, placeholder: 'indicator' });
```

```vue [TaskRow.vue]
<script setup lang="ts">
const { indicator } = makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el" :class="indicator && `drop-${indicator.side}`">{{ task.title }}</li>
</template>

<style scoped>
.drop-before { box-shadow: inset 0 2px 0 #42b883; }
.drop-after { box-shadow: inset 0 -2px 0 #42b883; }
</style>
```

| `indicator` 필드 | 담긴 값 |
| --- | --- |
| `list` | 드롭이 들어갈 리스트. |
| `index` | 렌더링된 리스트 기준의 삽입 인덱스. |
| `key` | 선이 붙은 항목. 빈 리스트에서는 `null`입니다(이때는 리스트에 선을 그리세요). |
| `side` | 그 항목의 `'before'` 또는 `'after'`. 트리에서는 `'inside'`가 추가됩니다. |
| `depth`, `parentKey` | 트리 전용: 드롭이 안착할 위치. [트리](/docs/guides/trees#an-insertion-line)를 참고하세요. |

리스트의 `indicator`는 선이 그 리스트 안에 있는 동안, 항목의 `indicator`는 선이 그 항목에 붙어
있는 동안 설정됩니다. 키보드로도 선을 움직일 수 있습니다.

## 바깥에 드롭하기 {#dropping-outside}

아무 대상도 없는 곳에서 드래그가 끝났을 때 일어나는 일은 리스트의 `dropOutside`가 정합니다:

| `dropOutside` | 항목은 |
| --- | --- |
| `'placeholder'`(기본값) | 자리가 마지막으로 표시된 곳에 안착합니다. |
| `'cancel'` | 원래 자리로 돌아갑니다. `placeholder: 'indicator'`일 때의 기본값입니다. |
| `'remove'` | 리스트에서 빠집니다. 밖으로 끌어내 삭제합니다. |

`'remove'`는 먼저 리스트의 `onBeforeDrop`에 묻습니다. 그다음 리스트의 `onDrop`이 `to.index === -1`로
실행되고, `e.result`에는 그 항목들이 빠진 리스트가 담깁니다. 드롭을 받는 휴지통도 같은 방식으로
동작합니다. [휴지통 영역](/docs/guides/drag-and-drop#trash-zones)을 참고하세요.

이동을 확인받거나, 먼저 서버에 저장하거나, 드롭을 스토어에 직접 적용하려면
[드롭 결정](/docs/guides/drop-decisions)을 참고하세요. 모든 리스트 옵션은
[makeSortableList API](/docs/api/make-sortable-list)에 있습니다.
