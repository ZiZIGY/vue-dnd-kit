## 평평하게 렌더링 {#rendered-flat}

트리는 보이는 노드를 순서대로 나열한 **평평한 리스트**로 렌더링되며, 각 노드에는 `depth`가
있습니다. 행의 들여쓰기는 직접 합니다. 이렇게 하면 모든 행이 한 컨테이너 안의 형제가 되므로,
리스트의 행처럼 미끄러지고 애니메이션됩니다.

```vue [FileTree.vue]
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { makeSortableTree, type Key } from '@vue-dnd-kit/core';
import TreeRow from './TreeRow.vue';

interface FileNode { id: string; name: string; folder?: boolean; children?: FileNode[] }

const files = ref<FileNode[]>([
  { id: 'src', name: 'src', folder: true, children: [{ id: 'main', name: 'main.ts' }] },
  { id: 'readme', name: 'README.md' },
]);
const collapsed = ref(new Set<Key>());
const INDENT = 18;

const root = useTemplateRef<HTMLElement>('root');
const { items } = makeSortableTree(root, {
  items: files,                                  // the root nodes
  indentation: INDENT,                           // px per level: match your row padding
  collapsed,
  canNest: (_node, parent) => !!parent.folder,   // only folders take children
});

const toggle = (key: Key) => (collapsed.value.has(key) ? collapsed.value.delete(key) : collapsed.value.add(key));
</script>

<template>
  <div ref="root">
    <TreeRow v-for="node in items" :key="node.key" :node="node" :indent="INDENT" @toggle="toggle" />
  </div>
</template>
```

```vue [TreeRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode, type Key } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const emit = defineEmits<{ toggle: [key: Key] }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { id: () => props.node.key });
</script>

<template>
  <div ref="el" :style="{ paddingLeft: `${node.depth * indent}px` }">
    <button
      v-if="node.item.folder"
      type="button"
      :aria-expanded="!node.collapsed"
      :aria-label="node.collapsed ? 'Expand' : 'Collapse'"
      @click="emit('toggle', node.key)"
    >
      {{ node.collapsed ? '▸' : '▾' }}
    </button>
    {{ node.item.name }}
  </div>
</template>
```

행은 리스트의 행처럼 `makeSortableItem`을 사용합니다. `items`에는 `FlatNode`가 담깁니다:

| `FlatNode` 필드 | 담긴 값 |
| --- | --- |
| `key` | 노드의 key(`getKey`, 기본값 `node.id`). `:key`와 행의 `id`에 사용하세요. |
| `item` | 원본 노드. |
| `depth` | 루트는 `0`. 드래그 중인 노드의 깊이는 그 노드가 안착**할** 깊이이므로, 그 자리의 들여쓰기가 실시간으로 바뀝니다. |
| `parentKey` | 부모의 key. 루트는 `null`. |
| `index` | 형제 사이에서의 인덱스. |
| `hasChildren`, `collapsed` | 펼치기 버튼용. |

자식은 `node.children`에서 읽고 그곳에 기록합니다. 다른 구조라면 `getChildren`과 `setChildren`을
사용하세요:

```ts
makeSortableTree(root, {
  items: outline,
  getKey: (node) => node.uuid,
  getChildren: (node) => node.nested,
  setChildren: (node, children) => { node.nested = children; },
});
```

## 중첩 {#nesting}

드래그는 두 가지 방법으로 깊이를 바꾸며, 둘 다 기본으로 켜져 있습니다(`nesting: 'both'`):

- **옆으로** (`'offset'`): `indentation` 픽셀만큼 왼쪽이나 오른쪽으로 드래그하면, 자리 주변의 행이
  허용하는 범위에서 한 단계 올라가거나 내려갑니다.
- **머무르기** (`'hover'`): 행의 가운데에 드래그를 머무르게 하면, 드롭이 그 행 안의 첫 번째 자식으로
  들어갑니다.

`indentation`을 행이 단계마다 추가하는 패딩 값으로 맞추면 오프셋이 포인터를 따라갑니다.
`axis: 'y'`이면 옆으로 움직일 수 없지만, 머무르기로는 여전히 중첩됩니다.

## 접힌 노드 {#collapsed-nodes}

`collapsed`는 자식이 숨겨진 노드의 key를 담은 `Set`입니다(ref 또는 getter). 그 자식은 `items`에
들어 있지 않습니다. 드래그한 폴더는 접혀 있든 아니든 하위 트리 전체를 함께 가져갑니다. 트리의
`animate` 옵션을 켜면 폴더가 보여 주거나 숨기는 행이 애니메이션과 함께 나타나고 사라집니다.

## 규칙 {#rules}

| 옵션 | 제한하는 것 |
| --- | --- |
| `canNest(node, parent)` | `node`가 `parent` 아래로 갈 수 있는지. 멀티 드래그에서는 드래그 중인 모든 노드에 대해 묻습니다. |
| `maxDepth` | 허용되는 가장 깊은 깊이(루트가 `0`). 드래그 중인 노드의 자손도 포함되므로, 자식과 손자가 있는 폴더는 최대 `maxDepth - 2` 깊이까지만 갈 수 있습니다. |
| `group.put` | 트리가 다른 리스트와 트리의 항목을 받을지 여부. |
| `onBeforeDrop` | 그 밖의 모든 것을 드롭할 때 결정합니다. [드롭 결정](/docs/guides/drop-decisions)을 참고하세요. |

규칙이 어떤 깊이를 거부하면, 자리는 통과하는 깊이 중 가장 깊은 곳을 택합니다. 통과하는 깊이가
없으면 자리는 그곳으로 옮겨 가지 않습니다. 복사본과 `createItem`으로 만든 노드도 `canNest`와
`maxDepth`를 따릅니다.

## 한 그룹의 트리와 리스트 {#trees-and-lists-in-one-group}

`group`이 같은 트리와 리스트는 두 리스트처럼 노드를 주고받습니다. 리스트로 옮긴 폴더는 하위 트리를
유지하고, 하위 트리와 함께 돌아옵니다. 복사는 리스트와 같은 방식(`clone`, `pull: 'clone'`, Alt 키)으로
동작하지만, `clone`은 **하위 트리 전체를 포함한** 복사본을 반환해야 하고 그 안의 모든 노드에 새 key가
필요합니다:

```ts
let count = 0;
const copyNode = (node: FileNode): FileNode => ({
  ...node,
  id: `${node.id}-${++count}`,
  children: node.children?.map(copyNode),
});

makeSortableTree(root, { items: files, group: 'files', clone: copyNode });
```

그룹, 복사, `createItem`은 [항목을 공유하는 리스트](/docs/guides/shared-lists)를 참고하세요.

## 삽입선 {#an-insertion-line}

`placeholder: 'indicator'`를 쓰면 드래그하는 동안 트리가 움직이지 않습니다. 각 행이 자신의
`indicator`를 읽고, 드롭이 안착할 깊이만큼 들여쓴 선을 그립니다:

```vue [TreeRow.vue]
<script setup lang="ts">
import { computed, useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const el = useTemplateRef<HTMLElement>('el');
const { indicator } = makeSortableItem(el, { id: () => props.node.key });

// 'inside': the drop goes into this row. Otherwise a line before or after it.
const into = computed(() => indicator.value?.side === 'inside');
const line = computed(() => {
  const value = indicator.value;
  if (!value || value.side === 'inside') return null;
  return { side: value.side, left: `${(value.depth ?? 0) * props.indent}px` };
});
</script>

<template>
  <div ref="el" class="row" :class="{ into }" :style="{ paddingLeft: `${node.depth * indent}px` }">
    {{ node.item.name }}
    <span v-if="line" class="line" :class="line.side" :style="{ left: line.left }" />
  </div>
</template>

<style scoped>
.row { position: relative; }
.row.into { background: color-mix(in srgb, #42b883 15%, transparent); }
.line { position: absolute; right: 0; height: 2px; background: #42b883; }
.line.before { top: -1px; }
.line.after { bottom: -1px; }
</style>
```

트리에서 `indicator`에는 `depth`와 `parentKey`가 추가됩니다. 드롭된 노드가 갖게 될 단계와 부모입니다.
옆으로 드래그하면 선이 단계 사이를 오갑니다. 이 모드에서는 트리 바깥에 드롭하면 취소됩니다.

## 드롭 {#the-drop}

트리의 드롭 이벤트는 리스트의 드롭 이벤트에 `from`과 `to`의 `parentKey`가 추가된 것입니다:

```ts
makeSortableTree(root, {
  items: files,
  onDrop: (e) => {
    console.log(e.keys, e.from.parentKey, '→', e.to.parentKey, e.to.index);
  },
});
```

`to.index`는 새 형제 사이에서의 위치이며, 노드가 이전 자리를 떠난 뒤를 기준으로 셉니다. 드롭하면
라이브러리가 바뀐 노드에 새 자식을 주고(`setChildren`) 새 루트 배열을 ref에 기록합니다.

`e.result.get(treeId)`는 새 루트 배열로 표현한 새 트리입니다. 바뀐 경로의 노드는 복사본이고, 손대지
않은 하위 트리는 공유되며, 원본 노드는 그대로 유지됩니다. 스토어나 불변 데이터라면 getter를 넘기고,
`e.preventDefault()`를 호출한 뒤 `e.result`를 저장하세요. 복사본은 `withChildren(node, children)`으로
만들며, 기본값은 새 자식을 가진 `{ ...node }`입니다. 클래스 인스턴스라면 직접 구현한 함수를
넘기세요.

## 키보드와 멀티 드래그 {#keyboard-and-multi-drag}

키보드에서는 :kbd{value="ArrowUp"}과 :kbd{value="ArrowDown"}으로 행 사이를 이동하고,
:kbd{value="ArrowLeft"}와 :kbd{value="ArrowRight"}로 주변 행이 허용하는 범위에서 깊이를 바꿉니다.

선택된 노드는 각자의 하위 트리와 함께 문서 순서대로 하나의 블록으로 움직입니다. 선택된 노드 안에
있는 다른 선택된 노드는 부모의 하위 트리에 실려 함께 갑니다. [멀티 드래그](/docs/guides/multi-drag)를
참고하세요.

모든 옵션은 [makeSortableTree API](/docs/api/make-sortable-tree)에 있습니다. 행이 수천 개인 트리는
[가상 리스트](/docs/guides/virtual-lists)를 참고하세요.
