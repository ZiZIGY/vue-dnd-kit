타일을 드래그한 다음, 섞고, 추가하고, 몇 개를 제거해 보세요. 정렬과 드롭은 기본으로
애니메이션됩니다. 버튼으로 인한 변경은 그리드가 `animate`를 켰기 때문에 애니메이션됩니다.

::

## 세 가지 애니메이션 {#three-animations}

| 옵션 | 위치 | 기본값 | 애니메이션 대상 |
| --- | --- | --- | --- |
| `animation` | 프로바이더, 리스트, 트리 | 켜짐, 200 ms | 정렬하는 동안, 드롭할 때, 취소할 때 항목이 새 자리로 미끄러지는 움직임. |
| `dropAnimation` | 프로바이더 | 켜짐, 250 ms | 오버레이가 자리에 안착하거나, 취소할 때 원래 자리로 돌아가는 움직임. |
| `animate` | 프로바이더, 리스트, 트리 | **꺼짐** | 드래그가 아닌 데이터 변경: 항목의 추가, 제거, 이동, 필터링, 트리 행의 표시와 숨김. |

각 옵션은 `true`(기본 타이밍), `false`(끔), `{ duration, easing }`, 또는 직접 애니메이션하는 함수를
받습니다.

```vue
<DnDProvider
  :animation="{ duration: 180, easing: 'cubic-bezier(.2, .8, .2, 1)' }"
  :drop-animation="{ duration: 300 }"
>
```

리스트나 트리 자체의 `animation`과 `animate`가 프로바이더의 설정보다 우선합니다.

## 정렬 {#sorting}

드래그하는 동안 초안의 순서가 바뀌고, 항목은 새 자리로 미끄러집니다. Web Animations API로 CSS
`translate` 속성에 FLIP을 적용합니다. `translate`는 사용자가 지정한 `transform`과 함께 적용되므로,
가상 리스트의 행 위치 지정이 그대로 유지됩니다. 애니메이션이 끝나기 전에 항목이 다시 움직이면, 다음
애니메이션은 현재 보이는 위치에서 시작합니다.

::warning
정렬 가능한 항목을 `<TransitionGroup>`으로 감싸지 마세요. 모든 이동이 두 번 애니메이션됩니다.
드래그가 아닌 변경에는 `animate`를 켜세요.
::

## 드롭 {#the-drop}

드롭하면 오버레이가 놓은 곳에서 항목의 자리로 날아갑니다. 취소하면 항목이 시작한 곳으로 돌아갑니다.
드롭 후 항목에 보이는 자리가 없으면(스크롤되어 화면 밖에 있거나, 폴더나 휴지통 영역에 드롭된 경우),
오버레이는 대신 드롭된 영역 안으로 줄어들며 서서히 사라집니다.

오버레이는 드래그하는 동안 안착할 자리의 크기도 따르므로(`overlayFit: 'slot'`, 기본값), 드롭할 때
크기를 바꿀 필요가 없습니다. `'source'`는 드래그 중인 요소의 크기를 유지합니다.
[오버레이](/docs/guides/overlay)를 참고하세요.

## 데이터 변경: animate {#data-changes-animate}

```ts
makeSortableList(listRef, { items: swatches, animate: true });
```

기본으로 꺼져 있는 `animate`는 드래그 없이 배열을 바꾸는 것을 애니메이션합니다. 정렬, 섞기, 한
그룹의 리스트 사이 이동, 항목의 추가, 제거, 필터링이 해당합니다. 트리에서는 노드를 펼치거나 접을
때 보이거나 숨겨지는 행도 포함합니다. `<DnDProvider animate>`는 모든 리스트와 트리에서 이 옵션을
켭니다.

각 부분을 따로 조정할 수 있습니다:

```ts
animate: { duration: 250, move: true, enter: true, leave: { duration: 150 } },
```

| 부분 | 기본 동작 |
| --- | --- |
| `move` | 자리가 바뀐 항목이 `animation`과 같이 미끄러집니다. |
| `enter` | 새로 나타난 항목이 제자리에서 서서히 나타납니다. |
| `leave` | 사라진 항목의 복사본이 원래 자리에서 조금 줄어들며 서서히 사라집니다. 복사본에는 `data-dnd-leaving`이 표시되고, 끝나면 제거됩니다. |

`duration`과 `easing`은 모든 부분에 적용됩니다. 각 부분은 `true`, 옵션, `false`, 또는 함수를
받습니다. 보이는 영역 근처의 항목만 애니메이션되므로, 가상 리스트가 마운트하지 않은 행은
건너뜁니다. 이 옵션은 `items`가 바뀔 때 읽으므로, 예제의 토글처럼 ref로 켜고 끌 수 있습니다.

## 직접 만드는 애니메이션 {#your-own-animations}

각 옵션은 함수도 받습니다. 함수는 컨텍스트를 받아 애니메이션을 시작하고, 그 `Animation`, 끝날 때
처리되는 Promise, 또는 아무것도 반환하지 않습니다.

```ts
// animation, animate.move: an item moved from `from` to `to`
({ key, element, from, to, options, reason, signal, reducedMotion }) => Animation | Promise | void
// dropAnimation: `to` is null when there is no visible slot; `into` is the zone it went into
({ overlay, from, to, into, reason, active, options, reducedMotion }) => …
// animate.enter: the element is already in place
({ key, element, to, options, reducedMotion }) => …
// animate.leave: `element` is a copy where the item was, removed when you finish
({ key, element, from, options, reducedMotion }) => …
```

라이브러리 없이 Web Animations API만 사용한 레이아웃 함수입니다:

```ts
import type { LayoutAnimationContext } from '@vue-dnd-kit/core';

const springy = ({ element, from, to, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  return element.animate(
    [{ translate: `${from.left - to.left}px ${from.top - to.top}px` }, { translate: '0 0' }],
    { duration: 400, easing: 'cubic-bezier(.34, 1.56, .64, 1)' },
  );
};
```

```vue
<DnDProvider :animation="springy">
```

커스텀 애니메이션이 라이브러리와 어긋나지 않게 하는 세 가지 규칙이 있습니다:

- `transform`이 아니라 **`translate`를 애니메이션하세요.** `from - to`에서 0까지입니다. 가상 리스트나
  CSS가 행에 지정한 transform과 함께 적용되며, 드래그는 이 값을 빼고 항목을 측정합니다.
- **`signal`을 따르세요.** 애니메이션이 끝나기 전에 항목이 다시 움직이면 중단(abort)됩니다. 즉시
  애니메이션을 멈추고 스타일을 지우세요. 바로 다음에 레이아웃을 측정합니다. 반환한 `Animation`은
  자동으로 취소됩니다.
- **오버레이에서는 위치와 크기**(`width`, `height`)를 애니메이션하고, `scale`은 쓰지 마세요.
  오버레이의 콘텐츠는 새 크기에 맞춰 다시 배치됩니다.

### GSAP {#gsap}

```ts [gsap-animations.ts]
import gsap from 'gsap';
import type {
  DropAnimationContext,
  EnterAnimationContext,
  LayoutAnimationContext,
  LeaveAnimationContext,
  Rect,
} from '@vue-dnd-kit/core';

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const tween = gsap.fromTo(
    element,
    { translate: `${from.left - to.left}px ${from.top - to.top}px` },
    { translate: '0px 0px', duration: 0.4, ease: 'power3.out' },
  );
  signal.addEventListener('abort', () => tween.revert());
  return tween.then();
};

const box = (rect: Rect) => ({ x: rect.left, y: rect.top, width: rect.width, height: rect.height });

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return gsap.to(overlay, { opacity: 0, duration: 0.2 }).then();
  return gsap.fromTo(overlay, box(from), { ...box(to), duration: 0.45, ease: 'back.out(1.2)' }).then();
};

const enter = ({ element, reducedMotion }: EnterAnimationContext) =>
  gsap.from(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.35 }).then();

const leave = ({ element, reducedMotion }: LeaveAnimationContext) =>
  gsap.to(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.25 }).then();

export const gsapAnimations = { animation: move, dropAnimation: drop, animate: { move, enter, leave } };
```

```vue
<DnDProvider v-bind="gsapAnimations">
```

### motion {#motion}

```ts [motion-animations.ts]
import { animate } from 'motion-v';
import type { DropAnimationContext, LayoutAnimationContext } from '@vue-dnd-kit/core';

const spring = { type: 'spring', duration: 0.45, bounce: 0.25 } as const;

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const controls = animate(
    element,
    { translate: [`${from.left - to.left}px ${from.top - to.top}px`, '0px 0px'] },
    spring,
  );
  signal.addEventListener('abort', () => {
    controls.stop();
    element.style.translate = '';
  });
  return controls.finished;
};

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return animate(overlay, { opacity: 0 }, { duration: 0.18 }).finished;
  return animate(
    overlay,
    { x: [from.left, to.left], y: [from.top, to.top], width: [from.width, to.width], height: [from.height, to.height] },
    spring,
  ).finished;
};
```

전체 옵션 타입은 [애니메이션](/docs/api/animations)에 있습니다.

## 동작 줄이기 {#reduced-motion}

`prefers-reduced-motion: reduce`이면 라이브러리 자체 애니메이션은 실행되지 않습니다. 항목과
오버레이는 곧바로 제자리로 갑니다. 직접 만든 함수는 항상 `reducedMotion: true`와 함께 실행되므로,
움직임을 건너뛸지 위의 예처럼 짧은 페이드를 남길지 함수가 결정합니다.

## 라이브러리가 일으키지 않은 레이아웃 변경 {#layout-changes-the-library-didnt-cause}

드래그 중에 다른 무언가가 행을 움직일 때(가상화 라이브러리의 재측정, 이미지 로딩 등), 변경이
렌더링되기 직전에 리스트의 `captureLayout()`을 호출하세요. 행을 현재 위치에서 측정하고, 다음
렌더링 후 새 자리로 애니메이션합니다. 드래그 중이 아닐 때는 아무것도 하지 않습니다.
[가상 리스트](/docs/guides/virtual-lists)를 참고하세요.
