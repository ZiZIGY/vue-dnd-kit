## 注目ポイント {#what-to-look-at}

- **`Gallery.vue`**：グリッドの周りのエリアに `makeSelectionArea`。エリアはボックス全体を占めているため、その上のどこからでも選択枠を始められます。選択枠は `isSelecting` と `style` から描画します。
- **`Shot.vue`**：`selected` はプロバイダーの選択にバインドされ、Ctrl/Cmd クリックで切り替わります。
- グリッドでは、マルチドラッグのオーバーレイは山積みになります：掴んだ写真が一番上、その後ろにほかの数枚、その上に件数。

さらに読む：[マルチドラッグと選択](/docs/guides/multi-drag) · [`makeSelectionArea`](/docs/api/make-selection-area)
