## 注目ポイント {#what-to-look-at}

- **`Board.vue`**：`makeDragArea(board, { axis, restrictToArea, modifiers })` が、ボード上で始まるすべてのドラッグのルールを設定します。オプションは ref とゲッターで、ドラッグの開始時に読み取られるため、スイッチの変更は次のドラッグから適用されます。
- ボードはドロップターゲットでもあります。`onDragEnd` は、ドロップされた場所の `left`/`top` である `position` にメモを置きます。
- **`Note.vue`** は、ドラッグできることを宣言するだけです：残りはエリアが行います。
