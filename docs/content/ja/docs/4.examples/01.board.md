## 注目ポイント {#what-to-look-at}

- **`Board.vue`**：列そのものが横方向の並べ替え可能なリストで、各列はヘッダーでドラッグする並べ替え可能なアイテムです（`handle`）。
- **`Column.vue`**：すべての列のカードが 1 つの `group` です。`put` は入ってくるカードを数える関数なので、WIP 制限に達した列はドラッグを拒否し、着地位置は元の列に留まります。非同期の `onBeforeDrop` はカードが Done に入る前に確認し、`'accept'`、`'reject'`、`'continue'`（ドラッグを続ける）のいずれかで答えます。
- **`Card.vue`**：`makeSortableItem` の `selected` を Ctrl/Cmd クリックにバインドしています：マルチドラッグでは選択全体が移動します。
- **`Trash.vue`**：カードだけを受け入れ（`accept: 'card'`）、`e.source.remove()` で削除する通常のドロップターゲット。
- **`CardOverlay.vue`**：カードのオーバーレイコンポーネント（リストの `overlay`）で、`DragPreview` のクローンで作られています：ドラッグ中はカードが傾き、選択の残りはその下に積み重なり、着地するとまっすぐに戻ります（`status`）。
