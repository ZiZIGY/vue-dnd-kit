## 注目ポイント {#what-to-look-at}

- **`Page.vue`**：ページは `placeholder: 'indicator'` を指定した並べ替え可能なツリーです：ドラッグ中は何も動かず、ブロックの行き先と深さを 1 本のラインが示します。`canNest` により、ブロックが入れるのはトグルの中だけです。
- **`BlockRow.vue`**：`handle: '.grip'` なので、テキストは編集も選択もでき、ドラッグを始めるのはハンドルだけです。
- **`Palette.vue`**：同じ `group` で、`pull: 'clone'` と `put: false` を指定したリスト：新しいブロック（`clone`）を送り出し、何も受け取りません。
- **`Editable.vue`**：ただの `contenteditable` テキスト。モデルは DOM から更新され、DOM へは書き戻されないため、キャレットが飛びません。
