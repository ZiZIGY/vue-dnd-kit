## 注目ポイント {#what-to-look-at}

- **`Playlist.vue`**：`axis: 'y'` と `modifiers: [restrictToParent]` が、トラックを軸の上とリストの内側に留めます。リストの両端には届きます。
- **`Track.vue`**：`handle: '.grip'`。ドラッグを始められるのはグリップ（`aria-label` 付きの `<button>`）だけです。`index` はドラフトに追従するため、ドラッグ中に番号が変わります。行は自分の背景を持っています：オーバーレイは行のコピーであり、コピーには行が自分で塗ったものしか表示されないからです。
- **`AppGrid.vue`**：`strategy: 'grid'` で 2 次元に並べ替えます。`overlay: AppOverlay` は、タイルのコピーの代わりにアイコンだけを持ち上げます。
- ドラッグ中のアイテムが着地する位置は、`[data-dnd-placeholder]::after` でスタイルを付けています。
