各サンプルは小さな Vue アプリです：`DnDProvider` を持つ `index.vue` と、それが必要とするコンポーネントで構成されています。デモの下にあるコードタブは、そのデモを実際に動かしているファイルそのものです。

## アプリ {#apps}

実際に作るときと同じ形の、まとまったインターフェースです。複数のリスト、ルール、オーバーレイ、キーボードが連携して動きます。

::card-group

::card{title="プロジェクトボード" icon="i-lucide-square-kanban" to="/docs/examples/board"}
並べ替えられる列、WIP 制限、Done の前の確認、複数選択、ゴミ箱。
::

::card{title="週間カレンダー" icon="i-lucide-calendar-days" to="/docs/examples/calendar"}
日と 30 分刻みの枠をまたいでドラッグする予定。グリッドにスナップします。
::

::card{title="ファイルマネージャー" icon="i-lucide-folder-open" to="/docs/examples/file-manager"}
フォルダーツリーとファイルのグリッド：範囲選択、フォルダーへのドロップ、Alt でコピー。
::

::card{title="ブロックエディター" icon="i-lucide-blocks" to="/docs/examples/block-editor"}
Notion 風のブロック。ハンドルで動かし、ネストし、パレットから挿入します。
::

::

## 基本パーツ {#building-blocks}

それぞれ 1 つのアイデアだけを扱い、1 分で読める大きさです。

::card-group

::card{title="カンバンボード" icon="i-lucide-columns-3" to="/docs/examples/kanban"}
カードをやり取りし、高さのどこでもドロップを受け付ける列。
::

::card{title="リストとグリッド" icon="i-lucide-list-ordered" to="/docs/examples/lists"}
グリップでドラッグする 1 軸のプレイリストと、ホーム画面風のアプリのグリッド。
::

::card{title="ファイルツリー" icon="i-lucide-list-tree" to="/docs/examples/tree"}
エディターのエクスプローラー：横方向へのドラッグやフォルダーへのホバーでネストします。
::

::card{title="マルチドラッグ" icon="i-lucide-images" to="/docs/examples/multi-drag"}
範囲選択や Ctrl/Cmd クリックで選び、選択全体を移動します。
::

::card{title="ドラッグ＆ドロップ" icon="i-lucide-folder-input" to="/docs/examples/drop-zones"}
それぞれ 1 種類だけを受け入れるフォルダーにファイルを仕分けます。ゴミ箱は何でも受け入れます。
::

::card{title="軸、境界、グリッド" icon="i-lucide-frame" to="/docs/examples/constraints"}
ルールをその場で変えられるボード：軸の固定、端、グリッド。
::

::card{title="ToDo リスト" icon="i-lucide-list-checks" to="/docs/examples/todo-list"}
グリップでドラッグする行。チェックボックスもそのまま使えます。
::

::card{title="リストのオプション" icon="i-lucide-sliders-horizontal" to="/docs/examples/sortable-options"}
ストラテジー、プレースホルダー、挙動を、リストが動いたまま切り替えます。
::

::card{title="仮想リスト" icon="i-lucide-rows-3" to="/docs/examples/virtual-list"}
1 万行のうち、DOM にあるのは数行だけ。
::

::card{title="コードからの移動" icon="i-lucide-wand-sparkles" to="/docs/examples/actions"}
ボタン、シャッフル、スクリプトによるドラッグ。どれも本物のドラッグです。
::

::card{title="ドラッグ可能な要素" icon="i-lucide-hand-grab" to="/docs/examples/draggable"}
どこからでも、ハンドルで、オーバーレイなしで、あるいはドラッグ不可。
::

::card{title="ドロップターゲット" icon="i-lucide-inbox" to="/docs/examples/droppable"}
一部のファイルを受け入れ、それ以外を拒否するゾーン。
::

::
