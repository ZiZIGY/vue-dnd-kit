## 注目ポイント {#what-to-look-at}

- **`TodoRow.vue`**：`handle: grip` なので、ドラッグを始めるのはグリップだけで、チェックボックスは使えるままです。`index` はドラフト内での行の位置で、ドラッグ中に変わります。
- **`TodoRow.vue`**：`isPlaceholder` で、着地位置を同じサイズの破線の穴として描きます。
- **`TodoList.vue`**：行はリストのドラフトの `items` を描画し、ドロップは `todos` に書き込まれます。

さらに読む：[並べ替え可能なリスト](/docs/guides/sortable-lists) · [`makeSortableItem`](/docs/api/make-sortable-item)
