## 注目ポイント {#what-to-look-at}

- **`FileCard.vue`**：`type`（`image` または `doc`）を持つ通常の `makeDraggable`。
- **`Folder.vue`**：`accept` が 1 つの型だけを受け入れる `makeDroppable`（デスクトップとゴミ箱は `'*'`）。`isAccepting` はドラッグを受け入れるフォルダーを強調表示し、受け入れないフォルダーは `isOver && !isAccepting` でそれを示します。`onDrop` がデータを変更する場所です：ライブラリは自分では何も動かしません。
- ファイルはどこでも同じ見た目なので、ドロップは飛んでいくだけです。残ったファイルは Vue の `<TransitionGroup>` で隙間へスライドします。
