## 注目ポイント {#what-to-look-at}

- **`TrackRow.vue`**：矢印ボタンには `moveItem(id, { index })`、行を矢印キーに渡すには `startDrag(id, { type: 'keyboard' })`。
- **`Queue.vue`**：シャッフルは `moveItem` を 1 つずつ順に await します。スクリプトによるドラッグは `startDrag` で始まり、`moveTo` で滑らかに動き、`drop()` で着地します。

さらに読む：[センサーとプログラムによるドラッグ](/docs/guides/sensors#programmatic-drags)
