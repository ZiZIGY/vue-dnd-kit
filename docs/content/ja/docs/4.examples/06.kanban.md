## 注目ポイント {#what-to-look-at}

- **`Column.vue`**：`group` が同じリストどうしはアイテムをやり取りします。ドロップは `column.cards`（prop の `toRef`）に書き込まれます。`dropzone: zone` で列全体がターゲットになるため、最後のカードの下で離したカードは末尾に着地します。
- **`Card.vue`**：自分の背景（`Canvas`）を持つ並べ替え可能なアイテムなので、オーバーレイもカードと同じ見た目になります。

さらに読む：[アイテムを共有するリスト](/docs/guides/shared-lists) · [`makeSortableList`](/docs/api/make-sortable-list)
