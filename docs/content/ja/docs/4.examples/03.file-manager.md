## 注目ポイント {#what-to-look-at}

- **`FileGrid.vue`**：ファイルは `clone` を指定した並べ替え可能なグリッド（`strategy: 'grid'`）なので、Alt を押すと移動ではなくコピーになります。`makeSelectionArea` が選択枠を描きます。それで選んだものがマルチドラッグで移動する選択になり、山積みで表示されます。
- **`FileTile.vue`**：`makeSortableItem` の `selected` を、クリックと Ctrl/Cmd クリックにバインドしています。
- **`useFolderDrop.ts`**：ツリーの行とフォルダーのタイルはドロップターゲットです。`accept` は関数です：フォルダーは自分自身、自分のサブフォルダー、開いているフォルダーを拒否します。フォルダーのタイルでは、タイルの中央だけがドロップを受け付け、端の近くではグリッドが並べ替わります。
- **`FileManager.vue`**：通常のドロップターゲットは Alt のことを知らないので、自分でキーを読み取り（VueUse の `useKeyModifier`）、コピーか移動かを決めます。
