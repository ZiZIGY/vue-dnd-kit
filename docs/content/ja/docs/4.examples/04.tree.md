## 注目ポイント {#what-to-look-at}

- **`FileTree.vue`**：`indentation`、`collapsed`、`canNest: (_node, parent) => !!parent.folder` を指定した `makeSortableTree`。子を持てるのはフォルダーだけです。
- **`TreeRow.vue`**：各行は `node.key` をキーとする並べ替え可能なアイテムです。左のパディングはドラッグ中も `node.depth` に追従するため、着地位置にはドロップ後の深さが表示されます。

さらに読む：[ツリー](/docs/guides/trees) · [`makeSortableTree`](/docs/api/make-sortable-tree)
