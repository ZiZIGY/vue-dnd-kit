## 注目ポイント {#what-to-look-at}

- **`Square.vue`**：64 のマスはどれも、`accept` が関数であるドロップターゲットです。駒をドラッグしている間に尋ねられるため、マスはその駒の合法手だけを受け入れます。それ以外の場所へのドロップは拒否され、駒は元の位置に戻ります。合法なマスは `isAccepting` で強調表示されます。ゲーム独自の状態がドラッグを追跡することはありません。駒の移動元のマスは `useDnD().active` を読みます。
- **`Piece.vue`**：通常のドラッグ可能な要素で、自分の手番でないときは `disabled` です。`keyboard: 'droppables'` により、矢印キーは駒を受け入れるマス、つまりその合法手の間だけをジャンプします。`snapCenterToCursor` は駒をポインターの下の中央に保ち、駒はページをスクロールしないため、タッチはすぐにドラッグになります（`activation`）。
- **オーバーレイ**は駒のデフォルトのクローンで、`[data-dnd-overlay]` からスタイルを付けています。`'dragging'` の間は浮き上がり（大きく、長い影）、着地する `'dropping'` で落ち着きます。マスに残された駒はうすくなります（`isDragging`）。
- **`index.vue`**：`announcements` は、id ではなく駒とマスを読み上げます。「Picked up the white knight on g1」「f3」のようにです。
- **`chess.ts`** と **`game.ts`**：ルールとゲームで、ドラッグ＆ドロップは含まれていません。チェックを考慮した合法手、キャスリング、アンパッサン、プロモーション、棋譜、元に戻す操作です。`onDrop` での着手が新しい局面を作り、駒は新しいマスで描画し直され、オーバーレイは動いた駒の上に着地します。
