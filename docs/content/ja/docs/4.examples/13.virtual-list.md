## 注目ポイント {#what-to-look-at}

- **`TaskList.vue`**：仮想リストには元の配列ではなくドラフトの `items` を渡すので、ドラッグ中に行が動きます。配列は `shallowRef` です。
- **`TaskList.vue`**：行のキーは、VueUse のドキュメントのようなインデックスではなく、id です。
- **`Row.vue`**：id はゲッター `{ id: () => props.task.id }` です：仮想リストがコンポーネントに別のタスクを渡すことがあるからです。

さらに読む：[仮想リスト](/docs/guides/virtual-lists)
