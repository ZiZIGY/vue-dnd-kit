```vue [App.vue]
<script setup lang="ts">
import { DnDProvider } from '@vue-dnd-kit/core';
</script>

<template>
  <DnDProvider :animation="{ duration: 200 }" @drag-end="save">
    <RouterView />
    <template #overlay="{ items, over, accepted }">
      <!-- optional: a custom overlay for every drag -->
    </template>
  </DnDProvider>
</template>
```

すべてのコンポーザブルは、プロバイダーの**内側**に描画されるコンポーネントで実行する必要があります。目指すのはアプリ全体で 1 つのプロバイダーです：ページの各部分は [`makeDragArea`](/docs/api/make-drag-area) で独自のルールを持てます。[プロバイダーのガイド](/docs/guides/provider)を参照してください。

ほとんどの props は、プロバイダーが必要とした時点で読まれます。1 つを変更すると、次のドラッグからそれが使われます。

## イベント {#events}

| イベント | ペイロード | タイミング |
| --- | --- | --- |
| `drag-start` | `DnDEvent` | ドラッグが始まった（アクティベーションの後）。 |
| `drag-move` | `DnDEvent` | ドラッグ中にポインターが動いた（最大で 1 フレームに 1 回）。 |
| `drag-over` | `DnDEvent` | ドラッグの下のターゲットが変わった。 |
| `drag-end` | `DnDEndEvent` | ドロップが成立し、書き込まれた。 |
| `drag-cancel` | `DnDEvent` | ドラッグがキャンセルされた、またはドロップが拒否された。 |

同じイベントに `onBeforeDrop` と `onDragResume` を加えたものが、[`useDnDMonitor`](/docs/api/use-dnd) を使えばプロバイダーの下のどこでも利用できます。ペイロードは[イベントのページ](/docs/api/events)にあります。

## `#overlay` スロット {#slot-overlay}

独自のオーバーレイコンポーネントを持たないすべてのドラッグについて、ポインターに追従するものを描画します（[オーバーレイのガイド](/docs/guides/overlay)を参照）。何も描画しない場合はクローンにフォールバックします。
