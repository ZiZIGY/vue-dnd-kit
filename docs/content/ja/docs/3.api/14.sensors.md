```ts
import { defineSensor, useSensor, pointerSensor, keyboardSensor } from '@vue-dnd-kit/core';
```

| エクスポート | 内容 |
| --- | --- |
| `pointerSensor` | Pointer Events を通じたマウス、タッチ、ペン。デフォルトで `sensors` に含まれます。 |
| `keyboardSensor` | Space/Enter で持ち上げとドロップ、矢印キーで移動、Escape でキャンセル。デフォルトで `sensors` に含まれます。 |
| `defineSensor(sensor)` | センサーオブジェクトに型を付けます。 |
| `useSensor(sensor)` | プロバイダーの下のコンポーネントで、そのコンポーネントが生きている間センサーを実行します。 |

センサーが伝えるのは「このアイテムをここからドラッグする」ということと、その後どこへ動いたか、ドロップしたかキャンセルされたかだけです。それ以外（何をドラッグできるか、アクティベーション、ドラッグは一度に 1 つ）はプロバイダーがチェックします。[センサーとプログラムによるドラッグ](/docs/guides/sensors)を参照してください。

下では、小さな独自のセンサー（`useSensor` で動かします）が、プロバイダー自身のセンサーと並んで、ミニマップからボードの駒をドラッグします。
