## DragPreview {#dragpreview}

```vue [StackOverlay.vue]
<script setup lang="ts">
import { DragPreview, type DragItem } from '@vue-dnd-kit/core';

defineProps<{ items: DragItem[] }>();
</script>

<template>
  <div class="stack">
    <DragPreview v-for="item in items.slice(0, 3)" :id="item.id" :key="item.id" />
  </div>
</template>
```

クローンは持ち上げた時点で、掴んだアイテムと、ドロップ順でその隣にある最大 4 つのほかのアイテムについて作られます。それ以外のアイテムでは、`DragPreview` はデフォルトスロットを描画するか、何も描画しません。ドロップが着地するとき、各プレビューはそれぞれのアイテムに着地します。[オーバーレイのガイド](/docs/guides/overlay)を参照してください。

## オーバーレイの props {#overlay-props}

オーバーレイコンポーネント（ドラッグ可能な要素、並べ替え可能なアイテム、リスト、ツリーの `overlay` オプション）とプロバイダーの `#overlay` スロットが受け取るもの。

::api-table{name="OverlaySlotProps"}
::

`OverlayProps` は同じ型で、`defineProps<OverlayProps>()` 用です。
