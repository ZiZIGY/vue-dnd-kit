モニター（`useDnDMonitor`）、プロバイダーのイベント、ドロップゾーンのフックは `DnDEvent` を受け取り、`onDragEnd` は `DnDEndEvent` を受け取ります。並べ替え可能なリストとツリーは、独自のドロップイベント（[`SortableDropEvent`](/docs/api/make-sortable-list#the-drop-event)、[`SortableTreeDropEvent`](/docs/api/make-sortable-tree#the-drop-event)）を自身の `onBeforeDrop` と `onDrop` に渡します。
