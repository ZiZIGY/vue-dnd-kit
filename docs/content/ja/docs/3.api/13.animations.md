プロバイダーの `animation`（並べ替え中のレイアウトの移動）、`dropAnimation`（オーバーレイの着地）、`animate`（ドラッグ以外によるデータの変更）は、`false`、オプション、または独自の関数（GSAP や motion 用）を受け付けます。リストとツリーは `animation` と `animate` を上書きできます。[アニメーション](/docs/guides/animations)を参照してください。

```vue
<DnDProvider :animation="{ duration: 180, easing: 'ease-out' }" :drop-animation="false" />
```

下の各レーンはそれぞれ独立したプロバイダーで、`animation`、`dropAnimation`、`animate`（`move` に関数を受け取ります）にそれぞれ 1 つの形を使っています。
