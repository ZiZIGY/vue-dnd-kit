```ts
function makeDraggable<TData = unknown>(
  target: MaybeElementRef,
  options?: DraggableOptions<TData>,
): DraggableReturn;
```

```ts
const el = useTemplateRef<HTMLElement>('el');
const { isDragging } = makeDraggable(el, { id: 'card', type: 'card', data: { title } });
```

[ドラッグ＆ドロップ](/docs/guides/drag-and-drop)を参照してください。並べ替え可能なアイテムもドラッグ可能な要素です：[`makeSortableItem`](/docs/api/make-sortable-item) は同じオプションに加えて、さらに多くのオプションを受け付けます。
