## モディファイア {#modifiers}

```ts
import { restrictToParent, snapToGrid } from '@vue-dnd-kit/core';

makeSortableList(list, { items, modifiers: [restrictToParent] });
makeDragArea(board, { modifiers: [snapToGrid({ x: 24, y: 24, smooth: true })] });
```

モディファイアはドラッグのオフセットを受け取り、新しいオフセットを返します。実行順は次のとおりです：プロバイダーの `modifiers`、ドラッグエリアのもの、ドラッグ可能な要素自身のもの（またはそのリストのもの）、次にエリアの境界（`restrictToArea`）、最後に `axis` による固定。[軸、境界、グリッド](/docs/guides/constraints)を参照してください。

| モディファイア | 役割 |
| --- | --- |
| `restrictToVerticalAxis` | 縦方向にだけ動かします。`axis: 'y'` オプションも同じことを、最後に行います。 |
| `restrictToHorizontalAxis` | 横方向にだけ動かします（`axis: 'x'`）。 |
| `restrictToWindowEdges` | オーバーレイをウィンドウ内に留めます。 |
| `restrictToParent` | オーバーレイを、ドラッグが始まったコンテナー（並べ替え可能なリスト、または通常のドラッグ可能な要素の親要素）内に留めます。 |
| `restrictToElement(element)` | オーバーレイを要素内に留めます（ref、ゲッター、または要素そのもの）。 |
| `restrictToFirstScrollableAncestor` | オーバーレイを、ドラッグ中の要素の最初のスクロール可能な祖先内に留めます。 |
| `snapToGrid(size \| options)` | グリッドにスナップさせます：`{ x, y, origin: 'container' \| 'delta', smooth }`。`'container'`（デフォルト）はボックスの左上をコンテナーの左上から引いたグリッド線に合わせ、`'delta'` はオフセットを丸めます。`smooth` はオーバーレイをセルの間で滑らかに移動させます。 |
| `snapCenterToCursor` | 掴んだ位置のオフセットを保つ代わりに、オーバーレイの中心をポインターの下に合わせます。 |

## 衝突判定 {#collision-detection}

```ts
import { closestCorners } from '@vue-dnd-kit/core';
```

```vue
<DnDProvider :collision="closestCorners" />
```

プロバイダーの `collision` がターゲットを選びます。最も良い候補が先頭に来ます。

| 関数 | 選ぶもの |
| --- | --- |
| `pointerFirst` | デフォルト：ポインターの下にあるもの。なければオーバーレイと重なっているもの。 |
| `pointerWithin` | ヒットテストによる、ポインターの下のターゲット（z 順序、オーバーレイ、shadow root を考慮）。 |
| `rectIntersection` | オーバーレイと重なっているターゲット：優先度が高いもの、次にネストが深いもの、次に IoU（Intersection over Union）が大きいもの。 |
| `closestCenter` | すべてのターゲットを、中心間の距離で。 |
| `closestCorners` | すべてのターゲットを、角どうしの距離の合計で（カンバンの列のように積み重なったターゲット向け）。 |
