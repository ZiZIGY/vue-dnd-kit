::api-signature{name="makeSortableTree"}
::

```ts
const root = useTemplateRef<HTMLElement>('root');
const { items } = makeSortableTree(root, { items: files, indentation: 20, collapsed });
```

各行は `id: () => node.key` を指定して [`makeSortableItem`](/docs/api/make-sortable-item) を呼び出します。[ツリー](/docs/guides/trees)を参照してください。
