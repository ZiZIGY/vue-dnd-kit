## フラットに描画する {#rendered-flat}

ツリーは、表示されているノードを順番に並べた**フラットなリスト**として描画され、各ノードは自分の `depth` を持ちます。行のインデントは自分で付けます。こうするとすべての行が 1 つのコンテナー内の兄弟になるため、行はリストの行と同じようにスライドし、アニメーションします。

```vue [FileTree.vue]
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { makeSortableTree, type Key } from '@vue-dnd-kit/core';
import TreeRow from './TreeRow.vue';

interface FileNode { id: string; name: string; folder?: boolean; children?: FileNode[] }

const files = ref<FileNode[]>([
  { id: 'src', name: 'src', folder: true, children: [{ id: 'main', name: 'main.ts' }] },
  { id: 'readme', name: 'README.md' },
]);
const collapsed = ref(new Set<Key>());
const INDENT = 18;

const root = useTemplateRef<HTMLElement>('root');
const { items } = makeSortableTree(root, {
  items: files,                                  // the root nodes
  indentation: INDENT,                           // px per level: match your row padding
  collapsed,
  canNest: (_node, parent) => !!parent.folder,   // only folders take children
});

const toggle = (key: Key) => (collapsed.value.has(key) ? collapsed.value.delete(key) : collapsed.value.add(key));
</script>

<template>
  <div ref="root">
    <TreeRow v-for="node in items" :key="node.key" :node="node" :indent="INDENT" @toggle="toggle" />
  </div>
</template>
```

```vue [TreeRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode, type Key } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const emit = defineEmits<{ toggle: [key: Key] }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { id: () => props.node.key });
</script>

<template>
  <div ref="el" :style="{ paddingLeft: `${node.depth * indent}px` }">
    <button
      v-if="node.item.folder"
      type="button"
      :aria-expanded="!node.collapsed"
      :aria-label="node.collapsed ? 'Expand' : 'Collapse'"
      @click="emit('toggle', node.key)"
    >
      {{ node.collapsed ? '▸' : '▾' }}
    </button>
    {{ node.item.name }}
  </div>
</template>
```

行は、リストの行と同じく `makeSortableItem` を使います。`items` には `FlatNode` が入ります。

| `FlatNode` のフィールド | 内容 |
| --- | --- |
| `key` | ノードのキー（`getKey`、デフォルトは `node.id`）。`:key` と行の `id` に使います。 |
| `item` | あなたのノード。 |
| `depth` | ルートは `0`。ドラッグ中のノードの深さは、それが着地する**予定の**深さなので、着地位置がリアルタイムでインデントされます。 |
| `parentKey` | 親のキー。ルートでは `null`。 |
| `index` | 兄弟の中でのインデックス。 |
| `hasChildren`、`collapsed` | 展開ボタン用。 |

子は `node.children` から読み取られ、そこに書き込まれます。ほかの形のデータには `getChildren` と `setChildren` を使います。

```ts
makeSortableTree(root, {
  items: outline,
  getKey: (node) => node.uuid,
  getChildren: (node) => node.nested,
  setChildren: (node, children) => { node.nested = children; },
});
```

## ネスト {#nesting}

ドラッグで深さを変える方法は 2 つあり、どちらもデフォルトでオンです（`nesting: 'both'`）。

- **横方向**（`'offset'`）：`indentation` ピクセルだけ左右にドラッグすると、1 階層上または下に移ります。着地位置の周りの行が許す範囲までです。
- **ホバー**（`'hover'`）：行の中央にドラッグを留めると、ドロップはその行の中に、最初の子として入ります。

`indentation` には、行が 1 階層ごとに加えるパディングを設定してください。そうすればオフセットがポインターに追従します。`axis: 'y'` ではドラッグは横に動けませんが、行はホバーでネストできます。

## 折りたたまれたノード {#collapsed-nodes}

`collapsed` は、子が非表示になっているノードのキーの `Set` です（ref またはゲッター）。それらの子は `items` に含まれません。ドラッグされたフォルダーは、折りたたまれているかどうかに関係なく、サブツリー全体を一緒に運びます。ツリーの `animate` オプションをオンにすると、フォルダーが表示・非表示にする行がアニメーションしながら出入りします。

## ルール {#rules}

| オプション | 制限する内容 |
| --- | --- |
| `canNest(node, parent)` | `node` を `parent` の下に置けるか。マルチドラッグでは、ドラッグ中のすべてのノードについて問い合わせます。 |
| `maxDepth` | 許可される最大の深さ。ルートは `0` です。ドラッグ中のノードの子孫も数えます：子と孫を持つフォルダーは、最大でも深さ `maxDepth - 2` までです。 |
| `group.put` | ツリーがほかのリストやツリーからアイテムを受け入れるかどうか。 |
| `onBeforeDrop` | それ以外のすべて。ドロップ時に判断します：[ドロップの判断](/docs/guides/drop-decisions)を参照してください。 |

ルールがある深さを拒否すると、着地位置はルールを満たす最も深い深さを取ります。どの深さも満たさない場合、着地位置はそこへ移動しません。コピーや `createItem` で作られたノードも `canNest` と `maxDepth` に従います。

## 同じグループのツリーとリスト {#trees-and-lists-in-one-group}

`group` が同じツリーとリストは、2 つのリストと同じようにノードをやり取りします。リストへ移動したフォルダーはサブツリーを保持し、戻ってくるときも一緒に戻ります。コピーはリストと同じように動作します（`clone`、`pull: 'clone'`、Alt キー）が、`clone` は**サブツリー全体を含む**コピーを返す必要があり、その中のすべてのノードに新しいキーが必要です。

```ts
let count = 0;
const copyNode = (node: FileNode): FileNode => ({
  ...node,
  id: `${node.id}-${++count}`,
  children: node.children?.map(copyNode),
});

makeSortableTree(root, { items: files, group: 'files', clone: copyNode });
```

グループ、コピー、`createItem` については[アイテムを共有するリスト](/docs/guides/shared-lists)を参照してください。

## 挿入ライン {#an-insertion-line}

`placeholder: 'indicator'` では、ドラッグ中にツリーは動きません。各行が自分の `indicator` を読み取ってラインを描き、ドロップが着地する深さまでインデントします。

```vue [TreeRow.vue]
<script setup lang="ts">
import { computed, useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const el = useTemplateRef<HTMLElement>('el');
const { indicator } = makeSortableItem(el, { id: () => props.node.key });

// 'inside': the drop goes into this row. Otherwise a line before or after it.
const into = computed(() => indicator.value?.side === 'inside');
const line = computed(() => {
  const value = indicator.value;
  if (!value || value.side === 'inside') return null;
  return { side: value.side, left: `${(value.depth ?? 0) * props.indent}px` };
});
</script>

<template>
  <div ref="el" class="row" :class="{ into }" :style="{ paddingLeft: `${node.depth * indent}px` }">
    {{ node.item.name }}
    <span v-if="line" class="line" :class="line.side" :style="{ left: line.left }" />
  </div>
</template>

<style scoped>
.row { position: relative; }
.row.into { background: color-mix(in srgb, #42b883 15%, transparent); }
.line { position: absolute; right: 0; height: 2px; background: #42b883; }
.line.before { top: -1px; }
.line.after { bottom: -1px; }
</style>
```

ツリーでは、`indicator` に `depth` と `parentKey` が加わります：ドロップされたノードが得る階層と親です。横にドラッグすると、ラインが階層の間を移動します。このモードでは、ツリーの外へのドロップはキャンセルされます。

## ドロップ {#the-drop}

ツリーのドロップイベントはリストのものと同じで、`from` と `to` に `parentKey` が加わります。

```ts
makeSortableTree(root, {
  items: files,
  onDrop: (e) => {
    console.log(e.keys, e.from.parentKey, '→', e.to.parentKey, e.to.index);
  },
});
```

`to.index` は新しい兄弟の中での位置で、ノードが元の場所を離れた後で数えます。ドロップ時、ライブラリは変更されたノードに新しい子を設定し（`setChildren`）、新しいルート配列をあなたの ref に書き込みます。

`e.result.get(treeId)` は、新しいルート配列としての新しいツリーです。変更されたパス上のノードはコピーで、変更のないサブツリーは共有され、あなたのノードはそのまま残ります。ストアやイミュータブルなデータでは、ゲッターを渡し、`e.preventDefault()` を呼んで `e.result` を保存してください。コピーは `withChildren(node, children)` で作られます。デフォルトは新しい子を持つ `{ ...node }` です。クラスのインスタンスには独自のものを渡してください。

## キーボードとマルチドラッグ {#keyboard-and-multi-drag}

キーボードでは、:kbd{value="ArrowUp"} と :kbd{value="ArrowDown"} で行の間を移動し、:kbd{value="ArrowLeft"} と :kbd{value="ArrowRight"} で周りの行が許す範囲で深さを変えます。

選択中のノードは 1 つのブロックとしてまとめて移動し、それぞれがサブツリーを伴い、ドキュメント順に並びます。選択中のノードの中にある選択中のノードは、親のサブツリーに乗って一緒に移動します。[マルチドラッグ](/docs/guides/multi-drag)を参照してください。

すべてのオプションは [makeSortableTree API](/docs/api/make-sortable-tree) にあります。数千行のツリーについては[仮想リスト](/docs/guides/virtual-lists)を参照してください。
