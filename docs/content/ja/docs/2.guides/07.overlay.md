ドラッグ中は、ボックスがポインターに追従します。これが**オーバーレイ**です。ドラッグされている要素自体は、着地する位置としてその場に残ります。ドロップすると、オーバーレイはその位置へ飛んでいき、消えます。

オーバーレイはコンポーネントの外、`body` にテレポートされます。デフォルトでは、ドラッグ中の要素のクローンを表示します。

::

## デフォルトのクローン {#the-default-clone}

クローンは、何かが動く前の、持ち上げた時点で作られます。要素のディープコピーです。

- フォームの値と `<canvas>` のピクセルはコピーされます。
- 要素がリストの外に出ると失われる計算済みスタイルはインライン化されます：継承されたフォントと色、祖先を通じてマッチするスタイル（`.list li { … }`）、テーブルのセル幅。テーブルの行は、専用のテーブルに包まれます。
- `id` と `data-dnd-*` 属性は取り除かれ、クローンには `aria-hidden` が付きます。
- UI キット（Vuetify、Quasar、PrimeVue、Naive UI）のリップルやその他の押下エフェクトは除外されます。

そのほか一緒に運ばれるべきでないものには **`data-dnd-no-clone`** を付けてください：メニューボタン、ツールチップ、バッジなどです。

```vue
<li ref="el" class="mail-row">
  {{ mail.subject }}
  <button type="button" aria-label="Archive" data-dnd-no-clone>…</button>
</li>
```

### 背景は推測されない {#backgrounds-arent-guessed}

クローンは要素をそのままの姿で表示します。背景をリストが塗っているために自分の背景を持たない行（白い `<ul>` の中の `<li>`、`v-list-item`、テーブルの行）は、**透けた**クローンになります。CSS でリストの背景を与えてください。

```vue [MailRow.vue]
<style scoped>
[data-dnd-overlay] .mail-row {
  background: var(--surface);
}
</style>
```

クローンは要素のクラスと属性を、Vue のスコープ属性も含めて保持するため、このルールはグローバルなスタイルシートでも、行の scoped スタイルでも機能します。もう 1 つの方法は、行自体に背景を付けることです。[並べ替え可能なリスト](/docs/guides/sortable-lists)のアプリアイコンのように、浮かんで見えることを意図したアイコンやタイルは、あえて透明のままにしています。

## ボックスのスタイル {#styling-the-box}

ボックスは `data-dnd-overlay` を持つ要素です。`position: fixed` と `pointer-events: none` が指定されており、その値はボックスがしていることを表します。

| `data-dnd-overlay` | タイミング |
| --- | --- |
| `"dragging"` | ポインターに追従している。 |
| `"dropping"` | 自分の位置に着地している、元の位置に戻っている、または非同期の `onBeforeDrop` を待っている。 |

ドラッグ中は持ち上がったように見せ、着地すると元に戻す例：

```css
[data-dnd-overlay='dragging'] .mail-row {
  box-shadow: 0 18px 32px -14px rgb(0 0 0 / 0.5);
}
```

## オーバーレイコンポーネント {#overlay-components}

クローン以外のものを表示するには、コンポーネントを渡します。コンポーネントはボックスの中に描画されます。

```vue [CardOverlay.vue]
<script setup lang="ts">
import type { OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <!-- Fill the box: it resizes to the slot and animates on drop. -->
  <div class="card-overlay" :class="{ refused: over && !accepted }">
    {{ (items[0]?.item as Task).title }}
    <small v-if="mode === 'copy'">+ copy</small>
    <span v-if="items.length > 1" class="count">{{ items.length }}</span>
  </div>
</template>

<style scoped>
.card-overlay { width: 100%; height: 100%; }
</style>
```

```ts
import CardOverlay from './CardOverlay.vue';

makeSortableList(listRef, { items: tasks, overlay: CardOverlay });          // every item of the list
makeSortableItem(el, { item: () => props.task, overlay: CardOverlay });      // this item
makeDraggable(el, { id: 'chip', overlay: CardOverlay });                     // a plain draggable
```

| `OverlayProps` | 内容 |
| --- | --- |
| `active` | ドラッグ（`id`、`ids`、`data`、`type`…）。 |
| `items` | ドラッグ中のすべてのアイテム。掴んだものが先頭：`{ id, item, data, type }`。並べ替え可能なリストのドラッグでは、`item` はリストのアイテムです。 |
| `over` | ドラッグの下のターゲット、またはドロップ中に着地するターゲット。何もない上と、キャンセルされたドラッグが元の位置に戻る間は `null`。 |
| `accepted` | `over` がドラッグを受け入れるかどうか：受け入れないときはオーバーレイを赤く色付けできます。 |
| `status` | `'dragging'` または `'dropping'`。 |
| `mode` | `'move'`、`'copy'`、`'swap'`、`'insert'` のいずれか。 |

コンポーネントはそのまま渡すことも、切り替えるために `shallowRef` に入れて渡すこともできます。深い `ref` や `reactive` には絶対に入れないでください。Vue がコンポーネントをリアクティブにして警告を出します。

[並べ替え可能なリスト](/docs/guides/sortable-lists)のアプリグリッドは、オーバーレイコンポーネントを使っています。アイコンだけが運ばれて持ち上がり、名前はその場に残ります。

## プロバイダーの `#overlay` スロット {#the-providers-overlay-slot}

独自のコンポーネントを持たないすべてのドラッグでは、プロバイダーのスロットがオーバーレイを描画します。

```vue [App.vue]
<DnDProvider>
  <RouterView />
  <template #overlay="{ items, mode, accepted }">
    <CardOverlay v-if="items[0]?.type.includes('card')" v-bind="{ items, mode, accepted }" />
  </template>
</DnDProvider>
```

スロットは、オーバーレイコンポーネントと同じ props を受け取ります。スロットが何も描画しないとき（上の `v-if`）、そのドラッグはクローンにフォールバックします。

## 優先順位 {#what-wins}

各ドラッグでは、次のうち最初に当てはまるものが使われます。

1. アイテム自身の `overlay`（`makeSortableItem`、`makeDraggable`）。
2. そのアイテムのリストまたはツリーの `overlay`。
3. プロバイダーの `#overlay` スロット（何も描画しない場合を除く）。
4. デフォルトのクローン。マルチドラッグでは、クローンの列または山積み：[マルチドラッグ](/docs/guides/multi-drag#the-default-overlay)を参照してください。

コンポーネントはドラッグの開始時に選ばれ、ほかのリストの上を通るときも含め、ドラッグの間ずっと同じものが使われます。

## `DragPreview`：レイアウトの中のクローン {#dragpreview-the-clone-in-your-layout}

`DragPreview` は、ドラッグ中の 1 つのアイテムについてライブラリのクローンを描画します。複数のアイテムを自分でレイアウトするオーバーレイコンポーネントや、クローンの周りに枠を付けるオーバーレイコンポーネントで使います。

```vue [CopyOverlay.vue]
<script setup lang="ts">
import { DragPreview, type OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <div class="with-badge">
    <DragPreview :id="active.id" :style="{ width: '100%', height: '100%' }" />
    <span v-if="mode === 'copy'" class="badge">+</span>
  </div>
</template>
```

クローンが存在するのは、掴んだアイテムと、その隣にある最大 4 つのほかのアイテムだけです。それ以外のアイテムでは、`DragPreview` はデフォルトスロットを描画します。プレビューを山積みにする例は[マルチドラッグ](/docs/guides/multi-drag#a-custom-overlay-for-several-items)を参照してください。

## サイズ：`overlayFit` {#size-overlayfit}

| `overlayFit`（プロバイダー） | ボックス |
| --- | --- |
| `'slot'`（デフォルト） | 着地する位置のサイズになります。幅の広いカードのリストの上では、幅が広がります。 |
| `'source'` | ドラッグ中の要素のサイズを保ちます。 |

`'slot'` では、ボックスはポインターを中心にサイズを変え、ポインターはボックス内の同じ比率の位置に留まります。コンテンツが拡大縮小されることはなく、新しいサイズでレイアウトし直されます。

ドロップはどちらの設定でも同じです。ボックスは着地先の要素へ飛んでいき、**その要素の**サイズへとアニメーションし、コンテンツは途中でレイアウトし直されます。2 つのリストでアイテムの見た目が異なる場合（パレットではコンパクトなチップ、ボードでは完全なカード）、元の要素のクローンはターゲットのサイズでレイアウトし直されるため、潰れたり引き伸ばされたりして見えることがあります。正しく見せる方法は 2 つあります。

- 着地しうるすべてのリストで、アイテムを**同じ見た目**にする。[ドラッグ＆ドロップ](/docs/guides/drag-and-drop)のファイルはどのフォルダーでも同じ固定サイズなので、ドロップは移動するだけです。
- オーバーレイコンポーネントで**ターゲットの見た目**を描画する。コンポーネントは `over` を受け取るので、上にあるリストの見た目に切り替えられ、どんなサイズでもボックスを埋められます。

オーバーレイコンポーネントのルートに固定サイズを指定すると、ボックスの中でそのサイズが保たれます。ボックスに追従させるには、ルートに `width: 100%; height: 100%` を指定してください。

## 描画される場所：`overlayTo` {#where-it-renders-overlayto}

プロバイダーはオーバーレイを `body` にテレポートします。`showModal()` で開いた `<dialog>` や shadow root の中では、オーバーレイはトップレイヤーの下に隠れたり、スタイルの適用範囲の外に出たりしてしまいます。`overlayTo` をそこにあるセレクターまたは要素に向けてください。

```vue
<DnDProvider overlay-to="#dialog-overlay">
```

## オーバーレイなし {#no-overlay}

`makeDraggable(el, { overlay: false })` にはボックスがまったくありません。返される `transform` によって、要素自体が動きます。[ドラッグ＆ドロップ](/docs/guides/drag-and-drop#without-an-overlay)を参照してください。ボックスがどう着地するかは、プロバイダーの `dropAnimation` で決まります：[アニメーション](/docs/guides/animations)を参照してください。
