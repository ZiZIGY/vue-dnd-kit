## グループ {#a-group}

`group` の名前が同じリストどうしは、アイテムをやり取りします。デフォルトでは、各リストがそれぞれ独自のグループです。

```vue [Column.vue]
<script setup lang="ts">
import { toRef, useTemplateRef } from 'vue';
import { makeSortableList } from '@vue-dnd-kit/core';
import Card from './Card.vue';

type Task = { id: string; title: string };
const props = defineProps<{ column: { id: string; title: string; cards: Task[] } }>();

const zone = useTemplateRef<HTMLElement>('zone');
const list = useTemplateRef<HTMLElement>('list');
const { items, isOver } = makeSortableList(list, {
  id: props.column.id,                   // names the list in drop events
  items: toRef(props.column, 'cards'),   // a writable ref into the reactive column
  group: 'board',                        // same name: cards move between these lists
  dropzone: zone,                        // the whole column takes drops
});
</script>

<template>
  <section ref="zone" :class="{ over: isOver }">
    <h3>{{ column.title }}</h3>
    <ul ref="list">
      <Card v-for="card in items" :key="card.id" :card="card" />
    </ul>
  </section>
</template>
```

```vue [Board.vue]
<script setup lang="ts">
import { reactive } from 'vue';
import Column from './Column.vue';

const columns = reactive([
  { id: 'todo', title: 'To do', cards: [{ id: 'vdk-12', title: 'Pick a palette' }] },
  { id: 'done', title: 'Done', cards: [] },
]);
</script>

<template>
  <Column v-for="column in columns" :key="column.id" :column="column" />
</template>
```

- 各列はそれぞれ独立したコンポーネントです：1 つのコンポーネントに 1 つのリスト。
- 親がリアクティブなオブジェクトを渡しているため、`toRef(props.column, 'cards')` は書き込み可能です。ドロップは、カードが出ていった配列と入ってきた配列の両方に書き込まれます。
- `id` はドロップイベントで `from.list` と `to.list` として現れ、`e.result`（ドロップで変わるすべてのリストの新しい配列）のキーにもなります。`id` と `group` は一度だけ読み取られます。
- キーはグループ全体で一意である必要があります。

リストの `onDrop` は、そのリスト**への**ドロップで実行されます。`todo` から `done` への移動では `done` リストの `onDrop` が呼ばれ、その `e.result` には両方のリストの新しい配列が入っています。

## 列全体でドロップを受け付ける：`dropzone` {#the-whole-column-takes-drops-dropzone}

背の高い列に短いリストがあると、最後のカードの下に空きスペースが残ります。`dropzone: zone` を指定すると、列の要素がリストに代わってドロップを受け付けます。最後のカードの下で離したカードは末尾に着地します。カードは `<ul>` の中に残ったままで、大きくなるのはドロップを受け付ける領域だけです。

::tip
`dropzone` がない場合、空のリストがドロップを受け付けるにはサイズが必要です：`min-height` を指定してください。
::

## 何が入り、何が出るか：`pull` と `put` {#what-goes-in-and-out-pull-and-put}

`group` にはオブジェクトも指定できます。

```ts
group: { name: 'board', pull: true, put: true }
```

| オプション | 値 |
| --- | --- |
| `pull` | `true`（デフォルト）：アイテムは外に出られます。`false`：出られません。`'clone'`：コピーが出ていき、アイテム自体は残ります。 |
| `put` | `true`（デフォルト）：アイテムは入れます。`false`：何も入れません。関数：ドラッグごとにあなたが決めます。 |

`put` 関数は `{ keys, items, types, from, to }` を受け取ります。`from` はアイテムの出どころのリストで、通常のドラッグ可能な要素の場合は `null` です。リスト内での移動は常に許可されます。

### 上限 {#limits}

カードを最大 3 枚まで入れられる列：

```ts
makeSortableList(list, {
  id: props.column.id,
  items: toRef(props.column, 'cards'),
  group: {
    name: 'board',
    put: ({ keys }) => props.column.cards.length + keys.length <= 3,
  },
});
```

ドラッグを拒否するリストの上では、着地位置はドラッグを始めた場所に戻ります。そのためリストは、ドロップしたらどうなるか、つまり何も起きないことをそのまま示します。そこでドロップするとキャンセルされ、カードは元の位置に戻ります。このようなドラッグの間、そのリストの `isAccepting` は `false` です：これを使って列を暗く表示できます。

型の異なる複数の選択中アイテムをドラッグするとき、`acceptMode` は、すべて（`'all'`、デフォルト）と一部（`'some'`）のどちらが `put` を通過する必要があるかを決めます。`'some'` では、通過したアイテムが着地し、それ以外は元の位置に戻ります。

## コピー：パレットと Alt キー {#copy-palettes-and-the-alt-key}

::example{name="palette" hint="パレットからドラッグ。Alt を押しながらドラッグするとコピー、ページの外にドロップすると削除" height="24rem"}
::

```ts [Palette.vue]
makeSortableList(list, {
  items: templates,
  group: { name: 'blocks', pull: 'clone', put: false },  // copies go out, nothing comes in
  sort: false,                                           // its own order stays
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),
});
```

```ts [Sheet.vue]
makeSortableList(list, {
  items: blocks,
  group: 'blocks',
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),  // for Alt-drags
});
```

- `pull: 'clone'` は、このリストから出ていくすべてのドラッグをコピーにします。元のアイテムは残り、コピーが運ばれて着地します。
- ドラッグ中に :kbd{value="Alt"} を押していてもコピーになります。どのリストからでも可能です。キーはプロバイダーの `copyModifier` で変更でき、`null` でオフにできます。
- どちらの場合も、アイテムの出どころのリストに `clone` が必要です。`clone` は**新しいキー**を持つコピーを返す必要があります。`clone` がなければ何もコピーされません。
- ドロップイベントは `mode: 'copy'` を持ち、`e.items` はコピーです。オーバーレイコンポーネントも `mode` を受け取るので、コピー中に「+」を表示できます（[オーバーレイ](/docs/guides/overlay)を参照）。

## 通常のドラッグ可能な要素をリストへ {#plain-draggables-into-a-list}

リストは、`makeDraggable` でドラッグされたものからアイテムを作る方法を知っていれば、それを受け入れます。

```ts
makeSortableList(list, {
  items: tasks,
  createItem: (active) => ({ id: crypto.randomUUID(), title: (active.data as Chip).title }),
});
```

ドラッグ可能な要素がリストの上にある間、作られたアイテムはドラフトの中に置かれ、ほかの行と同じようにあなたのテンプレートで描画されます。ドロップ時に本物のアイテムになります（`mode: 'insert'`、`from.list === null`）。拒否するには `undefined` を返します。`createItem` のないリストは、通常のドラッグ可能な要素を無視します。キーボードでは、リストの方向への矢印キーでドラッグ可能な要素を取り込みます。

## ずらす代わりに入れ替える {#swap-instead-of-shift}

```ts
makeSortableList(grid, { items: tiles, strategy: 'grid', behavior: 'swap' });
```

ドラッグ中のアイテムは下にあるアイテムと位置を入れ替え、ほかのアイテムは動きません。入れ替えはリアルタイムです：戻ったりリストの外に出たりすると元に戻ります。ドロップイベントは `mode: 'swap'` と、入れ替えた相手のアイテムである `partner` を持ちます。

- 同じグループの 2 つのリストは、両方が `behavior: 'swap'` を持つとき、互いの間で入れ替えます。ホバーされたアイテムはもう一方のリストへ移動するため、出ること（`pull: true`）と入ること（`put`）が許可されている必要があります。
- マルチドラッグは入れ替えではなく並べ替えになります。

## 挿入ライン {#an-insertion-line}

`placeholder: 'indicator'` では、ドラッグ中にリストは動かず、ドロップ先をラインで示します。ラインはあなたが描きます。

```ts [TaskList.vue]
const { items, indicator } = makeSortableList(listRef, { items: tasks, placeholder: 'indicator' });
```

```vue [TaskRow.vue]
<script setup lang="ts">
const { indicator } = makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el" :class="indicator && `drop-${indicator.side}`">{{ task.title }}</li>
</template>

<style scoped>
.drop-before { box-shadow: inset 0 2px 0 #42b883; }
.drop-after { box-shadow: inset 0 -2px 0 #42b883; }
</style>
```

| `indicator` のフィールド | 内容 |
| --- | --- |
| `list` | ドロップ先のリスト。 |
| `index` | 描画されたリストでの挿入インデックス。 |
| `key` | ラインが付くアイテム。空のリストでは `null`（その場合はリストにラインを描きます）。 |
| `side` | そのアイテムの前（`'before'`）か後（`'after'`）か。ツリーでは `'inside'` が加わります。 |
| `depth`、`parentKey` | ツリーのみ：ドロップの着地先。[ツリー](/docs/guides/trees#an-insertion-line)を参照してください。 |

リストの `indicator` はラインがそのリストにある間、アイテムの `indicator` はラインがそのアイテムに付いている間に設定されます。キーボードでもラインを動かせます。

## 外にドロップする {#dropping-outside}

ドラッグがどのターゲットの上でもない場所で終わったときにどうなるかは、リストの `dropOutside` で決まります。

| `dropOutside` | アイテムは |
| --- | --- |
| `'placeholder'`（デフォルト） | 着地位置が最後に表示されていた場所に着地します。 |
| `'cancel'` | 元の位置に戻ります。`placeholder: 'indicator'` のときのデフォルトです。 |
| `'remove'` | リストから取り除かれます：外へドラッグして削除。 |

`'remove'` は、まずリストの `onBeforeDrop` に問い合わせます。その後、リストの `onDrop` が `to.index === -1` で実行され、`e.result` にはアイテムを除いたリストが入ります。ドロップを受け付けるゴミ箱も同じように動作します：[ゴミ箱ゾーン](/docs/guides/drag-and-drop#trash-zones)を参照してください。

移動を確認する、先にサーバーに保存する、ドロップを自分でストアに適用する、といったことについては[ドロップの判断](/docs/guides/drop-decisions)を参照してください。リストのすべてのオプションは [makeSortableList API](/docs/api/make-sortable-list) にあります。
