## 選択 {#the-selection}

各プロバイダーは 1 つの選択、つまり id のリアクティブな集合を保持します。**選択中の**アイテムをドラッグすると、選択中のすべてのアイテムがドラッグされ、掴んだものが先頭になります。選択されていないアイテムをドラッグすると、そのアイテムだけがドラッグされます。

ユーザーがどう選択するかはライブラリが決めません。クリックのルールはあなたが決めます。ライブラリが勝手に選択をクリアすることもなく、選択はアンマウントの後も残ります。仮想リストが再利用する行などがその例です。

### Ctrl/Cmd クリック {#ctrlcmd-click}

すべての並べ替え可能なアイテムとドラッグ可能な要素は、選択にバインドされた書き込み可能な ref である `selected` を返します。

```vue [Shot.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ shot: { id: string } }>();
const el = useTemplateRef<HTMLElement>('el');
const { selected } = makeSortableItem(el, { item: () => props.shot });

const onClick = (event: MouseEvent) => {
  if (event.ctrlKey || event.metaKey) selected.value = !selected.value;
};
</script>

<template>
  <div ref="el" :class="{ selected }" @click="onClick">…</div>
</template>
```

ドラッグを終えるクリックは `@click` に届かないため、ドロップで選択が誤って切り替わることはありません。アイテムの操作には `pointerup` ではなく `@click` を使ってください。

### どこからでも：`useDnD().selection` {#from-anywhere-usedndselection}

```ts
import { useDnD, useDnDMonitor } from '@vue-dnd-kit/core';

const { selection } = useDnD();

selection.has('a');               // is it selected?
selection.add('a', 'b');          // select
selection.delete('a');            // deselect
selection.toggle('a');            // flip it, or force it: toggle('a', true)
selection.set(['a', 'c']);        // exactly these
selection.clear();
selection.ids;                    // a reactive ReadonlySet<Key>

// A plain click selects only that item, Ctrl/Cmd-click adds or removes it:
const onClick = (event: MouseEvent, id: string) => {
  if (event.ctrlKey || event.metaKey) selection.toggle(id);
  else selection.set([id]);
};

// Clear it after every drop, if your UI wants that:
useDnDMonitor({ onDragEnd: () => selection.clear() });
```

選択は id をキーにしているため、複数のリストのアイテムを含められます。1 回のドラッグで、プロバイダーの下にある選択中のすべてのアイテムが運ばれます。

## 範囲選択 {#rubber-band-selection}

`makeSelectionArea` は要素を選択エリアにします。その空いている場所を押すと選択枠が描かれ、枠が横切ったアイテムが選択されます。

```vue [Gallery.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSelectionArea } from '@vue-dnd-kit/core';
import PhotoGrid from './PhotoGrid.vue';

const area = useTemplateRef<HTMLElement>('area');
const { isSelecting, style } = makeSelectionArea(area);
</script>

<template>
  <div ref="area" class="area">
    <PhotoGrid />
    <div v-if="isSelecting" class="band" :style="style" />
  </div>
</template>

<style scoped>
.area {
  position: relative;   /* the band is absolutely positioned inside */
  min-height: 320px;    /* room around the items to start a band */
}

.band {
  border: 1px solid #42b883;
  background: color-mix(in srgb, #42b883 15%, transparent);
}
</style>
```

- 選択枠はあなたが描画します。`style` がエリアのコンテンツを基準に枠を配置します。
- エリアには **static 以外の position**（`relative` で十分です）が必要です。そうでないと、枠が別の場所に表示されます。
- 選択枠はエリア自体からしか始まらないため、エリアは大きくしてください。ぴったりしたラッパーではなく、アイテムの周りに余白のあるパネル全体です。上のギャラリーはボックス全体を占めています。
- アイテムの上で押すと、そのアイテムがドラッグされます。ボタン、入力欄、エリアのスクロールバーは、それぞれの押下を保持します。
- エリアやページがスクロールしても、選択枠はコンテンツに固定されたままです。:kbd{value="Escape"} で枠をキャンセルし、選択を元に戻します。
- 枠を描いている間、`useDnD().status` は `'selecting'` です。

| オプション | 役割 |
| --- | --- |
| `strategy` | `'toggle'`（デフォルト）：枠が横切ったアイテムの選択が反転します。`'select'`：枠の内側のアイテムだけが選択されるため、空いている場所をクリックするとエリア内のアイテムの選択が解除されます。 |
| `modifier` | 枠を描くために押している必要があるキー：`{ keys: ['Shift'], method: 'every' }`（または `'some'`）。 |
| `accept` | 枠がどのドラッグ可能な要素を選択するか。それらの `type` と照合される [accept ルール](/docs/guides/drag-and-drop#which-drags-a-target-takes)です。 |
| `disabled` | 枠を描けなくします。オンにすると、描画中の枠はキャンセルされます。 |
| `onSelected(ids)` | 枠が終わったときに、選択を引数として呼ばれます。 |
| `selection` | プロバイダーの選択の代わりに使う、独自の `Ref<Set<Key>>`。 |

エリアの中にエリアがある場合は、最も内側のものが押下を受け取ります。すべてのオプションは [makeSelectionArea API](/docs/api/make-selection-area) にあります。

## ほかのアイテムの動き方：`multiple` {#how-the-other-items-move-multiple}

マルチドラッグが始まったリストが、ドラッグ中にほかの選択中アイテムがどう動くかを決めます。

```ts
makeSortableList(listRef, { items: tasks, multiple: 'gaps' });
```

| `multiple` | ドラッグ中 | オーバーレイ |
| --- | --- | --- |
| `'group'`（デフォルト） | ほかのアイテムは元の位置を離れ、掴んだアイテムと一緒に連続した位置のブロックとして移動します。そのため、リストにはドロップの結果がすでに表示されています。 | リストに沿って、ドラッグ中のアイテムを最大 5 つまで並べた列。 |
| `'gaps'` | ほかのアイテムはドロップまでその場に留まり、薄く表示されます（`data-dnd-dragging`）。 | 同じ列。 |
| `'stack'` | ほかのアイテムはオーバーレイの中へ飛んでいきます。 | 掴んだアイテムと件数。 |

ドロップ時、アイテムは元の順序のまま、まとめてターゲットのインデックスに着地します。`'group'` と `'gaps'` では、オーバーレイの各アイテムがそれぞれ自分の位置へ飛んでいきます。

### デフォルトのオーバーレイ {#the-default-overlay}

`'group'` と `'gaps'` では、オーバーレイはドラッグ中のアイテムを着地する順に並べた列です。掴んだアイテムがポインターの下にあり、ほかのアイテムはドロップ順でその前後に並びます（横方向のリストでは行になります）。表示されるのは最大 5 つです。それを超えるアイテムは、その位置で件数として表示されます。列の先頭の `+N` は表示されているものより前に着地するアイテム、末尾の `+N` は後に着地するアイテムです。

グリッドでは、セル全体の列がページを覆ってしまうため、オーバーレイは山積みになります。最大 3 つのアイテムが掴んだアイテムの後ろに扇状に重なり、その上に合計数が表示されます。

通常のドラッグ可能な要素（`makeDraggable`）では、掴んだアイテムと件数が表示されます。

### 型の混在 {#mixed-types}

選択中のアイテムの型が異なる場合、ターゲットの `acceptMode` は、すべて（`'all'`、デフォルト）と一部（`'some'`）のどちらが条件を満たす必要があるかを決めます。[アイテムを共有するリスト](/docs/guides/shared-lists#limits)と[ドラッグ＆ドロップ](/docs/guides/drag-and-drop#which-drags-a-target-takes)を参照してください。

## 複数アイテム用のカスタムオーバーレイ {#a-custom-overlay-for-several-items}

オーバーレイコンポーネントとプロバイダーの `#overlay` スロットは `items` を受け取ります。ドラッグ中のすべてのアイテムで、掴んだものが先頭です。`DragPreview` はそのどれかについてライブラリのクローンを描画するので、あなたのレイアウトで本物の見た目を再利用できます。

```vue [PileOverlay.vue]
<script setup lang="ts">
import { DragPreview, type OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <div class="pile">
    <!-- The grabbed item on top, two more turned behind it -->
    <DragPreview
      v-for="(entry, i) in items.slice(0, 3)"
      :id="entry.id"
      :key="entry.id"
      class="card"
      :style="{ width: '100%', height: '100%', zIndex: 3 - i, rotate: `${i * 4}deg` }"
    >
      <!-- Shown for an item without a clone -->
      <div class="fallback">{{ entry.id }}</div>
    </DragPreview>
    <span v-if="items.length > 1" class="count">{{ items.length }}</span>
  </div>
</template>

<style scoped>
.pile { position: relative; width: 100%; height: 100%; }
.card { position: absolute; inset: 0; }
.fallback { width: 100%; height: 100%; border-radius: 8px; background: Canvas; }
.count { position: absolute; top: -8px; right: -8px; z-index: 4; }
</style>
```

```ts
makeSortableList(listRef, { items: photos, strategy: 'grid', overlay: PileOverlay });
```

クローンは持ち上げた時点で作られます。対象は、掴んだアイテムと、ドロップ順でその隣にある最大 4 つのほかのアイテムです（描画されている場合）。それ以外のアイテムでは、`DragPreview` はデフォルトスロットを描画します。プレビューは、上の `style` のようにサイズを指定しない限り、持ち上げた時点のアイテムのサイズになります（`class` と `style` はそのまま渡されます）。`'group'` と `'gaps'` では、ドロップ時に各プレビューが自分のアイテムの位置に着地します。オーバーレイコンポーネントについて詳しくは[オーバーレイ](/docs/guides/overlay)を参照してください。

## ツリー {#trees}

ツリーでは、選択中のノードは 1 つのブロックとして移動し、それぞれがサブツリーを伴い、ドキュメント順に並びます。選択中のノードの中にある選択中のノードは、親のサブツリーに乗って一緒に移動します。[ツリー](/docs/guides/trees)を参照してください。
