ファイルをいくつか選んでから、その 1 つをドラッグしてみましょう。ほかのファイルも一緒についてきます。`multiple` を切り替えると途中での動きが、レイアウトを切り替えるとグリッドのオーバーレイが見られます。

::example{name="multi-modes" hint="ファイルをクリック、Ctrl/Cmd クリック、Shift クリックしてから 1 つをドラッグし、モードを切り替えてみましょう" height="35rem"}
::

## 選択 {#the-selection}

各プロバイダーは 1 つの選択を持ちます：id のリアクティブな集合です。**選択されている**アイテムをドラッグすると、選択中のすべてのアイテムがドラッグされ、掴んだものが先頭になります。選択されていないアイテムをドラッグすると、そのアイテムだけがドラッグされます。

ライブラリはユーザーがどう選択するかを決めません。クリックのルールはあなたが決めます。また、ライブラリが自分で選択を解除することもなく、選択はアンマウントを越えて保たれます。仮想リストが再利用する行などがその例です。

### クリック：Ctrl/Cmd と Shift {#clicks-ctrlcmd-and-shift}

並べ替え可能なアイテムとドラッグ可能な要素はすべて `selected` を返します。これは選択にバインドされた書き込み可能な ref です。クラスやチェックボックス（`v-model="selected"`）にバインドするか、クリックハンドラーで設定します。

```vue [FileItem.vue]
<script setup lang="ts">
const { selected } = makeSortableItem(el, { item: () => props.file });
</script>

<template>
  <li ref="el" class="file" :class="{ selected }" @click="emit('pick', $event)">…</li>
</template>
```

デモではリストがルールを持っています。クリックで 1 つのファイルを選択し、Ctrl/Cmd クリックで 1 つを追加または除外し、Shift クリックで最後にクリックしたファイルからの範囲を選択します。

```ts [Files.vue]
const { selection } = useDnD();
let anchor: string | null = null;

const pick = (id: string, event: MouseEvent) => {
  const ids = items.value.map((file) => file.id);
  if (event.shiftKey && anchor) {
    const [a, b] = [ids.indexOf(anchor), ids.indexOf(id)];
    selection.set(ids.slice(Math.min(a, b), Math.max(a, b) + 1));
    return;
  }
  if (event.ctrlKey || event.metaKey) selection.toggle(id);
  else selection.set([id]);
  anchor = id;
};
```

ドラッグを終えるクリックは `@click` に届かないので、ドロップで選択が意図せず変わることはありません。アイテムの操作には `pointerup` ではなく `@click` を使ってください。

### どこからでも：`useDnD().selection` {#from-anywhere-usedndselection}

```ts
import { useDnD, useDnDMonitor } from '@vue-dnd-kit/core';

const { selection } = useDnD();

selection.has('a');               // is it selected?
selection.add('a', 'b');          // select
selection.delete('a');            // deselect
selection.toggle('a');            // flip it, or force it: toggle('a', true)
selection.set(['a', 'c']);        // exactly these
selection.clear();
selection.ids;                    // a reactive ReadonlySet<Key>

// Clear it after every drop, if your UI wants that:
useDnDMonitor({ onDragEnd: () => selection.clear() });
```

選択は id でキー付けされるので、複数のリストのアイテムや、通常のドラッグ可能な要素も含められます。ドラッグは、プロバイダー配下の選択中のアイテムをすべて運びます。

## 範囲選択 {#rubber-band-selection}

`makeSelectionArea` は要素を選択エリアにします。空いている場所を押すと選択枠が描かれ、それが横切ったアイテムが選択されます。このデスクトップで、いくつかのアイコンを囲むように枠を描いてから、その 1 つをドラッグしてみましょう。

::example{name="multi-select" hint="空いているデスクトップに枠を描いてから、選択したアイコンをドラッグしてみましょう" height="29rem"}
::

```vue [Desktop.vue]
<script setup lang="ts">
const desktop = useTemplateRef<HTMLElement>('desktop');
const { isSelecting, style } = makeSelectionArea(desktop, {
  strategy,                                                          // 'toggle' or 'select'
  modifier: () => (withShift.value ? { keys: ['Shift'], method: 'every' } : undefined),
});
</script>

<template>
  <!-- The area needs a position: the band is placed inside it. -->
  <div ref="desktop" class="desktop">
    <DesktopIcon v-for="icon in icons" :key="icon.id" :icon="icon" :offset="offset" />
    <div v-if="isSelecting" class="band" :style="style" />
  </div>
</template>

<style scoped>
.desktop { position: relative; height: 236px; }
.band { border: 1px solid #42b883; background: color-mix(in srgb, #42b883 15%, transparent); }
</style>
```

- 選択枠はあなたが描画します。`style` がエリアのコンテンツを基準に配置します。
- エリアには **static 以外の position**（`relative` で十分）が必要です。そうでないと選択枠が別の場所に表示されます。
- 選択枠はエリア自体からしか始まらないので、エリアは大きくしてください。ぴったり包むラッパーではなく、アイテムの周りに余白のあるパネル全体にします。
- アイテムの上で押すとドラッグになります。ボタン、入力欄、エリアのスクロールバーは自身の押下を保持します。
- エリアやページがスクロールしても、選択枠はコンテンツに固定されたままです。:kbd{value="Escape"} でキャンセルし、選択を元に戻します。
- 選択枠を描いている間、`useDnD().status` は `'selecting'` です。デスクトップの下の行はこれを読み取っています。

| オプション | 役割 |
| --- | --- |
| `strategy` | `'toggle'`（デフォルト）：選択枠が横切ったアイテムの選択状態が反転します。`'select'`：選択枠の内側のアイテムだけが選択された状態になるので、空いている場所をクリックするとエリアのアイテムの選択が解除されます。 |
| `modifier` | 枠を描くために押している必要があるキー：`{ keys: ['Shift'], method: 'every' }`（または `'some'`）。 |
| `accept` | 選択枠が選択するドラッグ可能な要素。`type` と照合する [accept ルール](/docs/guides/drag-and-drop#which-drags-a-target-takes)です。 |
| `disabled` | 選択枠なし。オンにすると、描画中の選択枠はキャンセルされます。 |
| `onSelected(ids)` | 選択枠が終わったときに、選択とともに呼ばれます。 |
| `selection` | プロバイダーの選択の代わりに使う、独自の `Ref<Set<Key>>`。 |

`strategy`、`modifier`、`disabled` は値、ref、ゲッターを受け取り、押下で選択枠が始まるときに読み取られます。エリアが入れ子の場合は、最も内側のエリアが押下を受け取ります。すべてのオプションは [makeSelectionArea API](/docs/api/make-selection-area) にあります。

アイコンは通常のドラッグ可能な要素（`makeDraggable`）なので、オーバーレイは掴んだアイコンと件数を表示し、ほかのアイコンはその場にとどまります。ここではそれらも追従させています：モニターがドラッグの `delta` を渡し、ドロップでそれぞれをその分だけ動かします。

```ts [Desktop.vue]
useDnDMonitor({
  onDragMove: ({ delta }) => (offset.value = delta),    // DesktopIcon: `translate` by it while it is dragged
  onDragCancel: () => (offset.value = null),
  onDragEnd({ active, delta, over }) {
    offset.value = null;
    if (over?.id !== 'desktop') return;
    for (const icon of icons.value) {
      if (!active.ids.includes(icon.id)) continue;
      icon.x += delta.x; // the demo also keeps each icon on the desktop
      icon.y += delta.y;
    }
  },
});
```

### フォルダーへ {#into-a-folder}

このウィンドウでは、選択枠でファイルを選び、フォルダーがそれを受け取ります。フォルダーの上では、ファイルの山が半透明になり、その下でフォルダーが開きます。ドロップすると、ファイルが次々とフォルダーへ飛び込み、フォルダーがごくりと飲み込みます。フォルダーをクリックすると開き、パスの Home へファイルをドラッグして戻せます。

::example{name="multi-finder" hint="いくつかのファイルを選択枠で囲み、フォルダーの上へドラッグしてみましょう" height="33rem"}
::

```ts [FolderTile.vue]
makeDroppable(el, {
  id: () => props.folder.id,
  accept: 'file',
  // The box stays where it was let go: the files fly in on their own (FilePile).
  dropAnimation: false,
  onDrop: (event) => emit('move', event.active.ids),
});
```

ファイルのオーバーレイは、`DragPreview` でクローンを並べ、自分で動かします。ドロップが始まると、各クローンからフォルダー（ドロップの `over`）までの道のりを測り、クローンごとに CSS アニメーションを少しずつ遅らせて開始します。ドロップは最後のアニメーションを待ちます。

```vue [FilePile.vue]
<script setup lang="ts">
watch(
  () => props.status,
  (status) => {
    if (status !== 'dropping' || !props.over) return;
    const icon = props.over.element.querySelector('svg')!.getBoundingClientRect();
    flights.value = cards().map((card, index) => ({ '--to-x': …, '--to-y': …, '--delay': `${index * 70}ms` }));
  },
  { flush: 'post' }, // once the move has rendered: the folder may have moved
);
</script>

<template>
  <div v-for="({ entry }, index) in pile" :key="entry.id" class="card" :class="{ flying: flights }" :style="flights?.[index]">
    <DragPreview :id="entry.id" :style="{ width: '100%', height: '100%' }" />
  </div>
</template>

<style scoped>
.card.flying { animation: fly 0.42s var(--delay) forwards; }
@keyframes fly { to { translate: var(--to-x) var(--to-y); scale: 0.15; opacity: 0.3; } }
</style>
```

フォルダーはボタンです。選択枠はボタンや入力欄の上では決して始まらないので、クリックでフォルダーが開きます。

## ほかのアイテムの動き：`multiple` {#how-the-other-items-move-multiple}

マルチドラッグが始まったリストが、実行中にほかの選択中アイテムがどう動くかを決めます。このページの最初のデモで切り替えてみましょう。

```ts
makeSortableList(listRef, { items: files, multiple: 'gaps' });
```

| `multiple` | ドラッグ中 | オーバーレイ |
| --- | --- | --- |
| `'group'`（デフォルト） | ほかのアイテムは元の場所を離れ、掴んだアイテムと一緒に 1 つの枠のかたまりとして移動するので、リストにはすでにドロップの結果が表示されます。 | リストに沿って並んだ、最大 5 つのドラッグ中アイテムの列。 |
| `'gaps'` | ほかのアイテムはドロップまでその場にとどまり、`data-dnd-dragging` が付きます。 | 同じ列。 |
| `'stack'` | ほかのアイテムはオーバーレイへ飛び込みます。 | 掴んだアイテムと件数。 |

ドロップすると、アイテムは元の順序のまま、まとめてターゲットのインデックスに着地します。`'group'` と `'gaps'` では、オーバーレイの各アイテムがそれぞれの枠へ飛んでいきます。このオプションはドラッグ開始時に読み取られるので、ref やゲッターで切り替えられます。

`'gaps'` で残されたアイテムのスタイルを設定します。デフォルトでは薄く表示されます。

```css
.file[data-dnd-dragging] {
  opacity: 0.35;
}
```

このキューでは、選んだ曲が 1 つのかたまりとして動きます（`'group'`、デフォルト）。キューにはすでに曲が入る位置が表示され、オーバーレイにはすべての曲が表示されます。サイドバーのプレイリストの上では、かたまりがドロップで何が起きるかを示す 1 つのチップになり、着地するときにそのチップがプレイリストの行に変わります。

::example{name="multi-playlist" hint="曲をクリックし、別の曲を Shift クリックして、キューの下のほうかプレイリストへドラッグしてみましょう" height="34rem"}
::

```ts [PlaylistLink.vue]
makeDroppable(el, {
  id: () => props.playlist.id,
  data: () => props.playlist,
  overlay: AddToPlaylist, // leaves its slot, the column of rows, out
  dropAnimation: intoRow, // takes the row's place and size, and fades into it
  onDrop: (event) => emit('add', event.active.ids),
});
```

### デフォルトのオーバーレイ {#the-default-overlay}

`'group'` と `'gaps'` では、オーバーレイは着地する順に並んだドラッグ中アイテムの列です。掴んだアイテムがポインターの下にあり、ほかのアイテムはドロップ順にその前後に並びます（横方向のリストでは行）。表示するのは最大 5 つです。それを超えるアイテムは、その位置で数として示されます：表示されたものより前に着地するアイテムは列の先頭に `+N`、後に着地するアイテムは末尾に `+N` です。

グリッドでは、セル全体の列はページを覆ってしまうので、オーバーレイは山になります：最大 3 つのアイテムが掴んだアイテムの後ろに扇状に広がり、合計数が上に表示されます。デモを Grid に切り替えると見られます。

通常のドラッグ可能な要素（`makeDraggable`）は、上のデスクトップのように、掴んだアイテムと件数を表示します。

## 一部だけを受け入れる {#taking-only-some}

リストの `onBeforeDrop` は、マルチドラッグの一部を受け入れることができます。受け入れるキーを返すと、ほかのアイテムは元の場所に戻ります。ここでは Scheduled がカバー画像のある投稿を受け入れます。

::example{name="multi-transfer" hint="選んだ 3 つの下書きを Scheduled へドラッグしてみましょう" height="28.5rem"}
::

```ts [PostList.vue]
const { items } = makeSortableList(list, {
  id: props.id,
  items: posts,
  group: 'blog',
  onBeforeDrop: (event) => {
    if (!props.needsCover || event.sameList) return true;
    const ready = event.keys.filter((_, index) => event.items[index]!.cover !== null);
    notice.value = `${ready.length} scheduled`;
    return ready; // the keys it takes; an empty list takes none
  },
});
```

- `event.keys` はドラッグ中のキーで、`event.items[i]` は `event.keys[i]` のアイテムです。
- 答えの後、`onDrop` は `accepted` と `rejected` を受け取り、`event.result` には部分的なドロップの後のリストが入ります。
- `onBeforeDrop` は非同期にできます。オーバーレイはドロップした場所で待ちます。[ドロップの判断](/docs/guides/drop-decisions)を参照してください。

### 上限 {#a-limit}

このボードでは、In progress と Review にカードの上限があります。満杯の列は何も受け取りません。その `group.put` が拒否し、その上ではカードの山が赤くなります。選んだカードの一部が入る余地のある列は、入るだけ受け取り、残りは元の位置に戻ります。そのことは、ドロップの前にその列のオーバーレイが示します。

::example{name="multi-wip" hint="To do のカードを 3 枚チェックし、1 枚を Review の上へ、次に In progress の上へドラッグしてみましょう" height="31rem"}
::

```ts [WipColumn.vue]
const room = (keys: Key[]) => limit - column.cards.filter((card) => !keys.includes(card.id)).length;

makeSortableList(list, {
  items: cards,
  group: { name: 'board', put: ({ keys, from, to }) => from === to || room(keys) > 0 },
  multiple: 'stack',
  overlay: CardPile, // red where `accepted` is false
  overOverlay: fit,
  onBeforeDrop: (event) => {
    if (event.sameList) return true;
    const free = room(event.keys);
    return free >= event.keys.length || event.keys.slice(0, free);
  },
});
```

`fit` は関数で、Vue は関数を関数型コンポーネントとして扱います。`fit` は列だけが知っている情報、つまり列の空きを `FitBadge` に渡し、カードの山をバッジのスロットとしてそのまま渡します。

```ts
const fit: FunctionalComponent<OverlayProps> = (overlay, { slots }) =>
  h(FitBadge, { count: overlay.items.length, room: room(overlay.items.map((item) => item.id)), limit }, slots);
```

### 型が混在する場合 {#mixed-types}

リストは、ドロップの前に型によって一部のアイテムを拒否することもできます。`acceptMode: 'some'` では、`group.put` がアイテムごとに個別に問い合わされます。少なくとも 1 つが合致すればリストはドラッグを受け入れ、残りはドロップ時に元の位置に戻ります。`'all'`（デフォルト）では、すべてのアイテムが合致する必要があります。

```ts
makeSortableList(gallery, {
  items: photos,
  group: { name: 'files', put: ({ types }) => types.includes('image') },
  acceptMode: 'some',
});
```

通常のドロップターゲットも `acceptMode` を受け取ります。[アイテムを共有するリスト](/docs/guides/shared-lists#limits)と[ドラッグ＆ドロップ](/docs/guides/drag-and-drop#which-drags-a-target-takes)を参照してください。

## 複数アイテム用の独自のオーバーレイ {#a-custom-overlay-for-several-items}

オーバーレイコンポーネントとプロバイダーの `#overlay` スロットは `items` を受け取ります：ドラッグ中のすべてのアイテムで、掴んだものが先頭です。アイテムそのものの代わりに要約を表示しましょう。ここでは件数、最初の件名、ドロップで何が起きるかを示しています。

::example{name="multi-summary" hint="チェックしたメールを Archive か Trash へドラッグするか、1 通だけドラッグしてみましょう" height="26rem"}
::

```vue [MailOverlay.vue]
<script setup lang="ts">
import { computed } from 'vue';
import type { DragItem, Over } from '@vue-dnd-kit/core';

const props = defineProps<{ items: DragItem[]; over: Over | null }>();

const first = computed(() => props.items[0]?.item as Mail);
const count = computed(() => props.items.length);
const action = computed(() => {
  const noun = count.value === 1 ? 'conversation' : 'conversations';
  if (props.over?.id === 'Archive') return `Archive ${count.value} ${noun}`;
  if (props.over?.id === 'Trash') return `Delete ${count.value} ${noun}`;
  return `Move ${count.value} ${noun}`;
});
</script>

<template>
  <!-- The box keeps the row's size; the summary hangs off its middle, by the pointer. -->
  <div class="box">
    <div class="summary" :class="{ stack: count > 1 }">
      <span class="count">{{ count }}</span>
      <strong>{{ action }}</strong>
      <small>{{ first.subject }}{{ count > 1 ? ` and ${count - 1} more` : '' }}</small>
    </div>
  </div>
</template>

<style scoped>
.box { position: relative; width: 100%; height: 100%; }
.summary { position: absolute; top: calc(50% + 10px); left: calc(50% + 10px); width: 230px; }
</style>
```

```ts [Mailbox.vue]
// The box is centered on the pointer, so the summary hangs off the pointer and leaves
// the zone under it in sight.
const { items } = makeSortableList(list, { items: mails, overlay: MailOverlay, modifiers: [snapCenterToCursor] });

// A zone takes the mails out of the inbox.
makeDroppable(archive, {
  id: 'Archive',
  onDrop: (event) => {
    event.source?.remove();
    selection.clear();
  },
});
```

代わりに実際のアイテムを並べるには、`DragPreview` でそれらのクローンを描画します。[オーバーレイのガイド](/docs/guides/overlay#dragpreview-the-clone-in-your-layout)では本の山を扇状に広げています。クローンは持ち上げ時に、掴んだアイテムと、ドロップ順でその隣にある最大 4 つのアイテムについて作られます。それ以外のアイテムでは、`DragPreview` はデフォルトスロットを描画します。`'group'` と `'gaps'` では、ドロップ時に各プレビューがそれぞれのアイテムの枠に着地します。

ここでは、選んだ写真がオーバーレイへ飛び込み（`'stack'`）、クローンとして山に積み重なります。アルバムの上では、アルバムのオーバーレイが山（そのスロット）をそのまま残し、その下にドロップで何が起きるかを表示します。そして山はアルバムのカバーへ着地します。

::example{name="multi-albums" hint="写真をいくつかクリックしてから、1 枚をアルバムへドラッグしてみましょう" height="30rem"}
::

```vue [PhotoStack.vue]
<template>
  <div class="stack">
    <div v-for="{ entry, angle } in stack" :key="entry.id" class="card" :style="{ rotate: `${angle}deg` }">
      <DragPreview :id="entry.id" :style="{ width: '100%', height: '100%' }" />
    </div>
    <span v-if="items.length > 1" class="count">{{ items.length }}</span>
  </div>
</template>
```

```ts [AlbumCard.vue]
makeDroppable(el, {
  id: () => props.album.id,
  data: () => props.album,
  overlay: AddToAlbum, // <slot /> and "+ Add 3 photos to Favorites" under it
  dropAnimation: intoCover,
  onDrop: (event) => emit('add', event.active.ids),
});
```

## ツリー {#trees}

ツリーでは、選択されたノードはそれぞれのサブツリーとともに、ドキュメント順に 1 つのかたまりとして動きます。選択されたノードの中にある選択されたノードは、親のサブツリーに乗って一緒に動きます。[ツリー](/docs/guides/trees)を参照してください。
