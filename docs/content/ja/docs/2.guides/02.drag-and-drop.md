並べ替え可能なリストではないものには、`makeDraggable` と `makeDroppable` を使います。フォルダーに入れるファイル、ゴミ箱、チェス盤、カレンダー、ボード上のメモなどです。

::example{name="drop-zones" hint="画像は Images へ、ドキュメントは Documents へ" height="30rem"}
::

## ドラッグ可能な要素 {#a-draggable}

```vue [FileCard.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeDraggable } from '@vue-dnd-kit/core';

const props = defineProps<{ file: { id: string; name: string; kind: 'image' | 'doc' } }>();
const el = useTemplateRef<HTMLElement>('el');

const { isDragging } = makeDraggable(el, {
  id: () => props.file.id,      // read back as `active.id`
  data: () => props.file,       // anything: `active.data`
  type: () => props.file.kind,  // matched by the targets' `accept`
});
</script>

<template>
  <div ref="el" :class="{ dragging: isDragging }">{{ file.name }}</div>
</template>
```

id はデータから取り、ゲッターとして渡してください。デフォルトの id は `useId()` から取られ、コンポーネントのインスタンスごとに新しくなるため、アプリの他の部分にとっては意味を持ちません。

| 返り値 | 内容 |
| --- | --- |
| `isDragging` | この要素がドラッグされている。 |
| `selected` | 書き込み可能。プロバイダーの[選択](/docs/guides/multi-drag)にバインドされています。 |
| `transform` | ドラッグのオフセット。`overlay: false` 用です（後述）。 |
| `id` | 使用中の id。 |

ボタン、入力欄、その他のインタラクティブな子要素ではポインタードラッグが始まらないため、ドラッグ可能な要素の中でもそのまま動作します。一部分だけでドラッグさせるには `handle` を渡します（[並べ替え可能なリスト](/docs/guides/sortable-lists#handles)を参照）。すべてのオプションは [makeDraggable API](/docs/api/make-draggable) にあります。

## ドロップターゲット {#a-drop-target}

```vue [Folder.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeDroppable } from '@vue-dnd-kit/core';

const props = defineProps<{ id: string; accept: string }>();
const emit = defineEmits<{ drop: [fileId: string | number] }>();
const el = useTemplateRef<HTMLElement>('el');

const { isOver, isAccepting } = makeDroppable(el, {
  id: props.id,
  accept: props.accept,
  onDrop: (event) => emit('drop', event.active.id),
});
</script>

<template>
  <section ref="el" :class="{ accepting: isAccepting, over: isOver && isAccepting, refused: isOver && !isAccepting }">
    <slot />
  </section>
</template>
```

| 返り値 | `true` になるとき |
| --- | --- |
| `isOver` | ドラッグがこのターゲットの上にある。受け入れるかどうかは問いません。 |
| `isAccepting` | 何かがドラッグされていて、このターゲットがそれを受け入れる：有効なゾーンを強調表示するのに使います。 |
| `placement` | 真偽値ではありません：`{ top, right, bottom, left }`。ポインターがターゲットのどの半分にあるかを表し、ホバーされていないときは `null` です。「このカードの前 / 後」に使います。 |

`isAccepting` なしの `isOver` は、ドラッグが拒否するターゲットの上にあることを意味します。上のフォルダーのように、それを表示してください。そこでドロップするとキャンセルされ、アイテムは元の位置に戻ります。

## ターゲットが受け入れるドラッグ {#which-drags-a-target-takes}

ドラッグ可能な要素の `type` が、ターゲットの `accept` と照合されます。

| `accept` | 受け入れるもの |
| --- | --- |
| 省略または `'*'` | すべて。 |
| `'image'` | 型が `image` のドラッグ可能な要素と、型のないもの。 |
| `['image', 'doc']` | どちらかの型と、型のないもの。 |
| `({ active, items, types }) => boolean` | 関数の判断に従います。 |

`type` のないドラッグ可能な要素は、どの文字列ルールにも当てはまります。それ以外のことには関数を使ってください。

```ts
makeDroppable(el, {
  accept: ({ items }) => items.every((item) => (item.data as File).size < 10_000_000),
});
```

`type` は配列にもできます（`['image', 'large']`）。一致する型が 1 つあれば十分です。

複数のアイテムを同時にドラッグするとき、`acceptMode` はいくつが条件を満たす必要があるかを決めます：`'all'`（デフォルト）または `'some'`。`'some'` の場合は、残すアイテムの id を `onBeforeDrop` から返すと、それ以外は元の位置に戻ります。[ドロップの判断](/docs/guides/drop-decisions)を参照してください。

## ドロップ {#the-drop}

通常のドロップターゲットの `onDrop` は、**あなたが**データを変更する場所です。ライブラリは自分では何も動かしません。

```ts
makeDroppable(el, {
  id: 'archive',
  onDrop: ({ active }) => {
    for (const id of active.ids) archive(id);   // every dragged id, the grabbed one first
  },
});
```

| イベントのフィールド | 内容 |
| --- | --- |
| `active` | ドラッグ：`id`、`ids`、`items`（それぞれ `{ id, data, type, item }`）、`data`、`type`。 |
| `over` | このターゲット：`id`、`data`、`element`、`rect`。 |
| `pointer`、`delta` | ポインターの位置と、開始位置からの移動量。 |
| `position` | ドラッグ中のボックスがこのターゲットの中のどこにあるか（次のセクション）。 |
| `source` | アイテムが並べ替え可能なリストから来た場合に設定されます：`{ list, remove() }`。 |

順序は `onBeforeDrop`（判断）、`onDrop`（適用）、そしてプロバイダーの `drag-end` です。ドロップの前に確認する、ドラッグを続ける、一部のアイテムだけを受け入れる、といったことについては[ドロップの判断](/docs/guides/drop-decisions)を参照してください。

## ドロップした場所に置く {#leave-it-where-it-was-dropped}

ボード、キャンバス、間取り図：アイテムは手を離した場所に留まります。すべてのイベントは `position` を持っています。これは、絶対配置したアイテムをドロップされた場所に置くための `left` / `top` です。

::example{name="constraints" hint="メモをドラッグし、軸を固定したりグリッドをオフにしたりしてみましょう" height="26rem"}
::

```ts [Board.vue]
const board = useTemplateRef<HTMLElement>('board');
makeDroppable(board, { id: 'board' });

useDnDMonitor({
  onDragEnd({ active, over, position }) {
    const note = notes.value.find((item) => item.id === active.id);
    if (!note || over?.id !== 'board' || !position) return;
    note.x = Math.round(position.x);
    note.y = Math.round(position.y);
  },
});
```

```vue [Note.vue]
<div ref="el" class="note" :style="{ left: `${note.x}px`, top: `${note.y}px` }">…</div>
```

`position` は、`over` の中でのドラッグ中のボックスの左上の角です。パディングの端から測り、スクロール量を加えた値です。何もない上では `null` です。`overlay: false` の場合は、要素自身の角になります。

::tip
`active.rect` と `delta` から位置を計算しないでください。ターゲットのボーダーとスクロールが抜け落ちます。こうしたボードのためのスナップ、境界、軸の固定は[制約](/docs/guides/constraints)にあります。
::

## 並べ替え可能なアイテムにドロップする {#drop-into-a-sortable-item}

並べ替え可能なリストの行もドロップターゲットにできます。ファイルを受け入れるフォルダーや、タスクを受け入れるグループなどです。アイテムの要素にドロップゾーンを設定します。

```ts [FolderRow.vue]
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { item: () => props.folder });

const { isOver } = makeDroppable(el, {
  accept: 'file',
  onDrop: (e) => {
    props.folder.children.push(...e.active.items.map((entry) => entry.item as FileEntry));
    e.source?.remove();   // take them out of the list they came from
  },
});
```

リストがそのドラッグを並べ替えようとしている間、このようなターゲットが有効になるのはアイテムの**中央部分**（リストの軸方向で 25〜75%）だけです。そこではドロップはアイテムの中に入り、リストは動きません。端の近くでは、リストは通常どおり並べ替えます。

- `accept` がドラッグを拒否するターゲットはスキップされます。リストはそのアイテムの上でも、ほかのアイテムと同じように並べ替えます。ファイルだけを受け入れるフォルダーの横を、フォルダーは並べ替えで通り過ぎられます。
- ターゲットが自分自身のドラッグを受け取ることはありません。
- ドロップ後にアイテムが表示されなくなる場合、オーバーレイは元の位置に戻る代わりに、ターゲットの中へ縮んで消えます。

## ゴミ箱ゾーン {#trash-zones}

並べ替え可能なリストで始まったドラッグは `e.source` を持っています。`remove()` を呼ぶと、リストはそのアイテムを取り除きます。

```ts
makeDroppable(trash, {
  id: 'trash',
  onDrop: (e) => e.source?.remove(),
});
```

その後、リスト自身の `onDrop` が `to.index === -1` で実行され、`e.result` にはアイテムを除いたリストが入ります。リストは、すべてのターゲットの外にドロップされたものを取り除くこともできます：[`dropOutside`](/docs/guides/shared-lists#dropping-outside) を参照してください。

## オーバーレイなしで {#without-an-overlay}

デフォルトでは、要素のクローンがポインターに追従し、要素自体はその場に残ります。`overlay: false` ではクローンはありません。`transform` を使って要素を自分で動かします。

```vue
<script setup lang="ts">
const { transform } = makeDraggable(el, { id: 'piece', overlay: false });
</script>

<template>
  <div ref="el" :style="transform && { transform: `translate3d(${transform.x}px, ${transform.y}px, 0)` }">♞</div>
</template>
```

クローンの代わりにカスタムのドラッグプレビューを使うには、[オーバーレイ](/docs/guides/overlay)を参照してください。

## キーボード {#keyboard}

フォーカスされたドラッグ可能な要素は、:kbd{value="Space"} または :kbd{value="Enter"} で持ち上げられます。矢印キーで 25 px ずつ動きます（プロバイダーの `keyboard.step`）。ドラッグ可能な要素に `keyboard: 'droppables'` を設定すると、代わりにそれを受け入れるターゲットの間をジャンプします。ゾーンどうしが離れている場合に向いています。詳しくは[アクセシビリティ](/docs/guides/accessibility)を参照してください。
