ライブラリがスタイルを付けるものはほとんどありません。ドラッグの各状態は 2 つの方法で受け取れます：クラスや条件付きのマークアップには、コンポーザブルが返す ref として。素の CSS には、`data-dnd-*` 属性として。

```vue [TaskRow.vue]
<script setup lang="ts">
const props = defineProps<{ task: Task }>();
const el = useTemplateRef<HTMLElement>('el');
const { isPlaceholder, selected } = makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el" class="row" :class="{ hole: isPlaceholder, selected }">{{ task.title }}</li>
</template>
```

## 返される ref {#the-returned-refs}

| コンポーザブル | 状態 |
| --- | --- |
| `makeSortableItem` | `isDragging`, `isPlaceholder`, `selected`, `indicator`, `index` |
| `makeSortableList`, `makeSortableTree` | `isOver`, `isAccepting`, `indicator`, `activeKey` |
| `makeDraggable` | `isDragging`, `selected`, `transform` |
| `makeDroppable` | `isOver`, `isAccepting`, `placement` |
| `makeDragArea` | `isDragging`, `isAutoScrolling` |
| `useDnD()` | `status`, `active`, `over`, `pointer`, `activation.progress` |

- `isPlaceholder`：この要素は、ドラッグ中のアイテムが着地する位置です。
- `isDragging`：このアイテムはドラッグの一部です（マルチドラッグでは、ドラッグ中のすべてのアイテム）。
- `isAccepting`：何かがドラッグされていて、このターゲットがそれを受け入れます。ドロップできる場所を強調表示しましょう。
- `isOver`：ドラッグがこのターゲットの上にあります。受け入れるかどうかは問いません。`isOver && !isAccepting` は拒否を意味し、表示する価値があります。
- `useDnD()` の `over.accepted`（オーバーレイの props では `accepted`）は、ドラッグを拒否するターゲットの上では `false` です。これでオーバーレイを赤く色付けできます。

```vue
<ul ref="list" :class="{ 'can-drop': isAccepting, over: isOver && isAccepting, refused: isOver && !isAccepting }">…</ul>
```

## data 属性 {#the-data-attributes}

| 属性 | 付く場所 | タイミング |
| --- | --- | --- |
| `data-dnd-placeholder` | 並べ替え可能なアイテム | ドラッグ中のアイテムが着地する位置であるとき。 |
| `data-dnd-dragging` | 並べ替え可能なアイテム | ドラッグされているがその場に留まっているとき：`'gaps'` モードのマルチドラッグにおけるほかのアイテム。 |
| `data-dnd-dragging="pointer"` または `"keyboard"` | `<html>` | ドラッグの間ずっと。 |
| `data-dnd-overlay="dragging"` または `"dropping"` | オーバーレイのボックス | 常に。着地中と、非同期の `onBeforeDrop` を待っている間は `dropping`。 |
| `data-dnd-leaving` | `animate` が残すコピー | 出ていったアイテムがフェードアウトしている間。 |
| `data-dnd-no-clone` | **あなたが付ける** | 要素をオーバーレイのクローンから除外します：ツールチップ、メニューボタン、バッジ。 |

```css
html[data-dnd-dragging] .drop-hint { display: block; }
html[data-dnd-dragging='keyboard'] .shortcuts { display: block; }
```

## デフォルトのスタイル {#default-styles}

プロバイダーは、ドキュメントごとに一度だけ、いくつかのルールを挿入します。これらは `:where()` で囲まれているため詳細度はゼロで、あなたが書くどのルールも優先されます。

```css
:where([data-dnd-placeholder]) { opacity: 0.4; }
:where([data-dnd-dragging]:not(html)) { opacity: 0.4; }
:where(html[data-dnd-dragging], html[data-dnd-dragging] *) { user-select: none !important; overflow-anchor: none !important; }
:where(html[data-dnd-dragging='pointer'], html[data-dnd-dragging='pointer'] *) { cursor: grabbing !important; }
```

ドラッグ中は着地位置が薄くなり、ページはテキストを選択せず、スクロールのアンカリングも行いません。ポインタードラッグ中はカーソルが掴んだ手の形になります。`:default-styles="false"` でこれらをオフにできます。ドラッグ可能なアイテムへの `cursor: grab` は、あなたが追加してください。

## レシピ {#recipes}

### 空の枠 {#an-empty-slot}

アイテムの薄いコピーの代わりに、着地する場所に空の破線のボックスを表示します。

```css
.card {
  position: relative;
}

.card[data-dnd-placeholder] {
  opacity: 1;
}

.card[data-dnd-placeholder]::after {
  content: '';
  position: absolute;
  inset: 0;
  border: 1.5px dashed color-mix(in srgb, currentColor 30%, transparent);
  border-radius: inherit;
  background: Canvas;
}
```

擬似要素がコンテンツを覆うため、着地位置はアイテムとまったく同じサイズを保ちます。ここでカードをドラッグして確認してください。

::example{name="kanban" hint="ドラッグ中のカードの着地位置は破線のボックスです" height="24rem"}
::

### リストが背景を塗る行 {#a-row-the-list-paints}

デフォルトのオーバーレイは、ドラッグ中の要素のクローンです。要素をそのままの姿で表示し、背景を推測しません。自分の背景を持たない行（白い `<ul>` の中の `<li>`、テーブルの行、UI キットのリストアイテム）は、透けたクローンになります。リストの背景を与えてください。

```css
[data-dnd-overlay] .row {
  background: var(--surface);
}
```

クローンは要素のクラスと属性（scoped スタイルの属性も含む）を保持するため、このルールは行自身の `<style scoped>` の中に、ほかのスタイルと並べて書けます。あるいは、行に自分の背景を与えてください。浮かんで見えることを意図したアイコンやタイルは透明のままです。

### ドラッグ中だけ持ち上がるオーバーレイ {#a-lifted-overlay-only-while-dragging}

```css
[data-dnd-overlay='dragging'] .card {
  box-shadow: 0 14px 28px -10px rgb(0 0 0 / 0.45);
}
```

影はカードが運ばれている間だけ付き、オーバーレイが `dropping` に切り替わると消えるため、カードは平らな状態で着地位置に着地します。カスタムのオーバーレイコンポーネントでは、同じルールがコンポーネントのルートを対象にします。または props から `status` を読み取ってください。

### モーションの軽減 {#reduced-motion}

ライブラリは `prefers-reduced-motion: reduce` のとき、すでに自身のアニメーションを止めています。ドラッグの周りに追加するトランジションでも同じようにしてください。

```css
@media (prefers-reduced-motion: reduce) {
  .column {
    transition: none;
  }
}
```

### やってはいけないこと {#dont}

- 並べ替え可能なアイテムの `transform` や `translate` に CSS の `transition` を付けないでください。ライブラリがそれらを自分でアニメーションさせ、計測中はそうしたトランジションをキャンセルします。
- [仮想リスト](/docs/guides/virtual-lists)の行の `height`、`margin`、`padding` をアニメーションさせないでください。

オーバーレイ（カスタムコンポーネント、サイズ、`DragPreview`）について詳しくは[オーバーレイ](/docs/guides/overlay)を参照してください。
