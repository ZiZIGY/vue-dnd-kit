タイルをドラッグしてから、いくつかシャッフル、追加、削除してみてください。並べ替えとドロップはデフォルトでアニメーションします。ボタンによる変更がアニメーションするのは、グリッドが `animate` をオンにしているからです。

::example{name="animate" hint="ドラッグ、シャッフル、追加、削除" height="22rem"}
::

## 3 つのアニメーション {#three-animations}

| オプション | 設定場所 | デフォルト | アニメーションの対象 |
| --- | --- | --- | --- |
| `animation` | プロバイダー、リスト、ツリー | オン、200 ms | 並べ替え中、ドロップ時、キャンセル時に、アイテムが新しい位置へスライドする動き。 |
| `dropAnimation` | プロバイダー | オン、250 ms | オーバーレイが自分の位置に着地する動き、またはキャンセル時に元の位置へ戻る動き。 |
| `animate` | プロバイダー、リスト、ツリー | **オフ** | ドラッグ以外によるデータの変更：アイテムの追加・削除・移動・フィルタリング、ツリーの行の表示・非表示。 |

それぞれ `true`（デフォルトのタイミング）、`false`（オフ）、`{ duration, easing }`、またはアニメーションを自分で行う関数を受け付けます。

```vue
<DnDProvider
  :animation="{ duration: 180, easing: 'cubic-bezier(.2, .8, .2, 1)' }"
  :drop-animation="{ duration: 300 }"
>
```

リストやツリー自身の `animation` と `animate` は、プロバイダーのものより優先されます。

## 並べ替え {#sorting}

ドラッグ中はドラフトが並べ替わり、アイテムは新しい位置へスライドします。これは Web Animations API を通じて CSS の `translate` プロパティで行う FLIP です。`translate` はあなたが指定した `transform` と合成されるため、仮想リストの行の配置は崩れません。アニメーションが終わる前にアイテムが再び動いた場合、次のアニメーションは表示されている位置から始まります。

::warning
並べ替え可能なアイテムを `<TransitionGroup>` で囲まないでください。すべての移動が二重にアニメーションしてしまいます。ドラッグ以外による変更には `animate` をオンにしてください。
::

## ドロップ {#the-drop}

ドロップ時、オーバーレイは離した場所からアイテムの位置へ飛んでいきます。キャンセル時は、アイテムが始まった場所へ戻ります。ドロップ後にアイテムの見える位置がない場合（スクロールで見えなくなった、フォルダーやゴミ箱ゾーンにドロップされた）、オーバーレイは代わりにフェードアウトし、ドロップされたゾーンの中へ縮んでいきます。

また、オーバーレイはドラッグ中に着地する位置のサイズになるため（`overlayFit: 'slot'`、デフォルト）、ドロップ時にサイズ変更は不要です。`'source'` はドラッグ中の要素のサイズを保ちます。[オーバーレイ](/docs/guides/overlay)を参照してください。

## データの変更：animate {#data-changes-animate}

```ts
makeSortableList(listRef, { items: swatches, animate: true });
```

デフォルトではオフの `animate` は、ドラッグ以外で配列が変わったときにアニメーションします：ソート、シャッフル、同じグループのリスト間の移動、アイテムの追加・削除・フィルタリング。ツリーでは、ノードの展開・折りたたみで表示・非表示になる行も対象です。`<DnDProvider animate>` はすべてのリストとツリーでこれをオンにします。

各パーツは個別に調整できます。

```ts
animate: { duration: 250, move: true, enter: true, leave: { duration: 150 } },
```

| パーツ | デフォルトの動作 |
| --- | --- |
| `move` | 位置が変わったアイテムが、`animation` と同じようにスライドします。 |
| `enter` | 現れたアイテムが、その場でフェードインします。 |
| `leave` | 出ていったアイテムのコピーが、元の場所で少し縮みながらフェードアウトします。コピーには `data-dnd-leaving` が付き、終わると取り除かれます。 |

`duration` と `easing` はすべてのパーツに適用されます。各パーツは `true`、オプション、`false`、または関数を受け付けます。アニメーションするのは表示領域の近くにあるアイテムだけなので、仮想リストがマウントしていない行はスキップされます。このオプションは `items` が変わったときに読み取られるため、例のトグルのように ref で切り替えられます。

## 独自のアニメーション {#your-own-animations}

どのオプションも関数を受け付けます。関数はコンテキストを受け取ってアニメーションを開始し、その `Animation`、終了時に確定する Promise、または何も返しません。

```ts
// animation, animate.move: an item moved from `from` to `to`
({ key, element, from, to, options, reason, signal, reducedMotion }) => Animation | Promise | void
// dropAnimation: `to` is null when there is no visible slot; `into` is the zone it went into
({ overlay, from, to, into, reason, active, options, reducedMotion }) => …
// animate.enter: the element is already in place
({ key, element, to, options, reducedMotion }) => …
// animate.leave: `element` is a copy where the item was, removed when you finish
({ key, element, from, options, reducedMotion }) => …
```

ライブラリを使わず、Web Animations API で書いたレイアウト関数：

```ts
import type { LayoutAnimationContext } from '@vue-dnd-kit/core';

const springy = ({ element, from, to, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  return element.animate(
    [{ translate: `${from.left - to.left}px ${from.top - to.top}px` }, { translate: '0 0' }],
    { duration: 400, easing: 'cubic-bezier(.34, 1.56, .64, 1)' },
  );
};
```

```vue
<DnDProvider :animation="springy">
```

カスタムアニメーションをライブラリと噛み合わせるための 3 つのルール：

- **`translate` をアニメーションさせる**。`transform` ではなく、`from - to` から 0 へ。仮想リストやあなたの CSS が行に付けた transform と合成でき、ドラッグはこれを除いてアイテムを計測します。
- **`signal` に従う**。アニメーションが終わる前にアイテムが再び動くと中断されます。すぐにアニメーションを止め、そのスタイルをクリアしてください：直後にレイアウトが計測されます。返された `Animation` は自動でキャンセルされます。
- **オーバーレイでは位置とサイズをアニメーションさせる**（`width`、`height`）。`scale` は決して使わないでください：コンテンツは新しいサイズでレイアウトし直されます。

### GSAP {#gsap}

```ts [gsap-animations.ts]
import gsap from 'gsap';
import type {
  DropAnimationContext,
  EnterAnimationContext,
  LayoutAnimationContext,
  LeaveAnimationContext,
  Rect,
} from '@vue-dnd-kit/core';

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const tween = gsap.fromTo(
    element,
    { translate: `${from.left - to.left}px ${from.top - to.top}px` },
    { translate: '0px 0px', duration: 0.4, ease: 'power3.out' },
  );
  signal.addEventListener('abort', () => tween.revert());
  return tween.then();
};

const box = (rect: Rect) => ({ x: rect.left, y: rect.top, width: rect.width, height: rect.height });

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return gsap.to(overlay, { opacity: 0, duration: 0.2 }).then();
  return gsap.fromTo(overlay, box(from), { ...box(to), duration: 0.45, ease: 'back.out(1.2)' }).then();
};

const enter = ({ element, reducedMotion }: EnterAnimationContext) =>
  gsap.from(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.35 }).then();

const leave = ({ element, reducedMotion }: LeaveAnimationContext) =>
  gsap.to(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.25 }).then();

export const gsapAnimations = { animation: move, dropAnimation: drop, animate: { move, enter, leave } };
```

```vue
<DnDProvider v-bind="gsapAnimations">
```

### motion {#motion}

```ts [motion-animations.ts]
import { animate } from 'motion-v';
import type { DropAnimationContext, LayoutAnimationContext } from '@vue-dnd-kit/core';

const spring = { type: 'spring', duration: 0.45, bounce: 0.25 } as const;

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const controls = animate(
    element,
    { translate: [`${from.left - to.left}px ${from.top - to.top}px`, '0px 0px'] },
    spring,
  );
  signal.addEventListener('abort', () => {
    controls.stop();
    element.style.translate = '';
  });
  return controls.finished;
};

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return animate(overlay, { opacity: 0 }, { duration: 0.18 }).finished;
  return animate(
    overlay,
    { x: [from.left, to.left], y: [from.top, to.top], width: [from.width, to.width], height: [from.height, to.height] },
    spring,
  ).finished;
};
```

オプションの完全な型は[アニメーション](/docs/api/animations)にあります。

## モーションの軽減 {#reduced-motion}

`prefers-reduced-motion: reduce` のときは、ライブラリ自身のアニメーションは実行されず、アイテムとオーバーレイはそのまま自分の位置へ移動します。あなたの関数は常に `reducedMotion: true` 付きで実行されるため、どうするかは関数が決めます：動きを省くか、上のレシピのように短いフェードを残すかです。

## ライブラリによらないレイアウトの変化 {#layout-changes-the-library-didnt-cause}

ドラッグ中にほかの何かが行を動かす場合（仮想化ライブラリの再計測、画像の読み込みなど）は、その変化が描画される直前にリストの `captureLayout()` を呼んでください。行を現在の位置で計測し、次の描画の後に新しい位置へアニメーションさせます。ドラッグ中でなければ何もしません。[仮想リスト](/docs/guides/virtual-lists)を参照してください。
