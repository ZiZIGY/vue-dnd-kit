自動でアニメーションするものは 3 つあります：並べ替え中にスライドするアイテム、ドロップ時に着地するオーバーレイ、そしてオンにした場合の、ドラッグ以外によるデータの変化です。どれも同じ値を、プロバイダー、またはアニメーションする対象により近い場所で受け取ります。

| オプション | 指定先 | デフォルト | アニメーションするもの |
| --- | --- | --- | --- |
| `animation` | プロバイダー、リスト、ツリー | オン、200 ms | 並べ替え中、ドロップ時、キャンセル時に新しい位置へスライドするアイテム。 |
| `dropAnimation` | プロバイダー、ドラッグ可能な要素、並べ替え可能なアイテム、リスト、ツリー、ドロップターゲット | オン、250 ms | 枠へ着地する、またはキャンセル時に元の位置へ戻るオーバーレイ。 |
| `animate` | プロバイダー、リスト、ツリー | **オフ** | ドラッグ以外によるデータの変化：追加・削除・移動・フィルターされたアイテム、表示・非表示になるツリーの行。 |

それぞれ `true`（デフォルトのタイミング）、`false`（オフ）、`{ duration, easing }`、または自分でアニメーションする関数を受け取ります。

```vue
<DnDProvider
  :animation="{ duration: 180, easing: 'cubic-bezier(.2, .8, .2, 1)' }"
  :drop-animation="{ duration: 300 }"
  animate
>
```

リストやツリー自身の `animation` と `animate` は、プロバイダーのものより優先されます。`dropAnimation` については[アイテムごと、ターゲットごと](#per-item-and-per-target)を参照してください。それ以外の動きはあなた次第です。オーバーレイ、枠、リストは [data 属性と ref](/docs/guides/styling) を持つ要素なので、CSS やアニメーションライブラリで動かせます。

## 並べ替え {#sorting}

ドラッグ中、リストのドラフトが並べ替わり、アイテムが新しい位置へスライドします。リストの `animation` を切り替えて、行を上下にドラッグしてみましょう。

::example{name="anim-sort" hint="タイミングを選んで、行を上下にドラッグしてみましょう" height="28rem"}
::

```ts [Ranking.vue]
const springy: LayoutAnimation = ({ element, from, to, reducedMotion }) => {
  if (reducedMotion) return;
  return element.animate(
    [{ translate: `${from.left - to.left}px ${from.top - to.top}px` }, { translate: '0 0' }],
    { duration: 500, easing: 'cubic-bezier(.34, 1.56, .64, 1)' },
  );
};

const { items } = makeSortableList(list, {
  items: ideas,
  animation: computed(() => choice.value.animation), // true, { duration: 600 }, springy or false
});
```

これは CSS の `translate` プロパティに対する FLIP で、Web Animations API を通じて行われます。`translate` はあなたのどんな `transform` とも合成されるので、仮想リストの行の配置は崩れません。アニメーションが終わる前にアイテムが再び動くと、次のアニメーションは表示されている位置から始まります。ドロップ時とキャンセル時も、同じアニメーションでアイテムが動きます。

リストの `animation` は値または ref を受け取り、移動のたびに読み取られます。上のように computed で切り替えられます。ここに渡す関数はゲッターではなく、アニメーションです。

::warning
並べ替え可能なアイテムを `<TransitionGroup>` で囲まないでください。すべての移動が二重にアニメーションします。ドラッグ以外による変化には [`animate`](#data-changes-animate) をオンにしてください。
::

## ドロップ {#the-drop}

ドロップ時、オーバーレイは離した場所からアイテムの枠へ、キャンセル時はアイテムが始まった場所へ飛んでいきます。`dropAnimation` を選び、カードをテーブルの外へドラッグして離してみましょう。ドロップはキャンセルされ、カードは元の位置に戻ります。

::example{name="anim-drop" hint="オプションを選び、カードをテーブルの外へドラッグして離してみましょう" height="22rem"}
::

```ts [index.vue]
/** The overlay arcs to its slot, as if tossed. */
const toss: DropAnimation = ({ overlay, from, to, reducedMotion }) => {
  if (reducedMotion) return;
  // No visible slot to land on: fade out where it is.
  if (!to) return overlay.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 200, fill: 'forwards' });
  const place = (x: number, y: number) => `translate3d(${x}px, ${y}px, 0)`;
  const rise = Math.min(120, Math.hypot(to.left - from.left, to.top - from.top) / 2);
  return overlay.animate(
    [
      { transform: place(from.left, from.top), width: `${from.width}px`, height: `${from.height}px` },
      { transform: place((from.left + to.left) / 2, Math.min(from.top, to.top) - rise), offset: 0.45 },
      { transform: place(to.left, to.top), width: `${to.width}px`, height: `${to.height}px` },
    ],
    { duration: 550, easing: 'ease-in-out', fill: 'forwards' },
  );
};
```

```vue
<DnDProvider :drop-animation="toss">
```

- ボックスは位置（`transform`）とサイズ（`width`、`height`）で着地します。中身は枠のサイズで再レイアウトされ、拡大縮小されることはありません。
- ドロップ後にアイテムの見える枠がない場合（スクロールで見えなくなった、フォルダーやゴミ箱ゾーンにドロップされた）、`to` は `null` です。そのときデフォルトではオーバーレイをフェードアウトさせ、ドロップされたゾーン（`into`）の中へ縮めるか、その場で消します。
- マルチドラッグでは、ほかのアイテムのクローンはそれぞれの枠に自動で着地します。`dropAnimation` が関数のときは、デフォルトのタイミングを使います。
- `dropAnimation` はドロップのたびに読み取られるので、デモのように ref にバインドしたプロバイダーの prop で切り替えられます。
- 着地中にスクロールしても、行き先がずれることはありません。ボックスは `position: fixed` なので、着地先（枠、ゾーン、なければドロップされたターゲット）に CSS の `translate` で追従し、それがアニメーションの動かす `transform` に重なります。独自のアニメーションでは、上の例のように `translate` ではなく `transform` をアニメーションしてください。

オーバーレイはドラッグ中にも着地する枠のサイズを取るので（`overlayFit: 'slot'`、デフォルト）、ドロップでサイズ変更が必要になることはまれです。[オーバーレイ](/docs/guides/overlay#size-overlayfit)を参照してください。

### アイテムごと、ターゲットごと {#per-item-and-per-target}

プロバイダーの `dropAnimation` がデフォルトです。ドラッグ可能な要素、並べ替え可能なアイテム、リスト（そのアイテム用）は独自のものを持てます。そしてドロップターゲットは、自分に着地するものについて最終的な決定権を持てます：`makeDroppable(el, { dropAnimation })`、リストやツリーの `overDropAnimation`。各ドロップについて、最初に設定されているものが使われます。

1. ターゲットのもの（キャンセル時はなし）。
2. ドラッグされたアイテム自身のもの、次にそのリストのもの。
3. プロバイダーのもの。

カートは、自分にドロップされたものをアイコンの中へ放り込み、商品が中に着地すると弾みます。カートの上では、商品のチップがサムネイルに変わります（[ターゲットのオーバーレイ](/docs/guides/overlay#targets-that-change-the-overlay)）。トランジションはショップ独自のものです。

::example{name="anim-cart" hint="商品をカートにドラッグしてみましょう" height="30rem"}
::

```ts [Cart.vue]
const intoCart: DropAnimation = ({ overlay, from, reducedMotion }) => {
  const end = icon.value?.getBoundingClientRect();
  if (!end || reducedMotion) {
    landed.value++;
    return overlay.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 150, fill: 'forwards' });
  }
  // `arc`: keyframes on a curve from where it was let go into the icon, shrinking.
  const animation = overlay.animate(arc(from, end), { duration: 520, fill: 'forwards' });
  animation.finished.then(() => landed.value++, () => {}); // the cart bounces
  return animation;
};

makeDroppable(el, {
  id: 'cart',
  overlay: CartThumb,
  dropAnimation: intoCart,
  onDrop: (event) => emit('add', event.active.data as Product),
});
```

```ts [index.vue]
// <DnDProvider :overlay-transition="morph">: the new content pops in, the old one shrinks away.
const morph: TransitionProps = {
  css: false,
  onEnter: (element, done) => pop(element, [{ opacity: 0, scale: 0.5 }, { opacity: 1, scale: 1 }], done),
  onLeave: (element, done) => {
    Object.assign((element as HTMLElement).style, { position: 'absolute', inset: '0' });
    pop(element, [{ opacity: 1 }, { opacity: 0, scale: 0.5 }], done);
  },
};
```

`false` も設定済みとみなされます：`dropAnimation: false` のターゲットは、オーバーレイをドロップされた場所に留めます。関数はターゲットを `over` として受け取るので、1 つの関数でターゲットごとに扱いを変えられます。

### コンテンツ自身の着地 {#the-contents-own-landing}

ドロップは、開始時にオーバーレイの中で実行中のアニメーションも待ちます：オーバーレイコンポーネントが `status: 'dropping'` で開始する CSS アニメーションとトランジションです。ゴミ箱の上では写真がくしゃくしゃに丸まり、ドロップされるとゴミ箱に投げ込まれ、入った時点でドロップが終わります。

::example{name="anim-trash" hint="写真をゴミ箱にドラッグしてみましょう。Undo で元に戻せます" height="27rem"}
::

```ts [TrashBin.vue]
makeDroppable(el, {
  id: 'trash',
  overlay: Crumple,
  // The box stays where it was let go: its content does the landing.
  dropAnimation: false,
  onDrop: (event) => emit('drop', event), // the gallery calls `event.source?.remove()`
});
```

```vue [Crumple.vue]
<template>
  <div class="crumple">
    <!-- `fall` is set at the drop: `--dx` and `--dy`, from the photo to `over`, the bin. -->
    <div class="paper" :class="{ falling: fall }" :style="fall">
      <slot />
    </div>
  </div>
</template>

<style scoped>
.paper { clip-path: polygon(…); rotate: -8deg; scale: 0.7; }
.paper.falling { animation: fall 0.55s forwards; }
@keyframes fall {
  to { translate: var(--dx) var(--dy); rotate: -120deg; scale: 0.12; opacity: 0; }
}
</style>
```

終了済みのアニメーションと無限ループは数に入らず、ドロップが待つのは最大 2 秒です。

## データの変化：`animate` {#data-changes-animate}

タイルをドラッグしてから、シャッフルしたり、追加・削除したりしてみましょう。ドラッグはデフォルトでアニメーションします。ボタンによる変化がアニメーションするのは、グリッドが `animate` をオンにしているからです。

::example{name="animate" hint="ドラッグ、シャッフル、追加、削除を試してみましょう" height="22.75rem"}
::

```ts
makeSortableList(listRef, { items: swatches, animate: true });
```

デフォルトでオフの `animate` は、ドラッグなしで配列を変えるものをアニメーションします：ソート、シャッフル、同じグループのリスト間での移動、アイテムの追加・削除・フィルター。ツリーでは、ノードの展開・折りたたみで表示・非表示になる行も対象です。`<DnDProvider animate>` で、すべてのリストとツリーでオンになります。

その各部分は個別に調整できます。

```ts
animate: { duration: 250, move: true, enter: true, leave: { duration: 150 } },
```

| 部分 | デフォルトの動き |
| --- | --- |
| `move` | 位置が変わったアイテムが、`animation` と同じようにスライドします。 |
| `enter` | 現れたアイテムがその場でフェードインします。 |
| `leave` | 去ったアイテムのコピーが元の場所で少し縮みながらフェードアウトします。`data-dnd-leaving` が付き、終わると取り除かれます。 |

`duration` と `easing` はすべての部分に適用され、各部分は `true`、オプション、`false`、関数を受け取ります。アニメーションするのは表示領域の近くにあるアイテムだけなので、仮想リストがマウントしていない行はスキップされます。このオプションは `items` が変わったときに読み取られるので、デモのトグルのように ref で切り替えられます。

## オーバーレイ：持ち上げ、傾け、落ち着かせる {#the-overlay-lift-tilt-settle}

オーバーレイの要素は何をしているかを示します：ポインターに追従している間は `data-dnd-overlay="dragging"`、着地中は `"dropping"` です。これらの状態に合わせて中身をアニメーションしましょう。カードを持ち上げると浮いて傾き、離すと着地しながら平らに戻ります。

::example{name="anim-overlay" hint="カードを持ち上げて動かし、離してみましょう" height="27.25rem"}
::

```vue [LiftCard.vue]
<style scoped>
@media (prefers-reduced-motion: no-preference) {
  /* Picked up: it lifts and tilts. */
  [data-dnd-overlay='dragging'] .card {
    animation: lift 0.22s cubic-bezier(0.2, 0.8, 0.2, 1) forwards;
  }

  /* Let go: it lies flat again while it lands. */
  [data-dnd-overlay='dropping'] .card {
    animation: settle 0.25s ease-in forwards;
  }
}

@keyframes lift {
  to { rotate: 3deg; scale: 1.04; box-shadow: 0 22px 36px -14px rgb(0 0 0 / 0.6); }
}

@keyframes settle {
  from { rotate: 3deg; scale: 1.04; box-shadow: 0 22px 36px -14px rgb(0 0 0 / 0.6); }
}
</style>
```

- クローンでは、キーフレームとトランジションのどちらも動作します。ルートにはインラインで `transform: none` が付いているので、アニメーションするのは `rotate` と `scale` プロパティです。キーフレームは状態が始まるときに一度再生されるので、持ち上げと着地に向いています。トランジションは状態の変化に双方向で追従します。
- **オーバーレイコンポーネント**ではトランジションが使えます。コンポーネントは `status` を prop として受け取ります。[プロバイダーのスロットのデモ](/docs/guides/overlay#the-providers-overlay-slot)のメモは、`status` が `'dropping'` になると `transition: rotate 0.25s` でまっすぐに戻ります。
- ボックス自体（`[data-dnd-overlay]`）には触れないでください。ライブラリがそれを動かし、サイズを設定します。

## 枠とリスト {#the-slot-and-the-lists}

ドラッグされた要素は、着地する**枠**としてリストに残り、`data-dnd-placeholder` が付きます。リストもドラッグについて知っています：受け入れるドラッグが実行中なら `isAccepting`、ドラッグが上にあれば `isOver` です。候補者をドラッグしてみましょう。すべてのレーンが準備状態になり、カードの下のレーンが強調表示され、件数が跳ね、枠が開いて呼吸するように動きます。

::example{name="anim-container" hint="候補者を Hired へドラッグしてみましょう" height="24.5rem"}
::

```vue [Lane.vue]
<script setup lang="ts">
const { items, isOver, isAccepting } = makeSortableList(list, {
  id: props.lane.id,
  items: toRef(props.lane, 'people'),
  group: 'pipeline',
  dropzone: zone,
});
</script>

<template>
  <section ref="zone" class="lane" :class="{ ready: isAccepting, over: isOver }">
    <h3>
      {{ lane.title }}
      <!-- A new element for every count: its animation plays on each change. -->
      <span :key="items.length" class="count">{{ items.length }}</span>
    </h3>
    <ul ref="list">…</ul>
  </section>
</template>

<style scoped>
.lane { transition: background-color 0.25s, box-shadow 0.25s; }
.lane.ready { box-shadow: inset 0 0 0 1px color-mix(in srgb, #42b883 35%, transparent); }
.lane.over { background: color-mix(in srgb, #42b883 8%, transparent); box-shadow: inset 0 0 0 1.5px #42b883; }
.count { animation: bump 0.3s ease-out; }
</style>
```

```css [Candidate.vue]
/* Opens where it appears, then breathes until the card lands. */
.candidate[data-dnd-placeholder] {
  animation: open 0.2s ease-out, breathe 1.2s ease-in-out 0.2s infinite;
}
```

- `items` はドラフトです。枠がレーンに入った時点で `length` がカードを数に入れるので、ドラッグ中に件数が変わります。
- 別のリストへ移った枠はそこでは新しい要素なので、キーフレームが再び再生されます。
- アニメーションするのは見た目にして、サイズは避けてください。ドラッグ中に大きくなるリストは、ポインターの下のターゲットを動かしてしまいます。グロー、アウトライン、色、`scale` は安全です。

## 独自のアニメーション {#your-own-animations}

どのオプションも関数を受け取ります。関数はコンテキストを受け取り、アニメーションを開始して、その `Animation`、終了時に確定する Promise、または何も返しません。ドラッグはドロップのアニメーションが終わると終了し、去るアイテムのコピーはそのアニメーションが終わると取り除かれますが、どちらも `options.duration`（ドロップは 250 ms、それ以外は 200 ms）から 1 秒を超えて待つことはありません。

```ts
// animation, animate.move: an item moved from `from` to `to`
({ key, element, from, to, options, reason, signal, reducedMotion }) => Animation | Promise | void
// dropAnimation: `to` is null when there is no visible slot; `into` is the zone it went into
({ overlay, from, to, into, reason, active, options, reducedMotion }) => …
// animate.enter: the element is already in place
({ key, element, to, options, reducedMotion }) => …
// animate.leave: `element` is a copy where the item was, removed when you finish
({ key, element, from, options, reducedMotion }) => …
```

`reason` は理由を示します：移動なら `'drag'` か `'change'`、オーバーレイなら `'drop'` か `'cancel'` です。`options` にはオプションのタイミングが入っているので、関数は隣で設定した `duration` に従えます。

独自のアニメーションをライブラリと同期させるための 3 つのルール：

- `transform` ではなく **`translate` をアニメーションしてください**。`from - to` から 0 へ動かします。仮想リストや CSS が行に付けた transform と合成でき、ドラッグはそれを除いてアイテムを測定します。
- **`signal` に従ってください。** アニメーションが終わる前にアイテムが再び動くと中止されます。アニメーションをすぐに止め、そのスタイルを消してください。直後にレイアウトが測定されます。返した `Animation` は自動でキャンセルされます。
- **オーバーレイでは位置とサイズ**（`width`、`height`）をアニメーションし、`scale` は使わないでください。中身が新しいサイズで再レイアウトされます。

### motion {#motion}

下のプレイリストは [motion](https://motion.dev/docs/vue) で動いています。行とドロップはプロバイダーの関数を通じてスプリングで動き、オーバーレイコンポーネントはポインターの速度に合わせて揺れます。

::example{name="anim-motion" hint="曲を左右にすばやくドラッグしてから離してみましょう" height="24.25rem"}
::

```vue [index.vue]
<script setup lang="ts">
import { animate } from 'motion-v';
import { DnDProvider, type DropAnimationContext, type LayoutAnimationContext } from '@vue-dnd-kit/core';

const spring = { type: 'spring', duration: 0.5, bounce: 0.3 } as const;

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const controls = animate(element, { translate: [`${from.left - to.left}px ${from.top - to.top}px`, '0px 0px'] }, spring);
  signal.addEventListener('abort', () => {
    controls.stop();
    element.style.translate = '';
  });
  return controls.finished;
};

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return animate(overlay, { opacity: 0 }, { duration: 0.18 }).finished;
  return animate(
    overlay,
    { x: [from.left, to.left], y: [from.top, to.top], width: [from.width, to.width], height: [from.height, to.height] },
    spring,
  ).finished;
};
</script>

<template>
  <DnDProvider :animation="move" :drop-animation="drop">
    <Playlist />
  </DnDProvider>
</template>
```

オーバーレイコンポーネントはプロバイダーの配下で描画されるので、その中で `useDnD()` が使えます。motion value を通じてポインターに追従します。

```vue [SongOverlay.vue]
<script setup lang="ts">
import { motion, useMotionValue, useReducedMotion, useSpring, useTransform, useVelocity } from 'motion-v';
import { useDnD, type DnDStatus, type DragItem } from '@vue-dnd-kit/core';

const props = defineProps<{ items: DragItem[]; status: DnDStatus }>();

const { pointer } = useDnD();
const x = useMotionValue(pointer.value?.x ?? 0);
watch(() => pointer.value?.x, (value) => value !== undefined && x.set(value));
const swing = useSpring(useTransform(useVelocity(x), [-1500, 0, 1500], [-12, 0, 12]), { stiffness: 350, damping: 18 });
const calm = useReducedMotion();
</script>

<template>
  <motion.div
    class="song-overlay"
    :style="{ rotate: calm ? 0 : swing }"
    :animate="{ scale: status === 'dropping' || calm ? 1 : 1.06 }"
  >
    …
  </motion.div>
</template>
```

### GSAP {#gsap}

```ts [gsap-animations.ts]
import gsap from 'gsap';
import type {
  DropAnimationContext,
  EnterAnimationContext,
  LayoutAnimationContext,
  LeaveAnimationContext,
  Rect,
} from '@vue-dnd-kit/core';

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const tween = gsap.fromTo(
    element,
    { translate: `${from.left - to.left}px ${from.top - to.top}px` },
    { translate: '0px 0px', duration: 0.4, ease: 'power3.out' },
  );
  signal.addEventListener('abort', () => tween.revert());
  return tween.then();
};

const box = (rect: Rect) => ({ x: rect.left, y: rect.top, width: rect.width, height: rect.height });

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return gsap.to(overlay, { opacity: 0, duration: 0.2 }).then();
  return gsap.fromTo(overlay, box(from), { ...box(to), duration: 0.45, ease: 'back.out(1.2)' }).then();
};

const enter = ({ element, reducedMotion }: EnterAnimationContext) =>
  gsap.from(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.35 }).then();

const leave = ({ element, reducedMotion }: LeaveAnimationContext) =>
  gsap.to(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.25 }).then();

export const gsapAnimations = { animation: move, dropAnimation: drop, animate: { move, enter, leave } };
```

```vue
<DnDProvider v-bind="gsapAnimations">
```

オプションの完全な型は[アニメーション](/docs/api/animations)にあります。

## モーションの軽減 {#reduced-motion}

`prefers-reduced-motion: reduce` では、ライブラリ自身のアニメーションは実行されません。アイテムとオーバーレイはすぐに所定の位置へ移り、オーバーレイが枠のサイズの間を滑らかに変化することもありません。あなたの関数は常に `reducedMotion: true` とともに実行されるので、判断は関数に任されます：動きを省くか、上のレシピのように短いフェードを残すかです。

CSS はあなた自身が対処してください。このページのデモのように、持ち上げ、傾き、脈動は `@media (prefers-reduced-motion: no-preference)` の中に置き、色の変化はその外に置きます。色の変化はドロップ先を伝えるものだからです。

## ライブラリによらないレイアウトの変化 {#layout-changes-the-library-didnt-cause}

ドラッグ中にほかの何かが行を動かすとき——仮想化ライブラリの再測定、画像の読み込み——変化が描画される直前にリストの `captureLayout()` を呼んでください。現在の位置で行を測定し、次の描画の後で新しい位置へアニメーションします。ドラッグ中でなければ何もしません。[仮想リスト](/docs/guides/virtual-lists)を参照してください。
