`@vue-dnd-kit/devtools` は、Vue DevTools（`vite-plugin-vue-devtools`）と Nuxt DevTools に **Vue DnD Kit** タブを追加します。ページ上のすべてのリスト、ツリー、ドロップターゲットをライブのミニマップに表示し、ジョイスティックで任意のアイテムをドラッグし、アプリの実行中にオプションを編集し、各ドラッグが何をしたかを記録します。動作するのは開発時のみで、本番ビルドには何も含まれません。

## インストール {#install}

```bash
npm i -D @vue-dnd-kit/devtools @vue-dnd-kit/actions
```

`@vue-dnd-kit/actions` は peer dependency です：タブからの移動はこれを通じて行われます。npm 7+ と pnpm は自動でインストールします。Yarn 1 では自分で追加してください。

::code-group

```ts [vite.config.ts]
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import vueDevTools from 'vite-plugin-vue-devtools';
import { vueDnDKitDevtools } from '@vue-dnd-kit/devtools/vite';

export default defineConfig({
  plugins: [vueDevTools(), vueDnDKitDevtools(), vue()],
});
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  // With @vue-dnd-kit/devtools installed, the tab appears in development.
  modules: ['@vue-dnd-kit/nuxt'],
});
```

::

Vite では、プラグインがタブを `/__vue-dnd-kit-devtools/` で配信し、Vue DevTools に追加し、アプリが起動する前にページがタブへ報告するようにします。`app.use()` は不要です。作用するのは開発サーバー（`vite serve`）だけで、ビルドには影響しません。

Nuxt では、`@vue-dnd-kit/nuxt` モジュールがパッケージを見つけ、タブを配信し、Nuxt DevTools に追加し、クライアントプラグインでページ側をインストールします。`vueDndKit: { devtools: false }` でオフにできます。

### プラグインを使わない場合 {#without-the-plugins}

独自の開発サーバーや、Vite が `index.html` から配信しないページ（SSR 構成）では、ページ側を自分でインストールします。

```ts [main.ts]
import { createApp } from 'vue';
import { DnDDevtools } from '@vue-dnd-kit/devtools';
import App from './App.vue';

const app = createApp(App);
app.use(DnDDevtools); // before mount: providers set up earlier aren't seen
app.mount('#app');
```

または、エントリーファイルで最初に `@vue-dnd-kit/devtools/auto` をインポートします。プラグインにタブを配信させつつページ側は自分でインストールする場合は、`vueDnDKitDevtools({ inject: false })` を使ってください。`@vue-dnd-kit/devtools/vite` の `serveTab()` が、タブを配信するミドルウェアです。

## 開き方 {#open-it}

- **Vue DevTools**：:kbd{value="Alt"} + :kbd{value="Shift"} + :kbd{value="D"}、またはページ下部の Vue ボタンを押し、**Vue DnD Kit** タブを開きます。
- **Nuxt DevTools**：:kbd{value="Shift"} + :kbd{value="Alt"} + :kbd{value="D"}、または Nuxt ボタンを押し、**Vue DnD Kit** を開きます（サイドバー、またはそのオーバーフローメニューにあります）。
- **専用のウィンドウ**：開発サーバーで `http://localhost:5173/__vue-dnd-kit-devtools/` を開くか、タブの ⧉ ボタンを押します。2 台目の画面で使うと便利です。

::warning
タブはブラウザーのバックグラウンドタブではなく、専用のウィンドウで開いておいてください。非表示のページはドラッグをキャンセルします。
::

## タブに表示されるもの {#what-the-tab-shows}

### ミニマップ {#the-mini-map}

リスト、ツリー、ドロップターゲットごとのライブなカードで、アイテムのコピーが実際の位置に表示されます。オーバーレイが表示するのと同じクローンです。ドラッグ中は、ドラッグを受け入れるリスト（青）と拒否するリスト（赤）、プレースホルダー、ポインターの下のターゲット、オーバーレイのボックス、そして `placeholder: 'indicator'` のリストの挿入ラインを示します。クリックでアイテムを選び、ダブルクリックでページをそのアイテムまでスクロールします。

ドロップが思った場所に入らないときに使ってください：どのリストがドラッグを受け入れるかが一目で分かります。

### 操作：ジョイスティック {#drive-the-joystick}

アイテムを選び（マップ上、ツリー内、または **Pick** で。Pick はページ上の次の押下を拾います）、ジョイスティックのノブを押し出します。アイテムが持ち上げられてその方向へ動き、ノブが中心から離れるほど速く動きます。**Drop** と **Cancel** でドラッグを終えます。

これは `devtools` という名前のセンサーによる本物のポインタードラッグなので、リストは並べ替わり、コンテナーは自動スクロールし、`onBeforeDrop` と `onDrop` もほかのドラッグと同じように実行されます。並べ替え可能なリストのアイテムにはボタンも表示されます：上へ、下へ、先頭へ、末尾へ、グループ内の別のリストへ。

| キー（タブ内） | 動作 |
| --- | --- |
| 矢印キーまたは :kbd{value="W"} :kbd{value="A"} :kbd{value="S"} :kbd{value="D"} | ノブをその方向へ押し出す。:kbd{value="Shift"} を押すといっぱいまで |
| :kbd{value="G"} | 選んだアイテムを持ち上げる |
| :kbd{value="Space"} / :kbd{value="Enter"} | ドロップ |
| :kbd{value="Escape"} | キャンセル |
| :kbd{value="P"} | ページ上で選ぶ |

### オプション {#options}

コールバック以外のすべてのオプションは、アプリの実行中に編集できます：プロバイダーのもの（`collision`、`modifiers`、`overlayFit`、`autoScroll`、アニメーション、`activation`、`keyboard`…）、リストのもの（`strategy`、`placeholder`、`behavior`、`multiple`、`dropOutside`、`disabled`…）、ツリー、ドロップターゲット、アイテムのもの。ノードを選んで **Options** を開いてください。

編集はすぐに、このページにだけ適用され、コードに書き込まれることはありません。リセットするか、プロバイダーがアンマウントされるか、ページを再読み込みするまで有効です。

### 状態 {#state}

各プロバイダーが知っていることをツリーで表示します：ドラッグのセッション（状態、アクティブな id とセンサー、ターゲットとそれが受け入れるかどうか、ポインター）、リストとツリー（順序とドラフト）、ドロップターゲット（ルール）、そしてアイテムの型とデータです。

### ログ {#log}

ドラッグごとに 1 つの帯：開始（id、センサー、出どころのリスト）、各 `over` と `left` と受け入れの可否、離した時点、`onBeforeDrop` の判定（受け入れ、一部受け入れ、フックによる拒否、ターゲットの `accept` による拒否）、そして `drop`（`e.result` と `preventDefault()` が呼ばれたかどうか）、または `cancel` とその理由。エントリーをクリックすると、そのデータが表示されます。

ドロップが拒否されたのに何に拒否されたのか分からないときや、制御されたリストが変わらなかったときに使ってください：ログを見れば、`preventDefault()` が実行されたかどうかと、`e.result` に何が入っていたかが分かります。

## 仕組み {#how-it-works}

プロバイダーは、ページ側がインストールするフックに報告します。タブがページを監視するまでは記録されるだけです。その後、ページはほかのモニターと同じようにイベントを受け取り、タブが表示する内容を送ります（ドラッグ中は 40 ms ごと、それ以外は 1 秒に 2 回）。数秒間どのタブも監視しなくなると停止します。タブは、ページのオリジンの `BroadcastChannel` を通じてページと通信します。あなたが求めたもの（ドラッグ、選択、オプションの上書き）以外は何も変更しません。
