## リストとその行 {#a-list-and-its-rows}

並べ替え可能なリストには、リストとその行の 2 つのコンポーネントが必要です。

```vue [TaskList.vue]
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { makeSortableList } from '@vue-dnd-kit/core';
import TaskRow from './TaskRow.vue';

const tasks = ref([
  { id: 1, title: 'Sketch the board' },
  { id: 2, title: 'Write the docs' },
  { id: 3, title: 'Ship v3' },
]);

const listRef = useTemplateRef<HTMLElement>('list');
const { items } = makeSortableList(listRef, { items: tasks });
</script>

<template>
  <ul ref="list">
    <TaskRow v-for="task in items" :key="task.id" :task="task" />
  </ul>
</template>
```

```vue [TaskRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ task: { id: number; title: string } }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el">{{ task.title }}</li>
</template>
```

行は、自分が描画されているリストに登録されます。すべてのリストに専用のコンポーネントが必要なのもこのためです。1 つのコンポーネントで作った 2 つのリストは、行を共有してしまいます。

## ドラフト {#the-draft}

`makeSortableList` は `items` を返します。これはあなたの配列の**ドラフト**です。ドラッグ中、ドラフトはリアルタイムで並べ替わります。ドラッグ中の行が新しい位置を占め、ほかの行はスライドして道を空けます。あなたの配列はドロップまで変わらず、ドロップ時にライブラリが新しい順序を書き込みます。

::example{name="quick-start" hint="リストの下の id があなたの配列です：ドロップ時に変わります"}
::

- あなたの配列ではなく `items` を描画してください。配列のほうを描画すると、ドロップまで何も動きません。
- 書き込みはリストの `onDrop` の後に行われます。`onDrop` の中では、あなたの配列はまだ古い順序で、`e.result` が新しい順序です。
- `tasks` は普通の `ref` なので、アプリの他の部分も、ほかの変更と同じようにこの変更を受け取ります。

```ts
makeSortableList(listRef, {
  items: tasks,
  onDrop: (e) => {
    console.log(e.from.index, '→', e.to.index, e.result.get(e.to.list));
  },
});
```

配列を `v-model` で受け取るリストコンポーネントは、そのモデルをそのまま渡します。

```ts
const tasks = defineModel<Task[]>({ required: true });
const { items } = makeSortableList(listRef, { items: tasks });   // the write emits update:modelValue
```

::tip
ストア、サーバーの状態、イミュータブルなデータを使っていますか？ref の代わりにゲッターか `computed` を渡してください。ライブラリは読み取り専用のソースには書き込みません。`e.preventDefault()` を呼んで、`e.result` を自分で適用してください。[ドロップの判断](/docs/guides/drop-decisions)を参照してください。
::

## キー {#keys}

行のキーは、インデックスや自動生成の id ではなく、必ずデータから取ります。デフォルトのキーは `item.id` で、文字列や数値の場合はアイテムそのものです。

```ts
// TaskList.vue: your items have another key
makeSortableList(listRef, { items: tasks, getKey: (task) => task.uuid });

// TaskRow.vue: `item` is keyed with the list's getKey…
makeSortableItem(el, { item: () => props.task });
// …or pass the key yourself
makeSortableItem(el, { id: () => props.task.uuid });
```

- `v-for` でも同じキーを使ってください：`:key="task.uuid"`。`:key="index"` では間違った行がアニメーションし、行の状態がほかの行に飛び移ります。
- キーは、アイテムをやり取りするすべてのリストの中で一意である必要があります。
- `item` と `id` はゲッターとして渡してください。そうすれば、props が変わっても行が同期し続けます。

## ストラテジー {#strategies}

| `strategy` | 用途 |
| --- | --- |
| `'vertical'`（デフォルト） | 縦に並んだ行。 |
| `'horizontal'` | 1 行だけの並び：タブ、チップ、タイムライン。 |
| `'grid'` | CSS グリッドや折り返す flex の行。アイテムのサイズが異なっていても使えます。 |

```ts
const { items } = makeSortableList(grid, { items: apps, strategy: 'grid' });
```

## ハンドル {#handles}

デフォルトでは、行全体でドラッグを開始できます（行の中のボタン、入力欄、その他のコントロールを除く）。一部分だけでドラッグさせるには `handle` を渡します。

```vue [Track.vue]
<script setup lang="ts">
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { item: () => props.track, handle: '.grip' });
</script>

<template>
  <li ref="el">
    {{ track.title }}
    <button type="button" class="grip" aria-label="Reorder">⠿</button>
  </li>
</template>
```

- `handle` はアイテム内のセレクター、または要素の ref です。
- ハンドルからのマウスドラッグは、通常の 4 px を待たずにすぐ始まります。
- ハンドルにはドラッグ用の属性（`role`、`tabindex`、`aria-*`）が付き、キーボードドラッグもハンドルから始まります。

ハンドルは `aria-label` 付きの `<button type="button">` にしてください。そのままでフォーカス可能で、スクリーンリーダーはそのラベルを読み上げます。アイコンだけの `<span>` でも動作します（ライブラリが `tabindex="0"` と `role="button"` を付与します）が、意味のある名前を持ちません。

::note
タッチドラッグは 200 ms の長押しの後に始まるため、ページは引き続きスクロールできます。ハンドルからすぐにドラッグを始めたい場合は、ハンドルに `touch-action: none` を、アイテムに `activation: { touch: { distance: 4 } }` を指定してください。
::

## 軸を固定する {#lock-the-axis}

```ts
makeSortableList(listRef, { items: tracks, axis: 'y' });
```

`axis: 'y'` はドラッグを縦軸に、`'x'` は横軸に固定します。アイテム自身の `axis` はリストのものより優先されます。ドラッグをリストの内側にも留めたい場合は、`restrictToParent` モディファイアを追加してください。上のプレイリストは両方を使っています。詳しくは[制約](/docs/guides/constraints)を参照してください。

## 着地位置のスタイル {#style-the-slot}

ドラッグ中の行は、着地する位置としてリストの中に残り、`data-dnd-placeholder` が付きます。デフォルトのスタイルはこれを 40% に薄くします。詳細度はゼロなので、あなたが書くどのルールも優先されます。

```css
/* An empty, dashed slot instead of a faded row */
.track[data-dnd-placeholder] {
  opacity: 1;
  position: relative;
}

.track[data-dnd-placeholder]::after {
  content: '';
  position: absolute;
  inset: 0;
  border: 1.5px dashed color-mix(in srgb, currentColor 30%, transparent);
  border-radius: inherit;
  background: Canvas;
}
```

`makeSortableItem` は同じ状態を ref として返し、さらにいくつかの値も返します。

| 返り値 | 内容 |
| --- | --- |
| `isPlaceholder` | この行が、ドラッグ中のアイテムが着地する位置である。 |
| `isDragging` | この行がドラッグされている（マルチドラッグでは、ドラッグ中のすべての行）。 |
| `index` | ドラフト内でのインデックス：ドラッグ中に変わります。 |
| `selected` | 書き込み可能。プロバイダーの選択にバインドされています。 |
| `indicator` | [インジケーターモード](/docs/guides/shared-lists#an-insertion-line)で、ラインが入る場所。 |

リストは、自身の強調表示のために `isOver` と `isAccepting` を返します。すべての属性とレシピは[スタイリング](/docs/guides/styling)にあります。

## 機能をオフにする {#turning-things-off}

- リストの `disabled`：リストからのドラッグも、リストへのドロップもできなくなります。アイテムの `disabled`：そのアイテムはドラッグできなくなります。
- `sort: false`：このリストの中ではアイテムを並べ替えられませんが、外へ出すことはできます（パレット。[アイテムを共有するリスト](/docs/guides/shared-lists)を参照）。

## アニメーション {#animations}

ドラッグ中、行は新しい位置へスライドし、ドロップした行は自分の位置に着地します。これはデフォルトでオンになっていて、コードは不要です。行を `<TransitionGroup>` で囲まないでください。移動が二重にアニメーションしてしまいます。ドラッグ以外による変更（追加、削除、シャッフル）には、リストの `animate` オプションをオンにしてください。[アニメーション](/docs/guides/animations)を参照してください。

オプションの完全な一覧は、[makeSortableList](/docs/api/make-sortable-list) と [makeSortableItem](/docs/api/make-sortable-item) の API にあります。
