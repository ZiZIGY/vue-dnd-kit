このページの内容はすべてデフォルトでオンです。Tab でトラックのグリップにフォーカスし、:kbd{value="Space"} を押して矢印キーで動かし、もう一度 :kbd{value="Space"} を押してください。元に戻すには :kbd{value="Escape"} を押します。

::example{name="lists" hint="Tab でグリップへ、Space、矢印キー、Space" height="28rem"}
::

通常あなたに残されているのは、アイテムの読み取りやすい名前と、まったくドラッグできない人のためにアイテムを移動するボタンです。

## キーボード {#the-keyboard}

| キー | 操作 |
| --- | --- |
| :kbd{value="Space"} / :kbd{value="Enter"} | フォーカスされたアイテムを持ち上げる。ドロップする。 |
| 矢印キー | 動かす：リストでは位置ごと、ツリーでは行と深さごと、自由なドラッグでは `keyboard.step` ピクセルずつ。 |
| :kbd{value="Escape"} | ドラッグをキャンセルする（ポインタードラッグも）。 |

- リストでは、同じグループの別のリストの方向へ矢印キーを押すと、アイテムがそちらへ移動します。
- 自由なドラッグでは、:kbd{value="Shift"} でステップが大きくなります。`makeDraggable(el, { keyboard: 'droppables' })` にすると、矢印キーは代わりに、そのアイテムを受け入れるターゲットの間をジャンプします。
- キーボードドラッグは、フォーカスされたドラッグ可能な要素またはそのハンドルから始まります。中にあるボタンや入力欄から始まることはないため、それらは自分のキー操作を保ちます。
- キーボードドラッグでは、端での自動スクロールの代わりに、ターゲットがスクロールして表示されます。
- ドロップ後、行が別のリストで再描画された場合でも、フォーカスはアイテムに戻ります。

### ほかのキー {#other-keys}

```vue
<DnDProvider :keyboard="{ keys: { start: ['KeyD'], drop: ['KeyD', 'Enter'], cancel: ['Escape'] }, step: 10 }">
```

キーの割り当ては `event.code`（`'Space'`、`'KeyD'`）または `event.key`（`'Enter'`）と照合されます。`step` は、自由なドラッグで矢印キーを 1 回押したときに動くピクセル数です（デフォルトは 25）。`:keyboard="false"` でキーボードドラッグはオフになりますが、:kbd{value="Escape"} は引き続きどのドラッグもキャンセルします。キーを変更したら、`screen-reader-instructions` も変更してください。

## ARIA 属性 {#aria-attributes}

すべてのドラッグ可能な要素と並べ替え可能なアイテムには、**自分で設定していない限り**、次の属性が付きます。

| 属性 | 値 |
| --- | --- |
| `tabindex` | 要素がもともとフォーカス可能でない場合に `0`。 |
| `role` | `button`。ただし、もともとボタンである `<button>` には付きません。 |
| `aria-roledescription` | `draggable`。並べ替え可能なアイテムでは `sortable`。 |
| `aria-describedby` | プロバイダーの操作説明。既存の id の隣に追加されます（ツールチップの id は残ります）。 |
| `aria-disabled` | `true` または `false`：アイテムが無効かどうか（無効なドラッグエリアによるものも含む）。 |
| `aria-pressed` | ドラッグされている間は `true`。 |

`attributes: false` でアイテムの属性をオフにします。ライブラリが設定していたものは取り除かれます。

### ハンドル：本物のボタンにする {#handles-make-them-real-buttons}

```vue [Track.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ track: { id: string; title: string } }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { item: () => props.track, handle: '.grip' });
</script>

<template>
  <li ref="el" class="track">
    {{ track.title }}
    <button type="button" class="grip" :aria-label="`Move ${track.title}`">⠿</button>
  </li>
</template>
```

`handle` を使うと、属性はハンドルに付き、キーボードドラッグもハンドルから始まります。`<button>` はフォーカス可能で、もともとボタンなので、`tabindex` や `role` は不要です。`aria-label` を付けてください：グリップのアイコンにはそれ自体の名前がなく、「Move Midnight Drive」は「button」よりも多くを伝えます。

## 読み上げ {#announcements}

プロバイダーのライブリージョンは、すべての持ち上げ、移動、ドロップ、キャンセルを読み上げます。並べ替え可能なリストは、アイテムの位置を伝えます：*「Picked up item t2 at position 2 of 5 in list playlist.」* 移動は、ドラッグが 500 ms 止まった時点で読み上げられます。

テキストには id が使われます。アイテムに読みやすい id を付けるか、テキストを自分で書いてください。

```ts
import type { Announcements, Key } from '@vue-dnd-kit/core';

const title = (id: Key) => tasks.value.find((task) => task.id === id)?.title ?? String(id);

const announcements: Partial<Announcements> = {
  onDragStart: ({ active }) => `Picked up ${title(active.id)}.`,
  onDragEnd: ({ active, dropped }) => (dropped ? `Dropped ${title(active.id)}.` : undefined),
  onDragCancel: ({ active }) => `${title(active.id)} went back to its place.`,
  onDragResume: ({ active }) => `${title(active.id)} was not dropped. It is still moving.`,
};
```

```vue
<DnDProvider :announcements="announcements" screen-reader-instructions="Press D to pick up a card…">
```

- テキストはそのイベントの読み上げを置き換えます。`undefined` はデフォルトのまま、`''` は何も読み上げません。指定しなかったイベントもデフォルトのままです。上の例の `onDragOver` における並べ替え可能なリストの位置などです。
- `onDragResume` は、`onBeforeDrop` が `'continue'` を返してドラッグが続くときに読み上げられます（[ドロップの判断](/docs/guides/drop-decisions)を参照）。
- `screenReaderInstructions` は、すべてのドラッグ可能な要素が `aria-describedby` で参照するテキストです。
- `:announcements="false"` はライブリージョンを無音にします。独自のライブリージョンで読み上げる場合などに使います。

::note
組み込みのテキストは英語です。ほかの言語にするには、5 つのテキストすべてと操作説明を指定してください。指定しなかったものは、並べ替え可能なリストの位置も含めて英語で読み上げられます。
::

## タッチ {#touch}

タッチドラッグは 200 ms の長押しの後に始まります。それまでに 5 px を超えて動かすと、代わりにページがスクロールするため、リストはスクロール可能なままです。どちらも `activation` で調整でき（[センサー](/docs/guides/sensors#activation-constraints)を参照）、`useDnD().activation.progress` から長押しのリングを描けます。

タッチドラッグは開始時に短く振動します。`:haptics="false"` でそれをオフにでき、オブジェクトを渡すと、ターゲットに入ったとき、ドロップしたとき、拒否されたときの振動を追加できます。

```vue
<DnDProvider :haptics="{ start: true, enter: 10, drop: 10, refuse: [20, 40, 20] }">
```

振動するのはタッチドラッグだけで、iOS Safari はまったく振動できません。

## モーションの軽減 {#reduced-motion}

`prefers-reduced-motion: reduce` のときは、ライブラリ自身のアニメーションは実行されません。あなたのアニメーション関数は `reducedMotion: true` 付きで引き続き実行されます。[アニメーション](/docs/guides/animations)を参照してください。

## ドラッグせずに移動する {#moving-without-dragging}

まったくドラッグできない人もいます。WCAG 2.5.7 は、「上へ移動」ボタンのように、シングルクリックでアイテムを移動する手段を求めています。`@vue-dnd-kit/actions` を使えば、そうしたボタンの 1 つひとつが本物の移動になります。

```bash
npm i @vue-dnd-kit/actions
```

```vue [TaskRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';
import { useDnDActions } from '@vue-dnd-kit/actions';

const props = defineProps<{ task: { id: string; title: string }; count: number }>();
const el = useTemplateRef<HTMLElement>('el');
const { index } = makeSortableItem(el, { item: () => props.task });
const { moveItem } = useDnDActions();
</script>

<template>
  <li ref="el">
    {{ task.title }}
    <button type="button" :disabled="index === 0" @click="moveItem(task.id, { index: index - 1 })">
      Move up
    </button>
    <button type="button" :disabled="index === count - 1" @click="moveItem(task.id, { index: index + 1 })">
      Move down
    </button>
    <button type="button" @click="moveItem(task.id, { list: 'done' })">Move to Done</button>
  </li>
</template>
```

`moveItem` はキーボードドラッグを最初から最後まで実行します。読み上げられ、`onBeforeDrop` と `onDrop` を通り、アニメーションし、フォーカスをアイテムに保ちます。ドロップが成立すると `true` で resolve します。`index` はアイテム自身を除いて位置を数えるため、「下へ」は `index + 1` です。詳しくは[センサーとプログラムによるドラッグ](/docs/guides/sensors#programmatic-drags)を参照してください。
