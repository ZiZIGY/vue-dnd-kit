## これは何か {#what-it-is}

Vue DnD Kit は、**コンポーザブル**の集まりと 1 つの**プロバイダー**コンポーネントです。要素は自分で描画し、そのテンプレート参照をコンポーザブルに渡すだけで、残りはライブラリが引き受けます。ポインター・タッチ・キーボードの入力、ターゲットの検出、並べ替え、アニメーション、自動スクロール、そしてスクリーンリーダーへの状況の伝達です。

ライブラリ自身が描画するのは、浮かんで動く**オーバーレイ**だけです。オーバーレイはデフォルトで、ドラッグ中の要素のクローンです。マークアップとスタイルはあなたのものです。

## できること {#what-you-get}

- **並べ替え可能なリストとグリッド**。ドラッグ中にリアルタイムで並べ替わります。描画するのは配列の*ドラフト*で、ドロップ時にライブラリが新しい順序をあなたの ref に書き込みます。
- **カンバンボード**：同じグループのリストどうしでアイテムをやり取りします。パレットからのコピー、通常のドラッグ可能な要素の受け入れ、ずらす代わりの入れ替えに対応しています。
- **ツリー**：横方向のオフセットや行へのホバーによるネスト、深さの制限、ルール。
- **マルチドラッグ**：選択の方法は自由（Ctrl クリック、範囲選択）。まとめて 1 つのブロックとして移動します。
- **デフォルトでアニメーション**：アイテムは新しい位置へスライドし、ドロップしたアイテムは自分の位置に着地します。
- **アクセシビリティ**：位置ごとに動かすキーボードドラッグ、ライブでの読み上げ、ARIA 属性。
- **仮想リスト**：TanStack Virtual と VueUse で、数千行にも対応します。
- **制御モード**：ストアやサーバー向けに、デフォルトの書き込みをスキップして結果を自分で適用できます。

## 全体の構成 {#how-it-fits-together}

| パーツ | 役割 |
| --- | --- |
| `DnDProvider` | ドラッグを管理します：入力、オーバーレイ、選択、自動スクロール、読み上げ。 |
| `makeSortableList` / `makeSortableItem` | 並べ替え可能なリストと、その行。 |
| `makeSortableTree` | 深さ付きのフラットな形で描画されるツリー。 |
| `makeDraggable` / `makeDroppable` | 自由なドラッグとドロップゾーン。 |
| `makeDragArea` | ページの一部に適用するルール：軸、境界、スナップ、自動スクロール。 |
| `makeSelectionArea` | 範囲選択。 |
| `useDnD` / `useDnDMonitor` | ドラッグの状態とイベント。プロバイダーの下ならどこでも使えます。 |

::tip
v2 から移行しますか？API が変わりました。`useDnDProvider` は `useDnD` に、`makeConstraintArea` と `makeAutoScroll` は `makeDragArea` になりました。並べ替え可能なリストは組み込みになりました。
::

## 動作要件 {#requirements}

- Vue **3.5** 以降。
- モダンブラウザー：Chrome と Edge 104+、Safari 15.4+、Firefox 104+。
- SSR と Nuxt に対応：オーバーレイとライブリージョンはクライアントでマウントされます。
