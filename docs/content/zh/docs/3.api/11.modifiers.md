## 修饰器 {#modifiers}

```ts
import { restrictToParent, snapToGrid } from '@vue-dnd-kit/core';

makeSortableList(list, { items, modifiers: [restrictToParent] });
makeDragArea(board, { modifiers: [snapToGrid({ x: 24, y: 24, smooth: true })] });
```

修饰器接收拖拽的偏移量，并返回一个新的偏移量。它们按顺序运行：provider 的 `modifiers`、拖拽区域的、可拖拽元素自己的（或其列表的），然后是区域的边界（`restrictToArea`），最后是 `axis` 锁定。参见[轴、边界与网格](/docs/guides/constraints)。

| 修饰器 | 作用 |
| --- | --- |
| `restrictToVerticalAxis` | 只垂直移动。`axis: 'y'` 选项效果相同，并且最后执行。 |
| `restrictToHorizontalAxis` | 只水平移动（`axis: 'x'`）。 |
| `restrictToWindowEdges` | 把浮层限制在窗口内。 |
| `restrictToParent` | 把浮层限制在拖拽开始时所在的容器内：可排序列表，或普通可拖拽元素的父元素。 |
| `restrictToElement(element)` | 把浮层限制在某个元素内（ref、getter 或元素本身）。 |
| `restrictToFirstScrollableAncestor` | 把浮层限制在被拖拽元素的第一个可滚动祖先内。 |
| `snapToGrid(size \| options)` | 吸附到网格：`{ x, y, origin: 'container' \| 'delta', smooth }`。`'container'`（默认）把盒子的左上角放在从容器左上角开始的网格线上；`'delta'` 对偏移量取整。`smooth` 让浮层在格子之间平滑滑动。 |
| `snapCenterToCursor` | 让浮层的中心对准指针，而不是保持抓取时的偏移。 |

## 碰撞检测 {#collision-detection}

```ts
import { closestCorners } from '@vue-dnd-kit/core';
```

```vue
<DnDProvider :collision="closestCorners" />
```

provider 的 `collision` 负责选出目标；最佳候选排在最前。

| 函数 | 选出什么 |
| --- | --- |
| `pointerFirst` | 默认：指针下方的目标，否则是与浮层重叠的目标。 |
| `pointerWithin` | 通过命中测试得到的指针下方的目标（遵循 z 轴顺序、浮层和 shadow root）。 |
| `rectIntersection` | 与浮层重叠的目标：先比较优先级，再比较嵌套深度，最后比较交并比。 |
| `closestCenter` | 所有目标，按中心之间的距离排序。 |
| `closestCorners` | 所有目标，按各角之间距离之和排序（适用于看板列这类上下堆叠的目标）。 |
