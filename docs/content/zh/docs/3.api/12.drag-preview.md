## DragPreview {#dragpreview}

```vue [StackOverlay.vue]
<script setup lang="ts">
import { DragPreview, type DragItem } from '@vue-dnd-kit/core';

defineProps<{ items: DragItem[] }>();
</script>

<template>
  <div class="stack">
    <DragPreview v-for="item in items.slice(0, 3)" :id="item.id" :key="item.id" />
  </div>
</template>
```

克隆在拿起时生成：抓起的项，以及按放置顺序与它相邻的其他项，数量为 provider 的 `overlayPreviews`（默认 5 个）。对于其他任何项，`DragPreview` 渲染它的默认插槽，或者什么都不渲染。放置时，每个预览飞向它自己对应的项；放置进某个区域（文件夹、回收站）时，预览依次进入该区域。参见[浮层指南](/docs/guides/overlay)。
