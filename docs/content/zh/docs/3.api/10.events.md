监听器（`useDnDMonitor`）、provider 的事件和 droppable 的钩子会收到 `DnDEvent`；`onDragEnd` 收到 `DnDEndEvent`。可排序列表和树会把它们自己的放置事件（[`SortableDropEvent`](/docs/api/make-sortable-list#the-drop-event)、[`SortableTreeDropEvent`](/docs/api/make-sortable-tree#the-drop-event)）传给各自的 `onBeforeDrop` 和 `onDrop`。
