provider 的 `animation`（排序时的布局移动）、`dropAnimation`（浮层落位）和 `animate`（非拖拽引起的数据变化）接受 `false`、选项，或你自己的函数——用于 GSAP 或 motion。列表和树可以覆盖 `animation` 和 `animate`。参见[动画](/docs/guides/animations)。

```vue
<DnDProvider :animation="{ duration: 180, easing: 'ease-out' }" :drop-animation="false" />
```

下面的每条泳道都是一个独立的 provider，它的 `animation`、`dropAnimation` 和 `animate`（后者在 `move` 中接受函数）都使用同一种取值形式。
