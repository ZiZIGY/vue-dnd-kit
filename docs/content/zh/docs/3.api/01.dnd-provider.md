```vue [App.vue]
<script setup lang="ts">
import { DnDProvider } from '@vue-dnd-kit/core';
</script>

<template>
  <DnDProvider :animation="{ duration: 200 }" @drag-end="save">
    <RouterView />
    <template #overlay="{ items, over, accepted }">
      <!-- optional: a custom overlay for every drag -->
    </template>
  </DnDProvider>
</template>
```

每个组合式函数都必须在渲染于 provider **内部**的组件中运行。目标是整个应用只用一个 provider：页面的各部分通过 [`makeDragArea`](/docs/api/make-drag-area) 获得自己的规则。参见 [provider 指南](/docs/guides/provider)。

大多数 props 在 provider 需要时才读取：改变其中一个，下一次拖拽就会使用新值。

## 事件 {#events}

| 事件 | 载荷 | 触发时机 |
| --- | --- | --- |
| `drag-start` | `DnDEvent` | 拖拽已开始（在激活之后）。 |
| `drag-move` | `DnDEvent` | 拖拽期间指针移动了（每帧最多一次）。 |
| `drag-over` | `DnDEvent` | 拖拽下方的目标发生了变化。 |
| `drag-end` | `DnDEndEvent` | 放置已完成并已写入。 |
| `drag-cancel` | `DnDEvent` | 拖拽被取消，或放置被拒绝。 |
| `drag-settle` | `DnDEndEvent` 或 `DnDEvent` | 拖拽的浮层已经落位：参数是 `drag-end` 或 `drag-cancel` 收到的那个事件。 |

同样的事件，再加上 `onBeforeDrop` 和 `onDragResume`，可以通过 [`useDnDMonitor`](/docs/api/use-dnd) 在 provider 之下的任何地方使用。它们的载荷见[事件页面](/docs/api/events)。

## `#overlay` 插槽 {#slot-overlay}
