## 看点 {#what-to-look-at}

- **`FileCard.vue`**：一个带 `type`（`image` 或 `doc`）的普通 `makeDraggable`。
- **`Folder.vue`**：一个 `accept` 只接收一种类型的 `makeDroppable`（桌面和垃圾桶为 `'*'`）。`isAccepting` 会点亮接收这次拖拽的文件夹；不接收的文件夹通过 `isOver && !isAccepting` 把这一点显示出来。`onDrop` 是修改数据的地方：库自己不会移动任何东西。
- 文件在任何地方看起来都一样，所以放置时只需要飞过去；留下的文件借助 Vue 的 `<TransitionGroup>` 滑过来填补空位。
