## 看点 {#what-to-look-at}

- **`FileGrid.vue`**：文件是一个带有 `clone` 的可排序网格（`strategy: 'grid'`），所以按住 Alt 时是复制而不是移动。`makeSelectionArea` 绘制选框；它产生的选中集合正是多项拖拽要移动的那些项，显示为一叠。
- **`FileTile.vue`**：来自 `makeSortableItem` 的 `selected`，绑定到单击和 Ctrl/Cmd 点击。
- **`useFolderDrop.ts`**：树的行和文件夹图块都是放置目标。`accept` 是一个函数：文件夹会拒绝它自己、它自己的子文件夹以及当前打开的文件夹。在文件夹图块上，只有图块的中间部分接收放置；靠近边缘时，网格会排序。
- **`FileManager.vue`**：文件夹是普通的放置目标；`event.mode` 表明 Alt 是否把这次拖拽变成了复制。
