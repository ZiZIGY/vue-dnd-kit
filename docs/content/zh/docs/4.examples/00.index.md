每个示例都是一个小型 Vue 应用：一个带有 `DnDProvider` 的 `index.vue`，以及它需要的组件。演示下方的代码标签页正是运行它的那些文件。

::card-group

::card{title="拖放" icon="i-lucide-folder-input" to="/docs/examples/drop-zones"}
把文件分类放进各自只接收一种类型的文件夹；垃圾桶接收任何文件。
::

::card{title="列表与网格" icon="i-lucide-list-ordered" to="/docs/examples/lists"}
通过拖拽手柄沿单一轴拖动的播放列表，以及一个主屏幕式的应用网格。
::

::card{title="看板" icon="i-lucide-columns-3" to="/docs/examples/kanban"}
互相交换卡片、在整列高度内的任何位置都能接收放置的列。
::

::card{title="文件树" icon="i-lucide-list-tree" to="/docs/examples/tree"}
编辑器的资源管理器：通过横向拖动或悬停在文件夹上来嵌套。
::

::card{title="多项拖拽" icon="i-lucide-images" to="/docs/examples/multi-drag"}
用框选或 Ctrl/Cmd 点击来选择，然后移动整个选中集合。
::

::card{title="轴、边界与网格" icon="i-lucide-frame" to="/docs/examples/constraints"}
一个规则可以实时改变的面板：轴锁定、边界、网格。
::

::
