## 看点 {#what-to-look-at}

- **`Page.vue`**：页面是一棵带有 `placeholder: 'indicator'` 的可排序树：拖拽时什么都不会移动，一条线显示块将去往的位置和深度。`canNest` 只允许块进入折叠块。
- **`BlockRow.vue`**：`handle: '.grip'`，所以文本仍然可以编辑和选择，只有手柄会开始拖拽。
- **`Palette.vue`**：一个 `group` 相同、带有 `pull: 'clone'` 和 `put: false` 的列表：它分发新块（`clone`），而且什么都不收回。
- **`Editable.vue`**：普通的 `contenteditable` 文本。模型根据 DOM 更新，但从不写回 DOM，所以光标不会跳动。
