## 看点 {#what-to-look-at}

- **`Playlist.vue`**：`axis: 'y'` 和 `modifiers: [restrictToParent]` 让曲目保持在轴上并留在列表内；列表的两端仍然可以到达。
- **`Track.vue`**：`handle: '.grip'`——只有拖拽手柄（一个带 `aria-label` 的 `<button>`）能开始拖拽。`index` 跟随草稿，所以拖拽时序号会变化。这一行有自己的背景：浮层是它的副本，而副本只会显示这一行自己绘制的内容。
- **`AppGrid.vue`**：`strategy: 'grid'` 在两个维度上排序；`overlay: AppOverlay` 只抬起图标，而不是图块的副本。
- 被拖拽项将落入的位置用 `[data-dnd-placeholder]::after` 设置样式。
