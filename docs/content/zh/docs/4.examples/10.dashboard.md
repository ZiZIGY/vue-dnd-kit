## 看点 {#what-to-look-at}

- **`Dashboard.vue`**：网格是一个使用 `strategy: 'grid'` 的可排序列表，这个策略可以排序大小不一的小组件。它根据自己的宽度（`useElementSize`）计算列数：四列、三列或两列。它的行至少 92 px 高，并随内容增高；`grid-auto-flow: dense` 会填补调整大小后留下的空洞。
- **`Widget.vue`**：小组件通过标题（`handle`）移动，所以它的内容可以自由使用：任务可以勾选，便签可以输入文字。它的角落本身是一个可拖拽元素，用来调整它的大小。
- **`WidgetBody.vue`**：小组件显示的内容。在便签里输入文字：行随文字增高，旁边的小组件也随行增高。没有任何东西去测量它们：这是网格自身的布局，库在拖拽开始时按它们当时的样子读取尺寸。
- **`widgets.ts`**：小组件、它们以格为单位的尺寸，以及网格的各项数值。

展开这个示例：网格变成四列，在小屏幕上变窄的小组件会恢复原来的宽度。

## 调整大小：角落是一个可拖拽元素 {#resizing-the-corner-is-a-draggable}

角落位于小组件内部，按下时拖动的是最近的可拖拽元素：角落，而不是小组件。它没有浮层，也从不移动。取而代之的是小组件变大。

```ts [Widget.vue]
makeDraggable(corner, {
  id: cornerId,
  type: 'resize',
  overlay: false,
  activation: { touch: { distance: 4 } }, // a finger resizes at once, not after a long press
  attributes: false,                       // no tab stop: Shift + arrows on the header resize
});
```

尺寸跟随指针：指针从按下处移动了多远，按整格计算。按住角落时，网格显示这个尺寸，其他小组件为它让出位置。

```ts [Widget.vue]
const preview = computed<Size | null>(() => {
  const start = from.value;
  if (!resizing.value || !start || !pointer.value) return null;
  return {
    w: clamp(cellsIn(pixels(own.value.w, props.cell) + pointer.value.x - start.x, props.cell), 1, props.columns),
    h: clamp(cellsIn(pixels(own.value.h, ROW) + pointer.value.y - start.y, ROW), 1, MAX_ROWS),
  };
});
```

放置会保留这个尺寸：一个监听器收到角落的 `onDragEnd`。:kbd{value="Escape"} 则会取消拖拽，小组件回到它自己的尺寸。

```ts [Widget.vue]
useDnDMonitor({
  onDragEnd: ({ active: dropped }) => {
    if (dropped.id === cornerId() && preview.value) emit('resize', preview.value);
  },
});
```

## 网格不参与调整大小 {#the-grid-sits-the-resize-out}

角落不是小组件，网格会拒绝它：放到拒绝这次拖拽的目标上就是取消。所以拖拽角落期间，网格处于 `disabled` 状态，角落的放置不落在任何目标上。

```ts [Dashboard.vue]
const { active } = useDnD();
const { items } = makeSortableList(grid, {
  items: widgets,
  strategy: 'grid',
  label: 'Dashboard',
  disabled: () => !!active.value?.type.includes('resize'),
});
```

## 自适应的尺寸 {#sizes-that-adapt}

小组件保持给它的尺寸。列数变少时，它永远不会比网格更宽（`Math.min(w, columns)`），网格重新有空间时，它会恢复自己的宽度。行有的是最小高度，而不是固定高度：由内容决定，同一行的小组件都会拉伸到最高的那个的高度。

## 键盘 {#the-keyboard}

用 Tab 移到小组件的标题上，按 :kbd{value="Space"} 拿起这个小组件。方向键在其他小组件之间移动它，:kbd{value="Space"} 放下它，:kbd{value="Escape"} 把它放回原处。标题获得焦点时，:kbd{value="Shift"} 加方向键每次按一格调整小组件的大小，屏幕阅读器会听到它的新尺寸。
