## 看点 {#what-to-look-at}

- **`TaskList.vue`**：传给虚拟列表的是草稿 `items`，而不是源数组，所以拖拽时行会移动。数组是一个 `shallowRef`。
- **`TaskList.vue`**：行以 id 作为 key，而不是像 VueUse 文档中那样以索引作为 key。
- **`Row.vue`**：id 是一个 getter，`{ id: () => props.task.id }`：虚拟列表可能会把另一个任务交给这个组件。
