## 看点 {#what-to-look-at}

- **`Gallery.vue`**：在网格周围的区域上使用 `makeSelectionArea`；这个区域填满了它的盒子，所以在其中任何地方都能开始画选框。根据 `isSelecting` 和 `style` 渲染选框。
- **`Shot.vue`**：`selected` 绑定到 provider 的选中集合；Ctrl/Cmd 点击会切换它。
- 在网格中，多项拖拽的浮层是一叠：抓起的照片在最上面，后面是另外几张，上面显示数量。
