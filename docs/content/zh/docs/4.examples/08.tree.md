## 看点 {#what-to-look-at}

- **`FileTree.vue`**：带有 `indentation`、`collapsed` 和 `canNest: (_node, parent) => !!parent.folder` 的 `makeSortableTree`——只有文件夹可以包含子节点。
- **`TreeRow.vue`**：每一行都是以 `node.key` 为 key 的可排序项；它的左内边距跟随 `node.depth`，拖拽时也是如此，所以占位会显示放置后的深度。
