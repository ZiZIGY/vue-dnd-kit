## 看点 {#what-to-look-at}

- **`TrackRow.vue`**：箭头按钮使用 `moveItem(id, { index })`，`startDrag(id, { type: 'keyboard' })` 则把这一行交给方向键。
- **`Queue.vue`**：打乱时依次 await 一个又一个 `moveItem`；脚本化拖拽用 `startDrag` 开始，用 `moveTo` 滑动，用 `drop()` 落下。
