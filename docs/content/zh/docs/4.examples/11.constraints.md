## 看点 {#what-to-look-at}

- **`Board.vue`**：`makeDragArea(board, { axis, restrictToArea, modifiers })` 为每一次从面板上开始的拖拽设定规则。这些选项是 ref 和一个 getter，在拖拽开始时读取，所以开关的改动会作用于下一次拖拽。
- 面板同时也是放置目标；`onDragEnd` 把便签放到 `position`，即它被放下处的 `left`/`top`。
- **`Note.vue`** 只声明它可以被拖拽：其余的都由区域负责。
