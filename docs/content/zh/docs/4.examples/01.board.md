## 看点 {#what-to-look-at}

- **`Board.vue`**：这些列本身是一个横向的可排序列表，每一列都是一个通过列头拖动的可排序项（`handle`）。
- **`Column.vue`**：所有列的卡片属于同一个 `group`。`put` 是一个统计进入卡片数量的函数，所以达到 WIP 上限的列会拒绝这次拖拽，空位留在原来的列中。异步的 `onBeforeDrop` 会在卡片进入 Done 之前询问，并回答 `'accept'`、`'reject'` 或 `'continue'`（继续拖拽）。
- **`Card.vue`**：来自 `makeSortableItem` 的 `selected`，绑定到 Ctrl/Cmd 点击：多项拖拽会移动整个选中集合。
- **`Trash.vue`**：一个只接收卡片（`accept: 'card'`）的普通放置目标，用 `e.source.remove()` 删除它们。
- **`CardOverlay.vue`**：卡片的浮层组件（列表的 `overlay`），由 `DragPreview` 克隆构成：拖拽时卡片会倾斜，选中集合中的其余卡片叠在它下面，落位时它会摆正（`status`）。
