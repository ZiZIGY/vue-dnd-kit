## 选中集合 {#the-selection}

每个 provider 维护一个选中集合：一个响应式的 id 集合。拖拽一个**已选中**的项，会拖拽所有选中的项，抓起的那个在最前。拖拽一个未选中的项，只会拖拽这一项。

库不决定用户如何选择：点击规则由你来定。它也从不自行清空选中集合，而且选中集合在组件卸载后依然保留，例如被虚拟列表回收的行。

### Ctrl/Cmd 点击 {#ctrlcmd-click}

每个可排序项和可拖拽元素都会返回 `selected`，一个绑定到选中集合的可写 ref：

```vue [Shot.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ shot: { id: string } }>();
const el = useTemplateRef<HTMLElement>('el');
const { selected } = makeSortableItem(el, { item: () => props.shot });

const onClick = (event: MouseEvent) => {
  if (event.ctrlKey || event.metaKey) selected.value = !selected.value;
};
</script>

<template>
  <div ref="el" :class="{ selected }" @click="onClick">…</div>
</template>
```

结束拖拽的那次点击不会到达 `@click`，所以放置永远不会意外切换选中状态。项的操作请用 `@click`，而不是 `pointerup`。

### 在任何地方：`useDnD().selection` {#from-anywhere-usedndselection}

```ts
import { useDnD, useDnDMonitor } from '@vue-dnd-kit/core';

const { selection } = useDnD();

selection.has('a');               // is it selected?
selection.add('a', 'b');          // select
selection.delete('a');            // deselect
selection.toggle('a');            // flip it, or force it: toggle('a', true)
selection.set(['a', 'c']);        // exactly these
selection.clear();
selection.ids;                    // a reactive ReadonlySet<Key>

// A plain click selects only that item, Ctrl/Cmd-click adds or removes it:
const onClick = (event: MouseEvent, id: string) => {
  if (event.ctrlKey || event.metaKey) selection.toggle(id);
  else selection.set([id]);
};

// Clear it after every drop, if your UI wants that:
useDnDMonitor({ onDragEnd: () => selection.clear() });
```

选中集合以 id 为键，因此可以包含多个列表中的项：一次拖拽会带走 provider 之下所有选中的项。

## 框选 {#rubber-band-selection}

`makeSelectionArea` 把一个元素变成选择区域：在其空白处按下会画出一个选框，选框经过的项会被选中：

```vue [Gallery.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSelectionArea } from '@vue-dnd-kit/core';
import PhotoGrid from './PhotoGrid.vue';

const area = useTemplateRef<HTMLElement>('area');
const { isSelecting, style } = makeSelectionArea(area);
</script>

<template>
  <div ref="area" class="area">
    <PhotoGrid />
    <div v-if="isSelecting" class="band" :style="style" />
  </div>
</template>

<style scoped>
.area {
  position: relative;   /* the band is absolutely positioned inside */
  min-height: 320px;    /* room around the items to start a band */
}

.band {
  border: 1px solid #42b883;
  background: color-mix(in srgb, #42b883 15%, transparent);
}
</style>
```

- 选框由你渲染：`style` 负责定位它，相对于区域的内容。
- 区域需要**非 static 的定位**（`relative` 就行），否则选框会出现在别的地方。
- 选框只能从区域本身开始，所以要把区域做大：整个面板，项的周围留有空间，而不是一个紧贴的包裹元素。上面的图库填满了它的整个盒子。
- 在项上按下会拖拽它。按钮、表单字段和区域的滚动条保留它们自己的按下行为。
- 区域或页面滚动时，选框始终锚定在内容上。:kbd{value="Escape"} 会取消选框并恢复之前的选中状态。
- 画选框期间，`useDnD().status` 为 `'selecting'`。

| 选项 | 作用 |
| --- | --- |
| `strategy` | `'toggle'`（默认）：选框经过的项切换状态。`'select'`：只有选框内的项最终被选中，因此在空白处点击会取消选中区域中的项。 |
| `modifier` | 画选框时必须按住的键：`{ keys: ['Shift'], method: 'every' }`（或 `'some'`）。 |
| `accept` | 选框选中哪些可拖拽元素，是一条与它们的 `type` 匹配的 [accept 规则](/docs/guides/drag-and-drop#which-drags-a-target-takes)。 |
| `disabled` | 不出现选框；开启它会取消正在进行的选框。 |
| `onSelected(ids)` | 选框结束时调用，参数是选中集合。 |
| `selection` | 用你自己的 `Ref<Set<Key>>` 代替 provider 的选中集合。 |

区域嵌套时，最内层的区域接收按下。所有选项见 [makeSelectionArea API](/docs/api/make-selection-area)。

## 其他项如何移动：`multiple` {#how-the-other-items-move-multiple}

多项拖拽从哪个列表开始，就由哪个列表决定拖拽期间其他选中项的行为：

```ts
makeSortableList(listRef, { items: tasks, multiple: 'gaps' });
```

| `multiple` | 拖拽期间 | 浮层 |
| --- | --- | --- |
| `'group'`（默认） | 其他项离开原位置，作为一组连续的位置随抓起的项一起移动，因此列表已经显示出放置的结果。 | 沿列表方向排列的一列，最多显示五个被拖拽的项。 |
| `'gaps'` | 其他项留在原处，变为半透明（`data-dnd-dragging`），直到放置。 | 同样的一列。 |
| `'stack'` | 其他项飞进浮层。 | 抓起的项加上数量。 |

放置时，这些项按原有顺序一起落到目标索引处。在 `'group'` 和 `'gaps'` 模式下，浮层中的每一项都会飞到它自己的位置上。

### 默认浮层 {#the-default-overlay}

在 `'group'` 和 `'gaps'` 模式下，浮层是被拖拽项按落下后顺序排成的一列：抓起的项在指针下方，其他项按放置顺序排在它前后（在水平列表中则是一行）。最多显示五项。超出的项在它们所在的位置计数：列首的 `+N` 表示落在显示项之前的项，列尾的 `+N` 表示落在之后的项。

在网格中，一整列单元格会遮住页面，所以浮层是一叠：最多三个项呈扇形排在抓起的项后面，顶部显示总数。

普通的可拖拽元素（`makeDraggable`）显示抓起的项加上数量。

### 混合类型 {#mixed-types}

选中的项类型各不相同时，目标上的 `acceptMode` 规定是全部（`'all'`，默认）还是部分（`'some'`）项必须符合。参见[共享项的列表](/docs/guides/shared-lists#limits)和[拖放](/docs/guides/drag-and-drop#which-drags-a-target-takes)。

## 多个项的自定义浮层 {#a-custom-overlay-for-several-items}

浮层组件和 provider 的 `#overlay` 插槽会收到 `items`：所有被拖拽的项，抓起的那个在最前。`DragPreview` 会渲染库为其中任意一项生成的克隆，因此你的布局可以复用真实的外观：

```vue [PileOverlay.vue]
<script setup lang="ts">
import { DragPreview, type OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <div class="pile">
    <!-- The grabbed item on top, two more turned behind it -->
    <DragPreview
      v-for="(entry, i) in items.slice(0, 3)"
      :id="entry.id"
      :key="entry.id"
      class="card"
      :style="{ width: '100%', height: '100%', zIndex: 3 - i, rotate: `${i * 4}deg` }"
    >
      <!-- Shown for an item without a clone -->
      <div class="fallback">{{ entry.id }}</div>
    </DragPreview>
    <span v-if="items.length > 1" class="count">{{ items.length }}</span>
  </div>
</template>

<style scoped>
.pile { position: relative; width: 100%; height: 100%; }
.card { position: absolute; inset: 0; }
.fallback { width: 100%; height: 100%; border-radius: 8px; background: Canvas; }
.count { position: absolute; top: -8px; right: -8px; z-index: 4; }
</style>
```

```ts
makeSortableList(listRef, { items: photos, strategy: 'grid', overlay: PileOverlay });
```

克隆在拿起时生成：抓起的项，以及按放置顺序与它相邻的最多四个其他项（如果它们已渲染）。对于其他任何项，`DragPreview` 渲染它的默认插槽。预览的尺寸是对应项在拿起时的尺寸，除非你像上面的 `style` 那样设置尺寸（`class` 和 `style` 会透传）。在 `'group'` 和 `'gaps'` 模式下，放置时每个预览都会落到它所对应项的位置上。关于浮层组件的更多内容见[浮层](/docs/guides/overlay)。

## 树 {#trees}

在树中，选中的节点作为一个整体移动，各自带着子树，按文档顺序排列。位于另一个选中节点内部的选中节点，会随父节点的子树一起移动。参见[树](/docs/guides/trees)。
