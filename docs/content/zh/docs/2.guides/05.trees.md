## 扁平渲染 {#rendered-flat}

树被渲染为可见节点按顺序组成的**扁平列表**，每个节点带有自己的 `depth`。行的缩进由你自己处理。这样每一行都是同一个容器中的兄弟元素，因此行可以像列表的行一样滑动和执行动画。

```vue [FileTree.vue]
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { makeSortableTree, type Key } from '@vue-dnd-kit/core';
import TreeRow from './TreeRow.vue';

interface FileNode { id: string; name: string; folder?: boolean; children?: FileNode[] }

const files = ref<FileNode[]>([
  { id: 'src', name: 'src', folder: true, children: [{ id: 'main', name: 'main.ts' }] },
  { id: 'readme', name: 'README.md' },
]);
const collapsed = ref(new Set<Key>());
const INDENT = 18;

const root = useTemplateRef<HTMLElement>('root');
const { items } = makeSortableTree(root, {
  items: files,                                  // the root nodes
  indentation: INDENT,                           // px per level: match your row padding
  collapsed,
  canNest: (_node, parent) => !!parent.folder,   // only folders take children
});

const toggle = (key: Key) => (collapsed.value.has(key) ? collapsed.value.delete(key) : collapsed.value.add(key));
</script>

<template>
  <div ref="root">
    <TreeRow v-for="node in items" :key="node.key" :node="node" :indent="INDENT" @toggle="toggle" />
  </div>
</template>
```

```vue [TreeRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode, type Key } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const emit = defineEmits<{ toggle: [key: Key] }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { id: () => props.node.key });
</script>

<template>
  <div ref="el" :style="{ paddingLeft: `${node.depth * indent}px` }">
    <button
      v-if="node.item.folder"
      type="button"
      :aria-expanded="!node.collapsed"
      :aria-label="node.collapsed ? 'Expand' : 'Collapse'"
      @click="emit('toggle', node.key)"
    >
      {{ node.collapsed ? '▸' : '▾' }}
    </button>
    {{ node.item.name }}
  </div>
</template>
```

行使用 `makeSortableItem`，与列表的行一样。`items` 中是 `FlatNode`：

| `FlatNode` 字段 | 内容 |
| --- | --- |
| `key` | 节点的 key（`getKey`，默认为 `node.id`）。用于 `:key` 和行的 `id`。 |
| `item` | 你的节点。 |
| `depth` | 根节点为 `0`。被拖拽节点的深度是它**将会**落入的深度，因此它的占位会实时缩进。 |
| `parentKey` | 父节点的 key，根节点为 `null`。 |
| `index` | 在兄弟节点中的索引。 |
| `hasChildren`、`collapsed` | 用于展开按钮。 |

子节点从 `node.children` 读取，也写回那里。其他数据结构使用 `getChildren` 和 `setChildren`：

```ts
makeSortableTree(root, {
  items: outline,
  getKey: (node) => node.uuid,
  getChildren: (node) => node.nested,
  setChildren: (node, children) => { node.nested = children; },
});
```

## 嵌套 {#nesting}

拖拽有两种方式改变深度，默认都开启（`nesting: 'both'`）：

- **横向**（`'offset'`）：向左或向右拖动 `indentation` 像素，就上升或下降一级，范围以占位周围的行所允许的为限。
- **悬停**（`'hover'`）：让拖拽停在某一行的中间，放置就会进入这一行，成为它的第一个子节点。

把 `indentation` 设为你的行每一级增加的内边距，这样偏移就能跟随指针。使用 `axis: 'y'` 时拖拽无法横向移动，但行仍然可以通过悬停来嵌套。

## 折叠的节点 {#collapsed-nodes}

`collapsed` 是子节点被隐藏的节点的 key 组成的 `Set`（ref 或 getter）。这些节点的子节点不在 `items` 中。被拖拽的文件夹会带上它的整棵子树，无论是否折叠。开启树的 `animate` 选项后，文件夹显示或隐藏的行会以动画方式进入和离开。

## 规则 {#rules}

| 选项 | 限制 |
| --- | --- |
| `canNest(node, parent)` | `node` 能否放到 `parent` 之下。多项拖拽时，会对每个被拖拽的节点询问。 |
| `maxDepth` | 允许的最大深度，根节点为 `0`。被拖拽节点的后代也计算在内：一个带有子节点和孙节点的文件夹，最多只能到深度 `maxDepth - 2`。 |
| `group.put` | 树是否接收来自其他列表和树的项。 |
| `onBeforeDrop` | 其他任何规则，在放置时决定：参见[决定放置](/docs/guides/drop-decisions)。 |

当规则拒绝某个深度时，占位会采用能通过规则的最大深度。没有任何深度能通过时，占位不会移到那里。副本以及由 `createItem` 创建的节点同样遵循 `canNest` 和 `maxDepth`。

## 同一分组中的树和列表 {#trees-and-lists-in-one-group}

`group` 相同的树和列表会互相交换节点，就像两个列表那样。移进列表的文件夹会保留它的子树，移回来时也带着它。复制的方式与列表相同（`clone`、`pull: 'clone'`、Alt 键），但 `clone` 必须返回**带有整棵子树**的副本，并且其中每个节点都需要新的 key：

```ts
let count = 0;
const copyNode = (node: FileNode): FileNode => ({
  ...node,
  id: `${node.id}-${++count}`,
  children: node.children?.map(copyNode),
});

makeSortableTree(root, { items: files, group: 'files', clone: copyNode });
```

分组、复制和 `createItem` 参见[共享项的列表](/docs/guides/shared-lists)。

## 插入线 {#an-insertion-line}

使用 `placeholder: 'indicator'` 时，树在拖拽期间不会移动。每一行读取自己的 `indicator` 并画出插入线，缩进到放置所落入的深度：

```vue [TreeRow.vue]
<script setup lang="ts">
import { computed, useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const el = useTemplateRef<HTMLElement>('el');
const { indicator } = makeSortableItem(el, { id: () => props.node.key });

// 'inside': the drop goes into this row. Otherwise a line before or after it.
const into = computed(() => indicator.value?.side === 'inside');
const line = computed(() => {
  const value = indicator.value;
  if (!value || value.side === 'inside') return null;
  return { side: value.side, left: `${(value.depth ?? 0) * props.indent}px` };
});
</script>

<template>
  <div ref="el" class="row" :class="{ into }" :style="{ paddingLeft: `${node.depth * indent}px` }">
    {{ node.item.name }}
    <span v-if="line" class="line" :class="line.side" :style="{ left: line.left }" />
  </div>
</template>

<style scoped>
.row { position: relative; }
.row.into { background: color-mix(in srgb, #42b883 15%, transparent); }
.line { position: absolute; right: 0; height: 2px; background: #42b883; }
.line.before { top: -1px; }
.line.after { bottom: -1px; }
</style>
```

在树中，`indicator` 还多了 `depth` 和 `parentKey`：被放下的节点将得到的层级和父节点。横向拖动会让插入线在层级之间移动。在这种模式下，放到树外面会取消拖拽。

## 放置 {#the-drop}

树的放置事件就是列表的放置事件，只是在 `from` 和 `to` 中多了 `parentKey`：

```ts
makeSortableTree(root, {
  items: files,
  onDrop: (e) => {
    console.log(e.keys, e.from.parentKey, '→', e.to.parentKey, e.to.index);
  },
});
```

`to.index` 是在新的兄弟节点中的位置，在节点离开原位置之后计算。放置时，库会给发生变化的节点设置新的子节点（`setChildren`），并把新的根数组写入你的 ref。

`e.result.get(treeId)` 是以新的根数组表示的新树：变化路径上的节点是副本，未受影响的子树是共享的，你的节点保持原样。对于 store 或不可变数据，传入 getter，调用 `e.preventDefault()` 并保存 `e.result`。副本由 `withChildren(node, children)` 创建，默认是带有新子节点的 `{ ...node }`；对于类实例，传入你自己的实现。

## 键盘与多项拖拽 {#keyboard-and-multi-drag}

使用键盘时，:kbd{value="ArrowUp"} 和 :kbd{value="ArrowDown"} 在行之间移动，:kbd{value="ArrowLeft"} 和 :kbd{value="ArrowRight"} 在周围的行允许的范围内改变深度。

选中的节点作为一个整体一起移动，各自带着子树，按文档顺序排列。位于另一个选中节点内部的选中节点，会随父节点的子树一起移动。参见[多项拖拽](/docs/guides/multi-drag)。

所有选项见 [makeSortableTree API](/docs/api/make-sortable-tree)。有成千上万行的树，参见[虚拟列表](/docs/guides/virtual-lists)。
