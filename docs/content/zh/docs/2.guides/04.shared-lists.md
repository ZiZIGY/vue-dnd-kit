## 分组 {#a-group}

`group` 名称相同的列表会互相交换项。默认情况下，每个列表自成一组。

```vue [Column.vue]
<script setup lang="ts">
import { toRef, useTemplateRef } from 'vue';
import { makeSortableList } from '@vue-dnd-kit/core';
import Card from './Card.vue';

type Task = { id: string; title: string };
const props = defineProps<{ column: { id: string; title: string; cards: Task[] } }>();

const zone = useTemplateRef<HTMLElement>('zone');
const list = useTemplateRef<HTMLElement>('list');
const { items, isOver } = makeSortableList(list, {
  id: props.column.id,                   // names the list in drop events
  items: toRef(props.column, 'cards'),   // a writable ref into the reactive column
  group: 'board',                        // same name: cards move between these lists
  dropzone: zone,                        // the whole column takes drops
});
</script>

<template>
  <section ref="zone" :class="{ over: isOver }">
    <h3>{{ column.title }}</h3>
    <ul ref="list">
      <Card v-for="card in items" :key="card.id" :card="card" />
    </ul>
  </section>
</template>
```

```vue [Board.vue]
<script setup lang="ts">
import { reactive } from 'vue';
import Column from './Column.vue';

const columns = reactive([
  { id: 'todo', title: 'To do', cards: [{ id: 'vdk-12', title: 'Pick a palette' }] },
  { id: 'done', title: 'Done', cards: [] },
]);
</script>

<template>
  <Column v-for="column in columns" :key="column.id" :column="column" />
</template>
```

- 每一列都是一个独立的组件：每个组件一个列表。
- `toRef(props.column, 'cards')` 是可写的，因为父组件传入的是响应式对象。放置会写入两个数组：卡片离开的那个，和它进入的那个。
- `id` 在放置事件中表现为 `from.list` 和 `to.list`，同时也是 `e.result` 的键，`e.result` 包含这次放置改变的每个列表的新数组。`id` 和 `group` 只读取一次。
- 在整个分组中，key 必须唯一。

列表的 `onDrop` 只在有项放**进**它时运行。从 `todo` 移到 `done` 会调用 `done` 列表的 `onDrop`，它的 `e.result` 中包含两个列表的新数组。

## 整列接收放置：`dropzone` {#the-whole-column-takes-drops-dropzone}

高列里的短列表会在最后一张卡片下方留出空白。使用 `dropzone: zone` 后，由列的元素替列表接收放置：在最后一张卡片下方松开的卡片会落到末尾。卡片仍然在 `<ul>` 中；变大的只是接收放置的区域。

::tip
没有 `dropzone` 时，空列表仍然需要有尺寸才能接收放置：给它设置 `min-height`。
::

## 什么能进、什么能出：`pull` 和 `put` {#what-goes-in-and-out-pull-and-put}

`group` 也可以接收一个对象：

```ts
group: { name: 'board', pull: true, put: true }
```

| 选项 | 取值 |
| --- | --- |
| `pull` | `true`（默认）：项可以离开。`false`：不能离开。`'clone'`：离开的是副本，项本身留下。 |
| `put` | `true`（默认）：项可以进入。`false`：什么都不能进入。函数：由你针对每次拖拽决定。 |

`put` 函数会收到 `{ keys, items, types, from, to }`。`from` 是项来自的列表，对于普通的可拖拽元素为 `null`。列表内部的移动总是允许的。

### 数量限制 {#limits}

一个最多容纳三张卡片的列：

```ts
makeSortableList(list, {
  id: props.column.id,
  items: toRef(props.column, 'cards'),
  group: {
    name: 'board',
    put: ({ keys }) => props.column.cards.length + keys.length <= 3,
  },
});
```

在拒绝这次拖拽的列表上方，占位会回到拖拽开始的地方，于是各列表显示的正是放置的结果：什么都不变。在那里放下会被取消，卡片飞回原处。在这样的拖拽期间，该列表的 `isAccepting` 为 `false`：可以用它把这一列调暗。

拖拽多个不同类型的选中项时，`acceptMode` 规定是全部（`'all'`，默认）还是部分（`'some'`）项必须通过 `put`。使用 `'some'` 时，通过的项会落下，其他的飞回原处。

## 复制：面板与 Alt 键 {#copy-palettes-and-the-alt-key}

::example{name="palette" hint="从面板中拖出；按住 Alt 拖动会复制；拖到页面外即可删除" height="24rem"}
::

```ts [Palette.vue]
makeSortableList(list, {
  items: templates,
  group: { name: 'blocks', pull: 'clone', put: false },  // copies go out, nothing comes in
  sort: false,                                           // its own order stays
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),
});
```

```ts [Sheet.vue]
makeSortableList(list, {
  items: blocks,
  group: 'blocks',
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),  // for Alt-drags
});
```

- `pull: 'clone'` 会复制从这个列表拖出的每一次拖拽。原项留下，副本被拖走并落下。
- 拖拽时按住 :kbd{value="Alt"} 也会复制，任何列表都可以。用 provider 的 `copyModifier` 更换按键，或设为 `null` 关闭这一功能。
- 无论哪种方式，项所来自的列表都需要 `clone`。它必须返回带有**新 key** 的副本。没有 `clone` 就不会复制任何东西。
- 放置事件带有 `mode: 'copy'`，`e.items` 是副本。浮层组件也会收到 `mode`，可以在复制时显示一个“+”（参见[浮层](/docs/guides/overlay)）。

## 把普通可拖拽元素放进列表 {#plain-draggables-into-a-list}

只要列表知道如何从用 `makeDraggable` 拖拽的元素创建项，它就能接收这些元素：

```ts
makeSortableList(list, {
  items: tasks,
  createItem: (active) => ({ id: crypto.randomUUID(), title: (active.data as Chip).title }),
});
```

当可拖拽元素位于列表上方时，创建出的项会放在草稿中，像其他行一样由你的模板渲染。放置时它才成为真正的项（`mode: 'insert'`，`from.list === null`）。返回 `undefined` 表示拒绝。没有 `createItem` 的列表会忽略普通的可拖拽元素。使用键盘时，朝列表方向按方向键即可把可拖拽元素放进去。

## 交换而非平移 {#swap-instead-of-shift}

```ts
makeSortableList(grid, { items: tiles, strategy: 'grid', behavior: 'swap' });
```

被拖拽的项与它下方的项交换位置，其他项保持不动。交换是实时的：移回去或移出列表都会撤销它。放置事件带有 `mode: 'swap'` 和 `partner`，即与之交换的那个项。

- 同一分组的两个列表都设置了 `behavior: 'swap'` 时，它们之间可以互相交换。被悬停的项会移到另一个列表中，因此它必须被允许离开（`pull: true`）和进入（`put`）。
- 多项拖拽会排序，而不是交换。

## 插入线 {#an-insertion-line}

使用 `placeholder: 'indicator'` 时，列表在拖拽期间保持不动，由一条线标出放置的位置。这条线由你来画：

```ts [TaskList.vue]
const { items, indicator } = makeSortableList(listRef, { items: tasks, placeholder: 'indicator' });
```

```vue [TaskRow.vue]
<script setup lang="ts">
const { indicator } = makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el" :class="indicator && `drop-${indicator.side}`">{{ task.title }}</li>
</template>

<style scoped>
.drop-before { box-shadow: inset 0 2px 0 #42b883; }
.drop-after { box-shadow: inset 0 -2px 0 #42b883; }
</style>
```

| `indicator` 字段 | 内容 |
| --- | --- |
| `list` | 放置的目标列表。 |
| `index` | 在渲染出的列表中的插入索引。 |
| `key` | 插入线所依附的项；在空列表中为 `null`（此时把线画在列表上）。 |
| `side` | 在该项之前（`'before'`）或之后（`'after'`）。树还会有 `'inside'`。 |
| `depth`、`parentKey` | 仅用于树：放置落在哪里。参见[树](/docs/guides/trees#an-insertion-line)。 |

插入线位于某个列表中时，该列表的 `indicator` 有值；插入线依附于某个项时，该项的 `indicator` 有值。键盘也可以移动插入线。

## 放到外面 {#dropping-outside}

拖拽结束时下方没有任何目标会发生什么，由列表的 `dropOutside` 决定：

| `dropOutside` | 这些项 |
| --- | --- |
| `'placeholder'`（默认） | 落到占位最后显示的位置。 |
| `'cancel'` | 飞回原处。使用 `placeholder: 'indicator'` 时的默认值。 |
| `'remove'` | 离开它们的列表：拖出去即删除。 |

`'remove'` 会先询问列表的 `onBeforeDrop`。随后列表的 `onDrop` 以 `to.index === -1` 运行，`e.result` 中是去掉这些项之后的列表。接收放置的垃圾桶也是同样的原理：参见[回收区](/docs/guides/drag-and-drop#trash-zones)。

如果要确认一次移动、先保存到服务器，或自己把放置结果应用到 store，参见[决定放置](/docs/guides/drop-decisions)。所有列表选项见 [makeSortableList API](/docs/api/make-sortable-list)。
