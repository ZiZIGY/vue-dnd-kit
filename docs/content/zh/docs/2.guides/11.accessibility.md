本页的所有功能都默认开启。用 Tab 聚焦到一首曲目的拖拽手柄，按 :kbd{value="Space"}，用方向键移动它，再按一次 :kbd{value="Space"}——或者按 :kbd{value="Escape"} 把它放回原处。

::example{name="lists" hint="Tab 到手柄，Space，方向键，Space" height="28rem"}
::

通常留给你做的是：给项起易读的名称，以及为完全无法拖拽的人提供移动项的按钮。

## 键盘 {#the-keyboard}

| 按键 | 操作 |
| --- | --- |
| :kbd{value="Space"} / :kbd{value="Enter"} | 拿起获得焦点的项；放下它。 |
| 方向键 | 移动它：在列表中逐个位置移动，在树中按行和深度移动，在自由拖拽中每次移动 `keyboard.step` 像素。 |
| :kbd{value="Escape"} | 取消拖拽——指针拖拽也可以。 |

- 在列表中，朝同一分组另一个列表的方向按方向键，会把项移到那里。
- 在自由拖拽中，:kbd{value="Shift"} 会让步长变大。`makeDraggable(el, { keyboard: 'droppables' })` 会让方向键改为在接收该项的目标之间跳转。
- 键盘拖拽从获得焦点的可拖拽元素或它的手柄开始——绝不会从其中的按钮或表单字段开始，因此它们保留自己的按键行为。
- 键盘拖拽会把目标滚动到视野中，而不是在边缘自动滚动。
- 放置后，焦点会回到这个项上，即使它的行已在另一个列表中重新渲染。

### 其他按键 {#other-keys}

```vue
<DnDProvider :keyboard="{ keys: { start: ['KeyD'], drop: ['KeyD', 'Enter'], cancel: ['Escape'] }, step: 10 }">
```

按键绑定匹配 `event.code`（`'Space'`、`'KeyD'`）或 `event.key`（`'Enter'`）。`step` 是自由拖拽中每按一次方向键移动的像素数（默认 25）。`:keyboard="false"` 关闭键盘拖拽，而 :kbd{value="Escape"} 仍然可以取消任何拖拽。修改按键时，也要同时修改 `screen-reader-instructions`。

## ARIA 属性 {#aria-attributes}

每个可拖拽元素和可排序项都会得到以下属性，**除非你自己设置了它们**：

| 属性 | 值 |
| --- | --- |
| `tabindex` | `0`，当元素本身不可聚焦时。 |
| `role` | `button`，`<button>` 除外，因为它本来就是按钮。 |
| `aria-roledescription` | `draggable`，可排序项上为 `sortable`。 |
| `aria-describedby` | provider 的操作说明，添加在已有的 id 旁边（提示框的 id 会保留）。 |
| `aria-disabled` | `true` 或 `false`：该项是否被禁用（包括被禁用的拖拽区域所禁用）。 |
| `aria-pressed` | 被拖拽时为 `true`。 |

`attributes: false` 会为某个项关闭这些属性；库已经设置的会被移除。

### 拖拽手柄：做成真正的按钮 {#handles-make-them-real-buttons}

```vue [Track.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ track: { id: string; title: string } }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { item: () => props.track, handle: '.grip' });
</script>

<template>
  <li ref="el" class="track">
    {{ track.title }}
    <button type="button" class="grip" :aria-label="`Move ${track.title}`">⠿</button>
  </li>
</template>
```

使用 `handle` 时，这些属性会加在手柄上，键盘拖拽也从它开始。`<button>` 本身可聚焦，也本来就是按钮，所以不需要 `tabindex` 或 `role`。给它一个 `aria-label`：拖拽手柄图标本身没有名称，而“Move Midnight Drive”比“button”提供的信息更多。

## 播报 {#announcements}

provider 中的实时区域会播报每一次拿起、移动、放置和取消。可排序列表会说明项所在的位置：*“Picked up item t2 at position 2 of 5 in list playlist.”* 移动会在拖拽停留 500 ms 后播报。

这些文本使用的是 id。给项起易读的 id，或者自己编写文本：

```ts
import type { Announcements, Key } from '@vue-dnd-kit/core';

const title = (id: Key) => tasks.value.find((task) => task.id === id)?.title ?? String(id);

const announcements: Partial<Announcements> = {
  onDragStart: ({ active }) => `Picked up ${title(active.id)}.`,
  onDragEnd: ({ active, dropped }) => (dropped ? `Dropped ${title(active.id)}.` : undefined),
  onDragCancel: ({ active }) => `${title(active.id)} went back to its place.`,
  onDragResume: ({ active }) => `${title(active.id)} was not dropped. It is still moving.`,
};
```

```vue
<DnDProvider :announcements="announcements" screen-reader-instructions="Press D to pick up a card…">
```

- 文本会替换该事件的播报；`undefined` 保留默认值；`''` 则什么都不播报。你没有写的事件也保留默认值，比如上面 `onDragOver` 中可排序列表的位置播报。
- 当 `onBeforeDrop` 返回 `'continue'`、拖拽继续时，会播报 `onDragResume`（参见[决定放置](/docs/guides/drop-decisions)）。
- `screenReaderInstructions` 是每个可拖拽元素通过 `aria-describedby` 指向的文本。
- `:announcements="false"` 让实时区域保持静默，例如当你通过自己的实时区域播报时。

::note
内置文本是英文的。如果要用其他语言，请提供全部五段文本和操作说明——你遗漏的每一段都会用英文播报，包括可排序列表的位置。
::

## 触摸 {#touch}

触摸拖拽在 200 ms 长按之后开始。在此之前移动超过 5 px 会改为滚动页面，所以列表仍然可以滚动。用 `activation` 调整这两个值（参见[传感器](/docs/guides/sensors#activation-constraints)），并可以根据 `useDnD().activation.progress` 画一个长按进度环。

触摸拖拽开始时会短暂振动。`:haptics="false"` 关闭振动；传入对象可以在进入目标、放下或被拒绝时添加振动：

```vue
<DnDProvider :haptics="{ start: true, enter: 10, drop: 10, refuse: [20, 40, 20] }">
```

只有触摸拖拽会振动，而 iOS Safari 完全无法振动。

## 减弱动态效果 {#reduced-motion}

设置了 `prefers-reduced-motion: reduce` 时，库自己的动画不会运行。你的动画函数仍然会运行，并收到 `reducedMotion: true`。参见[动画](/docs/guides/animations)。

## 无需拖拽的移动 {#moving-without-dragging}

有些人完全无法拖拽。WCAG 2.5.7 要求提供一种通过单击来移动项的方式，比如“上移”按钮。`@vue-dnd-kit/actions` 让每个这样的按钮都执行一次真正的移动：

```bash
npm i @vue-dnd-kit/actions
```

```vue [TaskRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';
import { useDnDActions } from '@vue-dnd-kit/actions';

const props = defineProps<{ task: { id: string; title: string }; count: number }>();
const el = useTemplateRef<HTMLElement>('el');
const { index } = makeSortableItem(el, { item: () => props.task });
const { moveItem } = useDnDActions();
</script>

<template>
  <li ref="el">
    {{ task.title }}
    <button type="button" :disabled="index === 0" @click="moveItem(task.id, { index: index - 1 })">
      Move up
    </button>
    <button type="button" :disabled="index === count - 1" @click="moveItem(task.id, { index: index + 1 })">
      Move down
    </button>
    <button type="button" @click="moveItem(task.id, { list: 'done' })">Move to Done</button>
  </li>
</template>
```

`moveItem` 从头到尾执行一次键盘拖拽：它会被播报、经过 `onBeforeDrop` 和 `onDrop`、执行动画，并让焦点保持在该项上。放置成功时它 resolve 为 `true`。`index` 计算位置时不包含项本身，所以“下移”是 `index + 1`。更多内容见[传感器与程序化拖拽](/docs/guides/sensors#programmatic-drags)。
