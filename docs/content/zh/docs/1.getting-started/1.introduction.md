## 它是什么 {#what-it-is}

Vue DnD Kit 是一组**组合式函数**加上一个 **provider** 组件。你渲染自己的元素，把它们的模板引用交给组合式函数，剩下的交给库来处理：指针、触摸和键盘输入，查找目标，重新排序，动画，自动滚动，以及告诉屏幕阅读器发生了什么。

除了一个浮动的**浮层**之外，它自己什么都不渲染——浮层默认是被拖拽元素的克隆。你的标记和样式仍然是你的。

## 你能得到什么 {#what-you-get}

- **可排序的列表和网格**，拖拽时实时重新排序。你渲染数组的*草稿*；放置时，库会把新的顺序写入你的 ref。
- **看板**：同一分组的列表互相交换项。可以从面板复制、接收普通的可拖拽元素、用交换代替平移。
- **树**：通过水平偏移或悬停在某一行上来嵌套，支持深度限制和规则。
- **多项拖拽**，使用你自己的选择方式（Ctrl 点击、框选）：整组项一起移动。
- **默认带动画**：项滑动到新位置，放置时落到它的位置上。
- **无障碍**：键盘按位置逐个拖拽、实时播报、ARIA 属性。
- **虚拟列表**：TanStack Virtual 和 VueUse，成千上万行。
- **受控模式**，适用于 store 和服务端：跳过默认写入，自己应用结果。

## 各部分如何配合 {#how-it-fits-together}

| 部分 | 作用 |
| --- | --- |
| `DnDProvider` | 掌管拖拽：输入、浮层、选中集合、自动滚动、播报。 |
| `makeSortableList` / `makeSortableItem` | 可重新排序的列表，以及它的行。 |
| `makeSortableTree` | 以带深度的扁平形式渲染的树。 |
| `makeDraggable` / `makeDroppable` | 自由拖拽和放置区。 |
| `makeDragArea` | 页面某一部分的规则：轴、边界、吸附、自动滚动。 |
| `makeSelectionArea` | 框选。 |
| `useDnD` / `useDnDMonitor` | 拖拽状态及其事件，在 provider 之下的任何地方都可使用。 |

::tip
从 v2 迁移过来？API 有变化：`useDnDProvider` 变成了 `useDnD`，`makeConstraintArea` 和 `makeAutoScroll` 合并成了 `makeDragArea`。可排序列表现在是内置的。
::

## 环境要求 {#requirements}

- Vue **3.5** 或更高版本。
- 现代浏览器：Chrome 和 Edge 104+、Safari 15.4+、Firefox 104+。
- 支持 SSR 和 Nuxt：浮层和实时区域只在客户端挂载。
