## Renderizado en plano {#rendered-flat}

Un árbol se renderiza como una **lista plana** de los nodos visibles, en orden, cada uno con su
`depth`. La sangría de las filas la pones tú. Así todas las filas son hermanas dentro de un mismo
contenedor, y se deslizan y se animan como las filas de una lista.

```vue [FileTree.vue]
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { makeSortableTree, type Key } from '@vue-dnd-kit/core';
import TreeRow from './TreeRow.vue';

interface FileNode { id: string; name: string; folder?: boolean; children?: FileNode[] }

const files = ref<FileNode[]>([
  { id: 'src', name: 'src', folder: true, children: [{ id: 'main', name: 'main.ts' }] },
  { id: 'readme', name: 'README.md' },
]);
const collapsed = ref(new Set<Key>());
const INDENT = 18;

const root = useTemplateRef<HTMLElement>('root');
const { items } = makeSortableTree(root, {
  items: files,                                  // the root nodes
  indentation: INDENT,                           // px per level: match your row padding
  collapsed,
  canNest: (_node, parent) => !!parent.folder,   // only folders take children
});

const toggle = (key: Key) => (collapsed.value.has(key) ? collapsed.value.delete(key) : collapsed.value.add(key));
</script>

<template>
  <div ref="root">
    <TreeRow v-for="node in items" :key="node.key" :node="node" :indent="INDENT" @toggle="toggle" />
  </div>
</template>
```

```vue [TreeRow.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode, type Key } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const emit = defineEmits<{ toggle: [key: Key] }>();
const el = useTemplateRef<HTMLElement>('el');
makeSortableItem(el, { id: () => props.node.key });
</script>

<template>
  <div ref="el" :style="{ paddingLeft: `${node.depth * indent}px` }">
    <button
      v-if="node.item.folder"
      type="button"
      :aria-expanded="!node.collapsed"
      :aria-label="node.collapsed ? 'Expand' : 'Collapse'"
      @click="emit('toggle', node.key)"
    >
      {{ node.collapsed ? '▸' : '▾' }}
    </button>
    {{ node.item.name }}
  </div>
</template>
```

Las filas usan `makeSortableItem`, como las filas de una lista. `items` contiene `FlatNode`:

| Campo de `FlatNode` | Qué contiene |
| --- | --- |
| `key` | La clave del nodo (`getKey`, por defecto `node.id`). Úsala para `:key` y para el `id` de la fila. |
| `item` | Tu nodo. |
| `depth` | `0` para las raíces. La profundidad del nodo arrastrado es donde **aterrizaría**, así que su hueco cambia de sangría en vivo. |
| `parentKey` | La clave del padre, `null` para las raíces. |
| `index` | El índice entre sus hermanos. |
| `hasChildren`, `collapsed` | Para el botón de expandir. |

Los hijos se leen de `node.children` y se escriben ahí. Para otras estructuras, usa `getChildren` y
`setChildren`:

```ts
makeSortableTree(root, {
  items: outline,
  getKey: (node) => node.uuid,
  getChildren: (node) => node.nested,
  setChildren: (node, children) => { node.nested = children; },
});
```

## Anidamiento {#nesting}

Un arrastre cambia la profundidad de dos formas, ambas activadas por defecto (`nesting: 'both'`):

- **Hacia un lado** (`'offset'`): arrastra a la izquierda o a la derecha `indentation` píxeles para
  subir o bajar un nivel, hasta donde lo permitan las filas alrededor del hueco.
- **Pasando por encima** (`'hover'`): mantén el arrastre sobre el centro de una fila y el drop irá
  dentro de ella, como su primer hijo.

Ajusta `indentation` al padding que añaden tus filas por nivel, para que el desplazamiento siga al
puntero. Con `axis: 'y'` el arrastre no puede moverse hacia los lados, pero las filas se siguen
anidando al pasar por encima.

## Nodos plegados {#collapsed-nodes}

`collapsed` es un `Set` de claves cuyos hijos están ocultos (una ref o un getter). Sus hijos no
están en `items`. Una carpeta arrastrada se lleva todo su subárbol, plegado o no. Con la opción
`animate` del árbol activada, las filas que una carpeta muestra u oculta aparecen y desaparecen
con animación.

## Reglas {#rules}

| Opción | Qué limita |
| --- | --- |
| `canNest(node, parent)` | Si `node` puede ir bajo `parent`. Un multi-drag pregunta por cada nodo arrastrado. |
| `maxDepth` | La profundidad máxima permitida, siendo `0` las raíces. Los descendientes del nodo arrastrado cuentan: una carpeta con hijos y nietos llega como mucho a la profundidad `maxDepth - 2`. |
| `group.put` | Si el árbol acepta ítems de otras listas y árboles. |
| `onBeforeDrop` | Cualquier otra cosa, decidida al soltar: consulta [decidir un drop](/docs/guides/drop-decisions). |

Cuando una regla rechaza una profundidad, el hueco toma la mayor profundidad que sí pasa. Donde
no pasa ninguna, el hueco no se mueve ahí. Las copias y los nodos creados con `createItem` también
respetan `canNest` y `maxDepth`.

## Árboles y listas en un mismo grupo {#trees-and-lists-in-one-group}

Un árbol y una lista con el mismo `group` intercambian nodos, igual que dos listas. Una carpeta
movida a la lista conserva su subárbol y vuelve con él. Las copias funcionan como en las listas
(`clone`, `pull: 'clone'`, la tecla Alt), pero `clone` debe devolver la copia **con todo su
subárbol**, y cada nodo dentro de ella necesita una clave nueva:

```ts
let count = 0;
const copyNode = (node: FileNode): FileNode => ({
  ...node,
  id: `${node.id}-${++count}`,
  children: node.children?.map(copyNode),
});

makeSortableTree(root, { items: files, group: 'files', clone: copyNode });
```

Consulta [listas que comparten ítems](/docs/guides/shared-lists) para los grupos, la copia y
`createItem`.

## Una línea de inserción {#an-insertion-line}

Con `placeholder: 'indicator'`, el árbol no se mueve mientras arrastras. Cada fila lee su
`indicator` y dibuja la línea, con la sangría de la profundidad en la que aterriza el drop:

```vue [TreeRow.vue]
<script setup lang="ts">
import { computed, useTemplateRef } from 'vue';
import { makeSortableItem, type FlatNode } from '@vue-dnd-kit/core';

const props = defineProps<{ node: FlatNode<FileNode>; indent: number }>();
const el = useTemplateRef<HTMLElement>('el');
const { indicator } = makeSortableItem(el, { id: () => props.node.key });

// 'inside': the drop goes into this row. Otherwise a line before or after it.
const into = computed(() => indicator.value?.side === 'inside');
const line = computed(() => {
  const value = indicator.value;
  if (!value || value.side === 'inside') return null;
  return { side: value.side, left: `${(value.depth ?? 0) * props.indent}px` };
});
</script>

<template>
  <div ref="el" class="row" :class="{ into }" :style="{ paddingLeft: `${node.depth * indent}px` }">
    {{ node.item.name }}
    <span v-if="line" class="line" :class="line.side" :style="{ left: line.left }" />
  </div>
</template>

<style scoped>
.row { position: relative; }
.row.into { background: color-mix(in srgb, #42b883 15%, transparent); }
.line { position: absolute; right: 0; height: 2px; background: #42b883; }
.line.before { top: -1px; }
.line.after { bottom: -1px; }
</style>
```

En los árboles, `indicator` añade `depth` y `parentKey`: el nivel y el padre que reciben los nodos
soltados. Arrastrar hacia un lado mueve la línea entre niveles. En este modo, soltar fuera del
árbol cancela el arrastre.

## El drop {#the-drop}

El evento de drop del árbol es el de una lista, con `parentKey` añadido a `from` y `to`:

```ts
makeSortableTree(root, {
  items: files,
  onDrop: (e) => {
    console.log(e.keys, e.from.parentKey, '→', e.to.parentKey, e.to.index);
  },
});
```

`to.index` es la posición entre los nuevos hermanos, contada después de que el nodo haya dejado su
sitio anterior. Al soltar, la biblioteca da a los nodos modificados sus nuevos hijos
(`setChildren`) y escribe un nuevo array de raíces en tu ref.

`e.result.get(treeId)` es el nuevo árbol como un nuevo array de raíces: los nodos de las rutas
modificadas son copias, los subárboles intactos se comparten y tus nodos se quedan como están. Para
un store o datos inmutables, pasa un getter, llama a `e.preventDefault()` y guarda `e.result`. Las
copias se hacen con `withChildren(node, children)`, que por defecto es `{ ...node }` con los nuevos
hijos; pasa la tuya para instancias de clases.

## Teclado y multi-drag {#keyboard-and-multi-drag}

Con el teclado, :kbd{value="ArrowUp"} y :kbd{value="ArrowDown"} se mueven entre filas, y
:kbd{value="ArrowLeft"} y :kbd{value="ArrowRight"} cambian la profundidad donde las filas de
alrededor lo permiten.

Los nodos seleccionados se mueven juntos como un solo bloque, cada uno con su subárbol, en el orden
del documento. Un nodo seleccionado dentro de otro nodo seleccionado viaja dentro del subárbol de
su padre. Consulta [multi-drag](/docs/guides/multi-drag).

Todas las opciones están en la [API de makeSortableTree](/docs/api/make-sortable-tree). Para
árboles con miles de filas, consulta [listas virtuales](/docs/guides/virtual-lists).
