## Un grupo {#a-group}

Las listas con el mismo nombre de `group` intercambian ítems. Por defecto, cada lista es un grupo
propio.

```vue [Column.vue]
<script setup lang="ts">
import { toRef, useTemplateRef } from 'vue';
import { makeSortableList } from '@vue-dnd-kit/core';
import Card from './Card.vue';

type Task = { id: string; title: string };
const props = defineProps<{ column: { id: string; title: string; cards: Task[] } }>();

const zone = useTemplateRef<HTMLElement>('zone');
const list = useTemplateRef<HTMLElement>('list');
const { items, isOver } = makeSortableList(list, {
  id: props.column.id,                   // names the list in drop events
  items: toRef(props.column, 'cards'),   // a writable ref into the reactive column
  group: 'board',                        // same name: cards move between these lists
  dropzone: zone,                        // the whole column takes drops
});
</script>

<template>
  <section ref="zone" :class="{ over: isOver }">
    <h3>{{ column.title }}</h3>
    <ul ref="list">
      <Card v-for="card in items" :key="card.id" :card="card" />
    </ul>
  </section>
</template>
```

```vue [Board.vue]
<script setup lang="ts">
import { reactive } from 'vue';
import Column from './Column.vue';

const columns = reactive([
  { id: 'todo', title: 'To do', cards: [{ id: 'vdk-12', title: 'Pick a palette' }] },
  { id: 'done', title: 'Done', cards: [] },
]);
</script>

<template>
  <Column v-for="column in columns" :key="column.id" :column="column" />
</template>
```

- Cada columna es un componente propio: una lista por componente.
- `toRef(props.column, 'cards')` es escribible porque el padre pasa un objeto reactivo. El drop
  escribe en los dos arrays, el que la tarjeta dejó y en el que entró.
- `id` aparece en los eventos de drop como `from.list` y `to.list`, y es la clave de `e.result`,
  los nuevos arrays de cada lista que cambia el drop. `id` y `group` se leen una sola vez.
- Las claves deben ser únicas en todo el grupo.

El `onDrop` de una lista se ejecuta para los drops **dentro** de ella. Un movimiento de `todo` a
`done` llama al `onDrop` de la lista `done`, y su `e.result` contiene los nuevos arrays de ambas
listas.

## Toda la columna acepta drops: `dropzone` {#the-whole-column-takes-drops-dropzone}

Una lista corta en una columna alta deja espacio vacío debajo de la última tarjeta. Con
`dropzone: zone`, el elemento de la columna recibe los drops de la lista: una tarjeta que se suelta
debajo de la última aterriza al final. Las tarjetas se quedan en el `<ul>`; solo crece la zona que
recibe los drops.

::tip
Sin `dropzone`, una lista vacía sigue necesitando un tamaño para recibir drops: dale un
`min-height`.
::

## Qué entra y qué sale: `pull` y `put` {#what-goes-in-and-out-pull-and-put}

`group` también acepta un objeto:

```ts
group: { name: 'board', pull: true, put: true }
```

| Opción | Valores |
| --- | --- |
| `pull` | `true` (por defecto): los ítems pueden salir. `false`: no pueden. `'clone'`: salen copias y los ítems se quedan. |
| `put` | `true` (por defecto): los ítems pueden entrar. `false`: no entra nada. Una función: decides en cada arrastre. |

Una función `put` recibe `{ keys, items, types, from, to }`. `from` es la lista de la que vienen los
ítems, `null` para elementos arrastrables simples. Los movimientos dentro de una lista siempre están
permitidos.

### Límites {#limits}

Una columna que admite como máximo tres tarjetas:

```ts
makeSortableList(list, {
  id: props.column.id,
  items: toRef(props.column, 'cards'),
  group: {
    name: 'board',
    put: ({ keys }) => props.column.cards.length + keys.length <= 3,
  },
});
```

Sobre una lista que rechaza el arrastre, el hueco vuelve a donde empezó el arrastre, así que las
listas muestran lo que haría un drop: nada. Un drop ahí se cancela y la tarjeta vuelve a su sitio.
El `isAccepting` de la lista es `false` durante ese arrastre: úsalo para atenuar la columna.

Cuando se arrastran varios ítems seleccionados de tipos distintos, `acceptMode` indica si deben
pasar `put` `'all'` (por defecto) o solo `'some'`. Con `'some'`, los que pasan aterrizan y los demás
vuelven a su sitio.

## Copiar: paletas y la tecla Alt {#copy-palettes-and-the-alt-key}

::example{name="palette" hint="Arrastra desde la paleta; Alt + arrastrar copia; suelta fuera de la página para eliminar" height="24rem"}
::

```ts [Palette.vue]
makeSortableList(list, {
  items: templates,
  group: { name: 'blocks', pull: 'clone', put: false },  // copies go out, nothing comes in
  sort: false,                                           // its own order stays
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),
});
```

```ts [Sheet.vue]
makeSortableList(list, {
  items: blocks,
  group: 'blocks',
  clone: (block) => ({ ...block, id: crypto.randomUUID() }),  // for Alt-drags
});
```

- `pull: 'clone'` copia cada arrastre que sale de la lista. El original se queda, y la copia viaja
  y aterriza.
- Mantener :kbd{value="Alt"} mientras arrastras también copia, desde cualquier lista. Cambia la
  tecla con el `copyModifier` del provider, o desactívala con `null`.
- En ambos casos, la lista de la que viene el ítem necesita `clone`. Debe devolver la copia con una
  **clave nueva**. Sin `clone`, no se copia nada.
- El evento de drop tiene `mode: 'copy'`, y `e.items` son las copias. Un componente de overlay
  también recibe `mode`, para mostrar un «+» mientras se copia (consulta [el overlay](/docs/guides/overlay)).

## Elementos arrastrables simples dentro de una lista {#plain-draggables-into-a-list}

Una lista acepta ítems arrastrados con `makeDraggable` cuando sabe crear un ítem a partir de ellos:

```ts
makeSortableList(list, {
  items: tasks,
  createItem: (active) => ({ id: crypto.randomUUID(), title: (active.data as Chip).title }),
});
```

Mientras el elemento arrastrable está sobre la lista, el ítem creado está en el borrador y tu
template lo renderiza como cualquier otra fila. Se vuelve real al soltar (`mode: 'insert'`,
`from.list === null`). Devuelve `undefined` para rechazarlo. Las listas sin `createItem` ignoran los
elementos arrastrables simples. Con el teclado, una flecha hacia la lista mete en ella el elemento
arrastrable.

## Intercambiar en lugar de desplazar {#swap-instead-of-shift}

```ts
makeSortableList(grid, { items: tiles, strategy: 'grid', behavior: 'swap' });
```

El ítem arrastrado intercambia su sitio con el que tiene debajo, y los demás no se mueven. El
intercambio es en vivo: volver atrás, o salir de la lista, lo deshace. El evento de drop tiene
`mode: 'swap'` y `partner`, el ítem con el que se intercambió.

- Dos listas de un mismo grupo intercambian entre sí cuando ambas tienen `behavior: 'swap'`. El ítem
  sobre el que se pasa se mueve a la otra lista, así que debe poder salir (`pull: true`) y entrar
  (`put`).
- Un multi-drag ordena en lugar de intercambiar.

## Una línea de inserción {#an-insertion-line}

Con `placeholder: 'indicator'`, la lista se queda quieta mientras arrastras y una línea muestra
dónde irá el drop. La línea la dibujas tú:

```ts [TaskList.vue]
const { items, indicator } = makeSortableList(listRef, { items: tasks, placeholder: 'indicator' });
```

```vue [TaskRow.vue]
<script setup lang="ts">
const { indicator } = makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el" :class="indicator && `drop-${indicator.side}`">{{ task.title }}</li>
</template>

<style scoped>
.drop-before { box-shadow: inset 0 2px 0 #42b883; }
.drop-after { box-shadow: inset 0 -2px 0 #42b883; }
</style>
```

| Campo de `indicator` | Qué contiene |
| --- | --- |
| `list` | La lista en la que entra el drop. |
| `index` | El índice de inserción en la lista tal como se renderiza. |
| `key` | El ítem al que está unida la línea; `null` en una lista vacía (en ese caso, dibújala en la lista). |
| `side` | `'before'` o `'after'` respecto a ese ítem. Los árboles añaden `'inside'`. |
| `depth`, `parentKey` | Solo árboles: dónde aterriza el drop. Consulta [árboles](/docs/guides/trees#an-insertion-line). |

El `indicator` de la lista tiene valor mientras la línea está en esa lista, y el `indicator` de un
ítem mientras está unida a ese ítem. El teclado también mueve la línea.

## Soltar fuera {#dropping-outside}

Lo que pasa cuando un arrastre termina sin ningún destino debajo lo decide el `dropOutside` de la
lista:

| `dropOutside` | Los ítems |
| --- | --- |
| `'placeholder'` (por defecto) | Aterrizan donde se mostró el hueco por última vez. |
| `'cancel'` | Vuelven a su sitio. Es el valor por defecto con `placeholder: 'indicator'`. |
| `'remove'` | Salen de su lista: arrastra fuera para eliminar. |

`'remove'` consulta primero el `onBeforeDrop` de la lista. Después se ejecuta el `onDrop` de la
lista con `to.index === -1`, y `e.result` contiene la lista sin los ítems. Una papelera que acepta
drops funciona igual: consulta [zonas de papelera](/docs/guides/drag-and-drop#trash-zones).

Para confirmar un movimiento, guardarlo antes en un servidor o aplicar tú mismo los drops a un
store, consulta [decidir un drop](/docs/guides/drop-decisions). Todas las opciones de lista están en
la [API de makeSortableList](/docs/api/make-sortable-list).
