La biblioteca casi no aplica estilos. Cada estado de un arrastre te llega de dos formas: como una
ref que devuelve el composable, para clases y marcado condicional, y como un atributo `data-dnd-*`,
para CSS puro.

```vue [TaskRow.vue]
<script setup lang="ts">
const props = defineProps<{ task: Task }>();
const el = useTemplateRef<HTMLElement>('el');
const { isPlaceholder, selected } = makeSortableItem(el, { item: () => props.task });
</script>

<template>
  <li ref="el" class="row" :class="{ hole: isPlaceholder, selected }">{{ task.title }}</li>
</template>
```

## Las refs devueltas {#the-returned-refs}

| Composable | Estado |
| --- | --- |
| `makeSortableItem` | `isDragging`, `isPlaceholder`, `selected`, `indicator`, `index` |
| `makeSortableList`, `makeSortableTree` | `isOver`, `isAccepting`, `indicator`, `activeKey` |
| `makeDraggable` | `isDragging`, `selected`, `transform` |
| `makeDroppable` | `isOver`, `isAccepting`, `placement` |
| `makeDragArea` | `isDragging`, `isAutoScrolling` |
| `useDnD()` | `status`, `active`, `over`, `pointer`, `activation.progress` |

- `isPlaceholder`: este elemento es el hueco en el que aterrizará un ítem arrastrado.
- `isDragging`: el ítem forma parte del arrastre (cada ítem arrastrado en un multi-drag).
- `isAccepting`: se está arrastrando algo y este destino lo acepta — resalta los sitios donde es
  posible un drop.
- `isOver`: el arrastre está sobre este destino, lo acepte o no. `isOver && !isAccepting` es un
  rechazo, y vale la pena mostrarlo.
- `over.accepted` de `useDnD()` (`accepted` en las props del overlay) es `false` sobre un destino
  que rechaza el arrastre: úsalo para teñir el overlay de rojo.

```vue
<ul ref="list" :class="{ 'can-drop': isAccepting, over: isOver && isAccepting, refused: isOver && !isAccepting }">…</ul>
```

## Los atributos data {#the-data-attributes}

| Atributo | En | Cuándo |
| --- | --- | --- |
| `data-dnd-placeholder` | ítem ordenable | Es el hueco en el que aterrizará un ítem arrastrado. |
| `data-dnd-dragging` | ítem ordenable | Se arrastra pero se queda en su sitio: los demás ítems de un multi-drag en modo `'gaps'`. |
| `data-dnd-dragging="pointer"` o `"keyboard"` | `<html>` | Durante todo el arrastre. |
| `data-dnd-overlay="dragging"` o `"dropping"` | la caja del overlay | Siempre. `dropping` mientras aterriza y mientras espera un `onBeforeDrop` asíncrono. |
| `data-dnd-leaving` | una copia que deja `animate` | Mientras un ítem que se fue se desvanece. |
| `data-dnd-no-clone` | **lo pones tú** | Deja el elemento fuera del clon del overlay: un tooltip, un botón de menú, un badge. |

```css
html[data-dnd-dragging] .drop-hint { display: block; }
html[data-dnd-dragging='keyboard'] .shortcuts { display: block; }
```

## Estilos por defecto {#default-styles}

El provider inyecta unas pocas reglas una vez por documento. Van envueltas en `:where()`, así que
su especificidad es cero y cualquier regla tuya gana:

```css
:where([data-dnd-placeholder]) { opacity: 0.4; }
:where([data-dnd-dragging]:not(html)) { opacity: 0.4; }
:where(html[data-dnd-dragging], html[data-dnd-dragging] *) { user-select: none !important; overflow-anchor: none !important; }
:where(html[data-dnd-dragging='pointer'], html[data-dnd-dragging='pointer'] *) { cursor: grabbing !important; }
```

Durante un arrastre, el hueco se atenúa, la página no selecciona texto ni ancla su scroll, y
durante un arrastre de puntero el cursor es una mano agarrando. `:default-styles="false"` los
desactiva. Añadir `cursor: grab` a los ítems arrastrables te toca a ti.

## Recetas {#recipes}

### Un hueco vacío {#an-empty-slot}

En lugar de una copia atenuada del ítem, muestra una caja vacía con borde discontinuo donde va a
aterrizar:

```css
.card {
  position: relative;
}

.card[data-dnd-placeholder] {
  opacity: 1;
}

.card[data-dnd-placeholder]::after {
  content: '';
  position: absolute;
  inset: 0;
  border: 1.5px dashed color-mix(in srgb, currentColor 30%, transparent);
  border-radius: inherit;
  background: Canvas;
}
```

El pseudoelemento cubre el contenido, así que el hueco mantiene el tamaño exacto del ítem. Arrastra
aquí una tarjeta para verlo:

::example{name="kanban" hint="El hueco de una tarjeta arrastrada es una caja con borde discontinuo" height="24rem"}
::

### Una fila que pinta la lista {#a-row-the-list-paints}

El overlay por defecto es un clon del elemento arrastrado. Muestra el elemento tal como es y no
adivina ningún fondo: una fila sin fondo propio — un `<li>` en un `<ul>` blanco, una fila de tabla,
el ítem de lista de un kit de UI — da un clon transparente. Dale el fondo de la lista:

```css
[data-dnd-overlay] .row {
  background: var(--surface);
}
```

El clon conserva las clases y los atributos del elemento — también el atributo de un estilo scoped
—, así que la regla funciona en el propio `<style scoped>` de la fila, junto a sus otros estilos. O
da a la fila un fondo propio. Los iconos y las baldosas pensados para flotar se quedan
transparentes.

### Un overlay elevado, solo mientras se arrastra {#a-lifted-overlay-only-while-dragging}

```css
[data-dnd-overlay='dragging'] .card {
  box-shadow: 0 14px 28px -10px rgb(0 0 0 / 0.45);
}
```

La sombra está mientras la tarjeta viaja y desaparece cuando el overlay pasa a `dropping`, así que
la tarjeta aterriza plana en su hueco. Para un componente de overlay personalizado, la misma regla
apunta a la raíz de tu componente; o lee `status` de sus props.

### Movimiento reducido {#reduced-motion}

La biblioteca ya detiene sus propias animaciones con `prefers-reduced-motion: reduce`. Haz lo mismo
con las transiciones que añadas alrededor de los arrastres:

```css
@media (prefers-reduced-motion: reduce) {
  .column {
    transition: none;
  }
}
```

### Qué no hacer {#dont}

- No pongas una `transition` de CSS en `transform` o `translate` de los ítems ordenables: la
  biblioteca los anima por su cuenta y cancela esas transiciones mientras mide.
- No animes `height`, `margin` ni `padding` de las filas de una [lista virtual](/docs/guides/virtual-lists).

Más sobre el overlay — componentes personalizados, su tamaño, `DragPreview` — en
[El overlay](/docs/guides/overlay).
