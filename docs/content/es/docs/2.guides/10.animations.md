Arrastra una baldosa y luego baraja, añade y quita algunas. La ordenación y el drop se animan por
defecto; los cambios de los botones se animan porque la cuadrícula activa `animate`.

::example{name="animate" hint="Arrastra, baraja, añade, quita" height="22rem"}
::

## Tres animaciones {#three-animations}

| Opción | Dónde | Por defecto | Qué anima |
| --- | --- | --- | --- |
| `animation` | provider, lista, árbol | activada, 200 ms | Los ítems que se deslizan a su nuevo sitio mientras ordenas, al soltar y al cancelar. |
| `dropAnimation` | provider | activada, 250 ms | El overlay que aterriza en su hueco, o que vuelve a su sitio al cancelar. |
| `animate` | provider, lista, árbol | **desactivada** | Los cambios de tus datos que no vienen de un arrastre: ítems añadidos, quitados, movidos o filtrados, filas de árbol que se muestran u ocultan. |

Cada una acepta `true` (los tiempos por defecto), `false` (desactivada), `{ duration, easing }` o
una función que hace la animación por tu cuenta.

```vue
<DnDProvider
  :animation="{ duration: 180, easing: 'cubic-bezier(.2, .8, .2, 1)' }"
  :drop-animation="{ duration: 300 }"
>
```

Los `animation` y `animate` propios de una lista o de un árbol tienen prioridad sobre los del
provider.

## Ordenación {#sorting}

Mientras arrastras, el borrador se reordena y los ítems se deslizan a su nuevo sitio: FLIP sobre la
propiedad CSS `translate`, mediante la Web Animations API. `translate` se combina con cualquier
`transform` tuyo, así que el posicionamiento de las filas de una lista virtual queda intacto. Cuando
un ítem se vuelve a mover antes de que termine su animación, la siguiente empieza desde donde se
muestra.

::warning
No envuelvas los ítems ordenables en `<TransitionGroup>`: cada movimiento se animaría dos veces.
Para los cambios que no vienen de un arrastre, activa `animate`.
::

## El drop {#the-drop}

Al soltar, el overlay vuela desde donde lo soltaste hasta el hueco del ítem; al cancelar, de vuelta
a donde empezó el ítem. Cuando el ítem no tiene un hueco visible después del drop — porque quedó
fuera de la vista o se soltó en una carpeta o en una zona de papelera —, el overlay se desvanece en
su lugar, encogiéndose dentro de la zona en la que se soltó.

Mientras arrastras, el overlay también toma el tamaño del hueco en el que aterrizará
(`overlayFit: 'slot'`, el valor por defecto), así que el drop no necesita cambiar de tamaño.
`'source'` mantiene el tamaño del elemento arrastrado. Consulta [El overlay](/docs/guides/overlay).

## Cambios de datos: animate {#data-changes-animate}

```ts
makeSortableList(listRef, { items: swatches, animate: true });
```

Desactivado por defecto, `animate` anima lo que cambia tu array sin un arrastre: una ordenación, un
barajado, un movimiento entre listas de un mismo grupo, un ítem añadido, quitado o filtrado. En un
árbol también cubre las filas que un nodo muestra u oculta al expandirse y plegarse.
`<DnDProvider animate>` lo activa para todas las listas y todos los árboles.

Sus partes se pueden ajustar una a una:

```ts
animate: { duration: 250, move: true, enter: true, leave: { duration: 150 } },
```

| Parte | Por defecto |
| --- | --- |
| `move` | Los ítems que cambiaron de sitio se deslizan, como con `animation`. |
| `enter` | Los ítems que aparecieron surgen con un fundido donde están. |
| `leave` | Una copia del ítem que se fue se desvanece donde estaba, encogiéndose un poco. Se marca con `data-dnd-leaving` y se elimina cuando termina. |

`duration` y `easing` se aplican a todas las partes; cada parte acepta `true`, opciones, `false` o
una función. Solo se animan los ítems cercanos al área visible, así que se omiten las filas que una
lista virtual no ha montado. La opción se lee cuando cambia `items`, así que una ref puede
activarla y desactivarla, como hace el interruptor del ejemplo.

## Tus propias animaciones {#your-own-animations}

Cada opción acepta también una función. Recibe un contexto, inicia la animación y devuelve su
`Animation`, una promesa que se resuelve cuando termina, o nada.

```ts
// animation, animate.move: an item moved from `from` to `to`
({ key, element, from, to, options, reason, signal, reducedMotion }) => Animation | Promise | void
// dropAnimation: `to` is null when there is no visible slot; `into` is the zone it went into
({ overlay, from, to, into, reason, active, options, reducedMotion }) => …
// animate.enter: the element is already in place
({ key, element, to, options, reducedMotion }) => …
// animate.leave: `element` is a copy where the item was, removed when you finish
({ key, element, from, options, reducedMotion }) => …
```

Una función de layout con la Web Animations API, sin ninguna biblioteca:

```ts
import type { LayoutAnimationContext } from '@vue-dnd-kit/core';

const springy = ({ element, from, to, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  return element.animate(
    [{ translate: `${from.left - to.left}px ${from.top - to.top}px` }, { translate: '0 0' }],
    { duration: 400, easing: 'cubic-bezier(.34, 1.56, .64, 1)' },
  );
};
```

```vue
<DnDProvider :animation="springy">
```

Tres reglas mantienen las animaciones personalizadas sincronizadas con la biblioteca:

- **Anima `translate`** de `from - to` a cero, no `transform`. Se combina con los transforms que
  las listas virtuales o tu CSS ponen en las filas, y los arrastres miden los ítems sin él.
- **Respeta `signal`.** Se aborta cuando el ítem se vuelve a mover antes de que termine la
  animación. Detén tu animación y limpia sus estilos al instante: el layout se mide justo después.
  Una `Animation` devuelta se cancela por ti.
- **En el overlay, anima la posición y el tamaño** (`width`, `height`), nunca `scale`: su contenido
  se vuelve a maquetar con el nuevo tamaño.

### GSAP {#gsap}

```ts [gsap-animations.ts]
import gsap from 'gsap';
import type {
  DropAnimationContext,
  EnterAnimationContext,
  LayoutAnimationContext,
  LeaveAnimationContext,
  Rect,
} from '@vue-dnd-kit/core';

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const tween = gsap.fromTo(
    element,
    { translate: `${from.left - to.left}px ${from.top - to.top}px` },
    { translate: '0px 0px', duration: 0.4, ease: 'power3.out' },
  );
  signal.addEventListener('abort', () => tween.revert());
  return tween.then();
};

const box = (rect: Rect) => ({ x: rect.left, y: rect.top, width: rect.width, height: rect.height });

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return gsap.to(overlay, { opacity: 0, duration: 0.2 }).then();
  return gsap.fromTo(overlay, box(from), { ...box(to), duration: 0.45, ease: 'back.out(1.2)' }).then();
};

const enter = ({ element, reducedMotion }: EnterAnimationContext) =>
  gsap.from(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.35 }).then();

const leave = ({ element, reducedMotion }: LeaveAnimationContext) =>
  gsap.to(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.25 }).then();

export const gsapAnimations = { animation: move, dropAnimation: drop, animate: { move, enter, leave } };
```

```vue
<DnDProvider v-bind="gsapAnimations">
```

### motion {#motion}

```ts [motion-animations.ts]
import { animate } from 'motion-v';
import type { DropAnimationContext, LayoutAnimationContext } from '@vue-dnd-kit/core';

const spring = { type: 'spring', duration: 0.45, bounce: 0.25 } as const;

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const controls = animate(
    element,
    { translate: [`${from.left - to.left}px ${from.top - to.top}px`, '0px 0px'] },
    spring,
  );
  signal.addEventListener('abort', () => {
    controls.stop();
    element.style.translate = '';
  });
  return controls.finished;
};

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return animate(overlay, { opacity: 0 }, { duration: 0.18 }).finished;
  return animate(
    overlay,
    { x: [from.left, to.left], y: [from.top, to.top], width: [from.width, to.width], height: [from.height, to.height] },
    spring,
  ).finished;
};
```

Los tipos completos de las opciones están en [Animaciones](/docs/api/animations).

## Movimiento reducido {#reduced-motion}

Con `prefers-reduced-motion: reduce`, las animaciones propias de la biblioteca no se ejecutan: los
ítems y el overlay van directamente a su sitio. Tus funciones se ejecutan siempre, con
`reducedMotion: true`, así que deciden ellas — omitir el movimiento o mantener un fundido corto,
como hacen las recetas de arriba.

## Cambios de layout que no causó la biblioteca {#layout-changes-the-library-didnt-cause}

Cuando otra cosa mueve filas durante un arrastre — un virtualizador que vuelve a medir, una imagen
que se carga —, llama al `captureLayout()` de la lista justo antes de que se renderice el cambio.
Mide las filas donde están y las anima a su nuevo sitio tras el siguiente renderizado. Fuera de un
arrastre no hace nada. Consulta [Listas virtuales](/docs/guides/virtual-lists).
