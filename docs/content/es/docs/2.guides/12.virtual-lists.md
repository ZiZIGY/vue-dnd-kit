La ordenación está guiada por los datos: el borrador `items` es un array nuevo en cada reordenación,
las filas tienen el ítem como clave y las animaciones solo necesitan las filas montadas. Así que
funciona cualquier virtualizador que renderice a partir de un array — pásale el borrador en lugar de
tu array.

## Las reglas {#the-rules}

1. Pasa al virtualizador el **borrador `items`**, no tu array de origen.
2. **Usa la clave del ítem como clave de las filas**, nunca el índice. Los ejemplos oficiales de
   TanStack y VueUse usan el índice; cámbialo.
3. Pasa los ids a `makeSortableItem` como **getter**, `{ id: () => props.item.id }`: el
   virtualizador puede pasarle otro ítem a un componente de fila.
4. Guarda los arrays grandes en una **`shallowRef`**. La biblioteca nunca recorre tus datos en
   profundidad.
5. Mantén el placeholder del mismo tamaño que la fila.
6. Usa un overscan de al menos 5 filas (VueUse: al menos 1), para que las filas estén montadas antes
   de que llegue a ellas el desplazamiento automático.
7. No animes `height`, `margin` ni `padding` de las filas, y no pongas `will-change` en el
   contenedor con scroll.

## TanStack Virtual {#tanstack-virtual}

```vue [TaskList.vue]
<script setup lang="ts">
import { computed, shallowRef, useTemplateRef } from 'vue';
import { defaultRangeExtractor, useVirtualizer, type Range } from '@tanstack/vue-virtual';
import { makeSortableList } from '@vue-dnd-kit/core';
import Row from './Row.vue';

const ROW = 40;
const tasks = shallowRef(makeRows(10_000));
const scrollRef = useTemplateRef<HTMLElement>('scroll');
const { items, activeIndex, captureLayout } = makeSortableList(scrollRef, { items: tasks });

// One computed that reads the draft once: TanStack memoizes measurements and the range on
// the identity of `getItemKey` and `rangeExtractor`, so they must be new after every reorder.
const virtualizer = useVirtualizer(
  computed(() => {
    const arr = items.value;
    const pin = activeIndex.value;
    return {
      count: arr.length,
      getScrollElement: () => scrollRef.value,
      estimateSize: () => ROW,
      overscan: 8,
      getItemKey: (index: number) => arr[index]!.id,
      // Keep the dragged row mounted while it is scrolled out of range.
      rangeExtractor: (range: Range) => {
        const indexes = defaultRangeExtractor(range);
        return pin < 0 || indexes.includes(pin) ? indexes : [...indexes, pin].sort((a, b) => a - b);
      },
      // Re-measures land after the library's animation pass: animate them too.
      onChange: () => captureLayout(),
    };
  }),
);
const rows = computed(() => virtualizer.value.getVirtualItems());
const measure = (el: unknown) => virtualizer.value.measureElement(el as HTMLElement | null);
</script>

<template>
  <div ref="scroll" style="height: 600px; overflow: auto; contain: strict">
    <div :style="{ height: `${virtualizer.getTotalSize()}px`, position: 'relative' }">
      <div
        v-for="row in rows"
        :key="(row.key as string)"
        :ref="measure"
        :data-index="row.index"
        :style="{ position: 'absolute', top: 0, left: 0, width: '100%', transform: `translateY(${row.start}px)` }"
      >
        <Row :item="items[row.index]!" />
      </div>
    </div>
  </div>
</template>
```

```vue [Row.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ item: { id: string; title: string } }>();
const el = useTemplateRef<HTMLElement>('el');
// A getter: the virtualizer may give this component another item.
makeSortableItem(el, { id: () => props.item.id });
</script>

<template>
  <div ref="el" class="row">{{ item.title }}</div>
</template>
```

- El contenedor con scroll es el elemento de la lista ordenable: la biblioteca lo ordena y lo
  desplaza automáticamente.
- Fijar la fila arrastrada (`rangeExtractor`) requiere filas posicionadas una a una, en absoluto,
  como arriba.
- Mantén el `anchorTo: 'start'` de TanStack, el valor por defecto. Con `lanes`, usa
  `@tanstack/vue-virtual` 3.19 o posterior.

### Columnas de kanban {#kanban-columns}

Cuando llega una tarjeta de otra columna, su altura puede diferir de la estimación de la columna.
Lee `activeSize` en el mismo computed y estima la fila entrante con su tamaño real:

```ts
const { items, activeIndex, activeSize, captureLayout } = makeSortableList(scrollRef, {
  id: props.column.id,
  items: props.column.tasks,
  group: 'board',
});

const virtualizer = useVirtualizer(
  computed(() => {
    const arr = items.value;
    const pin = activeIndex.value;
    const size = activeSize.value;
    return {
      count: arr.length,
      getScrollElement: () => scrollRef.value,
      // A card coming from another column gets its real height before it is measured.
      estimateSize: (index: number) => (index === pin && size ? size.height : 72),
      // …getItemKey, rangeExtractor and onChange as above
    };
  }),
);
```

## useVirtualList de VueUse {#vueuse-usevirtuallist}

```vue [TaskList.vue]
<script setup lang="ts">
import { shallowRef, useTemplateRef } from 'vue';
import { useVirtualList } from '@vueuse/core';
import { makeSortableList } from '@vue-dnd-kit/core';
import Row from './Row.vue';

const ROW = 40;
const tasks = shallowRef(makeRows(10_000));
// The outer element is the sortable list: `containerProps` owns the scroller's ref.
const listRef = useTemplateRef<HTMLElement>('list');
const { items } = makeSortableList(listRef, { items: tasks });
// A number keeps VueUse's math O(1). It must be the row's real height, borders and margins included.
const { list, containerProps, wrapperProps } = useVirtualList(items, { itemHeight: ROW, overscan: 8 });
</script>

<template>
  <div ref="list">
    <div v-bind="containerProps" style="height: 600px">
      <div v-bind="wrapperProps">
        <!-- Keyed by id, not by index as in VueUse's docs. -->
        <Row v-for="{ data } in list" :key="data.id" :item="data" :style="{ height: `${ROW}px` }" />
      </div>
    </div>
  </div>
</template>
```

VueUse no puede fijar la fila arrastrada: se desmonta cuando la sacas de la vista con el scroll. No
pasa nada — consulta más abajo.

## Qué se mantiene montado {#what-stays-mounted}

La fila arrastrada puede desmontarse mientras arrastras: quedó fuera del rango con el scroll, o el
virtualizador recicló su componente. El arrastre sobrevive a ello. El overlay sigue mostrando el
ítem, la selección se conserva por id y el ítem aterriza donde lo coloca el borrador. Las
animaciones solo afectan a las filas montadas.

Cuando el virtualizador lo permita, mantén montada de todos modos la fila arrastrada, como hace la
receta de TanStack con `rangeExtractor`. La lista te dice qué fila es:

| Devuelto por la lista | Para qué sirve |
| --- | --- |
| `activeIndex` | El índice de la fila que hay que mantener montada en el borrador de esta lista, `-1` cuando no está aquí. |
| `activeKey` | La clave de esa fila. |
| `activeSize` | El tamaño de la fila arrastrada al inicio del arrastre: estima con él una fila entrante. |
| `captureLayout()` | Llámala justo antes de un cambio de layout que no haya hecho la biblioteca (una nueva medición). Anima las filas desde donde estaban. Fuera de un arrastre no hace nada. |

## Árboles {#trees}

`makeSortableTree` devuelve un `items` plano con las filas visibles, así que un árbol se virtualiza
como una lista: con `node.key` como clave, y con `activeIndex` y `activeKey` indicando la fila que
hay que mantener montada. Consulta [Árboles](/docs/guides/trees).
