## La selección {#the-selection}

Cada provider mantiene una selección: un conjunto reactivo de ids. Arrastrar un ítem
**seleccionado** arrastra todos los ítems seleccionados, empezando por el que se agarró. Arrastrar
un ítem que no está seleccionado arrastra solo ese ítem.

La biblioteca no decide cómo selecciona la gente: las reglas de clic son tuyas. Tampoco limpia
nunca la selección por su cuenta, y la selección sobrevive a los desmontajes, como los de las filas
que recicla una lista virtual.

### Ctrl/Cmd-clic {#ctrlcmd-click}

Cada ítem ordenable y cada elemento arrastrable devuelve `selected`, una ref escribible vinculada a
la selección:

```vue [Shot.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ shot: { id: string } }>();
const el = useTemplateRef<HTMLElement>('el');
const { selected } = makeSortableItem(el, { item: () => props.shot });

const onClick = (event: MouseEvent) => {
  if (event.ctrlKey || event.metaKey) selected.value = !selected.value;
};
</script>

<template>
  <div ref="el" :class="{ selected }" @click="onClick">…</div>
</template>
```

El clic que termina un arrastre no llega a `@click`, así que un drop nunca cambia la selección por
accidente. Usa `@click`, no `pointerup`, para las acciones de los ítems.

### Desde cualquier lugar: `useDnD().selection` {#from-anywhere-usedndselection}

```ts
import { useDnD, useDnDMonitor } from '@vue-dnd-kit/core';

const { selection } = useDnD();

selection.has('a');               // is it selected?
selection.add('a', 'b');          // select
selection.delete('a');            // deselect
selection.toggle('a');            // flip it, or force it: toggle('a', true)
selection.set(['a', 'c']);        // exactly these
selection.clear();
selection.ids;                    // a reactive ReadonlySet<Key>

// A plain click selects only that item, Ctrl/Cmd-click adds or removes it:
const onClick = (event: MouseEvent, id: string) => {
  if (event.ctrlKey || event.metaKey) selection.toggle(id);
  else selection.set([id]);
};

// Clear it after every drop, if your UI wants that:
useDnDMonitor({ onDragEnd: () => selection.clear() });
```

La selección se indexa por id, así que puede contener ítems de varias listas: un arrastre se lleva
todos los ítems seleccionados bajo el provider.

## Selección con rectángulo {#rubber-band-selection}

`makeSelectionArea` convierte un elemento en un área donde pulsar sobre el espacio vacío dibuja un
rectángulo, y se seleccionan los ítems que atraviesa:

```vue [Gallery.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSelectionArea } from '@vue-dnd-kit/core';
import PhotoGrid from './PhotoGrid.vue';

const area = useTemplateRef<HTMLElement>('area');
const { isSelecting, style } = makeSelectionArea(area);
</script>

<template>
  <div ref="area" class="area">
    <PhotoGrid />
    <div v-if="isSelecting" class="band" :style="style" />
  </div>
</template>

<style scoped>
.area {
  position: relative;   /* the band is absolutely positioned inside */
  min-height: 320px;    /* room around the items to start a band */
}

.band {
  border: 1px solid #42b883;
  background: color-mix(in srgb, #42b883 15%, transparent);
}
</style>
```

- El rectángulo lo renderizas tú: `style` lo coloca, relativo al contenido del área.
- El área necesita una **posición no estática** (con `relative` basta), o el rectángulo acaba en
  otro sitio.
- Un rectángulo solo empieza desde el propio área, así que hazla grande: todo el panel, con espacio
  alrededor de los ítems, no un contenedor ajustado. La galería de arriba llena toda su caja.
- Pulsar sobre un ítem lo arrastra. Los botones, los campos y la barra de desplazamiento del área
  conservan sus pulsaciones.
- El rectángulo se mantiene anclado al contenido mientras el área o la página se desplazan.
  :kbd{value="Escape"} lo cancela y restaura la selección.
- `useDnD().status` es `'selecting'` mientras se dibuja un rectángulo.

| Opción | Qué hace |
| --- | --- |
| `strategy` | `'toggle'` (por defecto): los ítems que atraviesa el rectángulo cambian de estado. `'select'`: solo quedan seleccionados los ítems dentro del rectángulo, así que un clic en el espacio vacío deselecciona los ítems del área. |
| `modifier` | Teclas que hay que mantener para dibujar: `{ keys: ['Shift'], method: 'every' }` (o `'some'`). |
| `accept` | Qué elementos arrastrables selecciona el rectángulo, una [regla de aceptación](/docs/guides/drag-and-drop#which-drags-a-target-takes) comparada con su `type`. |
| `disabled` | Sin rectángulo; activarlo cancela uno en curso. |
| `onSelected(ids)` | Se llama cuando termina un rectángulo, con la selección. |
| `selection` | Una `Ref<Set<Key>>` propia en lugar de la selección del provider. |

Con áreas dentro de áreas, la más interior se queda con la pulsación. Todas las opciones están en la
[API de makeSelectionArea](/docs/api/make-selection-area).

## Cómo se mueven los demás ítems: `multiple` {#how-the-other-items-move-multiple}

La lista donde empieza un multi-drag decide qué hacen los demás ítems seleccionados mientras dura:

```ts
makeSortableList(listRef, { items: tasks, multiple: 'gaps' });
```

| `multiple` | Mientras arrastras | El overlay |
| --- | --- | --- |
| `'group'` (por defecto) | Los demás ítems dejan su sitio y viajan con el que se agarró como un solo bloque de huecos, así que la lista ya muestra el resultado del drop. | Una columna de hasta cinco ítems arrastrados, en la dirección de la lista. |
| `'gaps'` | Los demás se quedan donde están, atenuados (`data-dnd-dragging`), hasta el drop. | La misma columna. |
| `'stack'` | Los demás vuelan al overlay. | El ítem agarrado con un contador. |

Al soltar, los ítems aterrizan juntos en el índice de destino, en el orden que tenían. En `'group'`
y `'gaps'`, cada ítem del overlay vuela a su propio hueco.

### El overlay por defecto {#the-default-overlay}

En `'group'` y `'gaps'`, el overlay es una columna de los ítems arrastrados tal como aterrizarán:
el agarrado bajo el puntero, y los demás antes y después de él en el orden del drop (una fila en
las listas horizontales). Muestra hasta cinco ítems. Los que pasan de ahí se cuentan donde están:
`+N` al principio de la columna para los ítems que aterrizan antes de los mostrados, `+N` al final
para los que van después.

En las cuadrículas, una columna de celdas completas taparía la página, así que el overlay es una
pila: hasta tres ítems abiertos en abanico detrás del agarrado, con el total encima.

Los elementos arrastrables simples (`makeDraggable`) muestran el ítem agarrado con un contador.

### Tipos mezclados {#mixed-types}

Cuando los ítems seleccionados tienen tipos distintos, `acceptMode` en un destino indica si deben
encajar `'all'` (por defecto) o solo `'some'`. Consulta
[listas que comparten ítems](/docs/guides/shared-lists#limits) y
[arrastrar y soltar](/docs/guides/drag-and-drop#which-drags-a-target-takes).

## Un overlay personalizado para varios ítems {#a-custom-overlay-for-several-items}

Los componentes de overlay y el slot `#overlay` del provider reciben `items`: todos los ítems
arrastrados, empezando por el que se agarró. `DragPreview` renderiza el clon que hace la biblioteca
de cualquiera de ellos, para que tu diseño pueda reutilizar su aspecto real:

```vue [PileOverlay.vue]
<script setup lang="ts">
import { DragPreview, type OverlayProps } from '@vue-dnd-kit/core';

defineProps<OverlayProps>();
</script>

<template>
  <div class="pile">
    <!-- The grabbed item on top, two more turned behind it -->
    <DragPreview
      v-for="(entry, i) in items.slice(0, 3)"
      :id="entry.id"
      :key="entry.id"
      class="card"
      :style="{ width: '100%', height: '100%', zIndex: 3 - i, rotate: `${i * 4}deg` }"
    >
      <!-- Shown for an item without a clone -->
      <div class="fallback">{{ entry.id }}</div>
    </DragPreview>
    <span v-if="items.length > 1" class="count">{{ items.length }}</span>
  </div>
</template>

<style scoped>
.pile { position: relative; width: 100%; height: 100%; }
.card { position: absolute; inset: 0; }
.fallback { width: 100%; height: 100%; border-radius: 8px; background: Canvas; }
.count { position: absolute; top: -8px; right: -8px; z-index: 4; }
</style>
```

```ts
makeSortableList(listRef, { items: photos, strategy: 'grid', overlay: PileOverlay });
```

Los clones se toman al agarrar: del ítem agarrado y de hasta otros cuatro junto a él en el orden
del drop, si están renderizados. Para cualquier otro ítem, `DragPreview` renderiza su slot por
defecto. Una vista previa tiene el tamaño de su ítem en el momento de agarrarlo, a menos que le des
tamaño, como hace el `style` de arriba (`class` y `style` se transmiten). En `'group'` y `'gaps'`,
cada vista previa aterriza al soltar en el hueco de su propio ítem. Más sobre los componentes de
overlay en [el overlay](/docs/guides/overlay).

## Árboles {#trees}

En un árbol, los nodos seleccionados se mueven como un solo bloque, cada uno con su subárbol, en el
orden del documento. Un nodo seleccionado dentro de otro nodo seleccionado viaja dentro del
subárbol de su padre. Consulta [árboles](/docs/guides/trees).
