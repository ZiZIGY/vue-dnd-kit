## Qué observar {#what-to-look-at}

- **`TaskList.vue`**: la lista virtual recibe el borrador `items`, no el array de origen, así que
  las filas se mueven mientras arrastras. El array es un `shallowRef`.
- **`TaskList.vue`**: las filas usan el id como clave, no el índice como en la documentación de
  VueUse.
- **`Row.vue`**: el id es un getter, `{ id: () => props.task.id }`: la lista virtual puede pasarle
  otra tarea al componente.

Más información: [Listas virtuales](/docs/guides/virtual-lists)
