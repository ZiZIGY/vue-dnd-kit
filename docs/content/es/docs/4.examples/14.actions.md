## Qué observar {#what-to-look-at}

- **`TrackRow.vue`**: `moveItem(id, { index })` para los botones de flecha, y
  `startDrag(id, { type: 'keyboard' })` para pasar la fila a las teclas de flecha.
- **`Queue.vue`**: la mezcla espera un `moveItem` tras otro; el arrastre programado empieza con
  `startDrag`, se desliza con `moveTo` y aterriza con `drop()`.

Más información: [Sensores y arrastres programáticos](/docs/guides/sensors#programmatic-drags)
