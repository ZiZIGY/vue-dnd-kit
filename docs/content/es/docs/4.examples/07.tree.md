## Qué observar {#what-to-look-at}

- **`FileTree.vue`**: `makeSortableTree` con `indentation`, `collapsed` y
  `canNest: (_node, parent) => !!parent.folder` — solo las carpetas aceptan hijos.
- **`TreeRow.vue`**: cada fila es un ítem ordenable con `node.key` como clave; su padding izquierdo
  sigue a `node.depth`, también mientras arrastras, así que el hueco muestra la profundidad que
  tomará el drop.

Más información: [Árboles](/docs/guides/trees) · [`makeSortableTree`](/docs/api/make-sortable-tree)
