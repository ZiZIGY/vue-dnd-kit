Las props `animation` (movimientos de layout al ordenar), `dropAnimation` (el aterrizaje del
overlay) y `animate` (cambios de datos que no vienen de un arrastre) del provider aceptan `false`,
opciones o tu propia función — para GSAP o motion. Las listas y los árboles pueden sobrescribir
`animation` y `animate`. Consulta [Animaciones](/docs/guides/animations).

```vue
<DnDProvider :animation="{ duration: 180, easing: 'ease-out' }" :drop-animation="false" />
```
