## Modificadores {#modifiers}

```ts
import { restrictToParent, snapToGrid } from '@vue-dnd-kit/core';

makeSortableList(list, { items, modifiers: [restrictToParent] });
makeDragArea(board, { modifiers: [snapToGrid({ x: 24, y: 24, smooth: true })] });
```

Un modificador recibe el desplazamiento del arrastre y devuelve uno nuevo. Se ejecutan en orden:
los `modifiers` del provider, los de un área de arrastre, los propios del elemento arrastrable (o
los de su lista), luego los límites del área (`restrictToArea`) y, al final, el bloqueo de `axis`.
Consulta [Ejes, límites y cuadrículas](/docs/guides/constraints).

| Modificador | Qué hace |
| --- | --- |
| `restrictToVerticalAxis` | Solo mueve en vertical. La opción `axis: 'y'` hace lo mismo, al final. |
| `restrictToHorizontalAxis` | Solo mueve en horizontal (`axis: 'x'`). |
| `restrictToWindowEdges` | Mantiene el overlay dentro de la ventana. |
| `restrictToParent` | Mantiene el overlay dentro del contenedor donde empezó el arrastre: la lista ordenable, o el elemento padre de un elemento arrastrable simple. |
| `restrictToElement(element)` | Mantiene el overlay dentro de un elemento (una ref, un getter o el elemento). |
| `restrictToFirstScrollableAncestor` | Mantiene el overlay dentro del primer ancestro desplazable del elemento arrastrado. |
| `snapToGrid(size \| options)` | Ajusta a una cuadrícula: `{ x, y, origin: 'container' \| 'delta', smooth }`. `'container'` (por defecto) pone la esquina superior izquierda de la caja sobre líneas de cuadrícula trazadas desde la esquina superior izquierda del contenedor; `'delta'` redondea el desplazamiento. `smooth` desliza el overlay entre celdas. |
| `snapCenterToCursor` | Centra el overlay bajo el puntero en lugar de mantener el desplazamiento del agarre. |

## Detección de colisiones {#collision-detection}

```ts
import { closestCorners } from '@vue-dnd-kit/core';
```

```vue
<DnDProvider :collision="closestCorners" />
```

La `collision` del provider elige el destino; el mejor candidato va primero.

| Función | Qué elige |
| --- | --- |
| `pointerFirst` | Por defecto: lo que está bajo el puntero o, si no hay nada, lo que solapa el overlay. |
| `pointerWithin` | Los destinos bajo el puntero, mediante prueba de colisión (respetando el orden z, los overlays y los shadow roots). |
| `rectIntersection` | Los destinos que solapan el overlay: mayor prioridad, luego anidamiento más profundo, luego intersección sobre unión. |
| `closestCenter` | Todos los destinos, por distancia entre centros. |
| `closestCorners` | Todos los destinos, por la suma de las distancias entre esquinas (destinos apilados, como las columnas de un kanban). |
