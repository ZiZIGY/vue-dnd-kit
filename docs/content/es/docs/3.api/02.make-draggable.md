::api-signature{name="makeDraggable"}
::

```ts
const el = useTemplateRef<HTMLElement>('el');
const { isDragging } = makeDraggable(el, { id: 'card', type: 'card', data: { title } });
```

Consulta [Arrastrar y soltar](/docs/guides/drag-and-drop). Los ítems ordenables también son
elementos arrastrables: [`makeSortableItem`](/docs/api/make-sortable-item) acepta las mismas
opciones y alguna más.
