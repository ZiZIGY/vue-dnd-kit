```ts
import { defineSensor, useSensor, pointerSensor, keyboardSensor } from '@vue-dnd-kit/core';
```

| Export | Qué es |
| --- | --- |
| `pointerSensor` | Ratón, táctil y lápiz mediante Pointer Events. Está en `sensors` por defecto. |
| `keyboardSensor` | Space/Enter agarran y sueltan, las flechas mueven, Escape cancela. Está en `sensors` por defecto. |
| `defineSensor(sensor)` | Tipa un objeto sensor. |
| `useSensor(sensor)` | Ejecuta un sensor en un componente bajo el provider, mientras ese componente viva. |

Un sensor solo dice «arrastra este ítem desde aquí», luego adónde se ha movido y que se ha soltado o
se ha cancelado; el provider comprueba el resto (qué se puede arrastrar, la activación, un arrastre
a la vez). Consulta [Sensores y arrastres programáticos](/docs/guides/sensors).
