Le tri est piloté par les données : le brouillon `items` est un nouveau tableau à chaque
réordonnancement, les lignes ont l'item pour clé, et les animations n'ont besoin que des lignes
montées. N'importe quel virtualiseur qui rend à partir d'un tableau fonctionne donc — donnez-lui le
brouillon au lieu de votre tableau.

::example{name="virtual-list" hint="10 000 lignes, seules quelques-unes dans le DOM : faites-en glisser une, ou faites défiler pendant le glissement" height="26rem"}
::

## Les règles {#the-rules}

1. Donnez au virtualiseur le **brouillon `items`**, pas votre tableau source.
2. **Utilisez la clé de l'item comme clé des lignes**, jamais l'index. Les exemples officiels de
   TanStack et de VueUse utilisent l'index ; changez cela.
3. Passez les ids à `makeSortableItem` sous forme de **getter**, `{ id: () => props.item.id }` : le
   virtualiseur peut confier un autre item à un composant de ligne.
4. Gardez les grands tableaux dans une **`shallowRef`**. La bibliothèque ne parcourt jamais vos
   données en profondeur.
5. Gardez le placeholder à la même taille que la ligne.
6. Utilisez un overscan d'au moins 5 lignes (VueUse : au moins 1), pour que les lignes soient
   montées avant que le défilement automatique ne les atteigne.
7. N'animez pas la `height`, la `margin` ni le `padding` des lignes, et ne mettez pas de
   `will-change` sur le conteneur défilant.

## TanStack Virtual {#tanstack-virtual}

```vue [TaskList.vue]
<script setup lang="ts">
import { computed, shallowRef, useTemplateRef } from 'vue';
import { defaultRangeExtractor, useVirtualizer, type Range } from '@tanstack/vue-virtual';
import { makeSortableList } from '@vue-dnd-kit/core';
import Row from './Row.vue';

const ROW = 40;
const tasks = shallowRef(makeRows(10_000));
const scrollRef = useTemplateRef<HTMLElement>('scroll');
const { items, activeIndex, captureLayout } = makeSortableList(scrollRef, { items: tasks });

// One computed that reads the draft once: TanStack memoizes measurements and the range on
// the identity of `getItemKey` and `rangeExtractor`, so they must be new after every reorder.
const virtualizer = useVirtualizer(
  computed(() => {
    const arr = items.value;
    const pin = activeIndex.value;
    return {
      count: arr.length,
      getScrollElement: () => scrollRef.value,
      estimateSize: () => ROW,
      overscan: 8,
      getItemKey: (index: number) => arr[index]!.id,
      // Keep the dragged row mounted while it is scrolled out of range.
      rangeExtractor: (range: Range) => {
        const indexes = defaultRangeExtractor(range);
        return pin < 0 || indexes.includes(pin) ? indexes : [...indexes, pin].sort((a, b) => a - b);
      },
      // Re-measures land after the library's animation pass: animate them too.
      onChange: () => captureLayout(),
    };
  }),
);
const rows = computed(() => virtualizer.value.getVirtualItems());
const measure = (el: unknown) => virtualizer.value.measureElement(el as HTMLElement | null);
</script>

<template>
  <div ref="scroll" style="height: 600px; overflow: auto; contain: strict">
    <div :style="{ height: `${virtualizer.getTotalSize()}px`, position: 'relative' }">
      <div
        v-for="row in rows"
        :key="(row.key as string)"
        :ref="measure"
        :data-index="row.index"
        :style="{ position: 'absolute', top: 0, left: 0, width: '100%', transform: `translateY(${row.start}px)` }"
      >
        <Row :item="items[row.index]!" />
      </div>
    </div>
  </div>
</template>
```

```vue [Row.vue]
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { makeSortableItem } from '@vue-dnd-kit/core';

const props = defineProps<{ item: { id: string; title: string } }>();
const el = useTemplateRef<HTMLElement>('el');
// A getter: the virtualizer may give this component another item.
makeSortableItem(el, { id: () => props.item.id });
</script>

<template>
  <div ref="el" class="row">{{ item.title }}</div>
</template>
```

- Le conteneur défilant est l'élément de la liste triable : la bibliothèque le trie et le fait
  défiler automatiquement.
- Épingler la ligne glissée (`rangeExtractor`) demande des lignes positionnées une par une, en
  absolu, comme ci-dessus.
- Gardez l'`anchorTo: 'start'` de TanStack, la valeur par défaut. Avec `lanes`, utilisez
  `@tanstack/vue-virtual` 3.19 ou plus récent.

### Colonnes kanban {#kanban-columns}

Quand une carte arrive d'une autre colonne, sa hauteur peut différer de l'estimation de la colonne.
Lisez `activeSize` dans le même computed, et estimez la ligne entrante à sa taille réelle :

```ts
const { items, activeIndex, activeSize, captureLayout } = makeSortableList(scrollRef, {
  id: props.column.id,
  items: props.column.tasks,
  group: 'board',
});

const virtualizer = useVirtualizer(
  computed(() => {
    const arr = items.value;
    const pin = activeIndex.value;
    const size = activeSize.value;
    return {
      count: arr.length,
      getScrollElement: () => scrollRef.value,
      // A card coming from another column gets its real height before it is measured.
      estimateSize: (index: number) => (index === pin && size ? size.height : 72),
      // …getItemKey, rangeExtractor and onChange as above
    };
  }),
);
```

## useVirtualList de VueUse {#vueuse-usevirtuallist}

```vue [TaskList.vue]
<script setup lang="ts">
import { shallowRef, useTemplateRef } from 'vue';
import { useVirtualList } from '@vueuse/core';
import { makeSortableList } from '@vue-dnd-kit/core';
import Row from './Row.vue';

const ROW = 40;
const tasks = shallowRef(makeRows(10_000));
// The outer element is the sortable list: `containerProps` owns the scroller's ref.
const listRef = useTemplateRef<HTMLElement>('list');
const { items } = makeSortableList(listRef, { items: tasks });
// A number keeps VueUse's math O(1). It must be the row's real height, borders and margins included.
const { list, containerProps, wrapperProps } = useVirtualList(items, { itemHeight: ROW, overscan: 8 });
</script>

<template>
  <div ref="list">
    <div v-bind="containerProps" style="height: 600px">
      <div v-bind="wrapperProps">
        <!-- Keyed by id, not by index as in VueUse's docs. -->
        <Row v-for="{ data } in list" :key="data.id" :item="data" :style="{ height: `${ROW}px` }" />
      </div>
    </div>
  </div>
</template>
```

VueUse ne peut pas épingler la ligne glissée : elle est démontée quand vous la faites sortir de la
vue en défilant. Ce n'est pas grave — voir plus bas.

## Ce qui reste monté {#what-stays-mounted}

La ligne glissée peut être démontée pendant le glissement : elle est sortie de la plage par
défilement, ou le virtualiseur a recyclé son composant. Le glissement y survit. L'overlay continue
d'afficher l'item, la sélection est conservée par id, et l'item atterrit là où le brouillon le
place. Les animations ne touchent que les lignes montées.

Quand le virtualiseur le permet, gardez quand même la ligne glissée montée, comme le fait la
recette TanStack avec `rangeExtractor`. La liste vous indique de quelle ligne il s'agit :

| Renvoyé par la liste | À quoi il sert |
| --- | --- |
| `activeIndex` | L'index de la ligne à garder montée dans le brouillon de cette liste, `-1` quand elle n'y est pas. |
| `activeKey` | La clé de cette ligne. |
| `activeSize` | La taille de la ligne glissée au début du glissement : estimez avec elle une ligne entrante. |
| `captureLayout()` | Appelez-la juste avant un changement de mise en page que la bibliothèque n'a pas fait (une nouvelle mesure). Elle anime les lignes depuis l'endroit où elles étaient. En dehors d'un glissement, elle ne fait rien. |

## Arbres {#trees}

`makeSortableTree` renvoie un `items` plat des lignes visibles : un arbre se virtualise donc comme
une liste, avec `node.key` comme clé, et `activeIndex` et `activeKey` qui désignent la ligne à
garder montée. Voir [Arbres](/docs/guides/trees).
