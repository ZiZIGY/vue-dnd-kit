Faites glisser une tuile, puis mélangez, ajoutez et retirez-en quelques-unes. Le tri et le dépôt
sont animés par défaut ; les changements faits par les boutons sont animés parce que la grille
active `animate`.

::example{name="animate" hint="Glissez, mélangez, ajoutez, retirez" height="22rem"}
::

## Trois animations {#three-animations}

| Option | Où | Par défaut | Ce qu'elle anime |
| --- | --- | --- | --- |
| `animation` | provider, liste, arbre | activée, 200 ms | Les items qui glissent vers leur nouvelle place pendant le tri, au dépôt et à l'annulation. |
| `dropAnimation` | provider | activée, 250 ms | L'overlay qui atterrit sur son emplacement, ou qui revient à sa place à l'annulation. |
| `animate` | provider, liste, arbre | **désactivée** | Les changements de vos données qui ne viennent pas d'un glissement : items ajoutés, retirés, déplacés ou filtrés, lignes d'arbre affichées ou masquées. |

Chacune accepte `true` (le timing par défaut), `false` (désactivée), `{ duration, easing }`, ou une
fonction qui réalise l'animation vous-même.

```vue
<DnDProvider
  :animation="{ duration: 180, easing: 'cubic-bezier(.2, .8, .2, 1)' }"
  :drop-animation="{ duration: 300 }"
>
```

Les `animation` et `animate` propres à une liste ou à un arbre l'emportent sur ceux du provider.

## Tri {#sorting}

Pendant le glissement, le brouillon se réordonne et les items glissent vers leur nouvelle place :
du FLIP sur la propriété CSS `translate`, via la Web Animations API. `translate` se compose avec
n'importe lequel de vos `transform` : le positionnement des lignes d'une liste virtuelle reste donc
intact. Quand un item bouge de nouveau avant la fin de son animation, la suivante part de l'endroit
où il est affiché.

::warning
N'enveloppez pas les items triables dans `<TransitionGroup>` : chaque déplacement serait animé deux
fois. Pour les changements qui ne viennent pas d'un glissement, activez `animate`.
::

## Le dépôt {#the-drop}

Au dépôt, l'overlay vole de l'endroit où vous l'avez lâché jusqu'à l'emplacement de l'item ; à
l'annulation, il revient là où l'item a commencé. Quand l'item n'a pas d'emplacement visible après
le dépôt — parce qu'il a défilé hors de vue, ou qu'il a été déposé dans un dossier ou une zone de
corbeille —, l'overlay disparaît en fondu à la place, en se réduisant dans la zone où il a été
déposé.

Pendant le glissement, l'overlay prend aussi la taille de l'emplacement où il va atterrir
(`overlayFit: 'slot'`, la valeur par défaut) : le dépôt n'a donc pas besoin de redimensionnement.
`'source'` garde la taille de l'élément glissé. Voir [L'overlay](/docs/guides/overlay).

## Changements de données : animate {#data-changes-animate}

```ts
makeSortableList(listRef, { items: swatches, animate: true });
```

Désactivé par défaut, `animate` anime ce qui modifie votre tableau sans glissement : un tri, un
mélange, un déplacement entre les listes d'un même groupe, un item ajouté, retiré ou filtré. Dans un
arbre, il couvre aussi les lignes qu'un nœud affiche ou masque quand il se déplie et se replie.
`<DnDProvider animate>` l'active pour toutes les listes et tous les arbres.

Ses parties se règlent une par une :

```ts
animate: { duration: 250, move: true, enter: true, leave: { duration: 150 } },
```

| Partie | Par défaut |
| --- | --- |
| `move` | Les items qui ont changé de place glissent, comme avec `animation`. |
| `enter` | Les items apparus s'affichent en fondu là où ils sont. |
| `leave` | Une copie de l'item parti disparaît en fondu là où il était, en rétrécissant un peu. Elle est marquée `data-dnd-leaving` et retirée une fois l'animation terminée. |

`duration` et `easing` s'appliquent à toutes les parties ; chaque partie accepte `true`, des
options, `false` ou une fonction. Seuls les items proches de la zone visible sont animés : les
lignes qu'une liste virtuelle n'a pas montées sont donc ignorées. L'option est lue quand `items`
change : une ref peut donc la basculer, comme le fait l'interrupteur de l'exemple.

## Vos propres animations {#your-own-animations}

Chaque option accepte aussi une fonction. Elle reçoit un contexte, lance l'animation et renvoie son
`Animation`, une promesse qui se résout à la fin, ou rien.

```ts
// animation, animate.move: an item moved from `from` to `to`
({ key, element, from, to, options, reason, signal, reducedMotion }) => Animation | Promise | void
// dropAnimation: `to` is null when there is no visible slot; `into` is the zone it went into
({ overlay, from, to, into, reason, active, options, reducedMotion }) => …
// animate.enter: the element is already in place
({ key, element, to, options, reducedMotion }) => …
// animate.leave: `element` is a copy where the item was, removed when you finish
({ key, element, from, options, reducedMotion }) => …
```

Une fonction de mise en page avec la Web Animations API, sans bibliothèque :

```ts
import type { LayoutAnimationContext } from '@vue-dnd-kit/core';

const springy = ({ element, from, to, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  return element.animate(
    [{ translate: `${from.left - to.left}px ${from.top - to.top}px` }, { translate: '0 0' }],
    { duration: 400, easing: 'cubic-bezier(.34, 1.56, .64, 1)' },
  );
};
```

```vue
<DnDProvider :animation="springy">
```

Trois règles gardent les animations personnalisées en phase avec la bibliothèque :

- **Animez `translate`** de `from - to` jusqu'à zéro, et non `transform`. Il se compose avec les
  transforms que les listes virtuelles ou votre CSS appliquent aux lignes, et les glissements
  mesurent les items sans lui.
- **Respectez `signal`.** Il s'interrompt quand l'item bouge de nouveau avant la fin de
  l'animation. Arrêtez immédiatement votre animation et effacez ses styles : la mise en page est
  mesurée juste après. Une `Animation` renvoyée est annulée pour vous.
- **Sur l'overlay, animez la position et la taille** (`width`, `height`), jamais `scale` : la mise
  en page de son contenu est recalculée à la nouvelle taille.

### GSAP {#gsap}

```ts [gsap-animations.ts]
import gsap from 'gsap';
import type {
  DropAnimationContext,
  EnterAnimationContext,
  LayoutAnimationContext,
  LeaveAnimationContext,
  Rect,
} from '@vue-dnd-kit/core';

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const tween = gsap.fromTo(
    element,
    { translate: `${from.left - to.left}px ${from.top - to.top}px` },
    { translate: '0px 0px', duration: 0.4, ease: 'power3.out' },
  );
  signal.addEventListener('abort', () => tween.revert());
  return tween.then();
};

const box = (rect: Rect) => ({ x: rect.left, y: rect.top, width: rect.width, height: rect.height });

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return gsap.to(overlay, { opacity: 0, duration: 0.2 }).then();
  return gsap.fromTo(overlay, box(from), { ...box(to), duration: 0.45, ease: 'back.out(1.2)' }).then();
};

const enter = ({ element, reducedMotion }: EnterAnimationContext) =>
  gsap.from(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.35 }).then();

const leave = ({ element, reducedMotion }: LeaveAnimationContext) =>
  gsap.to(element, reducedMotion ? { opacity: 0, duration: 0.2 } : { opacity: 0, scale: 0.85, duration: 0.25 }).then();

export const gsapAnimations = { animation: move, dropAnimation: drop, animate: { move, enter, leave } };
```

```vue
<DnDProvider v-bind="gsapAnimations">
```

### motion {#motion}

```ts [motion-animations.ts]
import { animate } from 'motion-v';
import type { DropAnimationContext, LayoutAnimationContext } from '@vue-dnd-kit/core';

const spring = { type: 'spring', duration: 0.45, bounce: 0.25 } as const;

const move = ({ element, from, to, signal, reducedMotion }: LayoutAnimationContext) => {
  if (reducedMotion) return;
  const controls = animate(
    element,
    { translate: [`${from.left - to.left}px ${from.top - to.top}px`, '0px 0px'] },
    spring,
  );
  signal.addEventListener('abort', () => {
    controls.stop();
    element.style.translate = '';
  });
  return controls.finished;
};

const drop = ({ overlay, from, to, reducedMotion }: DropAnimationContext) => {
  if (reducedMotion) return;
  if (!to) return animate(overlay, { opacity: 0 }, { duration: 0.18 }).finished;
  return animate(
    overlay,
    { x: [from.left, to.left], y: [from.top, to.top], width: [from.width, to.width], height: [from.height, to.height] },
    spring,
  ).finished;
};
```

Les types complets des options se trouvent dans [Animations](/docs/api/animations).

## Mouvement réduit {#reduced-motion}

Avec `prefers-reduced-motion: reduce`, les animations propres à la bibliothèque ne s'exécutent pas :
les items et l'overlay vont directement à leur place. Vos fonctions s'exécutent toujours, avec
`reducedMotion: true` : c'est donc à elles de décider — sauter le mouvement, ou garder un court
fondu comme le font les recettes ci-dessus.

## Changements de mise en page que la bibliothèque n'a pas causés {#layout-changes-the-library-didnt-cause}

Quand autre chose déplace des lignes pendant un glissement — un virtualiseur qui remesure, une
image qui se charge —, appelez le `captureLayout()` de la liste juste avant que le changement ne
soit rendu. Il mesure les lignes là où elles sont et les anime vers leur nouvelle place après le
rendu suivant. En dehors d'un glissement, il ne fait rien. Voir [Listes virtuelles](/docs/guides/virtual-lists).
