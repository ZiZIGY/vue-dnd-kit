## Ce qu'il faut regarder {#what-to-look-at}

- **`FileCard.vue`** : un simple `makeDraggable` avec un `type` — `image` ou `doc`.
- **`Folder.vue`** : un `makeDroppable` dont l'`accept` accepte un seul type (`'*'` pour le bureau
  et la corbeille). `isAccepting` met en évidence les dossiers qui acceptent le glissement ; un
  dossier qui le refuse l'indique avec `isOver && !isAccepting`. `onDrop` est l'endroit où les
  données changent : la bibliothèque ne déplace rien d'elle-même.
- Les fichiers ont le même aspect partout : un dépôt ne fait donc que voler ; les fichiers restés
  en place glissent dans le vide laissé, grâce au `<TransitionGroup>` de Vue.

En savoir plus : [Glisser-déposer](/docs/guides/drag-and-drop) · [`makeDroppable`](/docs/api/make-droppable)
