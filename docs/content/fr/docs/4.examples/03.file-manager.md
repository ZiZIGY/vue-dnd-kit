## Ce qu'il faut regarder {#what-to-look-at}

- **`FileGrid.vue`** : les fichiers forment une grille triable (`strategy: 'grid'`) avec `clone` :
  Alt copie donc au lieu de déplacer. `makeSelectionArea` trace le rectangle de sélection ; la
  sélection qu'il crée est celle que déplace un multi-drag, affichée en pile.
- **`FileTile.vue`** : `selected` de `makeSortableItem`, lié à un clic et au Ctrl/Cmd-clic.
- **`useFolderDrop.ts`** : les lignes de l'arborescence et les tuiles de dossier sont des cibles
  de dépôt. `accept` est une fonction : un dossier refuse qu'on y dépose le dossier lui-même, ses
  propres sous-dossiers et le dossier ouvert. Sur une tuile de dossier, seul le milieu de la tuile accepte le dépôt ; près de
  ses bords, la grille trie.
- **`FileManager.vue`** : un dossier est une simple cible de dépôt ; `event.mode` indique si Alt
  a transformé le glissement en copie.
