## Ce qu'il faut regarder {#what-to-look-at}

- **`FileChip.vue`** : chaque fichier a un `type`, ce que vérifient les cibles de dépôt.
- **`Zone.vue`** : `accept` prend un type ou une liste de types. `isAccepting` met en évidence les
  zones qui accepteraient le glissement ; `isOver` sans `isAccepting`, c'est une zone qui le
  refuse.
- **`index.vue`** : une cible de dépôt ne déplace rien elle-même : `onDrop` indique quel fichier
  est entré, et c'est l'application qui le déplace.
