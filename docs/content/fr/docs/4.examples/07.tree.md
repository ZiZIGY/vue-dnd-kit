## Ce qu'il faut regarder {#what-to-look-at}

- **`FileTree.vue`** : `makeSortableTree` avec `indentation`, `collapsed` et
  `canNest: (_node, parent) => !!parent.folder` — seuls les dossiers acceptent des enfants.
- **`TreeRow.vue`** : chaque ligne est un item triable dont la clé est `node.key` ; son padding
  gauche suit `node.depth`, y compris pendant le glissement : l'emplacement montre donc la
  profondeur que prendra le dépôt.

En savoir plus : [Arbres](/docs/guides/trees) · [`makeSortableTree`](/docs/api/make-sortable-tree)
