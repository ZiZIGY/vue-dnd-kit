## Ce qu'il faut regarder {#what-to-look-at}

- **`Week.vue`** : `makeDragArea` donne aux jours leurs propres règles : `snapToGrid` (un jour sur
  une demi-heure) et `restrictToArea`, pour qu'un événement ne quitte jamais la semaine.
  `getKeyboardCoordinates` fait avancer les flèches d'une case.
- **`DayColumn.vue`** : chaque jour est une cible de dépôt. `position` dans l'événement de dépôt
  est l'endroit où la boîte de l'événement a atterri dans le jour : son haut donne la nouvelle
  heure de début.
- **`EventBlock.vue`** : un simple élément déplaçable, avec son propre composant d'overlay.
- **`EventOverlay.vue`** : affiche, pendant que l'événement se déplace, l'heure à laquelle il
  atterrirait, d'après `useDnD().position`, l'endroit où se trouve sa boîte dans le jour en
  dessous.
