## Ce qu'il faut regarder {#what-to-look-at}

- **`Board.vue`** : `makeDragArea(board, { axis, restrictToArea, modifiers })` fixe les règles de
  chaque glissement qui commence sur le tableau. Les options sont des refs et un getter, lus au
  début d'un glissement : les interrupteurs s'appliquent donc au glissement suivant.
- Le tableau est aussi une cible de dépôt ; `onDragEnd` place la note à `position`, le
  `left`/`top` où elle a été déposée.
- **`Note.vue`** se contente de dire qu'elle peut être glissée : la zone fait le reste.
