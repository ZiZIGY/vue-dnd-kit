Chaque exemple est une petite application Vue : un `index.vue` avec son `DnDProvider`, et les
composants dont il a besoin. Les onglets de code sous une démo sont les fichiers mêmes qui la font
tourner.

::card-group

::card{title="Glisser-déposer" icon="i-lucide-folder-input" to="/docs/examples/drop-zones"}
Des fichiers rangés dans des dossiers qui acceptent chacun un seul type ; une corbeille qui accepte
tout.
::

::card{title="Listes et grilles" icon="i-lucide-list-ordered" to="/docs/examples/lists"}
Une playlist qu'on fait glisser par sa poignée, sur un seul axe, et une grille d'applications
d'écran d'accueil.
::

::card{title="Tableau kanban" icon="i-lucide-columns-3" to="/docs/examples/kanban"}
Des colonnes qui s'échangent des cartes et acceptent les dépôts sur toute leur hauteur.
::

::card{title="Arborescence de fichiers" icon="i-lucide-list-tree" to="/docs/examples/tree"}
L'explorateur d'un éditeur : imbrication en glissant de côté ou en survolant un dossier.
::

::card{title="Multi-drag" icon="i-lucide-images" to="/docs/examples/multi-drag"}
Sélectionnez avec un rectangle de sélection ou par Ctrl/Cmd-clic, puis déplacez toute la sélection.
::

::card{title="Axes, limites et grilles" icon="i-lucide-frame" to="/docs/examples/constraints"}
Un tableau dont les règles changent en direct : verrouillage d'axe, bords, grille.
::

::
