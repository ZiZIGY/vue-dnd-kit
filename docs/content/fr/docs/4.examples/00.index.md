Chaque exemple est une petite application Vue : un `index.vue` avec son `DnDProvider`, et les
composants dont il a besoin. Les onglets de code sous une démo sont les fichiers mêmes qui la font
tourner.

## Applications {#apps}

Des interfaces complètes, telles que vous les construiriez : plusieurs listes, des règles, des
overlays et le clavier qui fonctionnent ensemble.

::card-group

::card{title="Tableau de projet" icon="i-lucide-square-kanban" to="/docs/examples/board"}
Des colonnes que vous réordonnez, des limites WIP, une confirmation avant Done, la sélection
multiple et une corbeille.
::

::card{title="Calendrier de la semaine" icon="i-lucide-calendar-days" to="/docs/examples/calendar"}
Des événements glissés d'un jour et d'une demi-heure à l'autre, alignés sur la grille.
::

::card{title="Gestionnaire de fichiers" icon="i-lucide-folder-open" to="/docs/examples/file-manager"}
Une arborescence de dossiers et une grille de fichiers : sélection au rectangle, dépôt sur les
dossiers, Alt pour copier.
::

::card{title="Éditeur de blocs" icon="i-lucide-blocks" to="/docs/examples/block-editor"}
Des blocs à la Notion, déplacés par leur poignée, imbriqués et insérés depuis une palette.
::

::card{title="Échecs" icon="i-lucide-chess-knight" to="/docs/examples/chess"}
Un échiquier dont les cases n'acceptent que les coups légaux : prises, tours de jeu, une pièce
soulevée, les flèches du clavier.
::

::
