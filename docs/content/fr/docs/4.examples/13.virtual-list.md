## Ce qu'il faut regarder {#what-to-look-at}

- **`TaskList.vue`** : la liste virtuelle reçoit le brouillon `items`, pas le tableau source : les
  lignes bougent donc pendant le glissement. Le tableau est un `shallowRef`.
- **`TaskList.vue`** : les lignes ont l'id pour clé, pas l'index comme dans la documentation de
  VueUse.
- **`Row.vue`** : l'id est un getter, `{ id: () => props.task.id }` : la liste virtuelle peut
  confier une autre tâche au composant.

En savoir plus : [Listes virtuelles](/docs/guides/virtual-lists)
