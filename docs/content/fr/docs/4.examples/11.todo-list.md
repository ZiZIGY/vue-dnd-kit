## Ce qu'il faut regarder {#what-to-look-at}

- **`TodoRow.vue`** : `handle: grip` : seule la poignée lance un glissement, et la case à cocher
  reste utilisable. `index` est la place de la ligne dans le brouillon : il change pendant le
  glissement.
- **`TodoRow.vue`** : `isPlaceholder` dessine l'emplacement comme un creux en pointillés de même
  taille.
- **`TodoList.vue`** : les lignes rendent le brouillon `items` de la liste ; le dépôt est écrit
  dans `todos`.
