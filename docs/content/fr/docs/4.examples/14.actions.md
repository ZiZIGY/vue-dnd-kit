## Ce qu'il faut regarder {#what-to-look-at}

- **`TrackRow.vue`** : `moveItem(id, { index })` pour les boutons fléchés, et
  `startDrag(id, { type: 'keyboard' })` pour confier la ligne aux touches fléchées.
- **`Queue.vue`** : le mélange attend chaque `moveItem` l'un après l'autre ; le glissement scripté
  commence avec `startDrag`, glisse avec `moveTo` et atterrit avec `drop()`.

En savoir plus : [Capteurs et glissements programmatiques](/docs/guides/sensors#programmatic-drags)
