## Modificateurs {#modifiers}

```ts
import { restrictToParent, snapToGrid } from '@vue-dnd-kit/core';

makeSortableList(list, { items, modifiers: [restrictToParent] });
makeDragArea(board, { modifiers: [snapToGrid({ x: 24, y: 24, smooth: true })] });
```

Un modificateur prend le décalage du glissement et en renvoie un nouveau. Ils s'exécutent dans
l'ordre : les `modifiers` du provider, ceux d'une zone de glissement, ceux propres à l'élément
déplaçable (ou ceux de sa liste), puis les limites de la zone (`restrictToArea`), et le verrouillage
d'`axis` en dernier. Voir [Axes, limites et grilles](/docs/guides/constraints).

| Modificateur | Ce qu'il fait |
| --- | --- |
| `restrictToVerticalAxis` | Ne déplace que verticalement. L'option `axis: 'y'` fait la même chose, en dernier. |
| `restrictToHorizontalAxis` | Ne déplace qu'horizontalement (`axis: 'x'`). |
| `restrictToWindowEdges` | Garde l'overlay à l'intérieur de la fenêtre. |
| `restrictToParent` | Garde l'overlay à l'intérieur du conteneur où le glissement a commencé : la liste triable, ou l'élément parent d'un élément déplaçable simple. |
| `restrictToElement(element)` | Garde l'overlay à l'intérieur d'un élément (une ref, un getter ou l'élément). |
| `restrictToFirstScrollableAncestor` | Garde l'overlay à l'intérieur du premier ancêtre défilable de l'élément glissé. |
| `snapToGrid(size \| options)` | Aligne sur une grille : `{ x, y, origin: 'container' \| 'delta', smooth }`. `'container'` (par défaut) place le coin supérieur gauche de la boîte sur des lignes de grille tracées depuis le coin supérieur gauche du conteneur ; `'delta'` arrondit le décalage. `smooth` fait glisser l'overlay d'une cellule à l'autre. |
| `snapCenterToCursor` | Centre l'overlay sous le pointeur au lieu de garder le décalage de la saisie. |

## Détection de collision {#collision-detection}

```ts
import { closestCorners } from '@vue-dnd-kit/core';
```

```vue
<DnDProvider :collision="closestCorners" />
```

La `collision` du provider choisit la cible ; le meilleur candidat vient en premier.

| Fonction | Ce qu'elle choisit |
| --- | --- |
| `pointerFirst` | Par défaut : ce qui est sous le pointeur, sinon ce que l'overlay chevauche. |
| `pointerWithin` | Les cibles sous le pointeur, par test de collision (ordre d'empilement, overlays et shadow roots respectés). |
| `rectIntersection` | Les cibles qui chevauchent l'overlay : priorité la plus haute, puis imbrication la plus profonde, puis rapport intersection sur union. |
| `closestCenter` | Toutes les cibles, par distance entre les centres. |
| `closestCorners` | Toutes les cibles, par somme des distances entre les coins (cibles empilées comme les colonnes d'un kanban). |
