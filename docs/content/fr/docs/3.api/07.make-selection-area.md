```ts
function makeSelectionArea(
  target: MaybeElementRef,
  options?: SelectionAreaOptions,
): SelectionAreaReturn;
```

```vue
<script setup lang="ts">
const area = useTemplateRef<HTMLElement>('area');
const { isSelecting, style } = makeSelectionArea(area);
</script>

<template>
  <div ref="area" class="area">
    <!-- items -->
    <div v-if="isSelecting" class="band" :style="style" />
  </div>
</template>
```

Un appui sur l'espace vide de la zone lance le rectangle ; c'est à vous de rendre le rectangle. Voir
[Multi-drag et sélection](/docs/guides/multi-drag).
