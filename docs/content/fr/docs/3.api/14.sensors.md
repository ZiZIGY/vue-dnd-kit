```ts
import { defineSensor, useSensor, pointerSensor, keyboardSensor } from '@vue-dnd-kit/core';
```

| Export | Ce que c'est |
| --- | --- |
| `pointerSensor` | Souris, toucher et stylet via les Pointer Events. Présent par défaut dans `sensors`. |
| `keyboardSensor` | Space/Enter saisissent et déposent, les flèches déplacent, Escape annule. Présent par défaut dans `sensors`. |
| `defineSensor(sensor)` | Type un objet capteur. |
| `useSensor(sensor)` | Fait tourner un capteur dans un composant sous le provider, pendant toute la durée de vie de ce composant. |

Un capteur dit seulement « fais glisser cet item depuis ici », puis où il s'est déplacé et qu'il a
déposé ou a été annulé ; le provider vérifie le reste (ce qui peut être glissé, l'activation, un
glissement à la fois). Voir [Capteurs et glissements programmatiques](/docs/guides/sensors).

Ci-dessous, un petit capteur personnalisé (lancé avec `useSensor`) fait glisser les pièces du
plateau depuis sa mini-carte, à côté des capteurs propres au provider.
