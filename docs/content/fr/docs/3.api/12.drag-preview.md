## DragPreview {#dragpreview}

```vue [StackOverlay.vue]
<script setup lang="ts">
import { DragPreview, type DragItem } from '@vue-dnd-kit/core';

defineProps<{ items: DragItem[] }>();
</script>

<template>
  <div class="stack">
    <DragPreview v-for="item in items.slice(0, 3)" :id="item.id" :key="item.id" />
  </div>
</template>
```

Les clones sont pris à la saisie : celui de l'item saisi et ceux de quatre autres au plus, voisins
dans l'ordre du dépôt. Pour tout autre item, `DragPreview` rend son slot par défaut, ou rien. Chaque
aperçu atterrit sur son propre item quand le dépôt atterrit. Voir le [guide de l'overlay](/docs/guides/overlay).

## Props de l'overlay {#overlay-props}

Ce que reçoivent un composant d'overlay (l'option `overlay` des éléments déplaçables, des items
triables, des listes et des arbres) et le slot `#overlay` du provider.

::
