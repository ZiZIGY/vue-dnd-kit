```ts
function makeDraggable<TData = unknown>(
  target: MaybeElementRef,
  options?: DraggableOptions<TData>,
): DraggableReturn;
```

```ts
const el = useTemplateRef<HTMLElement>('el');
const { isDragging } = makeDraggable(el, { id: 'card', type: 'card', data: { title } });
```

Voir [Glisser-déposer](/docs/guides/drag-and-drop). Les items triables sont aussi des éléments
déplaçables : [`makeSortableItem`](/docs/api/make-sortable-item) accepte les mêmes options, et
d'autres encore.
